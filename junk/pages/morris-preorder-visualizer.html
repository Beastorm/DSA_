🧵 Morris Preorder Traversal

Preorder with O(1) extra space: no stack, no recursion. When a node has a left subtree, a temporary thread is stitched from the subtree's rightmost node back up to the node — so the walk can return without remembering the path. Threads are cut as soon as they're used.
