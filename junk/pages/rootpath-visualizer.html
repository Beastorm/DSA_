🧭 Root-to-Node Path — Backtracking Visualizer

One guided flow, two parts. getPath does a DFS that pushes every node onto arr on the way down — and pops it back off when a subtree fails to find the target. That push/pop discipline is backtracking. Part 1 searches for x = 7 in the tree from main() (watch node 6 get pushed then popped, and the || short-circuit skip half the tree). Part 2 searches for a value that isn't there — every node gets pushed and popped. Just press ▶ Play.

📥 arr.push_back(val) on entry · 📤 arr.pop_back() when both subtrees fail. If the target is found, the returns race up without popping — so arr keeps exactly the root-to-target path.

🔀 getPath(left) || getPath(right) — if the left search succeeds, the right subtree is never explored (short-circuit), and the found path is preserved all the way up.
