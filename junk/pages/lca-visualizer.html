🧬 Lowest Common Ancestor — Recursion Visualizer

One guided flow, three scenarios. Each call returns a pointer: NULL (nothing found), the node itself if it is p or q (early stop!), or the LCA found deeper. Results bubble up — and the node where left and right both come back non-null is the split point: the LCA. Part 1 is the exact main() case (p=5, q=1), Part 2 hides both targets deep in one subtree, Part 3 makes one target the other's ancestor. Just press ▶ Play.

Tree P = node 5 Q = node 1
return root if it's NULL/p/q · else combine both sides: NULL → pass the other up · both non-null → this node is the LCA
What each call returned
The chip under each finished node shows the pointer its call returned. Watch non-null results rise toward the root — where two of them meet is the LCA.
