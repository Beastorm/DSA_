🏙️ Vertical Order Traversal — BFS + Column Map Visualizer

One guided flow, two parts. A BFS assigns every node a column number (root = 0, left child = −1, right child = +1 relative to its parent) and drops values into a map that stays sorted by column. Watch the queue work FIFO and the column lanes fill up in level order. Part 1 is the exact tree from main(), Part 2 a zigzag demo. Just press ▶ Play.

Tree & column lanes
left child → column − 1 · right child → column + 1 · BFS order inside each lane = top-to-bottom
columns map
🗝️ std::map keeps its keys sorted at all times — new keys slot into position automatically, so the final loop reads the columns left-to-right for free (each insert costs O(log k)).
Code
BFS queue
📤 Dequeue from the front, 📥 enqueue children at the back with their column numbers. Because BFS visits level by level, each lane collects values top-to-bottom — something a DFS preorder would get wrong.
