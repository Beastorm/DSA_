💎 Maximum Path Sum — Single-Pass DFS Visualizer

One guided flow, two parts. dfs() does a post-order sweep: each node computes the best one-sided path sum to return upward, while maxSum (passed by reference) considers the node as a turning point using both arms. Negative arms get clamped to 0 — watch for the ✂️ marks. Part 1 is the exact tree from main(), Part 2 adds negative nodes to show the clamps in action. Just press ▶ Play.

⚠️ dfs returns a one-sided path (max(left,right)+val) because the path must keep climbing toward a parent — but maxSum may use both arms with the node as turning point (left+right+val). Arms with negative sums are clamped to 0 (✂️ = dropped edge).
