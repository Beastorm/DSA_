👀 Left & Right View — DFS Visualizer

One guided flow, four parts. Both views use the same trick: a preorder DFS where the first node reached at each level wins — detected by answer.size() == level. leftDFS visits the left child first, rightDFS visits the right child first… and that one-line difference flips the whole view. Parts 1–2 run both on the tree from main(), Parts 3–4 on a zigzag demo where the two views trace opposite chains. Just press ▶ Play.

Tree & levels
first node reached at a level = the visible node  ·  answer.size() == level ⇔ "this level is still unclaimed"
answer vector
📏 answer.size() equals the number of levels already claimed — so when it equals the current level, this node is the first one there and gets pushed. One push per level, at most.
Code
Call stack
🔀 The ONLY difference between the two functions is the recursion order: leftDFS goes left-then-right, rightDFS goes right-then-left. Whichever side is explored first reaches each level first.
