🔭 Top View of a Binary Tree — BFS Visualizer

One guided flow, two parts. BFS assigns each node a vertical line (root = 0, left = −1, right = +1 relative to parent) — and the map keeps only the first node seen on each line. Because BFS visits level by level, that first node is exactly the one visible from above. Watch nodes win their line ✅ or get rejected 🚫 when the line is already taken. Part 1 is the exact tree from main() (note: the value 10 appears twice — lines, not values, decide the view). Just press ▶ Play.

Tree & line winners
left child → line − 1 · right child → line + 1 · first node on a line wins — later nodes hide behind it
lines map (mpp)
🗝️ map<int,int>: one slot per line, filled once by the first visitor (mpp.find(line) == mpp.end()). Keys stay sorted, so the final loop reads the view left-to-right for free.
Code
BFS queue
📤 Dequeue from the front, 📥 enqueue children at the back with line ± 1. BFS = level by level, so the first arrival on any line is the shallowest node there — the one seen from the top.
