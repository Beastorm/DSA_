# Take Gifts from the Richest Pile

> For `K` seconds, choose the pile with the most gifts and replace it with `floor(sqrt(pile))`. Return the total gifts left.

For each second:

```text
1. Pick the largest pile.
2. Replace it with floor(√largest).
3. Put it back.
```

---

## Example 1

```text
Gifts = [25, 64, 9, 4, 100]
K = 4
```

| Second | Richest pile | Put back | Piles after operation |
|---:|---:|---:|---|
| 1 | `100` | `10` | `[64, 25, 10, 9, 4]` |
| 2 | `64` | `8` | `[25, 10, 9, 8, 4]` |
| 3 | `25` | `5` | `[10, 9, 8, 5, 4]` |
| 4 | `10` | `3` | `[9, 8, 5, 4, 3]` |

```text
Total remaining = 9 + 8 + 5 + 4 + 3 = 29
```

## Why Use a Max Heap? 💡

Every second, we need the richest pile.

```text
maxHeap.top() = largest pile
```

```text
Gifts: [25, 64, 9, 4, 100]

          100  ← richest pile
         /   \
       64     25
      / \    /
     9   4  10
```

A max heap makes each operation efficient.

| Operation | Function | Time |
|---|---|---:|
| Get richest pile | `top()` | `O(1)` |
| Remove richest pile | `pop()` | `O(log N)` |
| Put back square root | `push()` | `O(log N)` |

---

## Algorithm

```text
1. Build a max heap from all gift piles.
2. Repeat at most K times:
      a. If the largest pile is 1, stop early.
      b. Remove the largest pile.
      c. Find floor(sqrt(largest)).
      d. Insert the new value into the heap.
3. Add all heap values and return the total.
```

## Why Can We Stop When the Top Is `1`?

```text
floor(√1) = 1
```

If the largest pile is `1`, then every pile is `1` or `0`.

```text
[1, 1, 1, 1]
```

No future operation can reduce the total.

```text
top <= 1 → stop early
```

## How Fast Does a Pile Shrink?

```text
1,000,000,000
      ↓ √
31,622
      ↓ √
177
      ↓ √
13
      ↓ √
3
      ↓ √
1
```

Large piles become small very quickly.

> This is why early stopping helps when `K` is very large.

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

long long pickGifts(const vector<int>& gifts, int k) {
    if (gifts.empty() || k <= 0) {
        return accumulate(gifts.begin(), gifts.end(), 0LL);
    }

    // C++ priority_queue<int> is a max heap.
    priority_queue<int> maxHeap(gifts.begin(), gifts.end());

    for (int second = 0; second < k; second++) {
        int richest = maxHeap.top();

        // All piles are now 1 or 0, so no further reduction is possible.
        if (richest <= 1) break;

        maxHeap.pop();

        // For standard integer constraints, truncating sqrt gives floor(sqrt()).
        int remaining = static_cast<int>(sqrt(richest));
        maxHeap.push(remaining);
    }

    long long total = 0;
    while (!maxHeap.empty()) {
        total += maxHeap.top();
        maxHeap.pop();
    }

    return total;
}

int main() {
    vector<int> gifts1 = {25, 64, 9, 4, 100};
    vector<int> gifts2 = {1, 1, 1, 1};
    vector<int> gifts3 = {9};
    vector<int> gifts4 = {1'000'000'000};

    cout << "[25, 64, 9, 4, 100], K = 4 → "
         << pickGifts(gifts1, 4) << endl;

    cout << "[1, 1, 1, 1], K = 4         → "
         << pickGifts(gifts2, 4) << endl;

    cout << "[9], K = 3                    → "
         << pickGifts(gifts3, 3) << endl;

    cout << "[1,000,000,000], K = 1        → "
         << pickGifts(gifts4, 1) << endl;

    return 0;
}
```

**Output:**

```text
[25, 64, 9, 4, 100], K = 4 → 29
[1, 1, 1, 1], K = 4         → 4
[9], K = 3                    → 1
[1,000,000,000], K = 1        → 31622
```

## Edge Cases

### `K = 0`

```text
No operation is performed.
Return the original sum.
```

### No Piles

```text
[]

Answer = 0
```

### All Piles Are `1`

```text
[1, 1, 1, 1]

√1 = 1
Answer stays 4
```

### One Pile

```text
[16], K = 2

16 → 4 → 2
Answer = 2
```

### Large Value

```text
[1,000,000,000], K = 1

floor(√1,000,000,000) = 31,622
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Build max heap | `O(N)` | Build from all piles. |
| K operations | `O(K log N)` | Each operation does one pop and one push. |
| Final sum | `O(N)` | Remove and add every remaining heap value. |
| Total time | `O(N + K log N)` | Heap updates dominate after setup. |
| Extra space | `O(N)` | Max heap stores all piles. |

With early termination, the actual number of operations can be much smaller than `K`.

## Interview Questions 🎯

### 1. Why use a max heap?

Each second requires the current largest gift pile.

### 2. Why can we stop when the maximum is `1`?

`floor(√1) = 1`, so no pile can decrease further.

### 3. What is the time complexity?

`O(N + K log N)`.

### 4. What is the space complexity?

`O(N)` for the max heap.

### 5. Why use `long long` for the final total?

Adding all remaining piles can exceed the range of `int`.

### 6. Does `sqrt(10)` give `3` in this problem?

Yes. Converting the positive result to `int` removes the decimal part:

```text
sqrt(10) ≈ 3.16 → 3
```

### 7. Which pattern should you recognize?

```text
Repeat K times:
pick maximum → transform it → put it back

Use a max heap.
```
