# Profit Maximisation — Stadium Seats

> You have rows of seats. Sell exactly `B` seats to get the **maximum total profit**.

If a row currently has `x` available seats:

```text
Sell one seat from that row → earn x profit
Then the row has x - 1 seats left
```

---

## First Understand the Price of One Row 💡

A row with `4` available seats gives these possible profits:

```text
First seat sold  → profit 4
Second seat sold → profit 3
Third seat sold  → profit 2
Fourth seat sold → profit 1
```

```text
Row with 4 seats: [4, 3, 2, 1]
```

A row with `3` seats gives:

```text
[3, 2, 1]
```

So for rows `[4, 3, 2]`, all possible seat profits are:

```text
Row 1: 4, 3, 2, 1
Row 2: 3, 2, 1
Row 3: 2, 1
```

To maximize profit, choose the biggest available profit each time.

---

## Example: `A = [4, 3, 2]`, `B = 5`

```text
Rows:

Row 1: 4 seats
Row 2: 3 seats
Row 3: 2 seats
```

The best 5 profits are:

```text
4, 3, 3, 2, 2
```

```text
Total = 4 + 3 + 3 + 2 + 2 = 14
```

## Why Is a Max Heap Needed?

At every sale, we must find the row with the largest number of seats.

```text
Rows = [4, 3, 2]

       4  ← largest row
      / \
     3   2
```

A max heap gives this largest value immediately:

```text
maxHeap.top() → largest row
```

After selling one seat:

```text
pop 4
profit += 4
push 3
```

```text
Heap now contains: [3, 3, 2]
```

---

## Simple Rule to Remember

```text
Pick largest row → add it to profit → reduce it by 1 → put it back
```

```text
pop max
add max to answer
push max - 1
```

Repeat `B` times.

---

## Algorithm

```text
1. Put all row seat counts in a max heap.
2. totalProfit = 0
3. Repeat B times:
      a. Take the maximum value from heap.
      b. Add it to totalProfit.
      c. Put maximum - 1 back into heap.
4. Return totalProfit.
```

If heap top becomes `0`, stop because every row has no seats left.

## Why Does Picking the Maximum Give Best Profit?

Suppose two rows currently have:

```text
Row A = 5 seats
Row B = 3 seats
```

If you sell from Row A now:

```text
profit = 5
Rows become [4, 3]
```

If you sell from Row B now:

```text
profit = 3
Rows become [5, 2]
```

Choosing Row A gives `5`, which is better than `3`. Row A still has `4` seats available later.

```text
Selling from the biggest row never loses profit.
```

So the greedy choice is always:

```text
sell from the maximum row
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

long long profitMaximisation(const vector<int>& rows, int seatsToSell) {
    if (rows.empty() || seatsToSell <= 0) return 0;

    // Default C++ priority_queue is a max heap.
    priority_queue<int> maxHeap(rows.begin(), rows.end());

    long long totalProfit = 0;

    for (int sale = 0; sale < seatsToSell; sale++) {
        int largestRow = maxHeap.top();

        // No row has a seat left.
        if (largestRow == 0) break;

        maxHeap.pop();

        // Selling from this row earns its current seat count.
        totalProfit += largestRow;

        // One seat is sold, so this row loses one seat.
        maxHeap.push(largestRow - 1);
    }

    return totalProfit;
}

int main() {
    vector<int> rows1 = {4, 3, 2};
    vector<int> rows2 = {1, 2, 3, 4, 5};
    vector<int> rows3 = {5};
    vector<int> rows4 = {0, 0, 0};

    cout << "Rows [4, 3, 2], B = 5 → "
         << profitMaximisation(rows1, 5) << endl;

    cout << "Rows [1, 2, 3, 4, 5], B = 6 → "
         << profitMaximisation(rows2, 6) << endl;

    cout << "Rows [5], B = 3 → "
         << profitMaximisation(rows3, 3) << endl;

    cout << "Rows [0, 0, 0], B = 5 → "
         << profitMaximisation(rows4, 5) << endl;

    return 0;
}
```

**Output:**

```text
Rows [4, 3, 2], B = 5 → 14
Rows [1, 2, 3, 4, 5], B = 6 → 22
Rows [5], B = 3 → 12
Rows [0, 0, 0], B = 5 → 0
```

## Edge Cases

### `B = 0`

```text
No seats are sold.
Profit = 0
```

### One Row

```text
Rows = [5], B = 3

Sell at prices: 5, 4, 3
Total = 12
```

### More Sales Than Available Seats

```text
Rows = [2, 1], B = 10

Sell at prices: 2, 1, 1
Then all rows become 0.

Total = 4
```

### All Rows Are Empty

```text
Rows = [0, 0, 0]

Heap top = 0 → stop
Profit = 0
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Build heap | `O(N)` | Put N row counts into a max heap. |
| Sell B seats | `O(B log N)` | Each sale performs one pop and one push. |
| Total time | `O(N + B log N)` | Heap work dominates after setup. |
| Extra space | `O(N)` | Heap stores row counts. |

## Interview Questions 🎯

### 1. Why use a max heap?

We need the row with the most available seats for every sale.

### 2. What does heap top represent?

The profit earned if we sell the next seat from the best row.

### 3. Why push `largestRow - 1` back?

One seat was sold, so that row now has one fewer available seat.

### 4. When can we stop early?

When heap top is `0`, because every row is empty.

### 5. What is the time complexity?

`O(N + B log N)`.

### 6. Why use `long long`?

The sum of many seat-sale profits may be larger than `int`.
