# Profit Maximisation — Stadium Seats

> Sell exactly `B` seats to get maximum profit.

Each row has a number of available seats. If a row currently has `x` seats:

```text
selling one seat gives profit x
then that row becomes x - 1
```

---

## Example 1

```text
Rows = [4, 3, 2]
B = 5
```

Always sell from the row with the most available seats.

| Sale | Largest row | Profit | Row becomes | Total profit |
|---:|---:|---:|---:|---:|
| 1 | `4` | `4` | `3` | `4` |
| 2 | `3` | `3` | `2` | `7` |
| 3 | `3` | `3` | `2` | `10` |
| 4 | `2` | `2` | `1` | `12` |
| 5 | `2` | `2` | `1` | `14` |

```text
Maximum profit = 4 + 3 + 3 + 2 + 2 = 14
```

## Example 2

```text
Rows = [1, 2, 3, 4, 5]
B = 6
```

```text
Profit values picked:
5, 4, 4, 3, 3, 3

Total = 5 + 4 + 4 + 3 + 3 + 3 = 22
```

## Why Use a Max Heap? 💡

Every sale needs the row with the most seats.

```text
maxHeap.top() = row that gives maximum profit now
```

```text
Rows: [4, 3, 2]

       4  ← sell from this row first
      / \
     3   2
```

After selling from row `4`:

```text
profit = 4
row becomes 3

Heap values: [3, 3, 2]
```

| Operation | Priority queue function | Time |
|---|---|---:|
| Get most profitable row | `top()` | `O(1)` |
| Remove that row | `pop()` | `O(log N)` |
| Add row with one fewer seat | `push()` | `O(log N)` |

---

## Greedy Rule

```text
Always sell from the row with the maximum remaining seats.
```

Why?

```text
Row A has 5 seats → selling now gives 5 profit
Row B has 3 seats → selling now gives 3 profit

5 > 3, so choosing Row A gives more profit now.
```

After the sale, Row A becomes `4`, which remains available for future sales.

```text
Pick highest available profit at every sale.
```

A max heap does exactly this.

---

## Algorithm

```text
1. Put all row seat counts into a max heap.
2. totalProfit = 0
3. Repeat B times:
      a. If max heap top is 0, stop early.
      b. Remove the largest seat count.
      c. Add that value to totalProfit.
      d. Put value - 1 back into the heap.
4. Return totalProfit.
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

long long profitMaximisation(const vector<int>& rows, int seatsToSell) {
    if (rows.empty() || seatsToSell <= 0) return 0;

    // C++ priority_queue<int> is a max heap.
    priority_queue<int> maxHeap(rows.begin(), rows.end());

    long long totalProfit = 0;

    for (int sale = 0; sale < seatsToSell; sale++) {
        int availableSeats = maxHeap.top();

        // No seats remain in any row.
        if (availableSeats == 0) break;

        maxHeap.pop();

        // Selling a seat gives profit equal to the current count.
        totalProfit += availableSeats;

        // One seat is sold from this row.
        maxHeap.push(availableSeats - 1);
    }

    return totalProfit;
}

int main() {
    vector<int> rows1 = {4, 3, 2};
    vector<int> rows2 = {1, 2, 3, 4, 5};
    vector<int> rows3 = {10};
    vector<int> rows4 = {0, 0, 0};

    cout << "[4, 3, 2], B = 5          → "
         << profitMaximisation(rows1, 5) << endl;

    cout << "[1, 2, 3, 4, 5], B = 6    → "
         << profitMaximisation(rows2, 6) << endl;

    cout << "[10], B = 3               → "
         << profitMaximisation(rows3, 3) << endl;

    cout << "[0, 0, 0], B = 5          → "
         << profitMaximisation(rows4, 5) << endl;

    return 0;
}
```

**Output:**

```text
[4, 3, 2], B = 5          → 14
[1, 2, 3, 4, 5], B = 6    → 22
[10], B = 3               → 27
[0, 0, 0], B = 5          → 0
```

## Edge Cases

### `B = 0`

```text
No seats are sold.
Profit = 0
```

### All Rows Empty

```text
Rows = [0, 0, 0]
```

```text
maxHeap.top() = 0 → stop immediately
Profit = 0
```

### One Row

```text
Rows = [5]
B = 3

Sell at: 5, 4, 3
Profit = 12
```

### More Sales Than Available Seats

```text
Rows = [2, 1]
B = 10

Sell at: 2, 1, 1
Then all rows are 0 → stop

Profit = 4
```

### Large Seat Counts

```text
Rows = [100000]
B = 100000

Profit = 100000 + 99999 + ... + 1
```

Use `long long` for the total profit.

## Same Max-Heap Pattern

```text
Problem                     Transform maximum value

Magician and Chocolates     max → floor(max / 2)
Take Gifts                  max → floor(sqrt(max))
Profit Maximisation         max → max - 1
```

All follow this pattern:

```text
Pick max → use it → transform it → put it back
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Build max heap | `O(N)` | Create heap from all rows. |
| B sales | `O(B log N)` | Each sale performs one pop and one push. |
| Total time | `O(N + B log N)` | Heap updates dominate after setup. |
| Extra space | `O(N)` | Max heap stores all row counts. |

Early termination can reduce actual work when all rows become `0` before `B` sales.

## Interview Questions 🎯

### 1. Why is a max heap used?

Each sale must choose the row with the highest current seat count.

### 2. Why is this greedy strategy optimal?

A larger current count always gives more profit than a smaller count. The max heap always selects the best available profit.

### 3. What happens after selling one seat?

That row’s available seat count decreases by `1` and is pushed back into the heap.

### 4. Why can we stop when heap top is `0`?

All other rows are also `0`, so no profitable sale remains.

### 5. What is the time complexity?

`O(N + B log N)`.

### 6. Why use `long long`?

The total profit can exceed the range of `int`.
