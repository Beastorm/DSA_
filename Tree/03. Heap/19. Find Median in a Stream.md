# Find the Median in a Number Stream

> Numbers arrive one at a time. After each insertion, return the median of all values received so far.

```text
Odd number of values:
use the single middle value

Even number of values:
average the two middle values
```

---

## Important Observation ⚠️

The median is determined by the middle one or two values after sorting.

```text
Sorted values: [2, 4, 7, 10, 15]
                         ↑
                    median = 7
```

For an even number of values:

```text
Sorted values: [2, 4, 7, 10, 15, 20]
                       ↑   ↑
Median = (7 + 10) / 2 = 8.5
```

The challenge is that values arrive continuously. Sorting the complete stream after every insertion is wasteful.

---

## Example

### Input Stream

```text
7, 11, 4, 9, 15, 2, 1, 18
```

### Running Medians

| New value | Sorted values so far | Median |
|---:|---|---:|
| 7 | `[7]` | `7.0` |
| 11 | `[7, 11]` | `9.0` |
| 4 | `[4, 7, 11]` | `7.0` |
| 9 | `[4, 7, 9, 11]` | `8.0` |
| 15 | `[4, 7, 9, 11, 15]` | `9.0` |
| 2 | `[2, 4, 7, 9, 11, 15]` | `8.0` |
| 1 | `[1, 2, 4, 7, 9, 11, 15]` | `7.0` |
| 18 | `[1, 2, 4, 7, 9, 11, 15, 18]` | `8.0` |

---

## Main Idea 💡

The video presents two approaches:

```text
1. Keep the stream in sorted order.
2. Split the stream into two balanced heaps.
```

The second approach is more efficient because the median only needs the boundary values:

```text
largest value in the lower half
smallest value in the upper half
```

Use:

```text
Lower half → max heap
Upper half → min heap
```

---

# Method 1: Maintain a Sorted Array

## Simple Idea

```text
1. Find the correct position for the new value.
2. Shift larger values to the right.
3. Insert the value.
4. Read the middle value or middle pair.
```

For example:

```text
Current sorted values: [4, 7, 9, 11, 15]
New value: 2
```

Shift the existing values:

```text
[_, 4, 7, 9, 11, 15]
```

Insert `2`:

```text
[2, 4, 7, 9, 11, 15]
```

---

## Median Calculation

For an odd number of values:

```text
middle index = size / 2
median = values[middle index]
```

For an even number of values:

```text
left middle  = size / 2 - 1
right middle = size / 2
median = (left middle value + right middle value) / 2.0
```

---

## C++ Code — Method 1 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class SortedArrayMedian {
    vector<int> values;

public:
    void insert(int x) {
        auto position = lower_bound(values.begin(), values.end(), x);
        values.insert(position, x);
    }

    double getMedian() const {
        if (values.empty()) {
            throw logic_error("Median is undefined for an empty stream");
        }

        int n = values.size();

        if (n % 2 == 1) {
            return static_cast<double>(values[n / 2]);
        }

        return (static_cast<double>(values[n / 2 - 1]) +
                static_cast<double>(values[n / 2])) / 2.0;
    }
};

int main() {
    vector<int> stream = {7, 11, 4, 9, 15, 2, 1, 18};
    SortedArrayMedian finder;

    cout << fixed << setprecision(1);

    for (int value : stream) {
        finder.insert(value);
        cout << "Inserted " << value
             << ", median = " << finder.getMedian() << endl;
    }

    return 0;
}
```

**Output:**

```text
Inserted 7, median = 7.0
Inserted 11, median = 9.0
Inserted 4, median = 7.0
Inserted 9, median = 8.0
Inserted 15, median = 9.0
Inserted 2, median = 8.0
Inserted 1, median = 7.0
Inserted 18, median = 8.0
```

### Complexity

```text
Find position: O(log S) with lower_bound
Shift values:  O(S)
One insertion: O(S) worst case
Total:        O(S²)
Median query: O(1)
Extra space:  O(S)
```

The vector search is fast, but shifting elements is expensive.

# Method 2: Two Heaps (Preferred) ⚡

## Main Idea

Split the values into two groups:

```text
Left half  → max heap
Right half → min heap
```

```text
leftMaxHeap  |  rightMinHeap
-------------|-------------
lower values |  higher values
```

The two heap tops are the only values needed for the median.

---

## Why a Max Heap for the Left Half?

Suppose the lower half is:

```text
[1, 4, 7]
```

The value closest to the middle is `7`, the largest value in the lower half.

```text
leftMaxHeap.top() = 7
```

A max heap gives this value immediately.

---

## Why a Min Heap for the Right Half?

Suppose the upper half is:

```text
[9, 11, 15]
```

The value closest to the middle is `9`, the smallest value in the upper half.

```text
rightMinHeap.top() = 9
```

A min heap gives this value immediately.

---

## Heap Invariants

### Ordering Invariant

Every value in the left heap must be less than or equal to every value in the right heap.

```text
leftMaxHeap.top() <= rightMinHeap.top()
```

when both heaps are non-empty.

### Size Invariant

Use this convention:

```text
left.size() == right.size()
or
left.size() == right.size() + 1
```

The left heap may contain one extra value.

---

## Insertion and Balancing

For a new value `x`:

```text
if left heap is empty:
    insert x into left
else if x <= left.top():
    insert x into left
else:
    insert x into right
```

Then rebalance:

```text
if right.size() > left.size():
    move right.top() to left

if left.size() > right.size() + 1:
    move left.top() to right
```

---

## Step-by-Step Walkthrough

### Insert 7

```text
Left:  [7]
Right: []
Median = 7
```

### Insert 11

```text
11 > left.top()

Left:  [7]
Right: [11]

Median = (7 + 11) / 2 = 9.0
```

### Insert 4

```text
4 <= left.top()

Left contains 4 and 7.
Right contains 11.

Median = left.top() = 7
```

### Insert 9

```text
9 goes to the right heap.

Both heaps have two values.
Median = (7 + 9) / 2 = 8.0
```

### Insert 15

```text
15 goes to the right heap.
Right becomes too large.

Move right.top() to the left heap.
The heaps are balanced again.

Median = 9
```

---

## C++ Code — Method 2 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class TwoHeapMedian {
    // Lower half: largest value at the top.
    priority_queue<int> leftMaxHeap;

    // Upper half: smallest value at the top.
    priority_queue<int, vector<int>, greater<int>> rightMinHeap;

    void balance() {
        if (rightMinHeap.size() > leftMaxHeap.size()) {
            leftMaxHeap.push(rightMinHeap.top());
            rightMinHeap.pop();
        }

        if (leftMaxHeap.size() > rightMinHeap.size() + 1) {
            rightMinHeap.push(leftMaxHeap.top());
            leftMaxHeap.pop();
        }
    }

public:
    void insert(int x) {
        if (leftMaxHeap.empty() || x <= leftMaxHeap.top()) {
            leftMaxHeap.push(x);
        } else {
            rightMinHeap.push(x);
        }

        balance();
    }

    double getMedian() const {
        if (leftMaxHeap.empty()) {
            throw logic_error("Median is undefined for an empty stream");
        }

        if (leftMaxHeap.size() > rightMinHeap.size()) {
            return static_cast<double>(leftMaxHeap.top());
        }

        return (static_cast<double>(leftMaxHeap.top()) +
                static_cast<double>(rightMinHeap.top())) / 2.0;
    }
};

int main() {
    vector<int> stream = {7, 11, 4, 9, 15, 2, 1, 18};
    TwoHeapMedian finder;

    cout << fixed << setprecision(1);

    for (int value : stream) {
        finder.insert(value);
        cout << "Inserted " << value
             << ", median = " << finder.getMedian() << endl;
    }

    return 0;
}
```

**Output:**

```text
Inserted 7, median = 7.0
Inserted 11, median = 9.0
Inserted 4, median = 7.0
Inserted 9, median = 8.0
Inserted 15, median = 9.0
Inserted 2, median = 8.0
Inserted 1, median = 7.0
Inserted 18, median = 8.0
```

### Complexity

```text
One insertion: O(log S)
Rebalancing:   O(log S) when a value moves
Median query:  O(1)
Total:         O(S log S)
Extra space:   O(S)
```

---

## Important Implementation Notes

### Use the Correct Heap Types

```text
Lower half → max heap
Upper half → min heap
```

### Balance After Every Insertion

The median is valid only after both heap invariants are restored.

### Use Floating-Point Division

```cpp
/ 2.0
```

is required for fractional medians.

### Remove Moved Values

When moving a value between heaps, both operations are required:

```cpp
rightMinHeap.push(leftMaxHeap.top());
leftMaxHeap.pop();
```

### Heap Is Not a Sorted Array

A heap gives fast access to its top, but its internal storage is not fully sorted.

## Method Comparison

| Method | Insert Cost | Total for S Values | Median Query | Extra Space |
|---|---:|---:|---:|---:|
| Sorted array | `O(S)` | `O(S²)` | `O(1)` | `O(S)` |
| Two heaps | `O(log S)` | `O(S log S)` | `O(1)` | `O(S)` |

---

## Edge Cases

### First Value

```text
Stream: [7]
Median: 7.0
```

### Two Values

```text
Stream: [7, 11]
Median: 9.0
```

### Duplicate Values

```text
Stream: [5, 5, 5]
Median: 5.0
```

### Negative Values

```text
Stream: [-10, -3, 4]
Median: -3.0
```

### Empty Stream

There is no median before a value is inserted. The code throws an exception for this case.

### Large Values

Cast before adding the two heap tops to avoid integer overflow:

```cpp
double result = (static_cast<double>(left.top()) +
                 static_cast<double>(right.top())) / 2.0;
```

## Interview Questions 🎯

### 1. Why is sorted insertion slow?

A new value can arrive at the front and force all existing values to shift.

### 2. Why is the left half a max heap?

We need the largest value from the lower half immediately.

### 3. Why is the right half a min heap?

We need the smallest value from the upper half immediately.

### 4. What size relationship should the heaps maintain?

```text
left.size() == right.size()
or
left.size() == right.size() + 1
```

### 5. What if the left heap has one extra value?

Its top is the median.

### 6. What if both heaps have equal size?

Average their tops.

### 7. What is the insertion complexity?

`O(log S)`.

### 8. What is the median-query complexity?

`O(1)`.

### 9. What is the most important invariant?

The left heap contains the lower half, the right heap contains the upper half, and their sizes differ by at most one.
