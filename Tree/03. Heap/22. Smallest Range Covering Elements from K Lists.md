# Smallest Range Covering Elements from K Lists

> Given `K` sorted lists, find the smallest range `[left, right]` that contains at least one value from **every list**.

If two ranges have the same length, return the one with the smaller left value.

---

## Example 1

```text
List 0: [4, 10, 15, 24, 26]
List 1: [0,  9, 12, 20]
List 2: [5, 18, 22, 30]
```

```text
Smallest range = [20, 24]

List 0 contributes: 24
List 1 contributes: 20
List 2 contributes: 22
```

```text
Range length = 24 - 20 = 4
```

## What Makes a Range Valid?

A range is valid only if it covers all lists.

```text
[4, 9]

List 0: 4 ✓
List 1: 9 ✓
List 2: 5 ✓

Valid range, length = 9 - 4 = 5
```

```text
[20, 24]

List 0: 24 ✓
List 1: 20 ✓
List 2: 22 ✓

Valid range, length = 4 ✓ (smaller)
```

---

## Main Idea: Keep One Value from Every List

At all times, select one current value from each list.

```text
Current values:

List 0 → 4
List 1 → 0
List 2 → 5

Current range = [0, 5]
```

```text
minimum current value = 0
maximum current value = 5
```

To improve the range, move forward in the list that has the **smallest** current value.

```text
Why?
The current minimum is holding the left end back.
Only moving that list can make the range start later.
```

---

## Why Use a Min Heap? 📚

The heap stores exactly one current value from each list.

```text
Heap item = (value, listIndex, elementIndex)
```

```text
Min heap top = smallest current value
currentMax   = largest current value

Current range = [min heap top, currentMax]
```

For the initial values:

```text
List 0 → 4
List 1 → 0
List 2 → 5

Min heap: 0, 4, 5
currentMax = 5
range = [0, 5]
```

---

## Algorithm

```text
1. Push the first value from each list into a min heap.
2. Set currentMax to the largest of those first values.
3. While every list is represented in the heap:
      a. Pop the smallest value (minValue).
      b. Current valid range = [minValue, currentMax].
      c. Update best range if it is smaller.
      d. Push the next value from the same list.
      e. Update currentMax if needed.
4. If one list runs out of values, stop.
5. Return best range.
```

## Why Stop When One List Is Exhausted?

Every valid range must contain an element from every list.

```text
List 1: [0, 9, 12, 20]
                     ↑
                 last element
```

After removing `20`, List 1 has no next value to push.

```text
No future window can contain List 1.
So no future range can cover all K lists.
```

Stop immediately.

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> smallestRange(const vector<vector<int>>& lists) {
    int k = lists.size();
    if (k == 0) return {};

    // value, list index, element index
    using Item = tuple<int, int, int>;
    priority_queue<Item, vector<Item>, greater<Item>> minHeap;

    int currentMax = INT_MIN;

    // Put one value from every list into the heap.
    for (int listIndex = 0; listIndex < k; listIndex++) {
        if (lists[listIndex].empty()) {
            return {}; // Impossible to cover an empty list.
        }

        int value = lists[listIndex][0];
        minHeap.push({value, listIndex, 0});
        currentMax = max(currentMax, value);
    }

    int bestLeft = 0;
    int bestRight = INT_MAX;

    while (true) {
        auto [currentMin, listIndex, elementIndex] = minHeap.top();
        minHeap.pop();

        long long currentWidth = 1LL * currentMax - currentMin;
        long long bestWidth = 1LL * bestRight - bestLeft;

        // Tie rule: keep the smaller left bound.
        if (currentWidth < bestWidth ||
            (currentWidth == bestWidth && currentMin < bestLeft)) {
            bestLeft = currentMin;
            bestRight = currentMax;
        }

        // This list has no next value, so no future full range is possible.
        if (elementIndex + 1 == lists[listIndex].size()) {
            break;
        }

        int nextValue = lists[listIndex][elementIndex + 1];
        minHeap.push({nextValue, listIndex, elementIndex + 1});
        currentMax = max(currentMax, nextValue);
    }

    return {bestLeft, bestRight};
}

void printRange(const vector<int>& range) {
    if (range.empty()) {
        cout << "No valid range\n";
    } else {
        cout << "[" << range[0] << ", " << range[1] << "]\n";
    }
}

int main() {
    vector<vector<int>> lists1 = {
        {4, 10, 15, 24, 26},
        {0, 9, 12, 20},
        {5, 18, 22, 30}
    };

    vector<vector<int>> lists2 = {
        {1, 2, 3},
        {1, 2, 3},
        {1, 2, 3}
    };

    vector<vector<int>> lists3 = {
        {10, 10},
        {11, 11}
    };

    cout << "Example 1: ";
    printRange(smallestRange(lists1));

    cout << "Example 2: ";
    printRange(smallestRange(lists2));

    cout << "Example 3: ";
    printRange(smallestRange(lists3));

    return 0;
}
```

**Output:**

```text
Example 1: [20, 24]
Example 2: [1, 1]
Example 3: [10, 11]
```

## Edge Cases

### All Lists Have the Same Value

```text
[1, 2, 3]
[1, 2, 3]
[1, 2, 3]
```

```text
Range = [1, 1]
Length = 0 (smallest possible)
```

### Only One List

```text
[5, 10, 15]
```

```text
Range = [5, 5]
```

One value already covers the only list.

### One Value in Each List

```text
[1]
[3]
[2]
```

```text
Range = [1, 3]
```

### An Empty List

```text
[1, 2]
[]
[3, 4]
```

No range can contain a value from the empty list.

```text
Answer = no valid range
```

---

## Complexity

Let `T` be the total number of values across all lists.

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(T log K)` | Each value enters/leaves heap once; heap has at most K values. |
| Extra space | `O(K)` | Heap stores one current value from each list. |

## Interview Questions 🎯

### 1. Why use a min heap?

The smallest current value decides the left side of the current range and is the only value we need to advance.

### 2. What does `currentMax` represent?

The largest of the one current value chosen from every list. It is the right side of the range.

### 3. Why move forward only in the list containing the minimum value?

Only that move can increase the left boundary and possibly make the range smaller.

### 4. Why does the heap contain one value from every list?

That guarantees every current range covers all K lists.

### 5. Why stop when one list is exhausted?

A future range cannot include a value from that list, so it cannot cover all lists.

### 6. What is the time complexity?

`O(T log K)`, where T is total values and K is number of lists.

### 7. What is the space complexity?

`O(K)`.
