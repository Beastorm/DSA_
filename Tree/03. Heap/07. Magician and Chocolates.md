# Magician and Chocolates

> There are `N` bags of chocolates. For `K` seconds, the magician always eats from the bag with the most chocolates, then puts back half of that bag.

For every second:

```text
1. Pick the largest bag.
2. Eat all chocolates in it.
3. Put back floor(largest / 2).
```

Return total chocolates eaten modulo:

```text
MOD = 1,000,000,007
```

---

```text
Bags = [6, 5]
K = 3
```

## Why Use a Max Heap? 💡

Every second, we need the largest bag.

```text
Max heap top() = largest bag
```

```text
Bags: [6, 5]

       6  ← max heap top
      /
     5
```

After eating `6`, put back `3`:

```text
       5  ← new largest
      /
     3
```

A max heap gives the largest value quickly.

| Operation | Priority queue function | Time |
|---|---|---:|
| Get largest bag | `top()` | `O(1)` |
| Remove largest bag | `pop()` | `O(log N)` |
| Put back half bag | `push()` | `O(log N)` |

---

## Algorithm

```text
1. Build a max heap from all bag values.
2. totalEaten = 0
3. Repeat K times:
      a. If largest bag is 0, stop early.
      b. Remove largest bag.
      c. Add it to totalEaten.
      d. Insert floor(largest / 2) back into heap.
4. Return totalEaten % MOD.
```

## Why Stop Early When Top Is `0`?

```text
Bags = [1, 1]
K = 10
```

```text
Second 1: eat 1, put back 0 → bags [1, 0], total = 1
Second 2: eat 1, put back 0 → bags [0, 0], total = 2
Second 3: top is 0 → stop
```

Eating `0` chocolates changes nothing, so extra iterations are useless.

## Chocolate Decay for One Bag

If there is one bag with `64` chocolates:

```text
64 → 32 → 16 → 8 → 4 → 2 → 1 → 0
```

The magician eats:

```text
64 + 32 + 16 + 8 + 4 + 2 + 1 = 127
```

> With multiple bags, the largest bag may change each second, so the heap decides which bag is chosen next.

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

const long long MOD = 1'000'000'007LL;

int magicianAndChocolates(const vector<int>& bags, int k) {
    if (bags.empty() || k <= 0) return 0;

    // C++ priority_queue<int> is a max heap by default.
    priority_queue<int> maxHeap(bags.begin(), bags.end());

    long long totalEaten = 0;

    for (int second = 0; second < k; second++) {
        int largestBag = maxHeap.top();

        // All remaining bags contain zero chocolates.
        if (largestBag == 0) break;

        maxHeap.pop();

        totalEaten = (totalEaten + largestBag) % MOD;

        // Integer division automatically gives floor(largestBag / 2).
        maxHeap.push(largestBag / 2);
    }

    return static_cast<int>(totalEaten);
}

int main() {
    vector<int> bags1 = {6, 5};
    vector<int> bags2 = {2, 4, 6, 8, 10};
    vector<int> bags3 = {1, 1};
    vector<int> bags4 = {0, 0, 0};

    cout << "[6, 5], K = 3              → "
         << magicianAndChocolates(bags1, 3) << endl;

    cout << "[2, 4, 6, 8, 10], K = 6    → "
         << magicianAndChocolates(bags2, 6) << endl;

    cout << "[1, 1], K = 10             → "
         << magicianAndChocolates(bags3, 10) << endl;

    cout << "[0, 0, 0], K = 3           → "
         << magicianAndChocolates(bags4, 3) << endl;

    return 0;
}
```

**Output:**

```text
[6, 5], K = 3              → 14
[2, 4, 6, 8, 10], K = 6    → 37
[1, 1], K = 10             → 2
[0, 0, 0], K = 3           → 0
```

## Handling Large Values

Use `long long` for the running total.

```text
A[i] can be large.
K can be large.
Total eaten can overflow int.
```

Take modulo after every addition:

```cpp
totalEaten = (totalEaten + largestBag) % MOD;
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Build max heap | `O(N)` | Construct heap from all bags. |
| Repeated operations | `O(K log N)` | At most `K` pop + push operations. |
| Total time | `O(N + K log N)` | Heap operations dominate after setup. |
| Extra space | `O(N)` | Max heap stores all bags. |

## Interview Questions 🎯

### 1. Why is a max heap used?

The magician must always choose the bag with the maximum chocolates.

### 2. Why insert half the bag back into the heap?

The bag remains available for future seconds, but with `floor(value / 2)` chocolates.

### 3. Why take modulo at every step?

It prevents the running total from growing too large.

### 4. Why can we stop when the maximum bag is zero?

All other bags are also zero, so no more chocolates can be eaten.

### 5. What is the time complexity?

`O(N + K log N)`.

### 6. What is the space complexity?

`O(N)` for the max heap.

### 7. Is the greedy choice always fixed?

Yes. The problem directly says to choose the current largest bag each second.
