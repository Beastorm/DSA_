# Is a Binary Tree a Max Heap?

> A binary tree is a max heap only when it satisfies **both** conditions:

```text
1. It is a complete binary tree.
2. Every parent value is greater than or equal to its children.
```

---

## Condition 1: Complete Binary Tree 💡

A complete binary tree fills levels from left to right.

```text
Complete ✓                    Not complete ✗

       1                           1
      / \                         / \
     2   3                       2   3
    / \                            \
   4   5                            5

No gaps in level order.        Node 2 has right child but no left child.
```

---

## Condition 2: Max Heap Order

Every parent must be at least as large as its children.

```text
Max heap ✓                     Not max heap ✗

       10                           5
      /  \                         / \
     8    9                       8   3
    / \                           ↑
   4   7                       8 > 5 → invalid
```

```text
parent ≥ left child
parent ≥ right child
```

---

## Example 1 — Valid Max Heap

```text
              97
            /    \
          46      37
         /  \    /  \
        12   3  7   31
       / \
      6   9
```

### Complete?

```text
Level 0: 97
Level 1: 46, 37
Level 2: 12, 3, 7, 31
Level 3: 6, 9
```

The last level is filled from the left.

```text
Complete = true ✓
```

### Max Heap Order?

```text
97 ≥ 46, 37 ✓
46 ≥ 12, 3  ✓
37 ≥ 7, 31  ✓
12 ≥ 6, 9   ✓
```

```text
Answer = true
```

---

## Example 2 — Heap Order Fails

```text
       1
      / \
     2   3
```

The tree is complete, but:

```text
1 < 2 ✗
1 < 3 ✗
```

```text
Answer = false
```

---

## Example 3 — Completeness Fails

```text
       10
      /  \
     9    8
      \
       7
```

Node `9` has a right child but no left child.

```text
There is a gap at 9.left.
Tree is not complete.
```

```text
Answer = false
```

# Index-Based Completeness Check

Treat the tree like a heap array.

```text
root index        = 0
left child index  = 2 × index + 1
right child index = 2 × index + 2
```

For the valid example:

```text
              97 (0)
            /        \
        46 (1)       37 (2)
        /    \       /     \
    12 (3)  3 (4)  7 (5)  31 (6)
     /  \
  6 (7)  9 (8)
```

There are `N = 9` nodes.

```text
Valid indexes are: 0 to 8

All actual node indexes are less than 9.
So the tree is complete. ✓
```

---

## Why Does an Index `>= N` Mean “Not Complete”?

For the incomplete tree:

```text
       10 (0)
      /  \
     9 (1) 8 (2)
      \
       7 (4)
```

There are only `N = 4` nodes, so valid indexes are:

```text
0, 1, 2, 3
```

But node `7` gets index `4`.

```text
index 4 >= N 4 → gap exists → not complete ✗
```

The missing position is index `3`, which would be the left child of node `9`.

---

## Full Algorithm

```text
Step 1: Count all nodes N.

Step 2: Check completeness:
        Assign array-style indexes.
        If any real node index >= N, return false.

Step 3: Check max-heap order:
        If left child > parent, return false.
        If right child > parent, return false.

Step 4: If every check passes, return true.
```

---

## Recursive Flow

```text
check(node, index, N):

if node is NULL:
    return true

if index >= N:
    return false  // Tree has a structural gap

if left child exists and left.value > node.value:
    return false  // Max heap order breaks

if right child exists and right.value > node.value:
    return false  // Max heap order breaks

return check(left child,  2 × index + 1, N)
   AND check(right child, 2 × index + 2, N)
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    int countNodes(TreeNode* root) {
        if (root == nullptr) return 0;

        return 1 + countNodes(root->left) + countNodes(root->right);
    }

    bool checkHeap(TreeNode* root, unsigned long long index, int totalNodes) {
        if (root == nullptr) return true;

        // A real node beyond valid array indexes means tree is not complete.
        if (index >= static_cast<unsigned long long>(totalNodes)) {
            return false;
        }

        // Max heap order: parent must be >= each existing child.
        if (root->left != nullptr && root->left->val > root->val) {
            return false;
        }

        if (root->right != nullptr && root->right->val > root->val) {
            return false;
        }

        return checkHeap(root->left, 2 * index + 1, totalNodes) &&
               checkHeap(root->right, 2 * index + 2, totalNodes);
    }

public:
    bool isHeap(TreeNode* root) {
        if (root == nullptr) return true;

        int totalNodes = countNodes(root);
        return checkHeap(root, 0, totalNodes);
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    // Valid max heap:
    //              97
    //            /    \
    //          46      37
    //         /  \    /  \
    //        12   3  7   31
    //       / \
    //      6   9
    TreeNode* validHeap = new TreeNode(97);
    validHeap->left = new TreeNode(46);
    validHeap->right = new TreeNode(37);
    validHeap->left->left = new TreeNode(12);
    validHeap->left->right = new TreeNode(3);
    validHeap->right->left = new TreeNode(7);
    validHeap->right->right = new TreeNode(31);
    validHeap->left->left->left = new TreeNode(6);
    validHeap->left->left->right = new TreeNode(9);

    // Complete tree, but max-heap order fails.
    TreeNode* orderFailure = new TreeNode(1);
    orderFailure->left = new TreeNode(2);
    orderFailure->right = new TreeNode(3);

    // Max-heap order is fine, but tree is not complete.
    TreeNode* structureFailure = new TreeNode(10);
    structureFailure->left = new TreeNode(9);
    structureFailure->right = new TreeNode(8);
    structureFailure->left->right = new TreeNode(7);

    Solution solution;
    cout << boolalpha;
    cout << "Valid heap:       " << solution.isHeap(validHeap) << endl;
    cout << "Order failure:    " << solution.isHeap(orderFailure) << endl;
    cout << "Structure failure: " << solution.isHeap(structureFailure) << endl;

    deleteTree(validHeap);
    deleteTree(orderFailure);
    deleteTree(structureFailure);
    return 0;
}
```

**Output:**

```text
Valid heap:       true
Order failure:    false
Structure failure: false
```

## Step-by-Step Check for Valid Heap

```text
At 97 (index 0):
0 < 9 ✓
97 ≥ 46 and 37 ✓

At 46 (index 1):
1 < 9 ✓
46 ≥ 12 and 3 ✓

At 12 (index 3):
3 < 9 ✓
12 ≥ 6 and 9 ✓

At 37 (index 2):
2 < 9 ✓
37 ≥ 7 and 31 ✓
```

All real nodes use indexes `0` through `8`, and every parent follows max heap order.

```text
Answer = true
```

## Edge Cases

### Empty Tree

```text
root = NULL
```

An empty tree is usually considered a valid heap.

```text
Answer = true
```

### Single Node

```text
  5
```

It is complete and has no child-order violation.

```text
Answer = true
```

### Left Child Only

```text
    10
   /
  9
```

This is complete.

```text
10 ≥ 9 ✓
Answer = true
```

### Right Child Only

```text
    10
      \
       9
```

This is not complete because there is a gap on the left.

```text
Answer = false
```

## Complexity

Let `N` be the number of nodes and `H` be tree height.

| Step | Time | Extra Space |
|---|---:|---:|
| Count nodes | `O(N)` | `O(H)` recursion |
| Check complete + heap order | `O(N)` | `O(H)` recursion |
| **Total** | **`O(N)`** | **`O(H)`** |

```text
If the tree is complete: H = O(log N)
For an arbitrary input tree: H can be O(N) in the worst case
```

## Interview Questions 🎯

### 1. What two conditions must a max heap satisfy?

```text
Complete binary tree
AND
Parent value ≥ children values
```

### 2. Why is max-heap order alone not enough?

A tree can follow parent-child order but still have structural gaps, so it is not a heap.

### 3. How does the index method check completeness?

Every real node must have an array-style index smaller than the total number of nodes.

### 4. What is the last internal node index in a heap array?

```text
(N / 2) - 1
```

### 5. Is a node with only a left child allowed in a complete tree?

Yes, if it appears at the last possible position.

### 6. Is a node with only a right child allowed?

No. It creates a gap on the left.

### 7. What is the time complexity?

`O(N)`.
