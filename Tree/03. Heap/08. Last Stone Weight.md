# Last Stone Weight

> Repeatedly smash the two heaviest stones. Return the weight of the last stone, or `0` if no stones remain.

Rules for stones `y ≥ x`:

```text
y == x → both stones are destroyed
y != x → destroy y and put back y - x
```

---

## Example 1

```text
Stones = [2, 7, 4, 1, 8, 1]
```

| Round | Two heaviest stones | Result | Stones left |
|---:|---|---:|---|
| 1 | `8, 7` | `8 - 7 = 1` | `[4, 2, 1, 1, 1]` |
| 2 | `4, 2` | `4 - 2 = 2` | `[2, 1, 1, 1]` |
| 3 | `2, 1` | `2 - 1 = 1` | `[1, 1, 1]` |
| 4 | `1, 1` | destroyed | `[1]` |

```text
One stone remains.
Answer = 1
```

## Why Use a Max Heap? 💡

Every round needs the two largest stone weights.

```text
maxHeap.top() = heaviest stone
```

```text
         8
        / \
       7   4
      / \ /
     2  1 1
```

A max heap lets us:

```text
get largest   → O(1)
remove largest → O(log N)
add remainder  → O(log N)
```

---

## Algorithm

```text
1. Put all stones in a max heap.
2. While heap has at least 2 stones:
      a. Remove y, the heaviest stone.
      b. Remove x, the second heaviest stone.
      c. If y != x, add y - x back to the heap.
3. If heap is empty, return 0.
4. Otherwise, return heap.top().
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

int lastStoneWeight(const vector<int>& stones) {
    // C++ priority_queue<int> is a max heap.
    priority_queue<int> maxHeap(stones.begin(), stones.end());

    while (maxHeap.size() > 1) {
        int heaviest = maxHeap.top();
        maxHeap.pop();

        int secondHeaviest = maxHeap.top();
        maxHeap.pop();

        // Only a non-zero remainder goes back into the heap.
        if (heaviest != secondHeaviest) {
            maxHeap.push(heaviest - secondHeaviest);
        }
    }

    return maxHeap.empty() ? 0 : maxHeap.top();
}

int main() {
    vector<int> stones1 = {2, 7, 4, 1, 8, 1};
    vector<int> stones2 = {1};
    vector<int> stones3 = {3, 3};
    vector<int> stones4 = {10, 4, 2, 10};
    vector<int> stones5 = {1, 3};

    cout << "[2, 7, 4, 1, 8, 1] → " << lastStoneWeight(stones1) << endl;
    cout << "[1]                → " << lastStoneWeight(stones2) << endl;
    cout << "[3, 3]             → " << lastStoneWeight(stones3) << endl;
    cout << "[10, 4, 2, 10]     → " << lastStoneWeight(stones4) << endl;
    cout << "[1, 3]             → " << lastStoneWeight(stones5) << endl;

    return 0;
}
```

**Output:**

```text
[2, 7, 4, 1, 8, 1] → 1
[1]                → 1
[3, 3]             → 0
[10, 4, 2, 10]     → 2
[1, 3]             → 2
```

## Edge Cases

### No Stones

```text
[]
```

```text
Answer = 0
```

### Two Equal Stones

```text
[4, 4]

4 == 4 → both destroyed
Answer = 0
```

### Two Unequal Stones

```text
[7, 3]

7 - 3 = 4
Answer = 4
```

### All Equal Stones

```text
[2, 2, 2, 2]

Round 1: smash 2, 2 → [2, 2]
Round 2: smash 2, 2 → []

Answer = 0
```

### Descending Values

```text
[10, 8, 6, 4, 2]

Round 1: 10 - 8 = 2 → [6, 4, 2, 2]
Round 2: 6 - 4 = 2  → [2, 2, 2]
Round 3: 2 and 2 destroy each other → [2]

Answer = 2
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Build max heap | `O(N)` | Build heap from all stones. |
| Smash rounds | `O(N log N)` | At most `N - 1` rounds, each with heap operations. |
| Total time | `O(N log N)` | Heap operations dominate. |
| Extra space | `O(N)` | Max heap stores all stone weights. |

## Interview Questions 🎯

### 1. Why use a max heap?

Every round requires the two heaviest stones.

### 2. Why does the loop run while heap size is greater than 1?

Smashing needs two stones. If zero or one stone remains, the process is finished.

### 3. What happens when the two stones have equal weights?

Both are destroyed, so nothing is inserted back.

### 4. What happens when the weights are different?

Insert the difference `heaviest - secondHeaviest` back into the heap.

### 5. What is the time complexity?

`O(N log N)`.

### 6. What is the space complexity?

`O(N)` for the max heap.

### 7. Does the input array change?

No. The solution builds a separate priority queue from the input values.
