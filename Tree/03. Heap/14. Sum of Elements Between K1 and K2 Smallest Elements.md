# Sum of Elements Between K1th and K2th Smallest Elements

> Given an array and two positions `K1` and `K2`, find the sum of elements whose **sorted positions** lie strictly between them.

```text
Include positions: K1 + 1 to K2 - 1
Do not include positions K1 or K2
```

Assume:

```text
1 <= K1 < K2 <= N
```

---

## Example 1

```text
Array = [2, 5, 3, 1, 4]
K1 = 2
K2 = 4
```

```text
Sorted = [1, 2, 3, 4, 5]
              ↑  ↑  ↑
             K1  take K2
              2    4
```

```text
Only position 3 is between positions 2 and 4.

Sum = 3
```

---

## Example 2

```text
Array = [20, 8, 22, 4, 12, 10, 14]
K1 = 3
K2 = 6
```

```text
Sorted = [4, 8, 10, 12, 14, 20, 22]
               ↑       ↑       ↑    ↑
              K1      take    take K2
              10       12      14  20
```

```text
Sum = 12 + 14 = 26
```

---

## What Does “Strictly Between” Mean? 💡

It means do not include the K1th and K2th values themselves.

```text
Sorted positions:  1   2   3   4   5
Values:           [1,  2,  3,  4,  5]

K1 = 2, K2 = 4

Do not take: 2nd value = 2
Take:        3rd value = 3
Do not take: 4th value = 4
```

```text
Answer = 3
```

---

# Method 1: Two Max Heaps + Scan

## Simple Idea

1. Find the K1th smallest value.
2. Find the K2th smallest value.
3. Add array values strictly between those values.

To find Kth smallest, use a max heap of size `K`.

```text
Max heap of size K keeps K smallest values.
Heap top = largest among them = Kth smallest.
```

---

## Find 3rd Smallest in Example 2

```text
Array = [20, 8, 22, 4, 12, 10, 14]
K1 = 3
```

Keep only 3 smallest values in a max heap:

```text
After all values:
heap contains [10, 8, 4]
                  ↑
                top = 10
```

```text
3rd smallest = 10
```

Similarly:

```text
6th smallest = 20
```

Now scan the array:

```text
10 < x < 20

20 → no
8  → no
22 → no
4  → no
12 → add
10 → no
14 → add

sum = 12 + 14 = 26
```

---

## C++ Code — Method 1 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

int kthSmallest(const vector<int>& array, int k) {
    priority_queue<int> maxHeap;

    for (int value : array) {
        maxHeap.push(value);

        // Keep only K smallest values.
        if (maxHeap.size() > k) {
            maxHeap.pop();
        }
    }

    return maxHeap.top();
}

long long sumBetweenK1K2UsingTwoHeaps(const vector<int>& array, int k1, int k2) {
    int k1Value = kthSmallest(array, k1);
    int k2Value = kthSmallest(array, k2);

    long long sum = 0;

    for (int value : array) {
        if (value > k1Value && value < k2Value) {
            sum += value;
        }
    }

    return sum;
}

int main() {
    vector<int> array1 = {2, 5, 3, 1, 4};
    vector<int> array2 = {20, 8, 22, 4, 12, 10, 14};

    cout << "Example 1 sum: "
         << sumBetweenK1K2UsingTwoHeaps(array1, 2, 4) << endl;

    cout << "Example 2 sum: "
         << sumBetweenK1K2UsingTwoHeaps(array2, 3, 6) << endl;

    return 0;
}
```

**Output:**

```text
Example 1 sum: 3
Example 2 sum: 26
```

### Complexity

```text
Find K1th smallest: O(N log K1)
Find K2th smallest: O(N log K2)
Scan values:        O(N)

Total: O(N log K2)
Extra space: O(K2)
```

### Important Duplicate Note

This value-range method is correct when values are distinct, which is the common version of this problem.

If duplicates are allowed and positions matter, use **Method 2**. It works directly with sorted positions.

# Method 2: One Max Heap of Size K2 (Preferred) ⚡

## Main Idea

A max heap of size `K2` keeps exactly the `K2` smallest values.

```text
Heap top = K2th smallest value
```

Pop values from largest to smallest:

```text
1st pop → K2th smallest        → do not add
next pops → values between K1 and K2 → add
last boundary → K1th smallest  → do not add
```

---

## Example 2 with One Heap

```text
Sorted = [4, 8, 10, 12, 14, 20, 22]
K1 = 3
K2 = 6
```

The 6 smallest values are:

```text
[4, 8, 10, 12, 14, 20]
```

A max heap stores them with `20` at the top.

```text
Heap pop order:
20 → 14 → 12 → 10 → 8 → 4

6th smallest  = 20 → skip
5th smallest  = 14 → add
4th smallest  = 12 → add
3rd smallest  = 10 → skip
```

```text
Sum = 14 + 12 = 26
```

---

## How Many Values Should We Add?

```text
Positions to add = K1 + 1 through K2 - 1

Count = K2 - K1 - 1
```

Example:

```text
K1 = 3, K2 = 6

Count = 6 - 3 - 1 = 2

Add 2 values: 14 and 12
```

---

## Algorithm

```text
1. Build a max heap of size K2.
   It stores the K2 smallest values.

2. Pop K2th smallest once.
   Do not add it.

3. Pop K2 - K1 - 1 values.
   Add each popped value to sum.

4. Do not add K1th smallest.

5. Return sum.
```

---

## C++ Code — Method 2 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

long long sumBetweenK1K2UsingOneHeap(const vector<int>& array, int k1, int k2) {
    priority_queue<int> maxHeap;

    // Keep only K2 smallest values.
    for (int value : array) {
        maxHeap.push(value);

        if (maxHeap.size() > k2) {
            maxHeap.pop();
        }
    }

    // Top is the K2th smallest element. Exclude it.
    maxHeap.pop();

    long long sum = 0;
    int elementsToAdd = k2 - k1 - 1;

    // Next largest values are positions K2-1 down to K1+1.
    for (int i = 0; i < elementsToAdd; i++) {
        sum += maxHeap.top();
        maxHeap.pop();
    }

    return sum;
}

int main() {
    vector<int> array1 = {2, 5, 3, 1, 4};
    vector<int> array2 = {20, 8, 22, 4, 12, 10, 14};

    cout << "Example 1 sum: "
         << sumBetweenK1K2UsingOneHeap(array1, 2, 4) << endl;

    cout << "Example 2 sum: "
         << sumBetweenK1K2UsingOneHeap(array2, 3, 6) << endl;

    return 0;
}
```

**Output:**

```text
Example 1 sum: 3
Example 2 sum: 26
```

---

## Step-by-Step Trace: Method 2

```text
Array = [2, 5, 3, 1, 4]
K1 = 2
K2 = 4

Sorted = [1, 2, 3, 4, 5]
                 ↑  ↑  ↑
                K1 take K2
```

Keep 4 smallest values:

```text
max heap contains: [4, 3, 2, 1]
                     ↑
                 top = 4 = K2th smallest
```

```text
Pop 4 → K2th smallest → skip

Elements to add = 4 - 2 - 1 = 1

Pop 3 → add to sum
sum = 3

Next value is 2 → K1th smallest → skip
```

```text
Answer = 3
```

## Edge Cases

### K2 and K1 Are Adjacent

```text
Array = [1, 2, 3, 4, 5]
K1 = 2, K2 = 3

There are no positions between them.
Answer = 0
```

### K1 = 1 and K2 = N

```text
Array = [1, 2, 3, 4, 5]
K1 = 1, K2 = 5

Take positions 2, 3, 4:
2 + 3 + 4 = 9
```

### Duplicates (Rank-Based Meaning)

```text
Array = [1, 2, 2, 2, 3]
K1 = 2, K2 = 5

Sorted = [1, 2, 2, 2, 3]
                 ↑  ↑  ↑
                K1 take K2

Take positions 3 and 4:
2 + 2 = 4
```

Method 2 gives `4` because it works with positions, not only value comparisons.

## Comparison

| Method | Time | Extra Space | Note |
|---|---:|---:|---|
| Two max heaps + scan | `O(N log K2)` | `O(K2)` | Simple for distinct values. |
| One max heap | `O(N log K2)` | `O(K2)` | Preferred; handles rank positions and uses one heap. |

## Interview Questions 🎯

### 1. Why use a max heap to find Kth smallest?

It keeps K smallest values. The largest among them, at heap top, is the Kth smallest.

### 2. Why does the one-heap method use heap size K2?

It needs all values up to the K2th smallest position.

### 3. Why is the K2th smallest excluded?

The question asks for values strictly between K1 and K2 positions.

### 4. How many values are added?

```text
K2 - K1 - 1
```

### 5. What happens when K2 = K1 + 1?

No values are between the two positions, so sum is `0`.

### 6. What is the time complexity of the preferred method?

`O(N log K2)`.

### 7. What is the space complexity?

`O(K2)`.
