# Merge K Sorted Arrays

> Given `K` sorted arrays, merge them into one sorted array containing every element.

```text
Input:
K arrays, each already sorted

Output:
One sorted array containing all values
```

For the version discussed in the video, there are `K` arrays and each array has `K` values.

```text
Total values = K²
```

The heap approach also works when the arrays have different lengths.

---

## Important Observation ⚠️

Each individual array is already sorted.

```text
Array 1: [3, 4, 5, 11]
Array 2: [1, 6, 7, 14]
Array 3: [4, 5, 8, 13]
Array 4: [6, 9, 10, 12]
```

The entire collection is not globally sorted, but every row is a sorted stream.

```text
✓ Each array can produce its next value in order
✗ All values together are not already sorted
```

The main opportunity is to merge the sorted streams instead of sorting every value from scratch.

---

## Example

### Input Arrays

```text
Array 1: [3, 4, 5, 11]
Array 2: [1, 6, 7, 14]
Array 3: [4, 5, 8, 13]
Array 4: [6, 9, 10, 12]
```

### Output

```text
[1, 3, 4, 4, 5, 5, 6, 6,
 7, 8, 9, 10, 11, 12, 13, 14]
```

Every input array contributes its values, and the result is globally sorted.

---

## Main Idea 💡

The video develops several approaches:

```text
1. Copy all values and sort them.
2. Put all values into one min heap.
3. Keep one current value from each array in a min heap.
4. Merge already-sorted array blocks with divide and conquer.
```

The most useful heap idea is:

```text
The next smallest value must be the first unprocessed value
from one of the K arrays.
```

---

# Method 1: Copy All Values and Sort

## Simple Idea

```text
1. Copy every value from every array into one vector.
2. Sort the vector.
3. Return the sorted vector.
```

For the example:

```text
Combined values:
[3, 4, 5, 11, 1, 6, 7, 14,
 4, 5, 8, 13, 6, 9, 10, 12]
```

After sorting:

```text
[1, 3, 4, 4, 5, 5, 6, 6,
 7, 8, 9, 10, 11, 12, 13, 14]
```

---

## C++ Code — Method 1 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> mergeUsingSort(const vector<vector<int>>& arrays) {
    vector<int> answer;

    for (const vector<int>& current : arrays) {
        answer.insert(answer.end(), current.begin(), current.end());
    }

    sort(answer.begin(), answer.end());
    return answer;
}

void printArray(const vector<int>& values) {
    for (int value : values) {
        cout << value << " ";
    }

    cout << endl;
}

int main() {
    vector<vector<int>> arrays = {
        {3, 4, 5, 11},
        {1, 6, 7, 14},
        {4, 5, 8, 13},
        {6, 9, 10, 12}
    };

    vector<int> answer = mergeUsingSort(arrays);

    cout << "Merged array: ";
    printArray(answer);

    return 0;
}
```

**Output:**

```text
Merged array: 1 3 4 4 5 5 6 6 7 8 9 10 11 12 13 14
```

### Complexity

For `K` arrays of length `K`:

```text
Copy values: O(K²)
Sort values: O(K² log K)
Extra space: O(K²)
```

This is the simplest baseline, but it ignores the fact that every input array is already sorted.

# Method 2: Min Heap Containing All Values

## Main Idea

Insert every value into a min heap and remove values one by one.

```text
1. Flatten all arrays into one collection.
2. Build a min heap.
3. Pop until the heap is empty.
4. Store each popped value in the answer.
```

The output is sorted because every pop returns the smallest remaining value.

---

## Heap Walkthrough

```text
All values are inserted into the heap.

First pops:
1 → 3 → 4 → 4 → 5 → 5 → 6 → 6
```

Continue until all `K²` values have been removed.

---

## C++ Code — Method 2 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> mergeUsingAllValuesHeap(
    const vector<vector<int>>& arrays
) {
    vector<int> values;

    for (const vector<int>& current : arrays) {
        values.insert(values.end(), current.begin(), current.end());
    }

    priority_queue<int, vector<int>, greater<int>> minHeap(
        values.begin(), values.end()
    );

    vector<int> answer;

    while (!minHeap.empty()) {
        answer.push_back(minHeap.top());
        minHeap.pop();
    }

    return answer;
}

void printArray(const vector<int>& values) {
    for (int value : values) {
        cout << value << " ";
    }

    cout << endl;
}

int main() {
    vector<vector<int>> arrays = {
        {3, 4, 5, 11},
        {1, 6, 7, 14},
        {4, 5, 8, 13},
        {6, 9, 10, 12}
    };

    vector<int> answer = mergeUsingAllValuesHeap(arrays);

    cout << "Merged array: ";
    printArray(answer);

    return 0;
}
```

**Output:**

```text
Merged array: 1 3 4 4 5 5 6 6 7 8 9 10 11 12 13 14
```

### Complexity

For `K²` total values:

```text
Heap construction: O(K²)
K² removals:      O(K² log K)
Extra heap space: O(K²)
```

This still stores every value in the heap.

# Method 3: Min Heap — One Candidate from Each Array

## Main Idea

Keep only one unprocessed candidate from each sorted array.

Initially insert the first value of every array:

```text
(3, array 0, index 0)
(1, array 1, index 0)
(4, array 2, index 0)
(6, array 3, index 0)
```

When an item is removed:

```text
1. Add its value to the answer.
2. Move one position right in the same array.
3. Insert the next value if it exists.
```

Each item stores:

```text
(value, array index, position inside array)
```

---

## Step-by-Step Walkthrough

### Initial Heap

```text
3, 1, 4, 6
```

### Remove 1

```text
Answer: 1
Next value from Array 2: 6
Heap: 3, 4, 6, 6
```

### Remove 3

```text
Answer: 1, 3
Next value from Array 1: 4
Heap: 4, 4, 6, 6
```

### Remove 4

```text
Answer: 1, 3, 4
Push the next value from whichever array supplied this 4.
```

Continue until the heap is empty.

---

## C++ Code — Method 3 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> mergeUsingOneCandidatePerArray(
    const vector<vector<int>>& arrays
) {
    using Item = tuple<int, int, int>;
    // value, array index, position inside that array

    int k = arrays.size();
    vector<Item> initial;

    for (int arrayIndex = 0; arrayIndex < k; arrayIndex++) {
        if (!arrays[arrayIndex].empty()) {
            initial.push_back({
                arrays[arrayIndex][0],
                arrayIndex,
                0
            });
        }
    }

    priority_queue<Item, vector<Item>, greater<Item>> minHeap(
        initial.begin(), initial.end()
    );

    vector<int> answer;

    while (!minHeap.empty()) {
        auto [value, arrayIndex, position] = minHeap.top();
        minHeap.pop();

        answer.push_back(value);

        int nextPosition = position + 1;

        if (nextPosition < static_cast<int>(arrays[arrayIndex].size())) {
            minHeap.push({
                arrays[arrayIndex][nextPosition],
                arrayIndex,
                nextPosition
            });
        }
    }

    return answer;
}

void printArray(const vector<int>& values) {
    for (int value : values) {
        cout << value << " ";
    }

    cout << endl;
}

int main() {
    vector<vector<int>> arrays = {
        {3, 4, 5, 11},
        {1, 6, 7, 14},
        {4, 5, 8, 13},
        {6, 9, 10, 12}
    };

    vector<int> answer = mergeUsingOneCandidatePerArray(arrays);

    cout << "Merged array: ";
    printArray(answer);

    return 0;
}
```

**Output:**

```text
Merged array: 1 3 4 4 5 5 6 6 7 8 9 10 11 12 13 14
```

### Complexity

Let `M` be the total number of values.

```text
Initial heap:       O(K)
M pop/push actions: O(M log K)
Extra heap space:   O(K)
```

When there are `K` arrays of length `K`:

```text
Time:  O(K² log K)
Space: O(K)
```

This is the main heap optimization because the heap never contains all `K²` values.

# Method 4: Merge the Already-Sorted Array Blocks

## Main Idea

The input arrays are already sorted, so do not divide each array into individual values unnecessarily.

Use divide and conquer on the **array blocks**:

```text
1. Split the K input arrays into two groups.
2. Recursively merge the left group.
3. Recursively merge the right group.
4. Merge the two sorted results.
```

For `K = 4`:

```text
[Array 1, Array 2, Array 3, Array 4]

Split into:
[Array 1, Array 2] and [Array 3, Array 4]

Then merge the two sorted results.
```

The split is based on the number of arrays, not on arbitrary positions inside the values.

---

## Why We Stop at One Array per Block

Every input array is already sorted.

```text
One array by itself is already a sorted block.
```

There is no reason to divide it into individual values before merging.

For an odd number of arrays, split by array count:

```text
K = 3

Left block:  1 array
Right block: 2 arrays
```

This keeps every original sorted array intact.

---

## C++ Code — Method 4 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> mergeTwoSortedArrays(
    const vector<int>& first,
    const vector<int>& second
) {
    vector<int> answer;
    answer.reserve(first.size() + second.size());

    int i = 0;
    int j = 0;

    while (i < static_cast<int>(first.size()) &&
           j < static_cast<int>(second.size())) {
        if (first[i] <= second[j]) {
            answer.push_back(first[i]);
            i++;
        } else {
            answer.push_back(second[j]);
            j++;
        }
    }

    while (i < static_cast<int>(first.size())) {
        answer.push_back(first[i]);
        i++;
    }

    while (j < static_cast<int>(second.size())) {
        answer.push_back(second[j]);
        j++;
    }

    return answer;
}

vector<int> mergeRange(
    const vector<vector<int>>& arrays,
    int left,
    int right
) {
    // One original array is already sorted.
    if (left == right) {
        return arrays[left];
    }

    int middle = left + (right - left) / 2;

    vector<int> leftResult = mergeRange(arrays, left, middle);
    vector<int> rightResult = mergeRange(arrays, middle + 1, right);

    return mergeTwoSortedArrays(leftResult, rightResult);
}

vector<int> mergeUsingSortedBlocks(
    const vector<vector<int>>& arrays
) {
    if (arrays.empty()) {
        return {};
    }

    return mergeRange(arrays, 0, arrays.size() - 1);
}

void printArray(const vector<int>& values) {
    for (int value : values) {
        cout << value << " ";
    }

    cout << endl;
}

int main() {
    vector<vector<int>> arrays = {
        {3, 4, 5, 11},
        {1, 6, 7, 14},
        {4, 5, 8, 13},
        {6, 9, 10, 12}
    };

    vector<int> answer = mergeUsingSortedBlocks(arrays);

    cout << "Merged array: ";
    printArray(answer);

    return 0;
}
```

**Output:**

```text
Merged array: 1 3 4 4 5 5 6 6 7 8 9 10 11 12 13 14
```

### Complexity

For `K` arrays with `K` values each:

```text
Each merge level processes K² values.
Number of levels: log K.

Time:        O(K² log K)
Extra space: O(K²)
```

This method avoids re-dividing the individual sorted arrays and directly merges sorted blocks.

---

## Method Comparison

| Method | Time | Extra Space | Main Idea |
|---|---:|---:|---|
| Copy + sort | `O(K² log K)` | `O(K²)` | Ignore input structure |
| Min heap of all values | `O(K² log K)` | `O(K²)` | Store every value |
| One candidate per array | `O(K² log K)` | `O(K)` | Store only current candidates |
| Merge sorted blocks | `O(K² log K)` | `O(K²)` | Merge existing sorted portions |

For equal-length arrays, the optimized heap method is attractive because it uses only `O(K)` auxiliary heap space.

---

## Edge Cases

### No Arrays

```text
Input: []
Output: []
```

### One Array

```text
Input: [[2, 5, 9]]
Output: [2, 5, 9]
```

### Empty Arrays

The heap method skips empty arrays during initialization.

```text
Input: [[], [1, 4], [], [2, 3]]
Output: [1, 2, 3, 4]
```

### Different Array Lengths

The one-candidate heap method works without changing the algorithm. It checks whether the next index exists before pushing it.

### Duplicate Values

```text
Input: [[1, 3], [1, 2]]
Output: [1, 1, 2, 3]
```

Duplicates are preserved.

---

## Complexity

Let `M` be the total number of elements.

| Method | Time | Extra Space |
|---|---:|---:|
| Copy + sort | `O(M log M)` | `O(M)` |
| Min heap of all values | `O(M log M)` | `O(M)` |
| One candidate per array | `O(M log K)` | `O(K)` |
| Merge sorted blocks | `O(M log K)` | `O(M)` |

For the video’s equal-size case, `M = K²`.

## Interview Questions 🎯

### 1. Why can we merge arrays instead of sorting every value?

Each input array is already sorted, so a k-way merge can use the existing order.

### 2. Why does the heap store array and position indexes?

After removing a value, the indexes identify the next value from the same array.

### 3. Why does the optimized heap use only O(K) heap space?

It stores one current candidate from each array.

### 4. Why does the all-values heap use more space?

It stores all `M` values at the same time.

### 5. What is the difference between the row heap and all-values heap?

The row heap inserts the next value only after its previous value is removed. The all-values heap inserts every value immediately.

### 6. Why should divide and conquer split by arrays rather than arbitrary values?

Each original array is already sorted. Splitting by array blocks preserves that useful structure.

### 7. What happens when the arrays have different lengths?

The heap method checks each array’s next position independently and works normally.

### 8. What is the best method for low auxiliary space?

The one-candidate-per-array min heap uses `O(K)` heap space.
