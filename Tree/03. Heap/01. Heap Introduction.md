# 🌳 Priority Queue and Binary Heap

> A priority queue removes elements by **priority**, not by arrival order.

A binary heap is the common data structure used to implement a priority queue efficiently.

---

## 1. What Is a Priority Queue?

A normal queue follows FIFO: first in, first out.

```text
Normal queue (FIFO):
[cold, flu, heart attack]
 ↑
processed first
```

A priority queue removes the most important element first.

```text
Priority queue:
[heart attack, flu, cold]
 ↑
processed first
```

```text
Emergency-room example:
Treatment order depends on severity, not arrival time.
```

> If two values have equal priority, tie order depends on the implementation. C++ `priority_queue` does **not** guarantee insertion order for equal values.

---

## 2. What Is a Binary Heap? 💡

A binary heap is a binary tree with two rules:

```text
1. It is a complete binary tree.
2. It follows the heap property.
```

### Complete Binary Tree

All levels are full except possibly the last one. The last level fills from left to right.

```text
Complete ✓                    Not complete ✗

       1                           1
      / \                         / \
     2   3                       2   3
    / \ /                       /     \
   4  5 6                       4       6

Last level fills left first.    A position is skipped in the middle.
```

### Heap Property

#### Min Heap

Every parent is smaller than or equal to its children.

```text
         1  ← smallest value
        / \
       3   2
      / \ / \
     6  5 4  8

parent ≤ children
```

#### Max Heap

Every parent is larger than or equal to its children.

```text
         9  ← largest value
        / \
       7   8
      / \ / \
     1  2 3  4

parent ≥ children
```

> A heap is **not fully sorted**. It only guarantees parent-child order. Siblings do not need to be sorted.

---

## 3. Array Representation

Because a heap is complete, we can store it in an array without pointers.

```text
Tree:                         Array:

         1                    [1, 3, 2, 6, 5, 4, 8]
        / \                    index: 0  1  2  3  4  5  6
       3   2
      / \ / \
     6  5 4  8
```

### Index Formulas (0-Based Indexing)

| Relation | Formula |
|---|---|
| Left child of index `i` | `2 × i + 1` |
| Right child of index `i` | `2 × i + 2` |
| Parent of index `i` | `(i - 1) / 2` |

Example: node at index `1` has value `3`.

```text
left child index  = 2 × 1 + 1 = 3  → value 6
right child index = 2 × 1 + 2 = 4  → value 5
parent index      = (1 - 1) / 2 = 0 → value 1
```

## 4. Step Up vs. Step Down

Every heap operation uses one of these two fixes.

| | Step Up / Bubble Up | Step Down / Heapify Down |
|---|---|---|
| Used by | Insert | Extract root / fix a node |
| Direction | Child → parent | Parent → child |
| Min heap swaps with | Larger parent | Smaller child |
| Max heap swaps with | Smaller parent | Larger child |
| Time | `O(log N)` | `O(log N)` |

```text
Memory trick:

Insert → new value starts at bottom → move UP
Remove root → replacement starts at top → move DOWN
```

---

### Step Up in a Min Heap

Insert `2` into:

```text
[1, 3, 4, 6, 5]
```

```text
Step 1: add at end
[1, 3, 4, 6, 5, 2]
                 ↑
```

```text
Step 2: parent of index 5 is index 2
2 < 4 → swap

[1, 3, 2, 6, 5, 4]
```

```text
Step 3: 2 > parent 1 → stop
```

---

### Step Down in a Min Heap

Extract minimum from:

```text
[1, 3, 2, 6, 5, 4]
```

```text
Step 1: save 1, move last value 4 to root
[4, 3, 2, 6, 5]
```

```text
Step 2: compare 4 with children 3 and 2
smallest child = 2 → swap

[2, 3, 4, 6, 5]
```

```text
Step 3: 4 has no children → done
```

---

## 5. Important Min Heap Operations

### `getMin()` — `O(1)`

```text
[1, 3, 2, 6, 5]
 ↑
root is always the minimum
```

### `insert(x)` — `O(log N)`

```text
Add x at the end → bubble up
```

### `extractMin()` — `O(log N)`

```text
Save root → move last element to root → heapify down
```

### `decreaseKey(index, newValue)` — `O(log N)`

```text
Make a value smaller → bubble up
```

### `deleteKey(index)` — `O(log N)`

```text
Replace with last element.
Then bubble up or bubble down, depending on the new value.
```

## 6. C++ Min Heap — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class MinHeap {
    vector<int> heap;

    int parent(int index) const { return (index - 1) / 2; }
    int leftChild(int index) const { return 2 * index + 1; }
    int rightChild(int index) const { return 2 * index + 2; }

    void bubbleUp(int index) {
        while (index > 0 && heap[parent(index)] > heap[index]) {
            swap(heap[parent(index)], heap[index]);
            index = parent(index);
        }
    }

    void heapifyDown(int index) {
        while (true) {
            int smallest = index;
            int left = leftChild(index);
            int right = rightChild(index);

            if (left < heap.size() && heap[left] < heap[smallest]) {
                smallest = left;
            }

            if (right < heap.size() && heap[right] < heap[smallest]) {
                smallest = right;
            }

            if (smallest == index) break;

            swap(heap[index], heap[smallest]);
            index = smallest;
        }
    }

public:
    bool empty() const {
        return heap.empty();
    }

    void insert(int value) {
        heap.push_back(value);
        bubbleUp(static_cast<int>(heap.size()) - 1);
    }

    optional<int> getMin() const {
        if (heap.empty()) return nullopt;
        return heap[0];
    }

    optional<int> extractMin() {
        if (heap.empty()) return nullopt;

        int minimum = heap[0];
        heap[0] = heap.back();
        heap.pop_back();

        if (!heap.empty()) {
            heapifyDown(0);
        }

        return minimum;
    }

    bool decreaseKey(int index, int newValue) {
        if (index < 0 || index >= heap.size() || newValue > heap[index]) {
            return false;
        }

        heap[index] = newValue;
        bubbleUp(index);
        return true;
    }

    bool deleteKey(int index) {
        if (index < 0 || index >= heap.size()) return false;

        heap[index] = heap.back();
        heap.pop_back();

        if (index < heap.size()) {
            // Decide whether the replacement must move up or down.
            if (index > 0 && heap[index] < heap[parent(index)]) {
                bubbleUp(index);
            } else {
                heapifyDown(index);
            }
        }

        return true;
    }

    void print() const {
        cout << "[";
        for (int i = 0; i < heap.size(); i++) {
            cout << heap[i];
            if (i + 1 < heap.size()) cout << ", ";
        }
        cout << "]\n";
    }
};

int main() {
    MinHeap minHeap;

    for (int value : {4, 1, 2, 6, 7, 3, 8, 5}) {
        minHeap.insert(value);
    }

    cout << "Initial heap: ";
    minHeap.print();

    cout << "Minimum: " << *minHeap.getMin() << endl;

    minHeap.insert(-1);
    cout << "After insert(-1), minimum: " << *minHeap.getMin() << endl;

    // Current index 3 has value 4 in this demonstration heap.
    minHeap.decreaseKey(3, -2);
    cout << "After decreaseKey(3, -2), minimum: " << *minHeap.getMin() << endl;

    cout << "Extracted minimum: " << *minHeap.extractMin() << endl;
    cout << "New minimum: " << *minHeap.getMin() << endl;

    minHeap.deleteKey(0);
    cout << "After deleteKey(0), minimum: " << *minHeap.getMin() << endl;

    return 0;
}
```

**Output:**

```text
Initial heap: [1, 4, 2, 5, 7, 3, 8, 6]
Minimum: 1
After insert(-1), minimum: -1
After decreaseKey(3, -2), minimum: -2
Extracted minimum: -2
New minimum: -1
After deleteKey(0), minimum: 1
```

## 7. C++ STL `priority_queue`

C++ has a built-in priority queue.

### Max Heap (Default)

```cpp
priority_queue<int> maxHeap;
maxHeap.push(4);
maxHeap.push(1);
maxHeap.push(7);

cout << maxHeap.top(); // 7
```

### Min Heap

```cpp
priority_queue<int, vector<int>, greater<int>> minHeap;
minHeap.push(4);
minHeap.push(1);
minHeap.push(7);

cout << minHeap.top(); // 1
```

## 8. Complexity Summary

| Operation | Time | Why |
|---|---:|---|
| `getMin()` / `top()` | `O(1)` | Root is stored at index `0`. |
| `insert()` | `O(log N)` | Bubble up at most tree height levels. |
| `extractMin()` / `pop()` | `O(log N)` | Move last node to root, then heapify down. |
| `decreaseKey()` | `O(log N)` | Smaller value may bubble up. |
| `deleteKey()` | `O(log N)` | Replacement may move up or down. |
| Build heap from array | `O(N)` | Bottom-up heapify is linear overall. |

```text
Heap height = O(log N)
because a heap is always a complete binary tree.
```

---

## 9. Min Heap vs. Max Heap

| Feature | Min Heap | Max Heap |
|---|---|---|
| Parent rule | `parent ≤ children` | `parent ≥ children` |
| Root contains | Smallest value | Largest value |
| Common use | Dijkstra, Prim, scheduling by earliest time | Heap sort, K largest values |
| Bubble-up condition | child `<` parent | child `>` parent |

## Interview Questions 🎯

### 1. Is a heap a BST?

No.

```text
BST: all left values < node < all right values
Heap: only parent-child order is guaranteed
```

### 2. Why can a heap be stored in an array?

A heap is a complete binary tree, so it has no gaps between positions in level order.

### 3. Why is `top()` `O(1)`?

The highest-priority value is always at the root, which is array index `0`.

### 4. Why does insertion bubble up?

The new value is added at the bottom and may violate order with its parent.

### 5. Why does extraction heapify down?

The last value moves to the root and may violate order with its children.

### 6. Why does a min-heap delete swap with the smaller child?

Swapping with the smaller child preserves the min-heap property.

### 7. What is the default `priority_queue` in C++?

A max heap.

### 8. How do you make a min heap in C++ STL?

```cpp
priority_queue<int, vector<int>, greater<int>> minHeap;
```
