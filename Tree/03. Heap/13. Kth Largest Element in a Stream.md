# Kth Largest Element in a Stream

> Design a class that receives numbers one by one and returns the current Kth largest value after every new number.

```text
add(value) → add value to stream → return current Kth largest
```

---

## Example

```text
K = 3
Initial numbers = [4, 5, 8, 2]
```

```text
Sorted descending: [8, 5, 4, 2]
                              ↑
                        3rd largest = 4
```

| Operation | All stream values (sorted) | 3rd largest |
|---|---|---:|
| Start | `[8, 5, 4, 2]` | `4` |
| `add(3)` | `[8, 5, 4, 3, 2]` | `4` |
| `add(5)` | `[8, 5, 5, 4, 3, 2]` | `5` |
| `add(10)` | `[10, 8, 5, 5, 4, 3, 2]` | `5` |
| `add(9)` | `[10, 9, 8, 5, 5, 4, 3, 2]` | `8` |
| `add(4)` | `[10, 9, 8, 5, 5, 4, 4, 3, 2]` | `8` |

```text
Output: [4, 5, 5, 8, 8]
```

---

## Main Idea: Min Heap of Size K 💡

Keep only the `K` largest values seen so far.

```text
K = 3
Stream values: [10, 8, 5, 3, 1]

Keep: [10, 8, 5]

Smallest among kept values = 5
5 is the 3rd largest value
```

Use a min heap:

```text
Min heap top = smallest among K largest values
             = Kth largest value
```

---

## Why Is the Heap Size Only K?

Suppose `K = 3`.

```text
Stream: [10, 8, 5, 3, 1]

Only top 3 values matter: 10, 8, 5
Values 3 and 1 can never be the 3rd largest while these bigger values exist.
```

So we remove smaller unnecessary values and keep only:

```text
[5, 8, 10]
 ↑
heap top = 5 = 3rd largest
```

---

## Constructor

For initial values, add every number to the min heap.

```text
If heap size becomes greater than K:
remove heap top (the smallest value)
```

Example:

```text
K = 3
nums = [4, 5, 8, 2]

Min heap after all values: [2, 4, 5, 8]
Remove smallest 2

Heap keeps: [4, 5, 8]
             ↑
          top = 4 = 3rd largest
```

---

## `add(value)` Operation

```text
1. Push the new value.
2. If heap size > K, pop the smallest value.
3. Heap top is the Kth largest value.
```

## Why Not a Max Heap?

A max heap gives only the largest value quickly.

```text
Max heap top = 1st largest
```

To find the Kth largest with a max heap, you would need to remove `K - 1` values first.

```text
For K = 3:
pop largest once
pop largest twice
top is now 3rd largest
```

That is not efficient for every new stream value.

A min heap of size `K` gives the answer directly:

```text
minHeap.top() = Kth largest → O(1) lookup
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class KthLargest {
    int k;
    priority_queue<int, vector<int>, greater<int>> minHeap;

public:
    KthLargest(int k, const vector<int>& nums) : k(k) {
        // Keep at most K largest initial values.
        for (int value : nums) {
            minHeap.push(value);

            if (minHeap.size() > k) {
                minHeap.pop();
            }
        }
    }

    int add(int value) {
        minHeap.push(value);

        // Remove the smallest value if we have more than K values.
        if (minHeap.size() > k) {
            minHeap.pop();
        }

        // Assumption: stream now contains at least K total values.
        return minHeap.top();
    }
};

int main() {
    vector<int> nums = {4, 5, 8, 2};
    KthLargest kthLargest(3, nums);

    cout << kthLargest.add(3) << endl;   // 4
    cout << kthLargest.add(5) << endl;   // 5
    cout << kthLargest.add(10) << endl;  // 5
    cout << kthLargest.add(9) << endl;   // 8
    cout << kthLargest.add(4) << endl;   // 8

    return 0;
}
```

**Output:**

```text
4
5
5
8
8
```

## Edge Cases

### New Value Is Too Small

```text
K = 2
Heap keeps: [5, 6]

add(1):
push 1 → [1, 5, 6]
pop 1  → [5, 6]

Return 5
```

The small value does not enter the top 2 largest values.

### New Value Is Very Large

```text
K = 2
Heap keeps: [5, 6]

add(10):
push 10 → [5, 6, 10]
pop 5   → [6, 10]

Return 6
```

### K = 1

```text
Min heap size = 1
Heap top = largest value seen so far
```

### Initial Array Has Fewer Than K Values

```text
K = 3
nums = [3]
```

The heap may initially have fewer than `K` values. A valid Kth largest answer exists only after the stream contains at least `K` total values.

## Complexity

| Operation | Time | Space |
|---|---:|---:|
| Constructor with N initial values | `O(N log K)` | `O(K)` |
| `add(value)` | `O(log K)` | `O(K)` |
| Read Kth largest | `O(1)` | `O(1)` |

```text
Why O(log K)?
The heap never stores more than K values.
```

## Interview Questions 🎯

### 1. Why use a min heap of size K?

It keeps the K largest values, and its smallest value is the Kth largest.

### 2. Why remove heap top when size becomes K + 1?

Heap top is the smallest value, so it cannot remain in the K largest values.

### 3. What does `minHeap.top()` represent?

The current Kth largest element in the stream.

### 4. What is the time complexity of `add()`?

`O(log K)`.

### 5. What is the space complexity?

`O(K)`.

### 6. Why is this better than sorting after every add?

Sorting repeatedly would be much slower as the stream grows. The heap updates only the values that matter.
