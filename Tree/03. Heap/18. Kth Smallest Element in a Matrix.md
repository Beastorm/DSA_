# Kth Smallest Element in a Row-and-Column Sorted Matrix

> Given an `N × N` matrix where every row and every column is sorted in ascending order, find the Kth smallest value.

```text
Rows:    left → right   are sorted
Columns: top  → bottom  are sorted
```

---

## Important Observation ⚠️

The matrix is sorted by rows and columns, but flattening it does not always produce one sorted array.

```text
[16, 28, 41, 64]
[22, 41, 68, 86]
```

Here, `22` appears in the second row but is smaller than `28` and `41` from the first row.

So:

```text
✓ Every row is sorted
✓ Every column is sorted
✗ The flattened matrix is not necessarily sorted
```

Also:

```text
K is 1-based
Duplicates count as separate elements
```

---

## Example

```text
Matrix:

[16, 28, 41, 64]
[22, 41, 68, 86]
[27, 50, 78, 87]
[36, 60, 80, 94]

K = 6
```

If all values were sorted:

```text
[16, 22, 27, 28, 36, 41, 41, 50,
 60, 64, 68, 78, 80, 86, 87, 94]
                              ↑
                       6th smallest = 41
```

```text
Answer = 41
```

---

## Main Idea 💡

The video explains the problem from a direct method to optimized methods:

```text
1. Copy all values and sort them.
2. Build one min heap containing all values.
3. Merge the sorted rows using a small min heap.
4. Explore right/down neighbors with a visited set.
5. Binary-search the answer value.
```

The important optimization is to avoid storing every matrix value when only the next smallest candidates are needed.

---

# Method 1: Copy All Values and Sort

## Simple Idea

```text
1. Copy all N² values into an array.
2. Sort the array.
3. Return values[K - 1].
```

For the example:

```text
Collected:
[16, 28, 41, 64, 22, 41, 68, 86,
 27, 50, 78, 87, 36, 60, 80, 94]

Sorted:
[16, 22, 27, 28, 36, 41, 41, 50,
 60, 64, 68, 78, 80, 86, 87, 94]
```

```text
K = 6
Answer = sorted[5] = 41
```

---

## C++ Code — Method 1 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

int kthSmallestUsingSort(const vector<vector<int>>& matrix, int k) {
    vector<int> values;

    for (const vector<int>& row : matrix) {
        for (int value : row) {
            values.push_back(value);
        }
    }

    sort(values.begin(), values.end());
    return values[k - 1];
}

int main() {
    vector<vector<int>> matrix = {
        {16, 28, 41, 64},
        {22, 41, 68, 86},
        {27, 50, 78, 87},
        {36, 60, 80, 94}
    };

    int k = 6;

    cout << "Kth smallest value: "
         << kthSmallestUsingSort(matrix, k) << endl;

    return 0;
}
```

**Output:**

```text
Kth smallest value: 41
```

### Complexity

```text
Collect values: O(N²)
Sort values:    O(N² log N)
Extra space:    O(N²)
```

This is the easiest method, but it does not use the sorted matrix structure.

# Method 2: Min Heap Containing All Values

## Simple Idea

A min heap always gives the smallest remaining value.

```text
1. Copy all matrix values into an array.
2. Build a min heap.
3. Remove the minimum K - 1 times.
4. Read the heap top.
```

The video also discusses building a heap from a complete range:

```cpp
priority_queue<int, vector<int>, greater<int>> minHeap(
    values.begin(), values.end()
);
```

This uses heapify instead of pushing every value separately.

---

## Heap Walkthrough

For the first few sorted values:

```text
16, 22, 27, 28, 36, 41, ...
```

For `K = 6`:

```text
Pop 16 → 1st smallest
Pop 22 → 2nd smallest
Pop 27 → 3rd smallest
Pop 28 → 4th smallest
Pop 36 → 5th smallest
Top 41 → 6th smallest
```

---

## C++ Code — Method 2 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

int kthSmallestUsingAllValuesHeap(const vector<vector<int>>& matrix, int k) {
    vector<int> values;

    for (const vector<int>& row : matrix) {
        values.insert(values.end(), row.begin(), row.end());
    }

    // Range construction builds the heap from all values.
    priority_queue<int, vector<int>, greater<int>> minHeap(
        values.begin(), values.end()
    );

    for (int removed = 1; removed < k; removed++) {
        minHeap.pop();
    }

    return minHeap.top();
}

int main() {
    vector<vector<int>> matrix = {
        {16, 28, 41, 64},
        {22, 41, 68, 86},
        {27, 50, 78, 87},
        {36, 60, 80, 94}
    };

    int k = 6;

    cout << "Kth smallest value: "
         << kthSmallestUsingAllValuesHeap(matrix, k) << endl;

    return 0;
}
```

**Output:**

```text
Kth smallest value: 41
```

### Complexity

There are `N²` values in the matrix.

```text
Heap construction: O(N²)
K removals:       O(K log N)
Total:            O(N² + K log N)
Extra space:      O(N²)
```

If values are inserted one by one, heap construction becomes `O(N² log N)`.

# Method 3: Min Heap — One Candidate from Each Row

## Main Idea

Treat every row as a sorted list.

Initially insert the first value from each row:

```text
(16, row 0, column 0)
(22, row 1, column 0)
(27, row 2, column 0)
(36, row 3, column 0)
```

When a value is removed, insert the next value from the **same row**.

```text
Pop (value, row, column)
Push (matrix[row][column + 1], row, column + 1)
```

The heap stores:

```text
(value, row, column)
```

The indexes are necessary because they identify which value comes next.

---

## Step-by-Step Walkthrough

```text
Initial heap: 16, 22, 27, 36
```

```text
Pop 16 → 1st smallest
Push 28 from row 0

Pop 22 → 2nd smallest
Push 41 from row 1

Pop 27 → 3rd smallest
Push 50 from row 2

Pop 28 → 4th smallest
Push 41 from row 0

Pop 36 → 5th smallest
Push 60 from row 3

Pop 41 → 6th smallest
```

```text
Answer = 41
```

---

## C++ Code — Method 3 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

int kthSmallestUsingRowHeap(const vector<vector<int>>& matrix, int k) {
    int n = matrix.size();
    using Item = tuple<int, int, int>; // value, row, column

    vector<Item> initial;

    for (int row = 0; row < n; row++) {
        initial.push_back({matrix[row][0], row, 0});
    }

    // Range construction heapifies the first-column candidates.
    priority_queue<Item, vector<Item>, greater<Item>> minHeap(
        initial.begin(), initial.end()
    );

    int answer = 0;

    for (int removed = 0; removed < k; removed++) {
        auto [value, row, column] = minHeap.top();
        minHeap.pop();

        answer = value;

        if (column + 1 < n) {
            minHeap.push({
                matrix[row][column + 1],
                row,
                column + 1
            });
        }
    }

    return answer;
}

int main() {
    vector<vector<int>> matrix = {
        {16, 28, 41, 64},
        {22, 41, 68, 86},
        {27, 50, 78, 87},
        {36, 60, 80, 94}
    };

    int k = 6;

    cout << "Kth smallest value: "
         << kthSmallestUsingRowHeap(matrix, k) << endl;

    return 0;
}
```

**Output:**

```text
Kth smallest value: 41
```

### Complexity

```text
Initial heap:       O(N)
K pop/push actions: O(K log N)
Total:              O(N + K log N)
Extra space:        O(N)
```

This is the main heap optimization from the video.

# Method 4: Neighbor Expansion with a Visited Set

## Main Idea

Start at the top-left cell and expand the matrix frontier.

```text
1. Push matrix[0][0].
2. Pop the smallest cell.
3. Try its bottom neighbor.
4. Try its right neighbor.
5. Continue until K cells are removed.
```

For a cell `(row, column)`:

```text
Bottom neighbor: (row + 1, column)
Right neighbor:  (row, column + 1)
```

---

## Why a Visited Set Is Required

A cell can be reached from two paths:

```text
(0, 1) → (1, 1)
(1, 0) → (1, 1)
```

Without a visited set, `(1, 1)` may be inserted twice.

```text
Before pushing a coordinate:
check whether it has already been visited
```

---

## C++ Code — Method 4 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

int kthSmallestUsingNeighborExpansion(
    const vector<vector<int>>& matrix,
    int k
) {
    int n = matrix.size();
    using Item = tuple<int, int, int>; // value, row, column

    priority_queue<Item, vector<Item>, greater<Item>> minHeap;
    set<pair<int, int>> visited;

    minHeap.push({matrix[0][0], 0, 0});
    visited.insert({0, 0});

    int answer = 0;

    for (int removed = 0; removed < k; removed++) {
        auto [value, row, column] = minHeap.top();
        minHeap.pop();

        answer = value;

        if (row + 1 < n &&
            visited.insert({row + 1, column}).second) {
            minHeap.push({
                matrix[row + 1][column],
                row + 1,
                column
            });
        }

        if (column + 1 < n &&
            visited.insert({row, column + 1}).second) {
            minHeap.push({
                matrix[row][column + 1],
                row,
                column + 1
            });
        }
    }

    return answer;
}

int main() {
    vector<vector<int>> matrix = {
        {16, 28, 41, 64},
        {22, 41, 68, 86},
        {27, 50, 78, 87},
        {36, 60, 80, 94}
    };

    int k = 6;

    cout << "Kth smallest value: "
         << kthSmallestUsingNeighborExpansion(matrix, k) << endl;

    return 0;
}
```

**Output:**

```text
Kth smallest value: 41
```

### Complexity

```text
At most K cells are explored.

Heap operations: O(K log K)
Visited storage: O(K)
Total:           O(K log K)
```

A full `N × N` boolean visited table would use `O(N²)` space instead.

# Method 5: Binary Search on the Value Range

## Main Idea

Do not binary-search matrix indexes. Binary-search the possible answer value.

```text
low  = matrix[0][0]
high = matrix[N - 1][N - 1]
```

For `mid`, count the values less than or equal to it.

```text
count < K:
    answer is larger
    low = mid + 1

count >= K:
    mid may be the answer
    high = mid
```

---

## Counting Values `<= mid`

Start at the bottom-left corner.

```text
[16, 28, 41, 64]
[22, 41, 68, 86]
[27, 50, 78, 87]
[36, 60, 80, 94]
 ↑
Start here
```

For `mid = 41`:

```text
36 <= 41
Count the full first column: 16, 22, 27, 36
count = 4
Move right
```

```text
60 > 41 → move up
50 > 41 → move up
41 <= 41
Count 28 and 41 from this column
count = 6
Move right
```

The pointer only moves up or right, so counting takes `O(N)` time.

---

## Binary Search Trace

```text
K = 6
low = 16
high = 94
```

| Step | `mid` | Count values `<= mid` | Decision |
|---:|---:|---:|---|
| 1 | 55 | 8 | Keep left range |
| 2 | 35 | 4 | Move right |
| 3 | 45 | 7 | Keep left range |
| 4 | 40 | 5 | Move right |
| 5 | 42 | 7 | Keep left range |
| 6 | 41 | 7 | Keep 41 as candidate |

```text
low = high = 41
Answer = 41
```

Using `<=` is important because duplicate values count separately.

---

## C++ Code — Method 5 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

long long countLessEqual(const vector<vector<int>>& matrix,
                         long long value) {
    int n = matrix.size();
    int row = n - 1;
    int column = 0;
    long long count = 0;

    while (row >= 0 && column < n) {
        if (matrix[row][column] <= value) {
            // All cells above this one in the column are also <= value.
            count += row + 1;
            column++;
        } else {
            row--;
        }
    }

    return count;
}

int kthSmallestUsingBinarySearch(
    const vector<vector<int>>& matrix,
    int k
) {
    int n = matrix.size();
    long long low = matrix[0][0];
    long long high = matrix[n - 1][n - 1];

    while (low < high) {
        long long mid = low + (high - low) / 2;

        if (countLessEqual(matrix, mid) < k) {
            low = mid + 1;
        } else {
            high = mid;
        }
    }

    return static_cast<int>(low);
}

int main() {
    vector<vector<int>> matrix = {
        {16, 28, 41, 64},
        {22, 41, 68, 86},
        {27, 50, 78, 87},
        {36, 60, 80, 94}
    };

    int k = 6;

    cout << "Kth smallest value: "
         << kthSmallestUsingBinarySearch(matrix, k) << endl;

    return 0;
}
```

**Output:**

```text
Kth smallest value: 41
```

### Complexity

```text
One count operation: O(N)
Binary-search steps: O(log R)
Total:               O(N log R)
Extra space:         O(1)
```

`R` is the numeric difference between the largest and smallest possible values.

---

## Method Comparison

| Method | Time | Extra Space | Main Trade-off |
|---|---:|---:|---|
| Copy + sort | `O(N² log N)` | `O(N²)` | Simplest, ignores structure |
| All-values min heap | `O(N² + K log N)` | `O(N²)` | Heap-based baseline |
| Row-frontier heap | `O(N + K log N)` | `O(N)` | Best heap approach |
| Neighbor expansion | `O(K log K)` | `O(K)` | Needs visited coordinates |
| Binary search on values | `O(N log R)` | `O(1)` | Best extra-space usage |

---

## Edge Cases

### K = 1

```text
Answer = matrix[0][0]
```

### K = N²

```text
Answer = matrix[N - 1][N - 1]
```

### Duplicate Values

```text
[5,  8]
[5, 10]

Sorted = [5, 5, 8, 10]
K = 2
Answer = 5
```

### One-Cell Matrix

```text
Matrix = [[42]]
K = 1
Answer = 42
```

### Boundary Cells

Do not read a next column when the current cell is already in the final column. Similarly, do not add a bottom neighbor from the final row.

## Interview Questions 🎯

### 1. Why is a flattened matrix not necessarily sorted?

Only each row and each column is sorted. Values from later rows can be smaller than values later in earlier rows.

### 2. Why does the row-heap method store row and column indexes?

They identify the next value to insert after a heap item is removed.

### 3. Why does the row-heap method use only O(N) space?

It stores only one current candidate from each row.

### 4. Why does neighbor expansion need a visited set?

A cell can be reached from both the cell above and the cell to its left.

### 5. Why start the binary-search count at bottom-left?

Each comparison lets us eliminate either a complete column segment or a row segment.

### 6. How are duplicates handled?

Count values using `<= mid`, and find the smallest value whose count is at least `K`.

### 7. Which method uses the least extra space?

Binary search on the value range uses `O(1)` extra space.
