# Kth Smallest Element in a Sorted Matrix

> Given an `N × N` matrix where every row and column is sorted in ascending order, find the Kth smallest value.

```text
Rows:    left → right   are sorted
Columns: top  → bottom  are sorted
```

---

## Example 1

```text
Matrix:

[ 1,  5,  9]
[10, 11, 13]
[12, 13, 15]

K = 8
```

If all values were sorted:

```text
[1, 5, 9, 10, 11, 12, 13, 13, 15]
                            ↑
                      8th smallest = 13
```

```text
Answer = 13
```

---

## Example 2

```text
Matrix:

[1, 2]
[1, 3]

K = 2
```

```text
Sorted values: [1, 1, 2, 3]
                     ↑
               2nd smallest = 1
```

Duplicates count as separate elements.

---

## Approaches Overview 💡

Let matrix size be `N × N`, so total elements are `N²`.

| Approach | Time | Extra Space | Best Use |
|---|---:|---:|---|
| Collect + sort | `O(N² log N)` | `O(N²)` | Simplest approach |
| Max heap of size K | `O(N² log K)` | `O(K)` | K is small |
| Min heap / merge rows | `O(K log N)` | `O(N)` | K is small and rows are sorted |
| Binary search on values | `O(N log V)` | `O(1)` | Best use of row + column sorting |
| `nth_element` | `O(N²)` average | `O(N²)` | STL convenience |

`V` is the value range:

```text
matrix[N-1][N-1] - matrix[0][0]
```

---

# Approach 1: Collect All Values and Sort

## Idea

```text
1. Copy all N² values into an array.
2. Sort the array.
3. Return array[K - 1].
```

```text
Matrix:
[1, 5, 9]
[10, 11, 13]
[12, 13, 15]

Collected: [1, 5, 9, 10, 11, 13, 12, 13, 15]
Sorted:    [1, 5, 9, 10, 11, 12, 13, 13, 15]
```

```text
K = 8 → answer = sorted[7] = 13
```

---

# Approach 2: Max Heap of Size K

## Idea

Keep the K smallest values seen so far.

```text
Max heap size = K
Heap top = largest among K smallest values
         = Kth smallest value
```

For every matrix value:

```text
push value
if heap size > K:
    pop heap top (largest value)
```

Example with `K = 3`:

```text
Values seen: 1, 5, 9, 10

Keep only 3 smallest:
[1, 5, 9]

10 is larger than the current K smallest values,
so it is removed from the max heap.
```

---

# Approach 3: Min Heap — Merge Sorted Rows

## Idea

Every row is already sorted, so treat each row as one sorted list.

```text
Row 0: [1, 5, 9]
Row 1: [10, 11, 13]
Row 2: [12, 13, 15]
```

Put the first value of every row into a min heap.

```text
Heap entries: (value, row, column)

(1, 0, 0)
(10, 1, 0)
(12, 2, 0)
```

When a value is popped, add the next value from the **same row**.

---

## Min-Heap Walkthrough: K = 4

```text
Initial heap values: 1, 10, 12
```

```text
Pop 1  → 1st smallest
Push next value from row 0: 5

Pop 5  → 2nd smallest
Push next value from row 0: 9

Pop 9  → 3rd smallest
Row 0 has no next value

Pop 10 → 4th smallest
```

```text
Answer = 10
```

---

# Approach 4: Binary Search on Value Range (Recommended) ⚡

## Main Idea

Do **not** binary-search matrix positions.

Binary-search the possible values between:

```text
low  = smallest matrix value = matrix[0][0]
high = largest matrix value  = matrix[N-1][N-1]
```

For every middle value `mid`, count how many matrix values are `<= mid`.

```text
count < K  → Kth smallest is larger → move low right
count >= K → mid could be answer     → move high left
```

At the end:

```text
low = smallest value with at least K matrix values ≤ low
```

That value is the Kth smallest.

---

## Count Values `<= mid` in O(N)

Start at bottom-left corner.

```text
matrix:
[ 1,  5,  9]
[10, 11, 13]
[12, 13, 15]

start here:
[12, 13, 15]
 ↑
(2, 0)
```

For `mid = 12`:

```text
At 12:
12 <= 12

All values above it in the same column are also <= 12:
1, 10, 12

count += 3
move right
```

```text
At 13:
13 > 12
move up
```

```text
At 11:
11 <= 12

Values above it in this column are also <= 12:
5, 11

count += 2
move right
```

```text
At 13:
13 > 12 → move up

At 9:
9 <= 12
count += 1
move right and stop
```

```text
Total count = 3 + 2 + 1 = 6
```

---

## Binary Search Trace: K = 8

```text
Matrix:
[ 1,  5,  9]
[10, 11, 13]
[12, 13, 15]

low = 1, high = 15
```

| Step | `mid` | Count values `<= mid` | Decision |
|---:|---:|---:|---|
| 1 | 8 | 2 | `2 < 8` → `low = 9` |
| 2 | 12 | 6 | `6 < 8` → `low = 13` |
| 3 | 14 | 8 | `8 >= 8` → `high = 14` |
| 4 | 13 | 8 | `8 >= 8` → `high = 13` |

```text
low = high = 13
Answer = 13
```

# Approach 5: C++ `nth_element`

## Idea

1. Flatten the matrix into one array.
2. Use `nth_element`.

`nth_element` puts the element that would be at index `K - 1` in sorted order into that exact position.

```text
Values before it ≤ answer
Values after it  ≥ answer
```

The full array is not sorted.

---

## Complete C++ Program — All Approaches

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
    int countLessEqual(const vector<vector<int>>& matrix, int value) {
        int n = matrix.size();
        int row = n - 1;
        int col = 0;
        int count = 0;

        // Start at bottom-left.
        while (row >= 0 && col < n) {
            if (matrix[row][col] <= value) {
                // All values above this cell in the same column are <= value.
                count += row + 1;
                col++;
            } else {
                row--;
            }
        }

        return count;
    }

public:
    // 1. Collect and sort.
    int usingSort(const vector<vector<int>>& matrix, int k) {
        vector<int> values;

        for (const vector<int>& row : matrix) {
            for (int value : row) {
                values.push_back(value);
            }
        }

        sort(values.begin(), values.end());
        return values[k - 1];
    }

    // 2. Keep K smallest values in a max heap.
    int usingMaxHeap(const vector<vector<int>>& matrix, int k) {
        priority_queue<int> maxHeap;

        for (const vector<int>& row : matrix) {
            for (int value : row) {
                maxHeap.push(value);

                if (maxHeap.size() > k) {
                    maxHeap.pop();
                }
            }
        }

        return maxHeap.top();
    }

    // 3. Merge N sorted rows with a min heap.
    int usingMinHeap(const vector<vector<int>>& matrix, int k) {
        int n = matrix.size();
        using Item = tuple<int, int, int>; // value, row, column
        priority_queue<Item, vector<Item>, greater<Item>> minHeap;

        for (int row = 0; row < n; row++) {
            minHeap.push({matrix[row][0], row, 0});
        }

        int answer = 0;

        for (int count = 0; count < k; count++) {
            auto [value, row, col] = minHeap.top();
            minHeap.pop();
            answer = value;

            if (col + 1 < n) {
                minHeap.push({matrix[row][col + 1], row, col + 1});
            }
        }

        return answer;
    }

    // 4. Binary search on the value range.
    int usingBinarySearch(const vector<vector<int>>& matrix, int k) {
        int n = matrix.size();
        int low = matrix[0][0];
        int high = matrix[n - 1][n - 1];

        while (low < high) {
            int mid = low + (high - low) / 2;

            if (countLessEqual(matrix, mid) < k) {
                low = mid + 1;
            } else {
                high = mid;
            }
        }

        return low;
    }

    // 5. Flatten then use STL nth_element.
    int usingNthElement(const vector<vector<int>>& matrix, int k) {
        vector<int> values;

        for (const vector<int>& row : matrix) {
            values.insert(values.end(), row.begin(), row.end());
        }

        nth_element(values.begin(), values.begin() + k - 1, values.end());
        return values[k - 1];
    }
};

int main() {
    vector<vector<int>> matrix = {
        {1, 5, 9},
        {10, 11, 13},
        {12, 13, 15}
    };

    int k = 8;
    Solution solution;

    cout << "Sort:          " << solution.usingSort(matrix, k) << endl;
    cout << "Max heap:      " << solution.usingMaxHeap(matrix, k) << endl;
    cout << "Min heap:      " << solution.usingMinHeap(matrix, k) << endl;
    cout << "Binary search: " << solution.usingBinarySearch(matrix, k) << endl;
    cout << "nth_element:   " << solution.usingNthElement(matrix, k) << endl;

    return 0;
}
```

**Output:**

```text
Sort:          13
Max heap:      13
Min heap:      13
Binary search: 13
nth_element:   13
```

## Complexity Comparison

| Approach | Time | Extra Space | Uses sorted rows/columns? |
|---|---:|---:|---|
| Collect + sort | `O(N² log N)` | `O(N²)` | No |
| Max heap of K | `O(N² log K)` | `O(K)` | No |
| Min heap merge | `O(K log N)` | `O(N)` | Uses sorted rows |
| Binary search | `O(N log V)` | `O(1)` | Uses rows and columns |
| `nth_element` | `O(N²)` average | `O(N²)` | No |

---

## Which Approach Should You Use?

```text
Need simplest solution:
→ Collect and sort

K is small:
→ Min heap merge rows: O(K log N)

Need the best space usage:
→ Binary search on values: O(1) extra space

Need quick one-time selection in C++:
→ nth_element
```

## Edge Cases

### K = 1

```text
Answer = smallest value = matrix[0][0]
```

### K = N²

```text
Answer = largest value = matrix[N-1][N-1]
```

### Duplicate Values

```text
Matrix:
[1, 2]
[1, 3]

Sorted: [1, 1, 2, 3]
K = 2
Answer = 1
```

Duplicates are counted separately.

### One-Cell Matrix

```text
Matrix = [[5]]
K = 1

Answer = 5
```

## Interview Questions 🎯

### 1. Why can each matrix row be treated as a sorted list?

The question guarantees every row is sorted in ascending order.

### 2. Why does min heap merging take `O(K log N)` time?

The heap holds at most one current value from each of N rows. We pop K times.

### 3. Why does binary search use values instead of indexes?

The Kth answer is a value. We can count how many matrix values are less than or equal to a candidate value.

### 4. How do we count values `<= mid` in `O(N)`?

Start at bottom-left. Move right when value is small enough; move up when it is too large.

### 5. What does binary search return when duplicates exist?

The smallest value that has at least K values less than or equal to it.

### 6. What is the most space-efficient approach?

Binary search on the value range: `O(1)` extra space.

### 7. What is `nth_element` complexity?

`O(N²)` average time for an `N × N` matrix because there are `N²` total values.
