# Kth Smallest Element in an Array

> Given an array and a 1-indexed value `K`, find the Kth smallest element.

```text
K = 1 → smallest element
K = 2 → second smallest element
...
```

---

## Example 1

```text
Array = [7, 10, 4, 3, 20, 15]
K = 3
```

```text
Sorted array = [3, 4, 7, 10, 15, 20]
                    ↑
              3rd smallest = 7
```

---

## Example 2

```text
Array = [7, 10, 4, 20, 15]
K = 4

Sorted array = [4, 7, 10, 15, 20]
                         ↑
                   4th smallest = 15
```

---

## Four Common Methods 💡

| Method | Time | Extra Space | Best Use |
|---|---:|---:|---|
| Sort | `O(N log N)` | `O(log N)` typical | Simple one-time solution |
| Max heap of size K | `O(N log K)` | `O(K)` | Stream input or small K |
| Min heap of all values | `O(N + K log N)` | `O(N)` | Need to remove smallest values repeatedly |
| Quickselect | `O(N)` average | `O(1)` iterative | Fast one-time selection |

---

# Method 1: Sort the Array

## Simple Idea

Sort the array. Then Kth smallest is at index `K - 1`.

```text
Array:  [7, 10, 4, 3, 20, 15]
Sorted: [3, 4, 7, 10, 15, 20]

K = 3
Index = K - 1 = 2
Answer = sorted[2] = 7
```

---

## C++ Code — Sort Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

int kthSmallestBySorting(vector<int> array, int k) {
    sort(array.begin(), array.end());
    return array[k - 1];
}

int main() {
    vector<int> array = {7, 10, 4, 3, 20, 15};
    int k = 3;

    cout << "Kth smallest: "
         << kthSmallestBySorting(array, k) << endl;

    return 0;
}
```

**Output:**

```text
Kth smallest: 7
```

### Complexity

```text
Time:  O(N log N)
Space: O(log N) typical stack space used by std::sort
```

# Method 2: Max Heap of Size K

## Main Idea

Keep only the `K` smallest values seen so far.

Use a max heap of size `K`:

```text
Heap contains K smallest values seen so far.
Heap top = largest among those K values.

That largest value = Kth smallest.
```

---

## Example: K = 3

```text
Array = [7, 10, 4, 3, 20, 15]
```

```text
Process 7, 10, 4:

Max heap: [10, 7, 4]
             ↑
       largest among 3 values
```

Process `3`:

```text
Push 3 → heap has 4 values
Remove heap top 10 (largest)

Heap now contains: [7, 4, 3]
                      ↑
                     top = 7
```

Process `20` and `15`:

```text
Both are larger than current top 7.
They cannot be part of the 3 smallest values.
```

```text
Answer = 7
```

---

## Algorithm

```text
1. Create an empty max heap.
2. For every value:
      a. Push it into the heap.
      b. If heap size becomes more than K, remove heap top.
3. Heap top is the Kth smallest value.
```

---

## C++ Code — Max Heap Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

int kthSmallestUsingMaxHeap(const vector<int>& array, int k) {
    priority_queue<int> maxHeap;

    for (int value : array) {
        maxHeap.push(value);

        // Remove the largest value so only K smallest values remain.
        if (maxHeap.size() > k) {
            maxHeap.pop();
        }
    }

    return maxHeap.top();
}

int main() {
    vector<int> array = {7, 10, 4, 3, 20, 15};
    int k = 3;

    cout << "Kth smallest: "
         << kthSmallestUsingMaxHeap(array, k) << endl;

    return 0;
}
```

**Output:**

```text
Kth smallest: 7
```

### Complexity

```text
Time:  O(N log K)
Space: O(K)
```

> This is useful when values arrive one by one in a stream and `K` is small.

# Method 3: Min Heap of All Values

## Simple Idea

Put every value in a min heap.

```text
Min heap top = smallest value
```

Remove the smallest value `K - 1` times. The next top is the Kth smallest value.

---

## Example: K = 3

```text
Array = [7, 10, 4, 3, 20, 15]

Min-heap pop order:
3 → 4 → 7 → 10 → 15 → 20
```

```text
Pop 3 → 1st smallest
Pop 4 → 2nd smallest
Top 7 → 3rd smallest
```

---

## C++ Code — Min Heap Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

int kthSmallestUsingMinHeap(const vector<int>& array, int k) {
    priority_queue<int, vector<int>, greater<int>> minHeap(array.begin(), array.end());

    // Remove the first K - 1 smallest values.
    for (int i = 1; i < k; i++) {
        minHeap.pop();
    }

    return minHeap.top();
}

int main() {
    vector<int> array = {7, 10, 4, 3, 20, 15};
    int k = 3;

    cout << "Kth smallest: "
         << kthSmallestUsingMinHeap(array, k) << endl;

    return 0;
}
```

**Output:**

```text
Kth smallest: 7
```

### Complexity

```text
Build heap: O(N)
K - 1 pops: O(K log N)

Total time:  O(N + K log N)
Space:       O(N)
```

# Method 4: Quickselect (Best Average Time) ⚡

## Main Idea

Quickselect uses the partition idea from Quicksort, but searches only the side that contains index `K - 1`.

```text
target index = K - 1
```

After partitioning:

```text
smaller values | pivot | larger values
```

If pivot lands at target index, it is the answer.

---

## Partition Example

```text
Array = [7, 10, 4, 3, 20, 15]
K = 3
Target index = 2
```

Use `15` as an example pivot:

```text
[7, 10, 4, 3 | 15 | 20]
                 ↑
           pivot index = 4
```

```text
Target index 2 is left of pivot index 4.
So continue only in the left part.
```

Quickselect does **not** sort both sides like Quicksort.

---

## Algorithm

```text
target = K - 1

while search range is valid:
    partition around a pivot

    if pivot index == target:
        return array[pivot index]

    if target < pivot index:
        search left side only
    else:
        search right side only
```

---

## C++ Code — Quickselect Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

int partitionArray(vector<int>& array, int left, int right, int pivotIndex) {
    int pivot = array[pivotIndex];
    swap(array[pivotIndex], array[right]);

    int storeIndex = left;

    for (int i = left; i < right; i++) {
        if (array[i] <= pivot) {
            swap(array[i], array[storeIndex]);
            storeIndex++;
        }
    }

    swap(array[storeIndex], array[right]);
    return storeIndex;
}

int kthSmallestQuickselect(vector<int> array, int k) {
    int targetIndex = k - 1;
    int left = 0;
    int right = static_cast<int>(array.size()) - 1;

    mt19937 generator(random_device{}());

    while (left <= right) {
        uniform_int_distribution<int> choosePivot(left, right);
        int pivotIndex = partitionArray(array, left, right, choosePivot(generator));

        if (pivotIndex == targetIndex) {
            return array[pivotIndex];
        }

        if (targetIndex < pivotIndex) {
            right = pivotIndex - 1;
        } else {
            left = pivotIndex + 1;
        }
    }

    return -1; // Invalid K
}

int main() {
    vector<int> array = {7, 10, 4, 3, 20, 15};
    int k = 3;

    cout << "Kth smallest: "
         << kthSmallestQuickselect(array, k) << endl;

    return 0;
}
```

**Output:**

```text
Kth smallest: 7
```

### Complexity

| Case | Time | Extra Space |
|---|---:|---:|
| Average | `O(N)` | `O(1)` |
| Worst case | `O(N²)` | `O(1)` |

A randomized pivot makes the bad case unlikely.

---

## Comparison

| Method | Time | Extra Space | When to Use |
|---|---:|---:|---|
| Sort | `O(N log N)` | `O(log N)` typical | Easiest one-time solution. |
| Max heap of K | `O(N log K)` | `O(K)` | Stream input or small K. |
| Min heap of N | `O(N + K log N)` | `O(N)` | Need repeated smallest removals. |
| Quickselect | `O(N)` average | `O(1)` | Best average time for one answer. |

---

## Special Cases

### `K = 1`

```text
Kth smallest = minimum value
```

### `K = N`

```text
Kth smallest = maximum value
```

### Duplicate Values

```text
Array = [2, 1, 2, 3]
K = 3

Sorted = [1, 2, 2, 3]
Answer = 2
```

Duplicates count as separate array elements.

### Invalid K

```text
K < 1 or K > N
```

Check validity before accessing an array or heap.

## Interview Questions 🎯

### 1. Why is max heap of size K useful?

It keeps only the K smallest values seen so far. Its top is the Kth smallest.

### 2. Why not use a min heap of size K for Kth smallest?

Its top is the smallest among the kept values, not the Kth smallest. A max heap keeps the largest of the K smallest at top.

### 3. Which method is best for streaming data?

A max heap of size K.

### 4. Which method has best average time for one query?

Quickselect: `O(N)` average time.

### 5. Does Quickselect fully sort the array?

No. It partitions only the side containing the target index.

### 6. What is the worst-case time of Quickselect?

`O(N²)`.

### 7. How do you find Kth largest instead?

Find the `(N - K + 1)`th smallest value, or use a min heap of size K.
