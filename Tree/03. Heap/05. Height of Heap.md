# Height of a Heap

> Given `N` nodes in a heap (a complete binary tree), find its height.

This guide counts height in **edges**:

```text
single root node → height = 0
```

---

## Important Height Convention ⚠️

Two definitions are common:

| Definition | Single-node tree | Formula for `N >= 1` |
|---|---:|---|
| Height in **edges** | `0` | `floor(log₂ N)` |
| Height in **nodes / levels** | `1` | `floor(log₂ N) + 1` |

This problem uses height in **edges**.

---

## Why Is Heap Height `floor(log₂ N)`? 💡

A heap is always a complete binary tree.

```text
Level 0:  1 node   = 2⁰
Level 1:  2 nodes  = 2¹
Level 2:  4 nodes  = 2²
Level h:  2ʰ nodes
```

```text
         *          level 0
        / \
       *   *         level 1
      / \ / \
     *  * *  *       level 2
```

A tree with height `h` has:

```text
2ʰ ≤ N < 2ʰ⁺¹
```

Taking `log₂`:

```text
h ≤ log₂(N) < h + 1
```

So:

```text
height = floor(log₂ N)
```

## Pattern Table

| Nodes `N` | Binary form | `floor(log₂ N)` | Height (edges) |
|---:|---|---:|---:|
| 1 | `1` | 0 | 0 |
| 2 | `10` | 1 | 1 |
| 3 | `11` | 1 | 1 |
| 4 | `100` | 2 | 2 |
| 5 | `101` | 2 | 2 |
| 6 | `110` | 2 | 2 |
| 7 | `111` | 2 | 2 |
| 8 | `1000` | 3 | 3 |
| 15 | `1111` | 3 | 3 |
| 16 | `10000` | 4 | 4 |

```text
Height increases only when N reaches a power of 2:

N = 1  → height 0
N = 2  → height 1
N = 4  → height 2
N = 8  → height 3
N = 16 → height 4
```

## Binary Representation Trick

The heap height is:

```text
number of bits in N - 1
```

Example:

```text
N = 5
binary = 101
bits = 3

height = 3 - 1 = 2
```

```text
N = 8
binary = 1000
bits = 4

height = 4 - 1 = 3
```

This is the same as finding the position of the most significant set bit.

---

## Three Ways to Find Height

### Method 1: `log2()`

```cpp
int height = static_cast<int>(log2(n));
```

Simple, but uses floating-point math.

---

### Method 2: Divide by 2 Repeatedly

```text
N = 8

8 → 4 → 2 → 1
    1   2   3 divisions

height = 3
```

---

### Method 3: Bit Operation

```text
height = position of most significant set bit
```

For a 32-bit unsigned integer:

```cpp
31 - __builtin_clz(n)
```

> `__builtin_clz(0)` is undefined, so always handle `N = 0` first.

---

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

// Method 1: logarithm
int heightUsingLog(int n) {
    if (n <= 0) return -1; // Empty tree convention
    return static_cast<int>(log2(n));
}

// Method 2: repeated division
int heightUsingLoop(int n) {
    if (n <= 0) return -1;

    int height = 0;
    while (n > 1) {
        n /= 2;
        height++;
    }

    return height;
}

// Method 3: most significant set bit
int heightUsingBits(unsigned int n) {
    if (n == 0) return -1;

    return 31 - __builtin_clz(n);
}

int main() {
    vector<int> testCases = {1, 2, 3, 4, 6, 7, 8, 15, 16};

    cout << left
         << setw(8) << "N"

    cout << string(38, '-') << endl;

    for (int n : testCases) {
        cout << setw(8) << n
             << setw(10) << heightUsingLog(n)
             << setw(10) << heightUsingLoop(n)
             << setw(10) << heightUsingBits(n) << endl;
    }

    return 0;
}
```

## Complexity

| Method | Time | Extra Space | Note |
|---|---:|---:|---|
| `log2(n)` | `O(1)` | `O(1)` | Simple, uses floating point. |
| Repeated division | `O(log N)` | `O(1)` | Integer-only method. |
| Bit operation | `O(1)` | `O(1)` | Fast and integer-based. |

## Special Cases

### Empty Heap

```text
N = 0
```

`log₂(0)` is undefined. This guide returns `-1` for an empty tree when height is measured in edges.

### One Node

```text
  *
```

```text
N = 1
height = 0 edges
levels = 1
```

## Interview Questions 🎯

### 1. Why is heap height `O(log N)`?

A heap is a complete binary tree, so every level roughly doubles the number of nodes.

### 2. What is the formula for height in edges?

```text
floor(log₂ N)
```

### 3. What is the formula if height is counted in nodes?

```text
floor(log₂ N) + 1
```

### 4. Why must we handle `N = 0` separately?

`log₂(0)` and `__builtin_clz(0)` are undefined.

### 5. When does heap height increase?

When `N` reaches a power of two: `2, 4, 8, 16, ...`.

### 6. Which method uses no floating point?

Repeated division or bit manipulation.
