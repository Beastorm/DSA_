# Heap Sort

> Heap Sort is a comparison-based sorting algorithm that uses a binary heap.

For **ascending order**:

```text
1. Build a max heap.
2. Repeatedly move the maximum value to the end.
```

---

## Example

```text
Input:  [4, 1, 2, 6, 7, 3, 8, 5]
Output: [1, 2, 3, 4, 5, 6, 7, 8]
```

---

## Why Use a Max Heap for Ascending Order? 💡

In a max heap, the root is always the largest value.

```text
         8  ← largest
        / \
       7   4
      / \ / \
     6  1 3  2
    /
   5
```

Move the root to the last open position:

```text
[max heap | sorted part]

[8, 7, 4, 6, 1, 3, 2, 5]
 ↓
[5, 7, 4, 6, 1, 3, 2 | 8]
                         ↑
                    8 is final
```

Repeat for the remaining heap. The largest values fill the array from right to left.

```text
Max heap → ascending order
Min heap → descending order
```

---

## Heap Sort Has Two Phases

```text
Phase 1: Build a max heap
Phase 2: Extract maximum values one by one
```

```text
Input array
    ↓
Build max heap
    ↓
Swap root with last unsorted position
    ↓
Heapify the smaller heap
    ↓
Repeat until one element remains
```

---

# Phase 1: Build a Max Heap

Start from the last internal node:

```text
last internal node = (N / 2) - 1
```

For `N = 8`:

```text
last internal node = (8 / 2) - 1 = 3
```

Heapify nodes from index `3` down to `0`.

# Phase 2: Extract Maximum Values

At every step:

```text
1. Swap root with last value in heap.
2. Reduce heap size by 1.
3. Heapify root down.
```

Use this notation:

```text
[heap part | sorted part]
```

## Heapify Down for a Max Heap

At an index:

```text
1. Compare node with left and right child.
2. Find the largest of the three.
3. If a child is larger, swap.
4. Continue from the child’s new position.
```

Example:

```text
[5, 7, 4, 6, 1, 3, 2]
 ↑
```

```text
5 has children 7 and 4
7 is largest → swap

[7, 5, 4, 6, 1, 3, 2]
    ↑
```

```text
5 has children 6 and 1
6 is largest → swap

[7, 6, 4, 5, 1, 3, 2] ✓
```

---

## Full Algorithm

```text
heapSort(array):

1. Build max heap:
   for i = N/2 - 1 down to 0:
       heapifyDown(array, N, i)

2. Sort:
   for last = N - 1 down to 1:
       swap(array[0], array[last])
       heapifyDown(array, last, 0)
```

---

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

// Fix max-heap property in the subtree rooted at index.
// heapSize tells us where the unsorted heap ends.
void heapifyDown(vector<int>& array, int heapSize, int index) {
    while (true) {
        int largest = index;
        int left = 2 * index + 1;
        int right = 2 * index + 2;

        if (left < heapSize && array[left] > array[largest]) {
            largest = left;
        }

        if (right < heapSize && array[right] > array[largest]) {
            largest = right;
        }

        // Parent is already larger than both children.
        if (largest == index) break;

        swap(array[index], array[largest]);
        index = largest;
    }
}

void heapSort(vector<int>& array) {
    int n = array.size();

    // Phase 1: build max heap.
    for (int i = n / 2 - 1; i >= 0; i--) {
        heapifyDown(array, n, i);
    }

    // Phase 2: move largest value to the end each time.
    for (int last = n - 1; last > 0; last--) {
        swap(array[0], array[last]);
        heapifyDown(array, last, 0);
    }
}

void printArray(const vector<int>& array) {
    cout << "[";
    for (int i = 0; i < array.size(); i++) {
        cout << array[i];
        if (i + 1 < array.size()) cout << ", ";
    }
    cout << "]\n";
}

int main() {
    vector<int> array = {4, 1, 2, 6, 7, 3, 8, 5};

    cout << "Before heap sort: ";
    printArray(array);

    heapSort(array);

    cout << "After heap sort:  ";
    printArray(array);

    return 0;
}
```

**Output:**

```text
Before heap sort: [4, 1, 2, 6, 7, 3, 8, 5]
After heap sort:  [1, 2, 3, 4, 5, 6, 7, 8]
```

## Complexity

| Phase | Time |
|---|---:|
| Build max heap | `O(N)` |
| Extract maximum `N - 1` times | `O(N log N)` |
| **Total** | **`O(N log N)`** |

| Resource | Complexity |
|---|---:|
| Extra space | `O(1)` |
| Stable? | No |

This implementation uses iterative heapify, so it needs only constant auxiliary space.

---

## Heap Sort vs. Other Sorts

| Algorithm | Best | Average | Worst | Extra Space | Stable? |
|---|---:|---:|---:|---:|---|
| Heap sort | `O(N log N)` | `O(N log N)` | `O(N log N)` | `O(1)` | No |
| Merge sort | `O(N log N)` | `O(N log N)` | `O(N log N)` | `O(N)` | Yes |
| Quick sort | `O(N log N)` | `O(N log N)` | `O(N²)` | `O(log N)` average | No |
| Bubble sort | `O(N)` | `O(N²)` | `O(N²)` | `O(1)` | Yes |

```text
Heap sort advantage: guaranteed O(N log N) and O(1) extra space
Heap sort drawback: not stable and often less cache-friendly than quick sort
```

## Interview Questions 🎯

### 1. Why is a max heap used for ascending Heap Sort?

The largest element is at the root and can be moved to the last unsorted position.

### 2. Why does Heap Sort use `O(1)` extra space?

It rearranges the input array in place. This version also uses iterative heapify.

### 3. Is Heap Sort stable?

No. Equal elements can change their relative order during swaps.

### 4. What is the time complexity of building a heap?

`O(N)` using bottom-up heapify.

### 5. What is Heap Sort’s worst-case time complexity?

`O(N log N)`.

### 6. Why is heap size reduced after each swap?

The last value is already in its final sorted position, so it must not be heapified again.

### 7. What changes for descending order?

Build a min heap instead of a max heap.
