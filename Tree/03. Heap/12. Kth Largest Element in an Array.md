# Kth Largest Element in an Array

> Given an array and a 1-indexed value `K`, find the Kth largest element.

It is **not** the Kth distinct value. Duplicate values count separately.

---

## Example 1

```text
nums = [3, 2, 1, 5, 6, 4]
K = 2

Sorted descending: [6, 5, 4, 3, 2, 1]
                       ↑
                 2nd largest = 5
```

---

## Example 2

```text
nums = [3, 2, 3, 1, 2, 4, 5, 5, 6]
K = 4

Sorted descending: [6, 5, 5, 4, 3, 3, 2, 2, 1]
                              ↑
                        4th largest = 4
```

---

## Kth Largest and Kth Smallest Relation 💡

```text
Kth largest = (N - K + 1)th smallest
```

Example:

```text
nums = [3, 2, 1, 5, 6, 4]
N = 6, K = 2

2nd largest
= (6 - 2 + 1)th smallest
= 5th smallest
= 5
```

```text
Ascending:  [1, 2, 3, 4, 5, 6]
                            ↑
                       5th smallest
```

---

## Four Common Methods

| Method | Time | Extra Space | Best Use |
|---|---:|---:|---|
| Sort | `O(N log N)` | `O(log N)` typical | Simple solution |
| Min heap of size K | `O(N log K)` | `O(K)` | Streams or small K |
| Max heap of all values | `O(N + K log N)` | `O(N)` | Repeated largest removals |
| Quickselect | `O(N)` average | `O(1)` iterative | Fast one-time answer |

# Method 1: Sort the Array

## Simple Idea

Sort in descending order. The answer is at index `K - 1`.

```text
nums = [3, 2, 1, 5, 6, 4]

Sort descending:
[6, 5, 4, 3, 2, 1]

K = 2
index = K - 1 = 1
answer = 5
```

---

## C++ Code — Sort Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

int kthLargestBySorting(vector<int> numbers, int k) {
    sort(numbers.begin(), numbers.end(), greater<int>());
    return numbers[k - 1];
}

int main() {
    vector<int> numbers = {3, 2, 1, 5, 6, 4};

    cout << "Kth largest: "
         << kthLargestBySorting(numbers, 2) << endl;

    return 0;
}
```

**Output:**

```text
Kth largest: 5
```

# Method 2: Min Heap of Size K (Recommended for Streams) ⚡

## Main Idea

Keep only the `K` largest values seen so far.

A min heap has the smallest value at its top.

```text
Heap contains the K largest values seen so far.
Heap top = smallest among those K values.

That smallest value = Kth largest.
```

---

## Example: K = 2

```text
nums = [3, 2, 1, 5, 6, 4]
```

```text
After processing all values, keep K = 2 largest values:

[5, 6]
 ↑
min heap top = 5

2nd largest = 5
```

### How It Handles a New Value

```text
Min heap of K largest: [5, 6]
                          ↑
                          5 is top

New value = 4
4 < 5 → not in K largest → ignore

New value = 7
7 > 5 → remove 5, insert 7
Heap now keeps [6, 7]
```

---

## Algorithm

```text
1. Create a min heap.
2. For every number:
      a. Push it into heap.
      b. If heap size is more than K, pop the smallest value.
3. Heap top is the Kth largest value.
```

---

## C++ Code — Min Heap Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

int kthLargestUsingMinHeap(const vector<int>& numbers, int k) {
    priority_queue<int, vector<int>, greater<int>> minHeap;

    for (int value : numbers) {
        minHeap.push(value);

        // Keep only K largest values.
        if (minHeap.size() > k) {
            minHeap.pop();
        }
    }

    return minHeap.top();
}

int main() {
    vector<int> numbers1 = {3, 2, 1, 5, 6, 4};
    vector<int> numbers2 = {3, 2, 3, 1, 2, 4, 5, 5, 6};

    cout << "2nd largest: " << kthLargestUsingMinHeap(numbers1, 2) << endl;
    cout << "4th largest: " << kthLargestUsingMinHeap(numbers2, 4) << endl;

    return 0;
}
```

**Output:**

```text
2nd largest: 5
4th largest: 4
```

### Complexity

```text
Time:  O(N log K)
Space: O(K)
```

# Method 3: Max Heap of All Values

## Simple Idea

Put all values in a max heap.

```text
Max heap pop order:
6 → 5 → 4 → 3 → 2 → 1
```

Remove the largest value `K - 1` times. The next top is Kth largest.

```text
K = 2

Pop 6 → 1st largest
Top 5 → 2nd largest
```

---

## C++ Code — Max Heap Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

int kthLargestUsingMaxHeap(const vector<int>& numbers, int k) {
    priority_queue<int> maxHeap(numbers.begin(), numbers.end());

    // Remove the first K - 1 largest values.
    for (int i = 1; i < k; i++) {
        maxHeap.pop();
    }

    return maxHeap.top();
}

int main() {
    vector<int> numbers = {3, 2, 1, 5, 6, 4};

    cout << "2nd largest: "
         << kthLargestUsingMaxHeap(numbers, 2) << endl;

    return 0;
}
```

**Output:**

```text
2nd largest: 5
```

### Complexity

```text
Build heap:  O(N)
K - 1 pops: O(K log N)

Total time:  O(N + K log N)
Space:       O(N)
```

# Method 4: Quickselect (Best Average Time)

## Main Idea

Quickselect uses partitioning like Quicksort, but it searches only one side.

For Kth largest:

```text
target index in ascending order = N - K
```

Example:

```text
nums = [3, 2, 1, 5, 6, 4]
N = 6, K = 2

Target index = 6 - 2 = 4

Sorted ascending: [1, 2, 3, 4, 5, 6]
                              ↑
                         index 4 = 5
```

---

## Partition Idea

```text
smaller values | pivot | larger values
```

If pivot lands at index `N - K`, it is the Kth largest value.

```text
If target index is left of pivot → search left part only
If target index is right of pivot → search right part only
```

---

## C++ Code — Quickselect Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

int partitionArray(vector<int>& numbers, int left, int right, int pivotIndex) {
    int pivot = numbers[pivotIndex];
    swap(numbers[pivotIndex], numbers[right]);

    int storeIndex = left;

    for (int i = left; i < right; i++) {
        if (numbers[i] <= pivot) {
            swap(numbers[i], numbers[storeIndex]);
            storeIndex++;
        }
    }

    swap(numbers[storeIndex], numbers[right]);
    return storeIndex;
}

int kthLargestQuickselect(vector<int>& numbers, int k) {
    int targetIndex = static_cast<int>(numbers.size()) - k;
    int left = 0;
    int right = static_cast<int>(numbers.size()) - 1;

    mt19937 generator(random_device{}());

    while (left <= right) {
        uniform_int_distribution<int> choosePivot(left, right);
        int pivotIndex = partitionArray(numbers, left, right, choosePivot(generator));

        if (pivotIndex == targetIndex) {
            return numbers[pivotIndex];
        }

        if (targetIndex < pivotIndex) {
            right = pivotIndex - 1;
        } else {
            left = pivotIndex + 1;
        }
    }

    return -1; // Invalid K
}

int main() {
    vector<int> numbers = {3, 2, 1, 5, 6, 4};

    cout << "2nd largest: "
         << kthLargestQuickselect(numbers, 2) << endl;

    return 0;
}
```

**Output:**

```text
2nd largest: 5
```

### Complexity

| Case | Time | Extra Space |
|---|---:|---:|
| Average | `O(N)` | `O(1)` |
| Worst case | `O(N²)` | `O(1)` |

The function changes the input array while partitioning.

---

## Kth Smallest vs. Kth Largest

| Task | Heap of Size K | Heap Top |
|---|---|---|
| Kth smallest | Max heap | Largest among K smallest = Kth smallest |
| Kth largest | Min heap | Smallest among K largest = Kth largest |

```text
Kth smallest → keep K small values → top is the largest of them
Kth largest  → keep K large values → top is the smallest of them
```

---

## Special Cases

### K = 1

```text
Kth largest = maximum value
```

### K = N

```text
Kth largest = minimum value
```

### Duplicates

```text
nums = [5, 5, 5, 5]
K = 2

Answer = 5
```

Duplicates are counted separately.

### Negative Values

```text
nums = [-1, -2, -3, -4]
K = 2

Sorted descending: [-1, -2, -3, -4]
Answer = -2
```

---

## Comparison

| Method | Time | Extra Space | When to Use |
|---|---:|---:|---|
| Sort | `O(N log N)` | `O(log N)` typical | Simplest solution. |
| Min heap of K | `O(N log K)` | `O(K)` | Streams or K much smaller than N. |
| Max heap of N | `O(N + K log N)` | `O(N)` | Need to pop several largest values. |
| Quickselect | `O(N)` average | `O(1)` | Fast one-time query. |

## Interview Questions 🎯

### 1. Why use a min heap of size K for Kth largest?

It keeps the K largest values. The smallest among them is the Kth largest.

### 2. Why not use a max heap of size K for Kth largest?

Its top would be the largest value, not the Kth largest.

### 3. Which method is best for stream input?

A min heap of size K.

### 4. What is the Quickselect target index for Kth largest?

```text
N - K
```

### 5. Does Quickselect sort the complete array?

No. It partitions only the side that contains the target index.

### 6. What is Quickselect’s worst-case time complexity?

`O(N²)`.

### 7. How do duplicates affect the answer?

They count as separate values; the question asks Kth largest, not Kth distinct largest.
