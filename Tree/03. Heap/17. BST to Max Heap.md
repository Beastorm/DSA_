# Convert a BST to a Max-Heap-Ordered Tree

> Rearrange the **values** of a BST so every parent is greater than or equal to its children, while keeping the same tree structure.

---

## Important Correction ⚠️

A non-trivial tree cannot be both a strict BST and a max heap at the same time when it has a right child.

```text
BST rule for a right child:
right child > parent

Max-heap rule for a right child:
parent ≥ right child
```

These rules conflict.

```text
      parent
          \
        right child

BST:      parent < right child
Max heap: parent ≥ right child
```

So after conversion:

```text
✓ Values are preserved
✓ Tree structure is preserved
✓ Max-heap order is satisfied
✗ BST property is no longer satisfied
```

---

## Example

### Input BST

```text
       4
      / \
     2   6
    / \ / \
   1  3 5  7
```

```text
BST inorder: [1, 2, 3, 4, 5, 6, 7]
```

### Output Max-Heap-Ordered Tree

```text
       7
      / \
     3   6
    / \ / \
   1  2 4  5
```

```text
Max heap order:
7 ≥ 3, 6 ✓
3 ≥ 1, 2 ✓
6 ≥ 4, 5 ✓
```

But it is not a BST anymore:

```text
Right child of 7 is 6
6 < 7 ✗ (BST property breaks, as expected)
```

---

## Main Idea 💡

Use two traversals:

```text
1. Inorder traversal
   → gives BST values in ascending sorted order

2. Postorder traversal
   → visits children before parent
```

Fill nodes in **postorder** using sorted values in ascending order.

```text
Small values go to children first.
Large values go to parents later.
```

That guarantees:

```text
parent value > child values
```

---

## Why Inorder Gives Sorted Values

For a BST:

```text
Inorder = Left → Root → Right
```

```text
       4
      / \
     2   6
    / \ / \
   1  3 5  7

Inorder: 1, 2, 3, 4, 5, 6, 7
```

Store these values:

```text
values = [1, 2, 3, 4, 5, 6, 7]
```

---

## Why Postorder Creates Max Heap Order

Postorder visits:

```text
Left → Right → Root
```

For the original tree:

```text
Postorder node positions:
1 → 3 → 2 → 5 → 7 → 6 → 4
```

Assign ascending values in that same order:

```text
Node position 1 → value 1
Node position 3 → value 2
Node position 2 → value 3
Node position 5 → value 4
Node position 7 → value 5
Node position 6 → value 6
Node position 4 → value 7
```

Children are visited before parents, so children receive smaller values.

```text
Parent is assigned later → parent receives a larger value ✓
```

---

## Step-by-Step Value Assignment

### Start with Sorted Values

```text
[1, 2, 3, 4, 5, 6, 7]
```

### Fill in Postorder

```text
Original positions:              New values:

       4                              7
      / \                            / \
     2   6                          3   6
    / \ / \                        / \ / \
   1  3 5  7                      1  2 4  5
```

```text
Postorder assignment:

old node 1 → 1
old node 3 → 2
old node 2 → 3
old node 5 → 4
old node 7 → 5
old node 6 → 6
old node 4 → 7
```

---

## Algorithm

```text
1. Run inorder traversal and store all node values.
   The values are sorted because input is a BST.

2. Set index = 0.

3. Run postorder traversal:
      a. Convert left subtree.
      b. Convert right subtree.
      c. Set current node value = values[index].
      d. Increase index.

4. Tree now follows max-heap order.
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    vector<int> sortedValues;
    int index = 0;

    void inorder(TreeNode* root) {
        if (root == nullptr) return;

        inorder(root->left);
        sortedValues.push_back(root->val);
        inorder(root->right);
    }

    void fillPostorder(TreeNode* root) {
        if (root == nullptr) return;

        fillPostorder(root->left);
        fillPostorder(root->right);

        // Children are filled first with smaller values.
        root->val = sortedValues[index++];
    }

public:
    void convertToMaxHeap(TreeNode* root) {
        sortedValues.clear();
        index = 0;

        // Step 1: collect sorted BST values.
        inorder(root);

        // Step 2: assign values in postorder.
        fillPostorder(root);
    }
};

void printLevelOrder(TreeNode* root) {
    if (root == nullptr) return;

    queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        TreeNode* current = q.front();
        q.pop();

        cout << current->val << " ";

        if (current->left) q.push(current->left);
        if (current->right) q.push(current->right);
    }

    cout << endl;
}

void printInorder(TreeNode* root) {
    if (root == nullptr) return;
    printInorder(root->left);
    cout << root->val << " ";
    printInorder(root->right);
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this BST:
           4
          / \
         2   6
        / \ / \
       1  3 5  7
    */
    TreeNode* root = new TreeNode(4);
    root->left = new TreeNode(2);
    root->right = new TreeNode(6);
    root->left->left = new TreeNode(1);
    root->left->right = new TreeNode(3);
    root->right->left = new TreeNode(5);
    root->right->right = new TreeNode(7);

    cout << "BST inorder before: ";
    printInorder(root);
    cout << endl;

    Solution solution;
    solution.convertToMaxHeap(root);

    cout << "Max-heap level order: ";
    printLevelOrder(root);

    cout << "Inorder after: ";
    printInorder(root);
    cout << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
BST inorder before: 1 2 3 4 5 6 7
Max-heap level order: 7 3 6 1 2 4 5
Inorder after: 1 3 2 7 4 6 5
```

The inorder output after conversion is not sorted, which confirms that the tree is no longer a BST.

---

## Important Structure Note

This conversion preserves the original shape of the BST.

```text
If original structure is complete:
result has complete structure + max-heap order
→ it is a true binary max heap

If original structure is not complete:
result has max-heap order, but is not a complete binary heap
```

The code guarantees **max-heap order**, not completeness of an arbitrary BST shape.

---

## Edge Cases

### Empty Tree

```text
root = NULL
```

Nothing changes.

### Single Node

```text
  5
```

```text
Result: 5
```

A single node is both a BST and a max heap.

### Left-Skewed BST

```text
    3
   /
  2
 /
1
```

```text
Inorder values: 1, 2, 3
Postorder positions: 1, 2, 3

Result values stay:
    3
   /
  2
 /
1
```

It follows max-heap order.

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(N)` | One inorder pass and one postorder pass. |
| Extra space | `O(N)` | Sorted-values array stores all values. |

The recursion stack needs `O(H)` extra space, where `H` is the tree height. The `O(N)` array dominates overall space.

## Interview Questions 🎯

### 1. Why is it impossible to keep strict BST and max-heap order together?

A BST right child must be greater than its parent, but a max-heap parent must be greater than or equal to its right child.

### 2. Why use inorder traversal first?

Inorder traversal of a BST gives values in sorted ascending order.

### 3. Why use postorder for assignment?

Postorder visits children before their parent. Assigning small-to-large values gives parents larger values.

### 4. Is the result still a BST?

No. Values are rearranged to satisfy max-heap order, so BST ordering is lost.

### 5. Does the algorithm change tree structure?

No. It changes only node values.

### 6. Is the result always a complete binary heap?

Only if the original BST shape was complete. The algorithm preserves shape.

### 7. What is the time complexity?

`O(N)`.
