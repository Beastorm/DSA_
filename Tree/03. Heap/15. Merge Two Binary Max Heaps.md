# Merge Two Binary Max Heaps

> Given two max heaps stored as arrays, combine them into one valid max heap.

A max heap follows:

```text
parent ≥ left child
parent ≥ right child
```

---

## Example

```text
Heap A:                 Heap B:

       10                    12
      /  \                  /  \
     5    6                7    9
    /
   2
```

```text
A = [10, 5, 6, 2]
B = [12, 7, 9]
```

---

## Main Idea 💡

Do not try to merge heaps like sorted arrays. Heap arrays are not fully sorted.

Instead:

```text
1. Concatenate both arrays.
2. Build one max heap from the combined array.
```

```text
A + B = [10, 5, 6, 2, 12, 7, 9]
```

Then use bottom-up heapify.

---

## Why Is Concatenation Not Enough?

Both original arrays are valid max heaps, but the combined array may not be one.

```text
Combined array:
[10, 5, 6, 2, 12, 7, 9]

As a tree:

          10
         /  \
        5    6
       / \  / \
      2  12 7  9
```

Problems:

```text
5 < 12 ✗
6 < 7  ✗
6 < 9  ✗
```

So we must heapify the combined array.

---

## Bottom-Up Heapify

For an array of size `N`:

```text
last internal node = (N / 2) - 1
```

For `N = 7`:

```text
last internal node = (7 / 2) - 1 = 2
```

Heapify nodes in reverse order:

```text
index 2 → index 1 → index 0
```

Leaf nodes do not need heapifying because they have no children.

---

## Step-by-Step Heapify Trace

### Step 1: Concatenate

```text
A = [10, 5, 6, 2]
B = [12, 7, 9]

merged = [10, 5, 6, 2, 12, 7, 9]
```

```text
          10  (0)
         /  \
        5    6  (1, 2)
       / \  / \
      2  12 7  9  (3, 4, 5, 6)
```

---

### Step 2: Heapify Index 2

```text
node = 6
children = 7, 9

largest = 9 → swap 6 and 9
```

```text
[10, 5, 9, 2, 12, 7, 6]
```

---

### Step 3: Heapify Index 1

```text
node = 5
children = 2, 12

largest = 12 → swap 5 and 12
```

```text
[10, 12, 9, 2, 5, 7, 6]
```

---

### Step 4: Heapify Index 0

```text
node = 10
children = 12, 9

largest = 12 → swap 10 and 12
```

```text
[12, 10, 9, 2, 5, 7, 6]
```

Final heap as a tree:

```text
          12
         /  \
        10   9
       / \  / \
      2   5 7  6
```

```text
12 ≥ 10, 9 ✓
10 ≥ 2, 5  ✓
9  ≥ 7, 6  ✓
```

---

## Important Note About Output

A heap does not have one unique array representation.

For the same values, more than one valid max-heap array may exist.

```text
[12, 10, 9, 2, 5, 7, 6]  ✓
[12, 10, 9, 2, 5, 6, 7]  ✓
```

Both are valid because every parent is at least as large as its children.

---

## Algorithm

```text
1. Create merged = A + B.
2. Let N = merged.size().
3. For i from (N / 2 - 1) down to 0:
      heapifyDown(merged, N, i)
4. Return merged.
```

---

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

void heapifyDown(vector<int>& heap, int heapSize, int index) {
    while (true) {
        int largest = index;
        int left = 2 * index + 1;
        int right = 2 * index + 2;

        if (left < heapSize && heap[left] > heap[largest]) {
            largest = left;
        }

        if (right < heapSize && heap[right] > heap[largest]) {
            largest = right;
        }

        // Parent is already larger than both children.
        if (largest == index) break;

        swap(heap[index], heap[largest]);
        index = largest;
    }
}

vector<int> mergeMaxHeaps(const vector<int>& firstHeap,
                          const vector<int>& secondHeap) {
    vector<int> merged;
    merged.reserve(firstHeap.size() + secondHeap.size());

    // Step 1: concatenate both heap arrays.
    merged.insert(merged.end(), firstHeap.begin(), firstHeap.end());
    merged.insert(merged.end(), secondHeap.begin(), secondHeap.end());

    // Step 2: build max heap from bottom to top.
    for (int i = static_cast<int>(merged.size()) / 2 - 1; i >= 0; i--) {
        heapifyDown(merged, static_cast<int>(merged.size()), i);
    }

    return merged;
}

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

int main() {
    vector<int> heapA = {10, 5, 6, 2};
    vector<int> heapB = {12, 7, 9};

    vector<int> mergedHeap = mergeMaxHeaps(heapA, heapB);

    cout << "Merged max heap: ";
    printVector(mergedHeap);

    return 0;
}
```

**Output:**

```text
Merged max heap: [12, 10, 9, 2, 5, 7, 6]
```

## Why Not Sort the Combined Array?

Sorting descending would make a valid max heap:

```text
[12, 10, 9, 7, 6, 5, 2]
```

But sorting is slower.

```text
Concatenate + sort:
O(N + M) + O((N + M) log(N + M))

Concatenate + build heap:
O(N + M) + O(N + M)
= O(N + M) ✓
```

Bottom-up heap construction avoids the extra `log` factor.

---

## Edge Cases

### One Heap Is Empty

```text
A = []
B = [8, 5, 6]

Merged = [8, 5, 6]
```

It is already a valid max heap.

### Both Heaps Are Empty

```text
A = []
B = []

Answer = []
```

### Equal Values

```text
A = [3, 3]
B = [3, 3]

Answer = [3, 3, 3, 3]
```

### One Heap Has Larger Values

```text
A = [3, 2, 1]
B = [100, 99, 98]

The merged heap has 100 at its root.
```

---

## Complexity

Let `N` be size of first heap and `M` be size of second heap.

| Step | Time | Space |
|---|---:|---:|
| Concatenate arrays | `O(N + M)` | `O(N + M)` |
| Bottom-up build heap | `O(N + M)` | `O(1)` extra |
| **Total** | **`O(N + M)`** | **`O(N + M)`** |

> The returned merged array itself uses `O(N + M)` space. The iterative heapify function uses `O(1)` extra space.

## Interview Questions 🎯

### 1. Why can’t we just concatenate two heaps?

Parent-child heap order can break across the new combined array.

### 2. What is the fastest way to merge two heap arrays?

Concatenate them, then use bottom-up heapify.

### 3. What is the time complexity?

`O(N + M)`.

### 4. Why is build heap `O(N)`, not `O(N log N)`?

Most nodes are leaves or near leaves, so they move down only a few levels.

### 5. Is the output heap array unique?

No. Different valid heap layouts can contain the same values.

### 6. Why is sorting not preferred?

Sorting costs `O((N+M) log(N+M))`, which is slower than heapifying.
