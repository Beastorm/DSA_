# Building a Heap — Two Methods

> Build a **min heap** from an array.

A min heap follows:

```text
parent ≤ left child
parent ≤ right child
```

Example input:

```text
[4, 1, 2, 6, 7, 3, 8, 5]
```

---

## The Input as a Complete Binary Tree

```text
         4  (index 0)
        / \
       1   2  (1, 2)
      / \ / \
     6  7 3  8  (3, 4, 5, 6)
    /
   5  (7)
```

This is not a min heap because:

```text
4 > 1 ✗
6 > 5 ✗
```

---

# Method 1: Insert One by One — `O(N log N)`

## Simple Idea

Start with an empty heap.

For every input value:

```text
1. Add the value at the end.
2. Bubble it up until heap property is restored.
```

```text
Insert → Bubble Up
```

---

## Step-by-Step Example

Build a min heap from:

```text
[4, 1, 2, 6, 7, 3, 8, 5]
```

```text
Insert 4:
[4]
```

```text
Insert 1:
[4, 1]
    ↑
1 < parent 4 → swap

[1, 4]
```

```text
Insert 2:
[1, 4, 2]

2 > parent 1 → no swap
```

```text
Insert 6, 7, 3, 8:
[1, 4, 2, 6, 7, 3, 8]
```

```text
Insert 5:
[1, 4, 2, 6, 7, 3, 8, 5]
                       ↑
parent of index 7 = index 3, value = 6

5 < 6 → swap

[1, 4, 2, 5, 7, 3, 8, 6] ✓
```

> Note: The last insertion **does** bubble up once because `5 < 6`.

---

## C++ Code — Method 1 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class MinHeap {
    vector<int> heap;

    int parent(int index) const {
        return (index - 1) / 2;
    }

    void bubbleUp(int index) {
        while (index > 0 && heap[index] < heap[parent(index)]) {
            swap(heap[index], heap[parent(index)]);
            index = parent(index);
        }
    }

public:
    void insert(int value) {
        heap.push_back(value);
        bubbleUp(static_cast<int>(heap.size()) - 1);
    }

    void buildHeap(const vector<int>& input) {
        for (int value : input) {
            insert(value);
        }
    }

    void print() const {
        cout << "[";
        for (int i = 0; i < heap.size(); i++) {
            cout << heap[i];
            if (i + 1 < heap.size()) cout << ", ";
        }
        cout << "]\n";
    }
};

int main() {
    vector<int> input = {4, 1, 2, 6, 7, 3, 8, 5};

    MinHeap minHeap;
    minHeap.buildHeap(input);

    cout << "Heap built by insertion: ";
    minHeap.print();

    return 0;
}
```

**Output:**

```text
Heap built by insertion: [1, 4, 2, 5, 7, 3, 8, 6]
```

---

## Why Is Method 1 `O(N log N)`?

Each insertion may bubble up to the root.

```text
Heap height = O(log N)
```

```text
N values × O(log N) work per insertion
= O(N log N)
```

This is useful when values arrive one by one.

# Method 2: Bottom-Up Heapify — `O(N)` ⚡

## Simple Idea

Copy the full array first. Then heapify internal nodes from bottom to top.

```text
1. Leaves are already valid heaps.
2. Start at the last internal node.
3. Heapify each internal node down to index 0.
```

```text
last internal node = (N / 2) - 1
```

For `N = 8`:

```text
last internal node = (8 / 2) - 1 = 3
```

---

## Why Skip Leaf Nodes?

Leaf nodes have no children, so they already follow heap property.

```text
Indexes:  0  1  2  3  4  5  6  7
Values:  [4, 1, 2, 6, 7, 3, 8, 5]

Internal nodes: 0, 1, 2, 3
Leaf nodes:         4, 5, 6, 7
```

```text
         4
        / \
       1   2
      / \ / \
     6  7 3  8
    /
   5

Leaves: 7, 3, 8, 5 → no children → no heapify needed
```

---

## Bottom-Up Heapify Walkthrough

### Initial Array

```text
[4, 1, 2, 6, 7, 3, 8, 5]
```

### Heapify Index 3

```text
index 3 = 6
left child index 7 = 5

5 < 6 → swap

[4, 1, 2, 5, 7, 3, 8, 6]
```

### Heapify Index 2

```text
index 2 = 2
children = 3, 8

2 is already smallest → no change
```

### Heapify Index 1

```text
index 1 = 1
children = 5, 7

1 is already smallest → no change
```

### Heapify Index 0

```text
index 0 = 4
children = 1, 2

1 is smallest → swap 4 and 1

[1, 4, 2, 5, 7, 3, 8, 6]
```

Now index 1 has value `4` and children `5`, `7`.

```text
4 is already smallest → done
```

Final heap:

```text
[1, 4, 2, 5, 7, 3, 8, 6]
```

---

## Final Heap as a Tree

```text
         1
        / \
       4   2
      / \ / \
     5  7 3  8
    /
   6
```

Every parent is smaller than its children. ✅

---

## C++ Code — Method 2 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class MinHeap {
    vector<int> heap;

    int leftChild(int index) const {
        return 2 * index + 1;
    }

    int rightChild(int index) const {
        return 2 * index + 2;
    }

    void heapifyDown(int index) {
        while (true) {
            int smallest = index;
            int left = leftChild(index);
            int right = rightChild(index);

            if (left < heap.size() && heap[left] < heap[smallest]) {
                smallest = left;
            }

            if (right < heap.size() && heap[right] < heap[smallest]) {
                smallest = right;
            }

            if (smallest == index) break;

            swap(heap[index], heap[smallest]);
            index = smallest;
        }
    }

public:
    void buildHeap(const vector<int>& input) {
        heap = input;

        // Heapify every internal node from bottom to top.
        for (int i = static_cast<int>(heap.size()) / 2 - 1; i >= 0; i--) {
            heapifyDown(i);
        }
    }

    void print() const {
        cout << "[";
        for (int i = 0; i < heap.size(); i++) {
            cout << heap[i];
            if (i + 1 < heap.size()) cout << ", ";
        }
        cout << "]\n";
    }
};

int main() {
    vector<int> input = {4, 1, 2, 6, 7, 3, 8, 5};

    MinHeap minHeap;
    minHeap.buildHeap(input);

    cout << "Heap built by bottom-up heapify: ";
    minHeap.print();

    return 0;
}
```

**Output:**

```text
Heap built by bottom-up heapify: [1, 4, 2, 5, 7, 3, 8, 6]
```

---

## Why Is Bottom-Up Heapify `O(N)`?

It may look like every node can move `O(log N)` levels, but most nodes are near the bottom.

```text
Many leaf nodes      → 0 work
Fewer lower nodes    → 1 step
Very few top nodes   → many steps
```

| Height from bottom | Approx. nodes | Max work per node |
|---:|---:|---:|
| `0` (leaves) | `N / 2` | `0` |
| `1` | `N / 4` | `1` |
| `2` | `N / 8` | `2` |
| `3` | `N / 16` | `3` |

```text
Total work ≈
(N/4 × 1) + (N/8 × 2) + (N/16 × 3) + ...

= O(N)
```

> There are many leaves doing no work and very few nodes near the root doing expensive work.

---

## Comparison

| Feature | Insert One by One | Bottom-Up Heapify |
|---|---:|---:|
| Time | `O(N log N)` | `O(N)` ✅ |
| Direction | Bubble up | Heapify down |
| Best use | Values arrive as a stream | All values are known upfront |
| Extra space beyond heap array | `O(1)` | `O(1)` |

---

## When Should You Use Each Method?

```text
Values arrive one at a time  → use insertion
Need dynamic updates         → use insertion

Already have a full array    → use bottom-up heapify
Heap sort / initial heap     → use bottom-up heapify
```

## Interview Questions 🎯

### 1. Why is bottom-up heap construction `O(N)`, not `O(N log N)`?

Most nodes are leaves or near the leaves, so they move down only a few levels.

### 2. Which index is the last internal node?

```text
(N / 2) - 1
```

### 3. Why are leaf nodes already valid heaps?

They have no children, so they cannot violate parent-child heap order.

### 4. Which method should be used when all elements are already in an array?

Bottom-up heapify.

### 5. Which method is useful for streaming input?

Insert one element at a time and bubble up.

### 6. What changes for a max heap?

Use the larger child during heapify and bubble larger values upward.

### 7. Is the heap array fully sorted after building a heap?

No. Only the heap property is guaranteed.
