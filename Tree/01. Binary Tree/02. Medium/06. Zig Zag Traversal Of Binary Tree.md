# Zigzag Traversal of a Binary Tree

> Visit the nodes level by level, but change the direction after every level.

- Level 1: left → right
- Level 2: right → left
- Level 3: left → right
- And so on...

This is also called **spiral traversal**.

---

## Example

```text
          1
        /   \
       2     3
      / \     \
     4   5     6
```

```text
Level 1, left → right:  [1]
Level 2, right → left:  [3, 2]
Level 3, left → right:  [4, 5, 6]
```

**Output:**

```text
[[1], [3, 2], [4, 5, 6]]
```

---

## Simple Idea 💡

Use **level-order traversal** with a queue.

For each level:

1. Take all nodes currently in the queue.
2. Store their values in a vector.
3. Put values from left to right or right to left based on the current direction.
4. Change the direction for the next level.

```text
Queue visits nodes normally:  left → right
Result is stored in zigzag order: changes every level
```

---

## How Do We Reverse a Level?

Suppose the current level has `size` nodes.

```text
leftToRight = true:   store at index i
leftToRight = false:  store at index size - 1 - i
```

For nodes `2, 3`:

```text
Normal order:       [2, 3]
Right-to-left order:[3, 2]
```

---

## Steps

1. If the tree is empty, return an empty result.
2. Put the root in a queue.
3. For every level, create a vector of that level's size.
4. Remove all nodes of the current level from the queue.
5. Store values in the correct zigzag position.
6. Add child nodes to the queue.
7. Reverse the direction for the next level.

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    vector<vector<int>> zigzagLevelOrder(TreeNode* root) {
        vector<vector<int>> result;
        if (root == nullptr) return result;

        queue<TreeNode*> q;
        q.push(root);
        bool leftToRight = true;

        while (!q.empty()) {
            int levelSize = q.size();
            vector<int> level(levelSize);

            for (int i = 0; i < levelSize; i++) {
                TreeNode* current = q.front();
                q.pop();

                // Choose where to store this value.
                int index = leftToRight ? i : levelSize - 1 - i;
                level[index] = current->val;

                if (current->left) q.push(current->left);
                if (current->right) q.push(current->right);
            }

            result.push_back(level);
            leftToRight = !leftToRight;  // Change direction.
        }

        return result;
    }
};

void printResult(const vector<vector<int>>& result) {
    cout << "[";

    for (int i = 0; i < result.size(); i++) {
        cout << "[";
        for (int j = 0; j < result[i].size(); j++) {
            cout << result[i][j];
            if (j + 1 < result[i].size()) cout << ", ";
        }
        cout << "]";
        if (i + 1 < result.size()) cout << ", ";
    }

    cout << "]\n";
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
              1
            /   \
           2     3
          / \     \
         4   5     6
    */
    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(3);
    root->left->left = new TreeNode(4);
    root->left->right = new TreeNode(5);
    root->right->right = new TreeNode(6);

    Solution solution;
    vector<vector<int>> answer = solution.zigzagLevelOrder(root);

    cout << "Zigzag traversal: ";
    printResult(answer);

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Zigzag traversal: [[1], [3, 2], [4, 5, 6]]
```

## Quick Walkthrough

Start with `leftToRight = true`.

| Level | Nodes removed from queue | Direction | Stored result |
|---:|---|---|---|
| 1 | `1` | Left → Right | `[1]` |
| 2 | `2, 3` | Right → Left | `[3, 2]` |
| 3 | `4, 5, 6` | Left → Right | `[4, 5, 6]` |

---

## Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N)` |
| Space | `O(N)` |

- Every node enters and leaves the queue once.
- The queue and the result can store up to `N` node values.

## Interview Questions 🎯

### 1. What is zigzag traversal?
It is level-order traversal where the direction changes at every level.

### 2. Why do we use a queue?
A queue helps us process the tree one level at a time.

### 3. How do we know how many nodes belong to one level?
Use `q.size()` before processing the level.

### 4. Why do we need `leftToRight`?
It tells us whether to store the current level from left to right or right to left.

### 5. Do we need to reverse the level vector after processing it?
No. We place each value directly at its correct index.

### 6. What is the time complexity?
`O(N)` because every node is processed once.

### 7. What is the space complexity?
`O(N)` because the queue and result can store node values.

### 8. Can zigzag traversal be done with two stacks?
Yes. One stack can process the current level and the other can prepare nodes for the next level.
