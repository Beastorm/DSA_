# Maximum Sum Path in a Binary Tree

> Find the largest sum that can be made using any connected path in a binary tree.

The path can start and end at **any node**, but a node cannot be used twice.

---

[Visualize  Maximum Sum Path in a Binary Tree](https://htmlpreview.github.io/?https://github.com/Beastorm/DSA_/blob/main/junk/pages/maxpathsum-visualizer.html)


## Example

```text
        -10
        /  \
       9    20
           /  \
          15   7
```

**Best path:** `15 → 20 → 7`  
**Answer:** `15 + 20 + 7 = 42`

---

## Simple Idea 💡

At every node, check if it can be the **middle** of the best path.

For example, at node `20`, we can make this path:

```text
15 → 20 → 7
```

So, the path sum through a node is:

```text
left branch + node value + right branch
```

But when we return to the parent, we can return only **one branch**:

```text
node value + max(left branch, right branch)
```

This is because a path cannot split into two branches when it continues to the parent.

---

## Important Rule: Ignore Negative Sums

If a child path gives a negative sum, do not include it.

```text
max(0, childPathSum)
```

For example, if the left branch sum is `-4`, using it will reduce the answer. So we use `0` instead.

---

## Steps

For every node:

1. Find the best sum from the left child.
2. Find the best sum from the right child.
3. Ignore negative sums.
4. Update the answer using `left + node + right`.
5. Return the better one-side path to the parent.

```text
              node
             /    \
         left      right

Full path:    left + node + right
Return value: node + max(left, right)
```

## C++ Code

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    int bestSum = INT_MIN;

    int dfs(TreeNode* node) {
        if (node == nullptr) return 0;

        // Get useful sums from both children.
        int leftSum = max(0, dfs(node->left));
        int rightSum = max(0, dfs(node->right));

        // Path that uses this node as the middle.
        bestSum = max(bestSum, leftSum + node->val + rightSum);

        // Return only one side to the parent.
        return node->val + max(leftSum, rightSum);
    }

public:
    int maxPathSum(TreeNode* root) {
        dfs(root);
        return bestSum;
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
            -10
            /  \
           9    20
               /  \
              15   7
    */
    TreeNode* root = new TreeNode(-10);
    root->left = new TreeNode(9);
    root->right = new TreeNode(20);
    root->right->left = new TreeNode(15);
    root->right->right = new TreeNode(7);

    Solution solution;
    cout << "Maximum path sum: " << solution.maxPathSum(root) << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Maximum path sum: 42
```

## Quick Walkthrough

At node `20`:

```text
left sum  = 15
right sum = 7
```

Path through `20`:

```text
15 + 20 + 7 = 42
```

The parent gets only the better side:

```text
20 + max(15, 7) = 35
```

## Complexity

| Item | Complexity |
|---|---:|
| Time | `O(N)` — visit every node once |
| Space | `O(H)` — recursion stack height |

> `bestSum` starts at `INT_MIN` so the code also works when all node values are negative.

## Interview Questions 🎯

### 1. Why do we return only one branch to the parent?
A parent can continue the path through either the left or right branch. It cannot use both branches in the returned path.

### 2. Why do we use `max(0, dfs(child))`?
A negative path makes the total smaller, so we ignore it.

### 3. Why is `bestSum` initialized with `INT_MIN`?
It handles trees with only negative values. For a tree with `-5`, the answer should be `-5`, not `0`.

### 4. What is the difference between `bestSum` and the DFS return value?
- `bestSum` can use both sides: `left + node + right`.
- DFS returns one side: `node + max(left, right)`.

### 5. Does the path need to start from the root?
No. It can start and end at any node.

### 6. What is the answer for a single-node tree?
The value of that node.

### 7. Can this be done without recursion?
Yes, with iterative postorder traversal, but recursion is simpler.

### 8. If the path must start from the root, what changes?
We only find the best path going downward from the root.
