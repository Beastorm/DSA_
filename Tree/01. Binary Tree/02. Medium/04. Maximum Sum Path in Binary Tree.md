# Maximum Sum Path in a Binary Tree

> Find the largest sum of values on **any valid path** in a binary tree.

A path may start and end at **any node**, but it cannot visit a node more than once.

---

## Example

```text
        -10
        /  \
       9    20
           /  \
          15   7
```

**Best path:** `15 → 20 → 7`  
**Maximum sum:** `15 + 20 + 7 = 42`

---

## Key Idea 💡

Treat **every node as the highest (turning) point** of a path.

At a node, a complete path can use:

```text
best path from left + current node + best path from right
```

However, when returning a value to its parent, we may choose **only one side**. Otherwise, the path would branch and no longer be a valid single path.

### Ignore negative branches

A negative branch only decreases the sum, so we ignore it using `max(0, branchSum)`.

---

## DFS Logic

For each node:

1. Get the best downward sum from the left and right child.
2. Replace negative sums with `0`.
3. Update the answer using a path that passes through this node.
4. Return the best **one-sided** downward path to the parent.

```text
              node
             /    \
     left path      right path

Path through node = left + node + right
Return to parent   = node + max(left, right)
```

---

## C++ Implementation

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    int bestSum = INT_MIN;

    int dfs(TreeNode* node) {
        if (node == nullptr) return 0;

        // A negative path is never helpful.
        int leftGain = max(0, dfs(node->left));
        int rightGain = max(0, dfs(node->right));

        // Use this node as the turning point of the path.
        bestSum = max(bestSum, node->val + leftGain + rightGain);

        // A parent can extend through only one child.
        return node->val + max(leftGain, rightGain);
    }

public:
    int maxPathSum(TreeNode* root) {
        dfs(root);
        return bestSum;
    }
};
```

---

## Quick Walkthrough

At node `20` in the example:

- left gain = `15`
- right gain = `7`
- path through `20` = `15 + 20 + 7 = 42` ✅

The value returned upward is only:

```text
20 + max(15, 7) = 35
```

## Complexity

| Resource | Complexity | Why |
|---|---:|---|
| Time | `O(N)` | Each node is visited once. |
| Space | `O(H)` | Recursive call stack, where `H` is tree height. |

> **Important:** Initializing `bestSum` with `INT_MIN` correctly handles a tree where every value is negative.

## Interview Questions 🎯

### 1. Why do we return only one branch to the parent?
Because a path can go in only one direction when it moves up to the parent. So we choose the better branch: **left or right**.

### 2. Why use `max(0, dfs(child))`?
If a branch sum is negative, adding it makes the answer smaller. So we ignore it and use `0` instead.

### 3. Why is `bestSum` set to `INT_MIN`?
It handles a tree where all values are negative. For example, for `[-5]`, the answer should be `-5`, not `0`.

### 4. What is the difference between `bestSum` and the value returned by DFS?
- `bestSum` checks a full path: `left + node + right`.
- DFS returns only one side: `node + max(left, right)`.

### 5. Does the path have to start from the root?
No. The path can start and end at **any node**.

### 6. What is the answer for one node?
That node’s value is the maximum path sum.

### 7. Can we solve it without recursion?
Yes, by using iterative postorder traversal. But recursion is easier to write and understand.

### 8. If the path must start from the root, what changes?
We only choose the best path going downward from the root. We do not check paths that start elsewhere.
