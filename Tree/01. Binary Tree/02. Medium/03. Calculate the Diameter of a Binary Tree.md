# Diameter of a Binary Tree

> Find the longest path between any two nodes in a binary tree.

The path **does not need to pass through the root**.

In this guide, diameter means the number of **edges** in the longest path.

[Visualize Diameter](https://htmlpreview.github.io/?https://github.com/Beastorm/DSA_/blob/main/junk/pages/diameter-combined.html)

---

## Example

```text
          1
         / \
        2   3
       /
      4
     /
    5
```

The longest path is:

```text
5 → 4 → 2 → 1 → 3
```

It has `4` edges, so:

**Diameter = 4**

---

## Important Idea 💡

Think of every node as the possible **middle point** of the longest path.

At any node:

```text
Diameter through this node = left height + right height
```

Why?

- `left height` = number of edges going down the left side
- `right height` = number of edges going down the right side
- Adding them gives the longest path that passes through the current node.

```text
         node
        /    \
     left    right

path through node = left height + right height
```

We check this for every node and keep the biggest answer.

---

## Approach 1: Brute Force

For every node:

1. Find the height of the left subtree.
2. Find the height of the right subtree.
3. Update the diameter using `leftHeight + rightHeight`.
4. Repeat for all nodes.

### Why is it slow?

The height of the same subtree is calculated again and again.

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int data;
    Node *left, *right;

    Node(int value) : data(value), left(nullptr), right(nullptr) {}
};

class Solution {
    int answer = 0;

    int height(Node* root) {
        if (root == nullptr) return 0;
        return 1 + max(height(root->left), height(root->right));
    }

    void findDiameter(Node* root) {
        if (root == nullptr) return;

        int leftHeight = height(root->left);
        int rightHeight = height(root->right);

        answer = max(answer, leftHeight + rightHeight);

        findDiameter(root->left);
        findDiameter(root->right);
    }

public:
    int diameterOfBinaryTree(Node* root) {
        findDiameter(root);
        return answer;
    }
};

void deleteTree(Node* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
              1
             / \
            2   3
           /
          4
         /
        5
    */
    Node* root = new Node(1);
    root->left = new Node(2);
    root->right = new Node(3);
    root->left->left = new Node(4);
    root->left->left->left = new Node(5);

    Solution solution;
    cout << "Diameter of the binary tree: "
         << solution.diameterOfBinaryTree(root) << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Diameter of the binary tree: 4
```

| Time | Space |
|---:|---:|
| `O(N²)` worst case | `O(H)` recursion stack |

## Approach 2: Optimal DFS (Recommended) ⚡

### Simple Idea

Calculate the height and diameter at the **same time**.

For every node:

1. Get the left subtree height.
2. Get the right subtree height.
3. Update the diameter: `leftHeight + rightHeight`.
4. Return the current node's height to its parent.

```text
return height = 1 + max(leftHeight, rightHeight)
```

Each node is visited only once.

---

## C++ Code — Optimal (Complete Program)

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int data;
    Node *left, *right;

    Node(int value) : data(value), left(nullptr), right(nullptr) {}
};

class Solution {
    int diameter = 0;

    int height(Node* root) {
        if (root == nullptr) return 0;

        int leftHeight = height(root->left);
        int rightHeight = height(root->right);

        // Longest path that passes through this node.
        diameter = max(diameter, leftHeight + rightHeight);

        // Return height to the parent.
        return 1 + max(leftHeight, rightHeight);
    }

public:
    int diameterOfBinaryTree(Node* root) {
        height(root);
        return diameter;
    }
};

void deleteTree(Node* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
              1
             / \
            2   3
           /
          4
         /
        5
    */
    Node* root = new Node(1);
    root->left = new Node(2);
    root->right = new Node(3);
    root->left->left = new Node(4);
    root->left->left->left = new Node(5);

    Solution solution;
    cout << "Diameter of the binary tree: "
         << solution.diameterOfBinaryTree(root) << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Diameter of the binary tree: 4
```

---

## Quick Walkthrough

At node `1` in the example:

```text
left height  = 3   (1 → 2 → 4 → 5)
right height = 1   (1 → 3)
```

So the path through node `1` has:

```text
3 + 1 = 4 edges
```

**Diameter = 4**

---

## Complexity

| Approach | Time | Space |
|---|---:|---:|
| Brute Force | `O(N²)` | `O(H)` |
| Optimal DFS | `O(N)` | `O(H)` |

- `N` = number of nodes
- `H` = height of the tree

> The recursive call stack uses `O(H)` space. In a skewed tree, this can be `O(N)`.

## Interview Questions 🎯

### 1. Does the diameter always pass through the root?
No. The longest path can be completely inside a subtree.

### 2. Why do we use `leftHeight + rightHeight`?
It gives the number of edges in the longest path that passes through the current node.

### 3. What does the `height()` function return?
It returns the height of the subtree, so its parent can use that value.

### 4. Why is the optimal solution `O(N)`?
Every node is visited only once.

### 5. Why is the brute-force solution `O(N²)`?
It calculates subtree heights repeatedly.

### 6. What is the diameter of a single-node tree?
`0`, because there are no edges.

### 7. What is the diameter of an empty tree?
`0`.

### 8. What if the question counts nodes instead of edges?
For a non-empty tree, add `1` to the edge-based diameter. Always check the problem definition.
