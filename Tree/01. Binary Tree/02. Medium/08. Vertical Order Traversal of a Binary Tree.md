# Vertical Order Traversal of a Binary Tree

> Print nodes column by column, from the **leftmost vertical column** to the **rightmost vertical column**.

If multiple nodes are in the same column, this problem asks us to keep them in **level-order (BFS) order**.

---

## Main Idea: Give Every Node a Column Number 💡

Start the root at column `0`.

```text
Move left   → column - 1
Move right  → column + 1
```

```text
               1 (column 0)
              /            \
     2 (column -1)      3 (column +1)
```

All nodes with the same column number belong in the same output list.

---

## Example

```text
                         1 (0)
                       /       \
                  2 (-1)       3 (+1)
                  /    \       /    \
             4 (-2)  10 (0)  9 (0)  11 (+2)
                \
                5 (-1)
                   \
                   6 (0)
```

### Group nodes by their column

```text
Column -2:  [4]
Column -1:  [2, 5]
Column  0:  [1, 10, 9, 6]
Column +1:  [3]
Column +2:  [11]
```

**Output:**

```text
[[4], [2, 5], [1, 10, 9, 6], [3], [11]]
```

## Why Do We Use BFS? 📚

BFS processes nodes level by level, from left to right.

For the example, nodes are removed from the queue in this order:

```text
Level 0:  1
Level 1:  2, 3
Level 2:  4, 10, 9, 11
Level 3:  5
Level 4:  6
```

Look at column `0`:

```text
1   is seen first
10  is seen next
9   is seen after 10
6   is seen last

Column 0 = [1, 10, 9, 6]
```

This matches the requirement: nodes in the same vertical column stay in **level-order sequence**.

## Visual BFS Walkthrough

Each queue item stores:

```text
(node, column)
```

### Start

```text
Queue: [(1, 0)]
Map:   {}
```

### Process node 1

```text
Take: (1, 0)
Add:  column 0 → [1]
Push: (2, -1), (3, +1)

Queue: [(2, -1), (3, +1)]
```

### Process node 2, then node 3

```text
Take: (2, -1)  → column -1: [2]
Push: (4, -2), (10, 0)

Take: (3, +1)  → column +1: [3]
Push: (9, 0), (11, +2)
```

Now the nodes in column `0` are added in this order:

```text
1 → 10 → 9 → 6
```

## How the Map Is Filled

We use this structure:

```text
map<int, vector<int>> columns;
```

```text
map key       = column number
vector value  = nodes in BFS order for that column
```

After BFS, the map looks like this:

```text
columns[-2] = [4]
columns[-1] = [2, 5]
columns[ 0] = [1, 10, 9, 6]
columns[+1] = [3]
columns[+2] = [11]
```

A `map` keeps keys sorted, so iterating through it automatically gives columns from left to right.

---

## Full Algorithm

```text
1. If root is NULL, return an empty answer.
2. Put (root, 0) in a queue.
3. While the queue is not empty:
      a. Remove (node, column).
      b. Add node's value to columns[column].
      c. Put left child in the queue with column - 1.
      d. Put right child in the queue with column + 1.
4. Read the map from smallest column to largest column.
5. Return all column vectors.
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int data;
    Node *left, *right;

    Node(int value) : data(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    vector<vector<int>> verticalOrder(Node* root) {
        vector<vector<int>> answer;
        if (root == nullptr) return answer;

        // column number -> node values in BFS order
        map<int, vector<int>> columns;

        // Each item stores: node and its column number.
        queue<pair<Node*, int>> q;
        q.push({root, 0});

        while (!q.empty()) {
            Node* current = q.front().first;
            int column = q.front().second;
            q.pop();

            columns[column].push_back(current->data);

            if (current->left) {
                q.push({current->left, column - 1});
            }

            if (current->right) {
                q.push({current->right, column + 1});
            }
        }

        // map is already sorted from smallest column to largest column.
        for (auto& entry : columns) {
            answer.push_back(entry.second);
        }

        return answer;
    }
};

void printResult(const vector<vector<int>>& result) {
    cout << "[";

    for (int i = 0; i < result.size(); i++) {
        cout << "[";
        for (int j = 0; j < result[i].size(); j++) {
            cout << result[i][j];
            if (j + 1 < result[i].size()) cout << ", ";
        }
        cout << "]";
        if (i + 1 < result.size()) cout << ", ";
    }

    cout << "]\n";
}

void deleteTree(Node* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
                             1
                           /   \
                          2     3
                         / \   / \
                        4  10 9  11
                         \
                          5
                           \
                            6
    */
    Node* root = new Node(1);
    root->left = new Node(2);
    root->right = new Node(3);
    root->left->left = new Node(4);
    root->left->right = new Node(10);
    root->right->left = new Node(9);
    root->right->right = new Node(11);
    root->left->left->right = new Node(5);
    root->left->left->right->right = new Node(6);

    Solution solution;
    cout << "Vertical order traversal: ";
    printResult(solution.verticalOrder(root));

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Vertical order traversal: [[4], [2, 5], [1, 10, 9, 6], [3], [11]]
```

## Important Note: Vertical Order vs. Vertical Traversal

Different platforms use two slightly different rules.

### This Problem: Keep BFS Order

If nodes share a column, keep the order in which BFS sees them.

```text
Column 0: [1, 10, 9, 6]
```

### Another Problem Variant: Sort Same Position by Value

Some platforms ask you to sort nodes when they share the **same row and column**. For that version, people use:

```cpp
map<int, map<int, multiset<int>>>
```

That can change the order of values like `10` and `9` to `9, 10`.

> Always read the tie-breaking rule in the question. This guide follows the rule in this problem: **level-order order**.

## Special Cases

### Empty Tree

```text
root = NULL
Answer = []
```

### Single Node Tree

```text
  1
```

```text
Column 0: [1]
Answer: [[1]]
```

### Left-Skewed Tree

```text
    1 (0)
   /
  2 (-1)
 /
3 (-2)
```

```text
Answer: [[3], [2], [1]]
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(N log N)` | Each map insertion takes `O(log N)` in the worst case. |
| Space | `O(N)` | The map, queue, and answer can store all nodes. |

- `N` = number of nodes in the tree.

## Interview Questions 🎯

### 1. Why do we give every node a column number?

It tells us which vertical line the node belongs to.

```text
left child  → parent column - 1
right child → parent column + 1
```

### 2. Why is BFS used instead of DFS here?

BFS naturally keeps nodes in level order.

```text
BFS: root level → next level → next level
```

So nodes in the same column are added in the required order.

### 3. Why use a map?

The map stores columns in sorted order:

```text
-2, -1, 0, 1, 2
```

This makes the output go from leftmost to rightmost.

### 4. What does the queue store?

A pair:

```text
(node pointer, column number)
```

### 5. What happens when two nodes share a column?

They are added to the same vector in BFS order.

```text
Example: column 0 = [1, 10, 9, 6]
```

### 6. What is the time complexity?

`O(N log N)` when using an ordered `map`.

### 7. Can it be made close to `O(N)`?

Yes. Use an `unordered_map` and track the minimum and maximum column. But the ordered-map solution is simpler and keeps columns sorted automatically.
