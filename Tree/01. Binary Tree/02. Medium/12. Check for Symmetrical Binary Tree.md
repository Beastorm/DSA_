# Check for a Symmetrical Binary Tree

> Return `true` if a binary tree is a mirror image of itself around its centre; otherwise return `false`.

Imagine drawing a vertical line through the root. The left and right sides must match in **opposite directions**.

---

## Example 1 — Symmetric Tree ✅

```text
              1
            /   \
           2     2
          / \   / \
         3   4 4   3
```

The matching mirror pairs are:

```text
left side              right side

2        ↔             2
3 (left) ↔             3 (right)
4 (right)↔             4 (left)
```

```text
Result: true
```

**Original visual references:** [Symmetric tree image](https://www.helpmestudybro.com/wp-content/uploads/2021/01/SymmetricTree.png) · [Mirror-comparison diagram](https://static.takeuforward.org/content/8.png-JBFezt2Z)

---

## Example 2 — Not Symmetric ❌

```text
              1
            /   \
           2     2
            \     \
             3     3
```

At the nodes with value `2`:

```text
left subtree's right child = 3
right subtree's left child = NULL
```

These positions should match, but they do not.

```text
Result: false
```

---

## Main Idea 💡

Do not compare both sides in the same direction.

```text
Wrong comparison:
left.left  with right.left
left.right with right.right
```

For a mirror, compare in **opposite directions**:

```text
Correct mirror comparison:
left.left  with right.right
left.right with right.left
```

---

## Mirror Diagram

```text
                root
               /    \
              A      B
             / \    / \
            C   D  E   F

For A and B to be mirrors:

A.data  must equal B.data
C       must mirror F
D       must mirror E
```

```text
isMirror(A, B) =
    A.data == B.data
    AND isMirror(A.left,  B.right)
    AND isMirror(A.right, B.left)
```

---

## Base Cases

### Case 1: Both nodes are empty

```text
A = NULL, B = NULL
```

Both positions match, so return `true`.

### Case 2: Only one node is empty

```text
A = 3, B = NULL
```

The structure is different, so return `false`.

### Case 3: Values are different

```text
A = 3, B = 4
```

The values do not match, so return `false`.

---

## Step-by-Step Walkthrough

For the symmetric example:

```text
              1
            /   \
           2     2
          / \   / \
         3   4 4   3
```

Start by comparing the root's children:

```text
isMirror(2, 2) → values match
```

Then compare opposite children:

```text
isMirror(3, 3)  → left.left  with right.right → match
isMirror(4, 4)  → left.right with right.left  → match
```

Finally, all children below these nodes are `NULL` on both sides.

```text
All mirror checks are true → tree is symmetric
```

---

## Full Algorithm

```text
1. If root is NULL, return true.
2. Compare root->left and root->right using isMirror().
3. In isMirror(leftNode, rightNode):
      a. If both are NULL, return true.
      b. If only one is NULL, return false.
      c. If values are different, return false.
      d. Compare leftNode->left with rightNode->right.
      e. Compare leftNode->right with rightNode->left.
4. Return the result.
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int data;
    Node *left, *right;

    Node(int value) : data(value), left(nullptr), right(nullptr) {}
};

class Solution {
    bool isMirror(Node* leftNode, Node* rightNode) {
        // Both positions are empty, so they match.
        if (leftNode == nullptr && rightNode == nullptr) {
            return true;
        }

        // Only one position has a node, so structures differ.
        if (leftNode == nullptr || rightNode == nullptr) {
            return false;
        }

        // Values must match, and children must match in opposite order.
        return leftNode->data == rightNode->data &&
               isMirror(leftNode->left, rightNode->right) &&
               isMirror(leftNode->right, rightNode->left);
    }

public:
    bool isSymmetric(Node* root) {
        if (root == nullptr) return true;

        return isMirror(root->left, root->right);
    }
};

void deleteTree(Node* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this symmetric tree:
                  1
                /   \
               2     2
              / \   / \
             3   4 4   3
    */
    Node* root = new Node(1);
    root->left = new Node(2);
    root->right = new Node(2);
    root->left->left = new Node(3);
    root->left->right = new Node(4);
    root->right->left = new Node(4);
    root->right->right = new Node(3);

    Solution solution;
    cout << boolalpha << "Is the tree symmetric? "
         << solution.isSymmetric(root) << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Is the tree symmetric? true
```

## Special Cases

### Empty Tree

```text
root = NULL
```

An empty tree is symmetric, so the answer is `true`.

### Single Node Tree

```text
  1
```

There is nothing on either side to compare.

```text
Answer = true
```

### Same Values but Wrong Structure

```text
      1
     / \
    2   2
   /     \
  3       3
```

This is symmetric because `3` is on the outside on both sides.

```text
      1
     / \
    2   2
     \   \
      3   3
```

This is not symmetric because both `3` nodes are on the right side of their parent.

---

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(N)` | Every node is checked at most once. |
| Extra space | `O(H)` | Recursive call stack, where `H` is tree height. |

- In a balanced tree, `H` is about `log N`.
- In a skewed tree, `H` can become `N`.

## Interview Questions 🎯

### 1. What does symmetric mean for a binary tree?

The left and right subtrees are mirror images.

```text
left.left  matches right.right
left.right matches right.left
```

### 2. Why can’t we compare left.left with right.left?

That checks whether subtrees are equal in the same direction, not mirrored.

```text
Mirror comparison must cross over.
```

### 3. Is a tree with the same values always symmetric?

No. The nodes must also be in mirrored positions.

```text
Same values + wrong structure = not symmetric
```

### 4. Is an empty tree symmetric?

Yes. Both its left and right sides are empty.

### 5. What is the time complexity?

`O(N)` because the tree is checked once.

### 6. What is the space complexity?

`O(H)` because of recursion, where `H` is the height of the tree.

### 7. Can this be solved iteratively?

Yes. Put pairs of mirror nodes into a queue and compare them one pair at a time.
