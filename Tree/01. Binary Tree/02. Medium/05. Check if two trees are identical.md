# Check if Two Binary Trees Are Identical

> Return `true` if two binary trees have the same **structure** and the same **node values**. Otherwise, return `false`.

Two trees are identical only when, for every matching position:

1. Both nodes have the same value.
2. Their left subtrees are identical.
3. Their right subtrees are identical.

---

## Example 1 — Identical Trees ✅

```text
Tree 1:              Tree 2:
      1                    1
     / \                  / \
    2   3                2   3
       / \                  / \
      4   5                4   5
```

**Output:** `true`

Both the values and the tree structure are the same.

---

## Example 2 — Not Identical ❌

```text
Tree 1:              Tree 2:
      1                    1
     / \                  / \
    2   3                2   3
       / \                /
      4   5              4
```

**Output:** `false`

Tree 1 has node `5`, but Tree 2 does not. Their structures are different.

---

## Simple Idea 💡

Compare both trees **at the same time**.

For every pair of nodes:

```text
1. Both are empty        → true
2. Only one is empty     → false
3. Values are different  → false
4. Otherwise, compare left children and right children
```

```text
same(tree1, tree2) =
    values are equal
    AND left subtrees are same
    AND right subtrees are same
```

---

## Steps

1. If both nodes are `NULL`, return `true`.
2. If one node is `NULL` and the other is not, return `false`.
3. If the node values are different, return `false`.
4. Recursively compare their left children.
5. Recursively compare their right children.

---

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int data;
    Node *left, *right;

    Node(int value) : data(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    bool isIdentical(Node* root1, Node* root2) {
        // Both trees have ended at this point.
        if (root1 == nullptr && root2 == nullptr) return true;

        // One tree has a node but the other does not.
        if (root1 == nullptr || root2 == nullptr) return false;

        // Current values must match, and both child pairs must match.
        return root1->data == root2->data &&
               isIdentical(root1->left, root2->left) &&
               isIdentical(root1->right, root2->right);
    }
};

void deleteTree(Node* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create Tree 1:
          1
         / \
        2   3
           / \
          4   5
    */
    Node* root1 = new Node(1);
    root1->left = new Node(2);
    root1->right = new Node(3);
    root1->right->left = new Node(4);
    root1->right->right = new Node(5);

    // Create the same Tree 2.
    Node* root2 = new Node(1);
    root2->left = new Node(2);
    root2->right = new Node(3);
    root2->right->left = new Node(4);
    root2->right->right = new Node(5);

    Solution solution;
    cout << boolalpha << "Are the trees identical? "
         << solution.isIdentical(root1, root2) << endl;

    deleteTree(root1);
    deleteTree(root2);
    return 0;
}
```

**Output:**

```text
Are the trees identical? true
```

## Quick Walkthrough

Start with both root nodes:

```text
1 and 1 → same
```

Then compare their children:

```text
2 and 2 → same
3 and 3 → same
4 and 4 → same
5 and 5 → same
```

All matching nodes have the same values and positions, so the answer is `true`.

---

## Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N + M)` |
| Space | `O(H)` |

- `N` and `M` are the number of nodes in the two trees.
- `H` is the maximum height of the trees, used by recursion.

> The function can stop early as soon as it finds a different value or structure.

---

## Interview Questions 🎯

### 1. When are two trees identical?
When they have the same structure and the same value at every matching node.

### 2. What if both current nodes are `NULL`?
Return `true`. Both trees are empty at that position.

### 3. What if only one current node is `NULL`?
Return `false`. Their structures are different.

### 4. Do the trees need the same values only?
No. Their positions must also be the same. Same values with a different structure means the trees are not identical.

### 5. Can we compare the trees using inorder traversal only?
No. Different tree structures can have the same inorder traversal. Compare matching nodes directly instead.

### 6. What is the time complexity?
`O(N + M)` in the worst case.

### 7. What is the space complexity?
`O(H)` because of the recursive call stack.

### 8. Can this be solved iteratively?
Yes. Use a queue or stack and store pairs of matching nodes.
