# Boundary Traversal of a Binary Tree

> Print the boundary nodes of a binary tree in **anti-clockwise** order, starting from the root.

The boundary has three parts:

```text
Root → Left boundary → Leaf nodes → Right boundary (bottom to top)
```

---

## Example

```text
               1
             /   \
            2     7
           /       \
          3         8
           \       /
            4     9
           / \   / \
          5   6 10 11
```

```text
Root:           1
Left boundary:   2, 3, 4
Leaf nodes:      5, 6, 10, 11
Right boundary:  9, 8, 7
```

**Output:**

```text
[1, 2, 3, 4, 5, 6, 10, 11, 9, 8, 7]
```

---

## Simple Idea 💡

Do the work in three parts:

1. Add the root.
2. Add the **left boundary** from top to bottom, without leaf nodes.
3. Add **all leaf nodes** from left to right.
4. Add the **right boundary** from bottom to top, without leaf nodes.

> Leaf nodes are not added to the left or right boundary. This prevents adding them twice.

---

## How Each Part Works

### 1. Left Boundary

Start at `root->left`.

- Add the current node if it is not a leaf.
- Move left if possible.
- Otherwise, move right.

```text
For the example: 2 → 3 → 4
```

### 2. Leaf Nodes

Use DFS and add every node with no left or right child.

```text
For the example: 5, 6, 10, 11
```

### 3. Right Boundary

Start at `root->right`.

- Move right if possible.
- Otherwise, move left.
- Store nodes in a temporary list.
- Reverse that list before adding it to the answer.

```text
Path found:          7 → 8 → 9
Add in reverse order: 9 → 8 → 7
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int data;
    Node *left, *right;

    Node(int value) : data(value), left(nullptr), right(nullptr) {}
};

class Solution {
    bool isLeaf(Node* node) {
        return node->left == nullptr && node->right == nullptr;
    }

    void addLeftBoundary(Node* root, vector<int>& answer) {
        Node* current = root->left;

        while (current != nullptr) {
            if (!isLeaf(current)) {
                answer.push_back(current->data);
            }

            // Prefer left; use right if left does not exist.
            current = current->left ? current->left : current->right;
        }
    }

    void addLeaves(Node* root, vector<int>& answer) {
        if (root == nullptr) return;

        if (isLeaf(root)) {
            answer.push_back(root->data);
            return;
        }

        addLeaves(root->left, answer);
        addLeaves(root->right, answer);
    }

    void addRightBoundary(Node* root, vector<int>& answer) {
        Node* current = root->right;
        vector<int> temporary;

        while (current != nullptr) {
            if (!isLeaf(current)) {
                temporary.push_back(current->data);
            }

            // Prefer right; use left if right does not exist.
            current = current->right ? current->right : current->left;
        }

        reverse(temporary.begin(), temporary.end());
        answer.insert(answer.end(), temporary.begin(), temporary.end());
    }

public:
    vector<int> boundaryTraversal(Node* root) {
        vector<int> answer;
        if (root == nullptr) return answer;

        // For a single-node tree, addLeaves will add the root once.
        if (!isLeaf(root)) {
            answer.push_back(root->data);
        }

        addLeftBoundary(root, answer);
        addLeaves(root, answer);
        addRightBoundary(root, answer);

        return answer;
    }
};

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

void deleteTree(Node* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
                   1
                 /   \
                2     7
               /       \
              3         8
               \       /
                4     9
               / \   / \
              5   6 10 11
    */
    Node* root = new Node(1);
    root->left = new Node(2);
    root->right = new Node(7);
    root->left->left = new Node(3);
    root->left->left->right = new Node(4);
    root->left->left->right->left = new Node(5);
    root->left->left->right->right = new Node(6);
    root->right->right = new Node(8);
    root->right->right->left = new Node(9);
    root->right->right->left->left = new Node(10);
    root->right->right->left->right = new Node(11);

    Solution solution;
    cout << "Boundary traversal: ";
    printVector(solution.boundaryTraversal(root));

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Boundary traversal: [1, 2, 3, 4, 5, 6, 10, 11, 9, 8, 7]
```

```text
After right boundary:     [1, 2, 3, 4, 5, 6, 10, 11, 9, 8, 7]
```

## Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N)` |
| Total space | `O(N)` |
| Extra space (without output) | `O(H)` |

- Every node is visited at most once by the leaf traversal.
- `H` is the height of the tree and is used by recursion.
- The answer vector can store up to `N` nodes.

## Interview Questions 🎯

### 1. What is the order of boundary traversal?
Root, left boundary, leaves, then right boundary in reverse order.

### 2. Why do we skip leaf nodes in the left and right boundary?
Because leaves are added separately. Skipping them avoids duplicates.

### 3. Why is the right boundary reversed?
Boundary traversal is anti-clockwise, so the right side must be printed from bottom to top.

### 4. How are leaf nodes added in left-to-right order?
Use DFS: first visit the left subtree, then the right subtree.

### 5. What happens for a single-node tree?
The answer is just the root node once.

### 6. What happens for an empty tree?
Return an empty vector.

### 7. What is the time complexity?
`O(N)` because the tree is traversed in linear time.

### 8. What is the extra space complexity?
`O(H)` for recursion, where `H` is the tree height.
