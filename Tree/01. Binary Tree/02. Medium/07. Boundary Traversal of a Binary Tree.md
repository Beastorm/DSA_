# Boundary Traversal of a Binary Tree

> Print the **outer boundary** of a binary tree in **anti-clockwise** order, starting from the root.

The answer is **not one connected path**. We collect boundary nodes in this order:

```text
root → left boundary → all leaf nodes → right boundary (bottom to top)
```

---

## Example

```text
                         1
                       /   \
                      2     7
                     /       \
                    3         8
                     \       /
                      4     9
                     / \   / \
                    5   6 10 11
```

### Boundary parts

```text
Root:            1
Left boundary:    2 → 3 → 4
Leaf nodes:       5 → 6 → 10 → 11
Right boundary:   9 → 8 → 7     (bottom to top)
```

So the result is:

```text
[1, 2, 3, 4, 5, 6, 10, 11, 9, 8, 7]
```

---

## Visual View of the Traversal 💡

Imagine moving around the **outside edge** of the tree in an anti-clockwise direction.

```text
                        [1]  ← start with root
                       /   \
                     [2]    (7)
                     /        \
                   [3]        (8)
                     \        /
                     [4]    (9)
                     / \    / \
                   [5] [6] [10] [11]

Left boundary:  [2] → [3] → [4]
Leaves:         [5] → [6] → [10] → [11]
Right boundary: [9] → [8] → [7]
```

The right boundary is written in reverse because we travel **upward** after reaching the leaves.

---

## Why Do We Split It into 3 Parts?

If we simply traverse the left and right sides, leaf nodes may be added twice.

For example, in this tree:

```text
    1
   /
  2
```

Node `2` is both:

```text
- on the left boundary
- a leaf node
```

To avoid duplicates:

```text
Left boundary  → add only non-leaf nodes
Leaf traversal → add every leaf node
Right boundary → add only non-leaf nodes
```

---

## Part 1: Add the Left Boundary

Start from `root->left`.

```text
Move left if possible.
If left does not exist, move right.
Do not add leaves here.
```

For the example:

```text
1
└── 2
    └── 3
        └── 4
            ├── 5   (leaf: skip here)
            └── 6   (leaf: skip here)

Added: [2, 3, 4]
```

---

## Part 2: Add All Leaf Nodes

A leaf has no children:

```text
leaf = left is NULL AND right is NULL
```

Use DFS in this order:

```text
visit left subtree first
visit right subtree next
```

This gives leaves from **left to right**:

```text
                  1
                /   \
               ...   ...
              / \   / \
             5   6 10 11

Leaf order: 5 → 6 → 10 → 11
```

---

## Part 3: Add the Right Boundary

Start from `root->right`.

```text
Move right if possible.
If right does not exist, move left.
Do not add leaves here.
```

For the example, we find this top-to-bottom path:

```text
7 → 8 → 9
```

But boundary traversal needs bottom-to-top order:

```text
Temporary list: [7, 8, 9]
Reverse it:     [9, 8, 7]
```

```text
      7      add later
       \
        8    add later
       /
      9      add first
     / \
   10  11    leaves: skip here
```

---

## Full Algorithm

```text
1. If the tree is empty, return an empty list.
2. Add the root (only if it is not a leaf).
3. Add the left boundary, excluding leaves.
4. Add all leaf nodes from left to right.
5. Add the right boundary in reverse order, excluding leaves.
```

### Building the Example Answer

```text
Start:                 [1]
After left boundary:   [1, 2, 3, 4]
After leaves:          [1, 2, 3, 4, 5, 6, 10, 11]
After right boundary:  [1, 2, 3, 4, 5, 6, 10, 11, 9, 8, 7]
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int data;
    Node *left, *right;

    Node(int value) : data(value), left(nullptr), right(nullptr) {}
};

class Solution {
    bool isLeaf(Node* node) {
        return node->left == nullptr && node->right == nullptr;
    }

    void addLeftBoundary(Node* root, vector<int>& answer) {
        Node* current = root->left;

        while (current != nullptr) {
            // Leaves are added later by addLeaves().
            if (!isLeaf(current)) {
                answer.push_back(current->data);
            }

            // Prefer left; if it does not exist, move right.
            current = current->left ? current->left : current->right;
        }
    }

    void addLeaves(Node* root, vector<int>& answer) {
        if (root == nullptr) return;

        if (isLeaf(root)) {
            answer.push_back(root->data);
            return;
        }

        // Left first gives leaf nodes in left-to-right order.
        addLeaves(root->left, answer);
        addLeaves(root->right, answer);
    }

    void addRightBoundary(Node* root, vector<int>& answer) {
        Node* current = root->right;
        vector<int> temporary;

        while (current != nullptr) {
            // Leaves are added later by addLeaves().
            if (!isLeaf(current)) {
                temporary.push_back(current->data);
            }

            // Prefer right; if it does not exist, move left.
            current = current->right ? current->right : current->left;
        }

        // Right boundary must appear from bottom to top.
        reverse(temporary.begin(), temporary.end());
        answer.insert(answer.end(), temporary.begin(), temporary.end());
    }

public:
    vector<int> boundaryTraversal(Node* root) {
        vector<int> answer;
        if (root == nullptr) return answer;

        // Do not add a leaf root here; addLeaves() will add it once.
        if (!isLeaf(root)) {
            answer.push_back(root->data);
        }

        addLeftBoundary(root, answer);
        addLeaves(root, answer);
        addRightBoundary(root, answer);

        return answer;
    }
};

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

void deleteTree(Node* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
                   1
                 /   \
                2     7
               /       \
              3         8
               \       /
                4     9
               / \   / \
              5   6 10 11
    */
    Node* root = new Node(1);
    root->left = new Node(2);
    root->right = new Node(7);
    root->left->left = new Node(3);
    root->left->left->right = new Node(4);
    root->left->left->right->left = new Node(5);
    root->left->left->right->right = new Node(6);
    root->right->right = new Node(8);
    root->right->right->left = new Node(9);
    root->right->right->left->left = new Node(10);
    root->right->right->left->right = new Node(11);

    Solution solution;
    cout << "Boundary traversal: ";
    printVector(solution.boundaryTraversal(root));

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Boundary traversal: [1, 2, 3, 4, 5, 6, 10, 11, 9, 8, 7]
```

## Special Cases

### Empty Tree

```text
root = NULL
Answer = []
```

### Single Node Tree

```text
  1
```

```text
Answer = [1]
```

The root is also a leaf, so `addLeaves()` adds it exactly once.

### Only Left Side

```text
    1
   /
  2
 /
3
```

```text
Answer = [1, 2, 3]
```

---

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(N)` | Leaf DFS visits all nodes once. |
| Output space | `O(N)` | The answer can contain all nodes. |
| Extra space | `O(H)` | Recursion stack and boundary temporary list. |

- `N` = number of nodes
- `H` = height of the tree

## Interview Questions 🎯

### 1. What is the order in boundary traversal?

```text
root → left boundary → leaves → right boundary in reverse
```

The reverse right boundary makes the final order anti-clockwise.

### 2. Why are leaf nodes skipped in the left and right boundary?

Leaves are collected separately. Without skipping them, a leaf could appear twice.

```text
    1
   /
  2

Wrong: [1, 2, 2]
Correct: [1, 2]
```

### 3. Why do we reverse the right boundary?

We first reach the right boundary from top to bottom:

```text
7 → 8 → 9
```

But the required anti-clockwise output returns upward:

```text
9 → 8 → 7
```

### 4. How do leaves appear from left to right?

Use DFS and visit the left child before the right child.

```text
      1
     / \
    2   3

Leaf order: 2, 3
```

### 5. What is the time complexity?

`O(N)` because every node is checked during the leaf traversal.

### 6. What happens for one node?

The root is a leaf, so the answer contains it once: `[root]`.
