# Check if a Binary Tree Is Balanced

> Return `true` if the tree is balanced; otherwise return `false`.

A binary tree is **balanced** when, at **every node**, the height difference between its left and right subtree is at most `1`.

```text
| left height - right height | ≤ 1
```

## Examples

### Balanced Tree ✅

```text
        3
       / \
      9   20
         /  \
        15   7
```

**Output:** `true`

At every node, the left and right subtree heights differ by no more than `1`.

### Unbalanced Tree ❌

```text
      1
     /
    2
     \
      3
```

**Output:** `false`

At node `1`:

```text
left height = 2
right height = 0
difference = 2   → not balanced
```

---

## Approach 1: Brute Force

For every node:

1. Find the height of its left subtree.
2. Find the height of its right subtree.
3. If the difference is greater than `1`, return `false`.
4. Check the left and right subtrees in the same way.

### Why is it slow?

It calculates the height of the same nodes again and again.

For example, it finds the height of a subtree at the root, then finds it again when checking that subtree.

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int data;
    Node *left, *right;

    Node(int value) : data(value), left(nullptr), right(nullptr) {}
};

class Solution {
    int height(Node* root) {
        if (root == nullptr) return 0;
        return 1 + max(height(root->left), height(root->right));
    }

public:
    bool isBalanced(Node* root) {
        if (root == nullptr) return true;

        int leftHeight = height(root->left);
        int rightHeight = height(root->right);

        if (abs(leftHeight - rightHeight) > 1) return false;

        return isBalanced(root->left) && isBalanced(root->right);
    }
};

void deleteTree(Node* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
            3
           / \
          9   20
             /  \
            15   7
    */
    Node* root = new Node(3);
    root->left = new Node(9);
    root->right = new Node(20);
    root->right->left = new Node(15);
    root->right->right = new Node(7);

    Solution solution;
    cout << boolalpha << "Is balanced: "
         << solution.isBalanced(root) << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Is balanced: true
```

| Time | Space |
|---:|---:|
| `O(N²)` in the worst case | `O(H)` recursion stack |

## Approach 2: Optimal Solution (Recommended) ⚡

### Simple Idea

Find the height and check balance **in the same DFS call**.

- Return the actual height if the subtree is balanced.
- Return `-1` if the subtree is unbalanced.

`-1` is a special signal meaning: **“This subtree is not balanced.”**

```text
If left or right returns -1:
    return -1

If |left height - right height| > 1:
    return -1

Otherwise:
    return 1 + max(left height, right height)
```

This avoids calculating heights repeatedly.

---

## C++ Code — Optimal

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int data;
    Node *left, *right;

    Node(int value) : data(value), left(nullptr), right(nullptr) {}
};

class Solution {
    int checkHeight(Node* root) {
        if (root == nullptr) return 0;

        int leftHeight = checkHeight(root->left);
        if (leftHeight == -1) return -1;  // Left subtree is unbalanced.

        int rightHeight = checkHeight(root->right);
        if (rightHeight == -1) return -1; // Right subtree is unbalanced.

        // Current node is unbalanced.
        if (abs(leftHeight - rightHeight) > 1) return -1;

        // Return normal height if this subtree is balanced.
        return 1 + max(leftHeight, rightHeight);
    }

public:
    bool isBalanced(Node* root) {
        return checkHeight(root) != -1;
    }
};

void deleteTree(Node* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
          1
         /
        2
         \
          3
    */
    Node* root = new Node(1);
    root->left = new Node(2);
    root->left->right = new Node(3);

    Solution solution;
    cout << boolalpha << "Is balanced: "
         << solution.isBalanced(root) << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Is balanced: false
```

## Quick Walkthrough

For this tree:

```text
      1
     /
    2
     \
      3
```

- Node `3` returns height `1`.
- Node `2` returns height `2`.
- At node `1`, left height is `2` and right height is `0`.
- Difference is `2`, so return `-1`.

**Answer:** `false`

## Complexity

| Approach | Time | Space |
|---|---:|---:|
| Brute Force | `O(N²)` | `O(H)` |
| Optimal DFS | `O(N)` | `O(H)` |

- `N` = number of nodes
- `H` = height of the tree

> The optimal solution visits each node only once.

## Interview Questions 🎯

### 1. What makes a tree balanced?
For every node, the difference between left and right subtree heights must be at most `1`.

### 2. Why is checking only the root not enough?
The root may look balanced, but a lower subtree can still be unbalanced.

### 3. Why does the brute-force solution take `O(N²)` time?
It finds subtree heights many times, so the same nodes are visited again and again.

### 4. Why do we return `-1` in the optimal solution?
`-1` is a simple signal that tells the parent the subtree is unbalanced.

### 5. What is the height of an empty tree?
`0`.

### 6. Is a single-node tree balanced?
Yes. Its left and right heights are both `0`.

### 7. Why is the optimal solution `O(N)`?
Each node is visited only once.

### 8. Can the recursion stack use `O(N)` space?
Yes. In a skewed tree, the height is `N`, so the recursive call stack can be `O(N)`.
