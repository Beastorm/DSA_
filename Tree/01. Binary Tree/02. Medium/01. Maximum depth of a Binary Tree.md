# Maximum Depth / Height of a Binary Tree

> Find the number of nodes in the longest path from the **root** to any **leaf node**.

In this problem, height is counted in **nodes**.

[Visualize Diameter Combined Page](https://beastorm.github.io/DSA_/junk/pages/diameter-combined.html)

---

## Example

```text
        1
       / \
      2   5
         / \
        4   6
       /
      5
```

The longest path is:

```text
1 → 5 → 4 → 5
```

**Maximum depth = 4**

---

## Approach 1: Recursion (Easy to Understand) 🌳

### Simple Idea

For each node:

```text
height = 1 + maximum height of its left and right child
```

- `1` is for the current node.
- We choose the taller subtree.
- If the node is `NULL`, its height is `0`.

```text
              root
             /    \
      left height  right height

height = 1 + max(left height, right height)
```

---

## Steps

1. If the node is `NULL`, return `0`.
2. Find the height of the left subtree.
3. Find the height of the right subtree.
4. Return `1 + max(leftHeight, rightHeight)`.

---

## C++ Code — Recursive

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int data;
    Node *left, *right;

    Node(int value) : data(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    int maxDepth(Node* root) {
        // Empty tree has height 0.
        if (root == nullptr) return 0;

        int leftHeight = maxDepth(root->left);
        int rightHeight = maxDepth(root->right);

        // Current node + taller subtree.
        return 1 + max(leftHeight, rightHeight);
    }
};

void deleteTree(Node* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
            1
           / \
          2   5
             / \
            4   6
           /
          5
    */
    Node* root = new Node(1);
    root->left = new Node(2);
    root->right = new Node(5);
    root->right->left = new Node(4);
    root->right->right = new Node(6);
    root->right->left->left = new Node(5);

    Solution solution;
    cout << "Maximum depth: " << solution.maxDepth(root) << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Maximum depth: 4
```

### Quick Example

For this tree:

```text
    3
   / \
  1   2
```

```text
height(1) = 1
height(2) = 1
height(3) = 1 + max(1, 1) = 2
```

**Answer: `2`**

## Approach 2: Level Order Traversal (Queue) 📚

### Simple Idea

Count the levels one by one.

```text
Level 1: root
Level 2: root's children
Level 3: next children
...
```

The total number of levels is the maximum depth.

---

## C++ Code — Iterative

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;

        queue<TreeNode*> q;
        q.push(root);
        int depth = 0;

        while (!q.empty()) {
            int levelSize = q.size();
            depth++;  // We are processing one new level.

            for (int i = 0; i < levelSize; i++) {
                TreeNode* current = q.front();
                q.pop();

                if (current->left) q.push(current->left);
                if (current->right) q.push(current->right);
            }
        }

        return depth;
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
            1
           / \
          2   5
             / \
            4   6
           /
          5
    */
    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(5);
    root->right->left = new TreeNode(4);
    root->right->right = new TreeNode(6);
    root->right->left->left = new TreeNode(5);

    Solution solution;
    cout << "Maximum depth: " << solution.maxDepth(root) << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Maximum depth: 4
```

---

## Complexity

| Approach | Time | Space |
|---|---:|---:|
| Recursive DFS | `O(N)` | `O(H)` |
| Iterative BFS | `O(N)` | `O(N)` |

- `N` = number of nodes
- `H` = height of the tree

> Recursive DFS uses stack space. For a skewed tree, `H` can become `N`.

## Interview Questions 🎯

### 1. What is the base case in the recursive solution?
If the node is `NULL`, return `0` because an empty tree has no nodes.

### 2. Why do we add `1`?
The `1` counts the current node.

### 3. What is the difference between height and depth?
In many questions, they are used in the same way. Usually, **depth** is the distance from the root, while **height** is the longest path down to a leaf. Here, both mean the number of nodes on the longest root-to-leaf path.

### 4. Which approach should we use: DFS or BFS?
Use recursive DFS when you want short and simple code. Use BFS when you want to process the tree level by level.

### 5. What is the height of an empty tree?
`0` in this problem.

### 6. What is the height of a tree with one node?
`1`, because the root itself is one node.

### 7. Why can BFS use `O(N)` space?
In a wide tree, the queue may store many nodes from the same level.

### 8. What changes if height is counted in edges instead of nodes?
A single node would have height `0` instead of `1`. Always check the question’s definition.
