# Right and Left View of a Binary Tree

> The **right view** contains the nodes visible when looking at the tree from the right side.
>
> The **left view** contains the nodes visible when looking at the tree from the left side.

There is exactly **one visible node from each level**.

---

## Example 1

```text
        1
       / \
      2   3
       \   \
        5   4
```

### Looking from the left

```text
Level 0 → 1
Level 1 → 2
Level 2 → 5

Left view = [1, 2, 5]
```

### Looking from the right

```text
Level 0 → 1
Level 1 → 3
Level 2 → 4

Right view = [1, 3, 4]
```

```text
Left side                         Right side

    1                                  1
   /                                  / \
 [2]                                 2  [3]
   \                                     \
   [5]                                   [4]
```

**Right-view output:** `[1, 3, 4]`

**Original visual reference:** [Open view diagram](https://assets.leetcode.com/users/images/26546a56-7899-476f-b5a1-064cf6797c0a_1614930857.1147668.png)

---

## Main Idea 💡

At each level:

```text
Left view  → take the first node
Right view → take the last node
```

For Example 1, level order is:

```text
Level 0: [1]
Level 1: [2, 3]
Level 2: [5, 4]
```

```text
First values: [1, 2, 5]  → left view
Last values:  [1, 3, 4]  → right view
```

---

# Approach 1: BFS / Level Order (Brute Force)

## Simple Idea

1. Use a queue to process one level at a time.
2. Store all nodes of each level.
3. Take the first value for the left view.
4. Take the last value for the right view.

```text
Queue processes the tree like this:

        1
      /   \
     2     3
      \     \
       5     4

Level 0: [1]
Level 1: [2, 3]
Level 2: [5, 4]
```

---

## BFS Walkthrough

### Level 0

```text
Queue before: [1]
Remove: 1
Level: [1]

left view gets:  1  (first)
right view gets: 1  (last)
```

### Level 1

```text
Queue before: [2, 3]
Remove: 2, 3
Level: [2, 3]

left view gets:  2
right view gets: 3
```

### Level 2

```text
Queue before: [5, 4]
Remove: 5, 4
Level: [5, 4]

left view gets:  5
right view gets: 4
```

---

## C++ Code — BFS Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int data;
    Node *left, *right;

    Node(int value) : data(value), left(nullptr), right(nullptr) {}
};

class Solution {
    vector<vector<int>> levelOrder(Node* root) {
        vector<vector<int>> levels;
        if (root == nullptr) return levels;

        queue<Node*> q;
        q.push(root);

        while (!q.empty()) {
            int levelSize = q.size();
            vector<int> level;

            for (int i = 0; i < levelSize; i++) {
                Node* current = q.front();
                q.pop();

                level.push_back(current->data);

                if (current->left) q.push(current->left);
                if (current->right) q.push(current->right);
            }

            levels.push_back(level);
        }

        return levels;
    }

public:
    vector<int> leftView(Node* root) {
        vector<int> answer;
        vector<vector<int>> levels = levelOrder(root);

        for (const vector<int>& level : levels) {
            answer.push_back(level.front());
        }

        return answer;
    }

    vector<int> rightView(Node* root) {
        vector<int> answer;
        vector<vector<int>> levels = levelOrder(root);

        for (const vector<int>& level : levels) {
            answer.push_back(level.back());
        }

        return answer;
    }
};

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

void deleteTree(Node* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
            1
           / \
          2   3
           \   \
            5   4
    */
    Node* root = new Node(1);
    root->left = new Node(2);
    root->right = new Node(3);
    root->left->right = new Node(5);
    root->right->right = new Node(4);

    Solution solution;

    cout << "Left view:  ";
    printVector(solution.leftView(root));

    cout << "Right view: ";
    printVector(solution.rightView(root));

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Left view:  [1, 2, 5]
Right view: [1, 3, 4]
```

---

## BFS Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(N)` | Every node is added to and removed from the queue once. |
| Space | `O(N)` | The queue and stored level vectors can hold all nodes. |

# Approach 2: DFS (Optimal Space) ⚡

## Simple Idea

While doing DFS, remember which levels already have an answer.

```text
If answer.size() == currentLevel:
    this is the first node seen at this level
    add it to the answer
```

The order of recursion decides the view:

```text
Left view:  visit left child first
Right view: visit right child first
```

---

## DFS Diagram

### Left View — Visit Left First

```text
        1      first node at level 0 → add 1
       / \
      2   3    first node at level 1 → add 2
       \
        5       first node at level 2 → add 5

DFS order starts: 1 → 2 → 5
Left view: [1, 2, 5]
```

When DFS reaches node `3` and then `4`, levels 1 and 2 already have values, so they are skipped.

### Right View — Visit Right First

```text
        1      first node at level 0 → add 1
       / \
      2   3    first node at level 1 → add 3
           \
            4  first node at level 2 → add 4

DFS order starts: 1 → 3 → 4
Right view: [1, 3, 4]
```

---

## C++ Code — DFS Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int data;
    Node *left, *right;

    Node(int value) : data(value), left(nullptr), right(nullptr) {}
};

class Solution {
    void leftDFS(Node* root, int level, vector<int>& answer) {
        if (root == nullptr) return;

        // First node reached at this level is visible from the left.
        if (answer.size() == level) {
            answer.push_back(root->data);
        }

        leftDFS(root->left, level + 1, answer);
        leftDFS(root->right, level + 1, answer);
    }

    void rightDFS(Node* root, int level, vector<int>& answer) {
        if (root == nullptr) return;

        // First node reached at this level is visible from the right.
        if (answer.size() == level) {
            answer.push_back(root->data);
        }

        rightDFS(root->right, level + 1, answer);
        rightDFS(root->left, level + 1, answer);
    }

public:
    vector<int> leftView(Node* root) {
        vector<int> answer;
        leftDFS(root, 0, answer);
        return answer;
    }

    vector<int> rightView(Node* root) {
        vector<int> answer;
        rightDFS(root, 0, answer);
        return answer;
    }
};

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

void deleteTree(Node* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
            1
           / \
          2   3
           \   \
            5   4
    */
    Node* root = new Node(1);
    root->left = new Node(2);
    root->right = new Node(3);
    root->left->right = new Node(5);
    root->right->right = new Node(4);

    Solution solution;

    cout << "Left view:  ";
    printVector(solution.leftView(root));

    cout << "Right view: ";
    printVector(solution.rightView(root));

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Left view:  [1, 2, 5]
Right view: [1, 3, 4]
```

---

## DFS Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(N)` | DFS visits every node once. |
| Extra space | `O(H)` | Recursion stack, where `H` is tree height. |

> In a balanced tree, `H` is about `log N`. In a skewed tree, `H` can be `N`.

## Interview Questions 🎯

### 1. What is the difference between left view and right view?

```text
Left view  → first node at every level
Right view → last node at every level
```

### 2. How does BFS find the views?

For every level:

```text
first queue node → left view
last queue node  → right view
```

### 3. How does DFS find the left view?

Visit the left child before the right child. The first node found at a level becomes the left-view node.

### 4. How does DFS find the right view?

Visit the right child before the left child. The first node found at a level becomes the right-view node.

### 5. Which approach uses less extra space?

DFS usually uses `O(H)` recursion stack space. The brute-force BFS version stores all levels, so it uses `O(N)` space.

### 6. Does every level always add one node to the view?

Yes. A non-empty level has one leftmost node and one rightmost node. They may be the same node.
