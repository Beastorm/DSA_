# Top View of a Binary Tree

> Return the nodes visible when the binary tree is viewed from **above**.

For every vertical column, only the **highest node** is visible.

---

## Main Idea: Vertical Columns 💡

Give every node a column number.

```text
root        → column 0
left child  → column - 1
right child → column + 1
```

When two nodes have the same column, the one closer to the root hides the lower one.

---

## Example 1

```text
                         1 (0)
                       /       \
                  2 (-1)       3 (+1)
                  /    \       /    \
             4 (-2)  10 (0)  9 (0)  11 (+2)
                \
                5 (-1)
                   \
                   6 (0)
```

### What is visible from the top?

```text
Column -2: 4                  → visible
Column -1: 2 is above 5       → 2 is visible
Column  0: 1 is above 10,9,6  → 1 is visible
Column +1: 3                  → visible
Column +2: 11                 → visible
```

```text
Top view: [4, 2, 1, 3, 11]
```

### Top-view diagram

```text
            4     2     1     3     11
            |     |     |     |      |
Columns:   -2    -1     0    +1     +2

Hidden nodes below their column:
                 5    10, 9, 6
```

**Output:**

```text
[4, 2, 1, 3, 11]
```

**Original visual reference:** [Open top-view diagram](https://static.takeuforward.org/content/-isIohPVt)

## Why Do We Use BFS? 📚

BFS visits nodes from top to bottom, level by level.

```text
Level 0:  1
Level 1:  2, 3
Level 2:  4, 10, 9, 11
Level 3:  5
Level 4:  6
```

So the **first node** we see in a column is always the highest node in that column.

```text
Column 0 receives nodes in this order:
1 → 10 → 9 → 6

Keep the first value only: 1
```

---

## BFS Walkthrough

The queue stores this pair:

```text
(node, column)
```

### Start

```text
Queue: [(1, 0)]
Map:   {}
```

### Process node 1

```text
Take: (1, 0)
Column 0 is empty → store 1
Push: (2, -1), (3, +1)

Map: { 0: 1 }
```

### Process node 2 and node 3

```text
Take: (2, -1) → store 2 at column -1
Take: (3, +1) → store 3 at column +1

Map: { -1: 2, 0: 1, +1: 3 }
```

### Process lower nodes

```text
Take: (10, 0)
Column 0 already has 1 → do not replace it

Take: (9, 0)
Column 0 already has 1 → do not replace it
```

The final map is:

```text
-2 → 4
-1 → 2
 0 → 1
+1 → 3
+2 → 11
```

Reading the map from left to right gives:

```text
[4, 2, 1, 3, 11]
```

---

## Full Algorithm

```text
1. If the tree is empty, return an empty list.
2. Put (root, 0) into a queue.
3. While the queue is not empty:
      a. Remove (node, column).
      b. If this column is not in the map, store node's value.
      c. Push the left child with column - 1.
      d. Push the right child with column + 1.
4. Read the map from smallest column to largest column.
5. Return the stored values.
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int data;
    Node *left, *right;

    Node(int value) : data(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    vector<int> topView(Node* root) {
        vector<int> answer;
        if (root == nullptr) return answer;

        // column number -> first (topmost) value in that column
        map<int, int> topNode;

        // Queue stores: node and its column number.
        queue<pair<Node*, int>> q;
        q.push({root, 0});

        while (!q.empty()) {
            Node* current = q.front().first;
            int column = q.front().second;
            q.pop();

            // Store only the first node seen in this column.
            if (topNode.find(column) == topNode.end()) {
                topNode[column] = current->data;
            }

            if (current->left) {
                q.push({current->left, column - 1});
            }

            if (current->right) {
                q.push({current->right, column + 1});
            }
        }

        // map keys are sorted: leftmost column to rightmost column.
        for (auto& entry : topNode) {
            answer.push_back(entry.second);
        }

        return answer;
    }
};

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

void deleteTree(Node* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
                             1
                           /   \
                          2     3
                         / \   / \
                        4  10 9  11
                         \
                          5
                           \
                            6
    */
    Node* root = new Node(1);
    root->left = new Node(2);
    root->right = new Node(3);
    root->left->left = new Node(4);
    root->left->right = new Node(10);
    root->right->left = new Node(9);
    root->right->right = new Node(11);
    root->left->left->right = new Node(5);
    root->left->left->right->right = new Node(6);

    Solution solution;
    cout << "Top view: ";
    printVector(solution.topView(root));

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Top view: [4, 2, 1, 3, 11]
```

## Special Cases

### Empty Tree

```text
root = NULL
Top view = []
```

### Single Node Tree

```text
  1
```

```text
Top view = [1]
```

### Left-Skewed Tree

```text
    1
   /
  2
 /
3
```

Every node has a different column:

```text
Top view = [3, 2, 1]
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(N log N)` | Each ordered-map operation can take `O(log N)`. |
| Space | `O(N)` | The queue and map can store up to `N` nodes. |

- `N` = number of nodes in the tree.

> If an `unordered_map` is used with minimum/maximum column tracking, the average time can be close to `O(N)`. The ordered `map` solution is simpler because it automatically keeps columns sorted.

## Interview Questions 🎯

### 1. Why does BFS give the top view?

BFS visits higher levels before lower levels.

```text
First node seen in a column = topmost node in that column
```

### 2. Why do we store only the first node at a column?

Every later node in the same column is below it and is hidden from the top.

```text
column 0: 1 → 10 → 9
keep:     1
```

### 3. Why use a map?

The map sorts column numbers from left to right.

```text
-2, -1, 0, +1, +2
```

### 4. What does the queue store?

```text
(node pointer, column number)
```

### 5. What is the difference between top view and vertical order traversal?

```text
Vertical order: keeps all nodes in a column
Top view:       keeps only the first / highest node in a column
```

### 6. What is the time complexity?

`O(N log N)` with an ordered `map`.
