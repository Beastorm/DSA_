# Convert a Binary Tree to Follow the Children Sum Property

> Change node values so that every non-leaf node equals the sum of its children.

```text
node.value = leftChild.value + rightChild.value
```

- A missing child has value `0`.
- Node values may only **increase**.
- Node values must never decrease.
- The tree structure cannot change.

---

## What Is the Children Sum Property?

```text
        10
       /  \
      6    4

10 = 6 + 4  ✓
```

A leaf node has no children, so we do not change it.

```text
  7

leaf node → already valid
```

---

## Two Important Cases 💡

### Case 1: Children Sum Is Greater Than or Equal to Parent

```text
       5
      / \
     3   4

children sum = 3 + 4 = 7
```

We can increase the parent:

```text
       7
      / \
     3   4

7 = 3 + 4 ✓
```

```text
childSum >= parent → pull the child sum up to the parent
```

---

### Case 2: Children Sum Is Less Than Parent

```text
       10
      /  \
     3    4

children sum = 7
```

We cannot do this:

```text
10 → 7  ✗  (decreasing is not allowed)
```

So we push the parent value down to one child:

```text
       10
      /  \
    10    4
```

Then recursively fix the subtree. Finally, update the parent using its updated children.

```text
childSum < parent → push the parent value down first
```

---

## Why Do We Need Top-Down and Bottom-Up Work?

The algorithm works in three steps at every node:

```text
1. Top-down:
   If children are too small, push the parent's value down.

2. Recurse:
   Fix the left and right subtrees.

3. Bottom-up:
   Set the parent to the sum of its now-updated children.
```

```text
          parent
             |
             |  Step 1: push value down if needed
             v
      fix left subtree and right subtree
             |
             |  Step 3: use final child values
             v
       parent = left + right
```

---

## Example

### Before

```text
          50
         /  \
        7    2
       / \  / \
      3  5 1  30
```

### Step 1: Process node `50`

```text
children sum = 7 + 2 = 9
9 < 50
```

We cannot decrease `50`, so copy `50` to its left child:

```text
          50
         /  \
       50    2
       / \  / \
      3  5 1  30
```

---

### Step 2: Fix the Left Subtree

At node `50`:

```text
children sum = 3 + 5 = 8
8 < 50
```

Push `50` down to its left child:

```text
         50
        /  \
      50    5
```

Now its children already satisfy the rule:

```text
50 + 5 = 55
```

So update the parent:

```text
         55
        /  \
      50    5
```

---

### Step 3: Fix the Right Subtree

At node `2`:

```text
children sum = 1 + 30 = 31
31 >= 2
```

Increase the parent to `31`:

```text
         31
        /  \
       1   30
```

---

### Step 4: Final Update of the Root

```text
left child  = 55
right child = 31

root = 55 + 31 = 86
```

### After

```text
          86
         /  \
        55   31
       / \  / \
      50 5 1  30
```

### Verify

```text
55 = 50 + 5   ✓
31 = 1 + 30   ✓
86 = 55 + 31  ✓
```

> More than one valid final tree can exist. The code below uses a common fixed rule: when children are too small, copy the parent value to the left child; if there is no left child, copy it to the right child.

---

## Full Algorithm

```text
changeTree(node):

1. If node is NULL, return.
2. Find childSum = left value + right value.
3. If childSum >= node value:
       node value = childSum
   Else:
       copy node value to the left child if it exists,
       otherwise copy it to the right child.
4. Recursively fix the left and right subtrees.
5. If node is not a leaf:
       node value = updated left value + updated right value.
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    void changeTree(TreeNode* root) {
        if (root == nullptr) return;

        // Find the current sum of child values.
        int childSum = 0;
        if (root->left) childSum += root->left->val;
        if (root->right) childSum += root->right->val;

        // Top-down adjustment.
        if (childSum >= root->val) {
            // Increasing the parent is allowed.
            root->val = childSum;
        } else {
            // Parent cannot be decreased, so push its value down.
            if (root->left) {
                root->left->val = root->val;
            } else if (root->right) {
                root->right->val = root->val;
            }
        }

        // Fix both subtrees.
        changeTree(root->left);
        changeTree(root->right);

        // Bottom-up adjustment using final child values.
        int finalSum = 0;
        if (root->left) finalSum += root->left->val;
        if (root->right) finalSum += root->right->val;

        // Do not change a leaf to 0.
        if (root->left || root->right) {
            root->val = finalSum;
        }
    }
};

void printLevelOrder(TreeNode* root) {
    if (root == nullptr) return;

    queue<TreeNode*> q;
    q.push(root);

    cout << "[";
    bool first = true;

    while (!q.empty()) {
        TreeNode* current = q.front();
        q.pop();

        if (!first) cout << ", ";
        cout << current->val;
        first = false;

        if (current->left) q.push(current->left);
        if (current->right) q.push(current->right);
    }

    cout << "]\n";
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
              50
             /  \
            7    2
           / \  / \
          3  5 1  30
    */
    TreeNode* root = new TreeNode(50);
    root->left = new TreeNode(7);
    root->right = new TreeNode(2);
    root->left->left = new TreeNode(3);
    root->left->right = new TreeNode(5);
    root->right->left = new TreeNode(1);
    root->right->right = new TreeNode(30);

    Solution solution;

    cout << "Before: ";
    printLevelOrder(root);

    solution.changeTree(root);

    cout << "After:  ";
    printLevelOrder(root);

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Before: [50, 7, 2, 3, 5, 1, 30]
After:  [86, 55, 31, 50, 5, 1, 30]
```

### Single Node

```text
  5
```

A leaf is not changed.


### Node with One Child

```text
       10
       /
      3
```

```text
childSum = 3 < 10
copy 10 to the only child
```

```text
       10
       /
      10
```

```text
10 = 10 + 0 ✓
```

### Child Sum Already Matches Parent

```text
       9
      / \
     4   5
```

No value needs to change.

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(N)` | Each node is visited once. |
| Extra space | `O(H)` | Recursive call stack, where `H` is tree height. |

- `N` = number of nodes.
- In a skewed tree, `H` can be `N`, so worst-case extra space is `O(N)`.

## Interview Questions 🎯

### 1. Why can’t we only do bottom-up updates?

If child sum is smaller than the parent, bottom-up would require decreasing the parent.

```text
parent = 10, child sum = 7
10 → 7 is not allowed
```

### 2. Why do we push the parent value down before recursion?

It gives the child subtree a value that is not smaller than its parent requirement. The child subtree can then be fixed using only increases.

### 3. Why do we update the parent again after recursion?

Children may increase while their own subtrees are fixed. The parent must use their final values.

### 4. Why are leaves not changed to `0`?

Leaves have no children, but their values must not decrease. We leave them unchanged.

### 5. Is the final tree always unique?

No. Different valid ways of increasing children can produce different trees. The property only requires parent = child sum and no decreases.

### 6. What is the time complexity?

`O(N)` because every node is processed once.

### 7. What is the recursion-space complexity?

`O(H)`, where `H` is the height of the tree.
