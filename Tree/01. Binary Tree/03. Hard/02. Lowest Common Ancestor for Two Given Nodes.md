# Lowest Common Ancestor (LCA) of Two Nodes in a Binary Tree

> Find the lowest node that has both given nodes `p` and `q` as descendants.

A node is allowed to be a descendant of **itself**. So if `p` is an ancestor of `q`, then `p` is the LCA.

[Lowest Common Ancestor (LCA) of Two Nodes in a Binary Tree](https://htmlpreview.github.io/?https://github.com/Beastorm/DSA_/blob/main/junk/pages/lca-visualizer.html)

---

## Example Tree

```text
           3
          / \
         5   1
        / \ / \
       6  2 0  8
         / \
        7   4
```

---

## Example 1: `p = 5`, `q = 1`

```text
           3   ← LCA
          / \
      p=5   q=1
```

Node `5` is in the left subtree of `3`, and node `1` is in the right subtree of `3`.

```text
They split at node 3.
LCA = 3
```

---

## Example 2: `p = 5`, `q = 4`

```text
           3
          /
      p=5   ← LCA
        \
         2
          \
          q=4
```

Node `5` is already an ancestor of node `4`.

```text
LCA = 5
```

---

## Main Idea 💡

At each node, search for `p` and `q` in both subtrees.

```text
leftResult  = LCA(left subtree)
rightResult = LCA(right subtree)
```

Then decide:

```text
Both results are not NULL  → p and q are on opposite sides
                              current node is the LCA

Only left result exists     → return left result
Only right result exists    → return right result
```

---

## The 4 Important Cases

### Case 1: Current node is `NULL`

```text
return NULL
```

There is no target node in this path.

---

### Case 2: Current node is `p` or `q`

```text
return current node
```

This node may be the LCA itself.

```text
        5  ← p and possible LCA
         \
          2
           \
            4  ← q
```

When the recursion reaches `5`, it returns `5` immediately.

---

### Case 3: `p` and `q` are on opposite sides

```text
              3  ← current node is LCA
             / \
            5   1
           p     q

leftResult  = 5
rightResult = 1
```

Both results exist, so return `3`.

---

### Case 4: Both nodes are in the same subtree

```text
          3
         /
        5  ← LCA is somewhere here
       / \
      6   2
         / \
        7   4
           p   q
```

The right subtree of `3` returns `NULL`, so return the result from the left subtree.

---

## Recursive Flow

```text
lca(root, p, q):

if root is NULL, p, or q:
    return root

leftResult  = lca(root.left, p, q)
rightResult = lca(root.right, p, q)

if leftResult is NULL:
    return rightResult

if rightResult is NULL:
    return leftResult

return root
```

---

## Step-by-Step Trace: LCA of `5` and `1`

```text
           3
          / \
         5   1
```

```text
lca(3, 5, 1)

  search left:
  lca(5, 5, 1) → current node is p → return 5

  search right:
  lca(1, 5, 1) → current node is q → return 1

leftResult = 5
rightResult = 1

both are non-NULL → return 3 ✓
```

---

## Step-by-Step Trace: LCA of `5` and `4`

```text
           3
          / \
         5   1
          \
           2
            \
             4
```

```text
lca(3, 5, 4)

  search left:
  lca(5, 5, 4) → current node is p → return 5

  search right:
  subtree rooted at 1 does not contain p or q → return NULL

leftResult = 5
rightResult = NULL

return 5 ✓
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int data;
    TreeNode *left, *right;

    TreeNode(int value) : data(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        // Reached the end, or found one target node.
        if (root == nullptr || root == p || root == q) {
            return root;
        }

        TreeNode* leftResult = lowestCommonAncestor(root->left, p, q);
        TreeNode* rightResult = lowestCommonAncestor(root->right, p, q);

        // Both targets are found in different subtrees.
        if (leftResult != nullptr && rightResult != nullptr) {
            return root;
        }

        // Both targets are in one subtree, or one target is an ancestor.
        return (leftResult != nullptr) ? leftResult : rightResult;
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
               3
              / \
             5   1
            / \ / \
           6  2 0  8
             / \
            7   4
    */
    TreeNode* root = new TreeNode(3);
    root->left = new TreeNode(5);
    root->right = new TreeNode(1);
    root->left->left = new TreeNode(6);
    root->left->right = new TreeNode(2);
    root->right->left = new TreeNode(0);
    root->right->right = new TreeNode(8);
    root->left->right->left = new TreeNode(7);
    root->left->right->right = new TreeNode(4);

    Solution solution;

    // Example 1: LCA of 5 and 1 is 3.
    TreeNode* p = root->left;
    TreeNode* q = root->right;
    TreeNode* lca1 = solution.lowestCommonAncestor(root, p, q);
    cout << "LCA of 5 and 1: " << lca1->data << endl;

    // Example 2: 5 is an ancestor of 4, so LCA is 5.
    TreeNode* lca2 = solution.lowestCommonAncestor(root, root->left,
                                                    root->left->right->right);
    cout << "LCA of 5 and 4: " << lca2->data << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
LCA of 5 and 1: 3
LCA of 5 and 4: 5
```

## Special Cases

### One Target Is the Root

```text
       3  ← p
      / \
     5   1  ← q
```

```text
LCA(3, 1) = 3
```

The root is an ancestor of every node in the tree.

### Both Targets Are the Same Node

```text
LCA(5, 5) = 5
```

The base case returns that node immediately.

### Both Nodes Are Deep in One Subtree

```text
       5
      / \
     6   2
        / \
       7   4
      p     q
```

```text
LCA(7, 4) = 2
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(N)` | In the worst case, every node is visited. |
| Extra space | `O(H)` | Recursive call stack, where `H` is tree height. |

```text
Balanced tree → H ≈ log N → O(log N) stack space
Skewed tree   → H = N     → O(N) stack space
```

---

## Important Assumption

This standard solution assumes both `p` and `q` are present in the tree.

If one node is missing, the function can return the node that does exist. If the problem does **not** guarantee both nodes exist, add extra checks to confirm that both were found.

## Interview Questions 🎯

### 1. Why do we return the current node when it equals `p` or `q`?

A node can be a descendant of itself. It may be the LCA if the other target is below it.

### 2. When is the current node the LCA?

When the left and right recursive calls both return a non-NULL node.

```text
One target is on the left, and the other is on the right.
```

### 3. What if both targets are in the same subtree?

One recursive call returns `NULL`; return the non-NULL result from the subtree containing both targets.

### 4. What if `p == q`?

That same node is the LCA.

### 5. Why compare node pointers instead of values?

Nodes may have duplicate values in a general binary tree. Pointers identify the exact nodes.

### 6. What is the time complexity?

`O(N)` in the worst case.

### 7. What is the space complexity?

`O(H)` because of recursion.

### 8. How can we solve it iteratively?

Store each node’s parent using DFS or BFS. Then walk upward from both nodes until their first common parent is found.
