# Print Root-to-Node Path in a Binary Tree

> Return the path from the root to a target node.

The target value is unique and is guaranteed to be present in the tree.

```text
Path = root → ... → target
```

---

## Example

```text
          3
         / \
        5   1
       / \ / \
      6  2 0  8
        / \
       7   4
```

**Target:** `7`

```text
Root-to-node path: 3 → 5 → 2 → 7
```

**Output:**

```text
[3, 5, 2, 7]
```

---

## Main Idea: DFS + Backtracking 💡

Keep a vector named `path` while searching for the target.

At every node:

```text
1. Add the current node to path.
2. If it is the target, return true.
3. Search the left subtree.
4. Search the right subtree.
5. If target is not found, remove the current node from path.
```

Removing the node in step 5 is called **backtracking**.

---

## Why Do We Need Backtracking?

DFS may first enter a path that does not contain the target.

```text
          3
         /
        5
       / \
      6   2
         /
        7
```

Suppose the target is `7`.

```text
Go to 3: path = [3]
Go to 5: path = [3, 5]
Go to 6: path = [3, 5, 6]
```

Node `6` is not the target and has no children.

```text
Wrong path: [3, 5, 6]
Remove 6:  [3, 5]     ← backtracking
```

Now DFS can try node `2`:

```text
Go to 2: path = [3, 5, 2]
Go to 7: path = [3, 5, 2, 7]  ✓ found
```

Without `pop_back()`, the wrong node `6` would stay in the final path.

## Step-by-Step Trace

```text
Target = 7

findPath(3)
path = [3]

  findPath(5)
  path = [3, 5]

    findPath(6)
    path = [3, 5, 6]
    6 is not target, no children
    pop 6 → path = [3, 5]

    findPath(2)
    path = [3, 5, 2]

      findPath(7)
      path = [3, 5, 2, 7]
      7 is target → return true ✓
```

After finding the target, every previous recursive call returns `true` without removing its node from `path`.

---

## Full Algorithm

```text
findPath(node, path, target):

1. If node is NULL, return false.
2. Add node's value to path.
3. If node's value equals target, return true.
4. If target is found in the left or right subtree, return true.
5. Remove the current node from path.
6. Return false.
```

---

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int data;
    Node *left, *right;

    Node(int value) : data(value), left(nullptr), right(nullptr) {}
};

class Solution {
    bool findPath(Node* root, int target, vector<int>& path) {
        if (root == nullptr) return false;

        // Include this node in the current path.
        path.push_back(root->data);

        // Target found: keep the current path.
        if (root->data == target) return true;

        // Search left and right subtrees.
        if (findPath(root->left, target, path) ||
            findPath(root->right, target, path)) {
            return true;
        }

        // Target is not below this node, so remove it from the path.
        path.pop_back();
        return false;
    }

public:
    vector<int> rootToNodePath(Node* root, int target) {
        vector<int> path;
        findPath(root, target, path);
        return path;
    }
};

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

void deleteTree(Node* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
              3
             / \
            5   1
           / \ / \
          6  2 0  8
            / \
           7   4
    */
    Node* root = new Node(3);
    root->left = new Node(5);
    root->right = new Node(1);
    root->left->left = new Node(6);
    root->left->right = new Node(2);
    root->right->left = new Node(0);
    root->right->right = new Node(8);
    root->left->right->left = new Node(7);
    root->left->right->right = new Node(4);

    int target = 7;
    Solution solution;

    cout << "Path from root to " << target << ": ";
    printVector(solution.rootToNodePath(root, target));

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Path from root to 7: [3, 5, 2, 7]
```

---

## Important Note About “Leaf Node”

The code works for **any target node**, not only a leaf.

```text
If target = 2
Path = [3, 5, 2]
```

If the problem strictly says the target must be a leaf, use this check instead:

```cpp
if (root->data == target && root->left == nullptr && root->right == nullptr) {
    return true;
}
```

In this problem, values are unique and the target is guaranteed to exist, so checking `root->data == target` is enough.

```text

```

### Target Is Deep in the Tree

```text
    1
   /
  2
   \
    4
     \
      5
```

```text
Target = 5
Path = [1, 2, 4, 5]
```

### Empty Tree

```text
root = NULL
Path = []
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(N)` | In the worst case, DFS checks every node. |
| Extra space | `O(H)` | Recursion stack and current path length. |

- `N` = number of nodes
- `H` = height of the tree

> For a skewed tree, `H` can be `N`, so worst-case space is `O(N)`.

## Interview Questions 🎯

### 1. Why do we use `path.pop_back()`?

It removes a node from a path that does not lead to the target.

```text
[3, 5, 6]  → target not found below 6
[3, 5]     → backtrack and try another branch
```

### 2. Why does the function return `bool`?

`true` tells parent calls that the target was found. `false` tells them to try another branch or backtrack.

### 3. What happens after the target is found?

Each parent returns `true` immediately, so nodes in the correct path are not removed.

### 4. What if values are not unique?

A target value is not enough to identify one node. Pass the target node pointer instead.

### 5. What is the time complexity?

`O(N)` in the worst case.

### 6. What is the space complexity?

`O(H)` for recursion and the current root-to-node path.

### 7. Can this be solved iteratively?

Yes. Store each node’s parent while doing DFS or BFS, then rebuild the path from target to root and reverse it.
