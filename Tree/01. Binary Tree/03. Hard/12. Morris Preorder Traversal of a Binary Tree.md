# Morris Preorder Traversal of a Binary Tree

> Return preorder traversal (`Root → Left → Right`) using **O(1) auxiliary space**.

Morris traversal avoids recursion and an explicit stack by creating temporary links called **threads**.

---

## Example

```text
       1
      / \
     2   3
    / \
   4   5
        \
         6
```

```text
Preorder = [1, 2, 4, 5, 6, 3]
```

---

## Standard Preorder vs. Morris Preorder 💡

| Standard preorder | Morris preorder |
|---|---|
| Uses recursion or a stack | Uses temporary thread links |
| Extra space: `O(H)` | Auxiliary space: `O(1)` |
| Does not change tree pointers | Changes pointers temporarily, then restores them |

```text
Both visit nodes in this order:
Root → Left → Right
```

---

## The Main Challenge

In preorder, after finishing a left subtree, we need to return to its parent and then visit the right subtree.

Normally, recursion or a stack remembers the parent.

```text
        1
       / \
      2   3
```

After visiting node `2`, how do we return to node `1` without a stack?

**Answer:** Create a temporary thread from the rightmost node of the left subtree back to the current node.

---

## What Is the Inorder Predecessor?

For a node with a left child, its predecessor is the **rightmost node in its left subtree**.

```text
       1
      /
     2
      \
       5  ← predecessor of 1
        \
         6
```

To find it:

```text
prev = current->left
while (prev->right != NULL && prev->right != current):
    prev = prev->right
```

---

## Create a Temporary Thread

Before threading:

```text
       1
      / \
     2   3
    / \
   4   5
        \
         6
```

The rightmost node in the left subtree of `1` is `6`.

Create this temporary link:

```text
6.right → 1
```

```text
       1
      / \
     2   3
    / \
   4   5
        \
         6
          \
           1  ← temporary thread
```

After completing the left subtree, following this thread brings us back to `1`.

> The thread is always removed before moving to the right subtree, so the original tree is restored.

---

## Two Cases at Every Node

### Case 1: No Left Child

```text
current->left == NULL
```

There is no left subtree to visit.

```text
PRINT current
move current to current->right
```

```text
      4
       \
        2  ← temporary thread

Print 4, then move right to 2.
```

---

### Case 2: Has a Left Child

Find the predecessor in the left subtree.

#### 2A. Thread Does Not Exist Yet

```text
prev->right == NULL
```

```text
1. Set prev->right = current   (create thread)
2. PRINT current               (preorder prints root first)
3. Move current = current->left
```

#### 2B. Thread Already Exists

```text
prev->right == current
```

This means the left subtree is finished.

```text
1. Set prev->right = NULL      (remove thread)
2. Move current = current->right
3. Do NOT print current again
```

---

## Morris Inorder vs. Morris Preorder

The only important difference is **when we print** the current node.

```text
Morris Inorder:                 Morris Preorder:

thread created  → go left       thread created  → PRINT, then go left
thread removed  → PRINT          thread removed  → go right, no print
```

```text
Preorder must print a node before visiting its left subtree.
```

## Step-by-Step Trace

```text
       1
      / \
     2   3
    / \
   4   5
        \
         6
```

### At Node 1

```text
left child exists
predecessor = 6
6.right is NULL

create thread: 6.right = 1
print 1
move left to 2

answer = [1]
```

### At Node 2

```text
left child exists
predecessor = 4
4.right is NULL

create thread: 4.right = 2
print 2
move left to 4

answer = [1, 2]
```

### At Node 4

```text
no left child
print 4
move right → 2 (using temporary thread)

answer = [1, 2, 4]
```

### Back at Node 2

```text
predecessor = 4
4.right already points to 2

remove thread: 4.right = NULL
move right to 5
```

### At Nodes 5 and 6

```text
5 has no left child → print 5, move right to 6
6 has no left child → print 6, move right to 1 (thread)

answer = [1, 2, 4, 5, 6]
```

### Back at Node 1

```text
predecessor = 6
6.right already points to 1

remove thread: 6.right = NULL
move right to 3
```

### At Node 3

```text
no left child
print 3
move right to NULL

answer = [1, 2, 4, 5, 6, 3]
```

## Full Algorithm

```text
current = root

while current is not NULL:

    if current has no left child:
        add current value to answer
        current = current.right

    else:
        find predecessor = rightmost node in current.left subtree

        if predecessor.right is NULL:
            predecessor.right = current   // create thread
            add current value to answer   // preorder action
            current = current.left

        else:
            predecessor.right = NULL      // remove thread
            current = current.right
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    vector<int> getPreorder(TreeNode* root) {
        vector<int> preorder;
        TreeNode* current = root;

        while (current != nullptr) {
            if (current->left == nullptr) {
                // No left subtree: visit current and move right.
                preorder.push_back(current->val);
                current = current->right;
            } else {
                // Find rightmost node in current's left subtree.
                TreeNode* predecessor = current->left;

                while (predecessor->right != nullptr &&
                       predecessor->right != current) {
                    predecessor = predecessor->right;
                }

                if (predecessor->right == nullptr) {
                    // First time at current: make a thread and print root.
                    predecessor->right = current;
                    preorder.push_back(current->val);
                    current = current->left;
                } else {
                    // Left subtree is done: remove thread and go right.
                    predecessor->right = nullptr;
                    current = current->right;
                }
            }
        }

        return preorder;
    }
};

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
           1
          / \
         2   3
        / \
       4   5
            \
             6
    */
    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(3);
    root->left->left = new TreeNode(4);
    root->left->right = new TreeNode(5);
    root->left->right->right = new TreeNode(6);

    Solution solution;
    cout << "Morris preorder traversal: ";
    printVector(solution.getPreorder(root));

    // Morris traversal restored all temporary links, so deletion is safe.
    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Morris preorder traversal: [1, 2, 4, 5, 6, 3]
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(N)` | A link is created and removed at most once; nodes are processed a constant number of times. |
| Auxiliary space | `O(1)` | Only pointer variables are used. |
| Output space | `O(N)` | The returned preorder vector stores all node values. |

> Morris traversal is `O(1)` **auxiliary** space. The output array is usually not counted as extra traversal space.

## Interview Questions 🎯

### 1. Why is Morris traversal `O(1)` auxiliary space?

It does not use recursion, a stack, or a queue. It uses a few pointers and temporary tree links.

### 2. What is a thread in Morris traversal?

A temporary pointer from the predecessor back to the current node.

```text
predecessor.right → current
```

### 3. Why is the thread removed?

The original tree must be restored after traversal.

### 4. When is a node printed in Morris preorder?

```text
No left child             → print immediately
Thread created first time → print before moving left
Thread found again        → do not print
```

### 5. What is the difference between Morris inorder and preorder?

```text
Inorder  → print when removing a thread
Preorder → print when creating a thread
```

### 6. Can Morris traversal be used for inorder too?

Yes. Morris traversal was originally designed for inorder traversal.

### 7. Does Morris traversal permanently modify the tree?

No. Every temporary thread is removed before traversal finishes.

### 8. What is the time complexity?

`O(N)`.
