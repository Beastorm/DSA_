# Flatten Binary Tree to Linked List

> Convert a binary tree into a linked list in **preorder** order.

Rules:

```text
1. Use right pointer as the next pointer.
2. Set every left pointer to NULL.
3. Do not create new nodes.
```

---

## Example

```text
Before:

       1
      / \
     2   5
    / \   \
   3   4   6
            \
             7
```

Preorder traversal is:

```text
1 → 2 → 3 → 4 → 5 → 6 → 7
```

After flattening:

```text
1
 \
  2
   \
    3
     \
      4
       \
        5
         \
          6
           \
            7
```

```text
Every left pointer = NULL
```

---

## Main Idea 💡

The flattened list must follow:

```text
Root → Left → Right
```

This is exactly preorder traversal.

```text
Original tree:        Flattened list:

       1                  1 → 2 → 3 → 4 → 5 → 6 → 7
      / \
     2   5
    / \   \
   3   4   6
            \
             7
```

---

# Approach 1: Recursive Reverse Preorder

## Simple Idea

Process nodes in reverse preorder order:

```text
Right → Left → Root
```

Keep a pointer `previous` that points to the already-built linked list.

For every node:

```text
root->right = previous
root->left = NULL
previous = root
```

---

## Why Process Right Before Left?

Preorder needs this final order:

```text
Root → Left → Right
```

If we build the list backward, we process:

```text
Right → Left → Root
```

Example:

```text
Desired list: 1 → 2 → 3
Build backward: 3, then 2, then 1
```

```text
previous = NULL

visit 3 → 3.right = NULL, previous = 3
visit 2 → 2.right = 3,    previous = 2
visit 1 → 1.right = 2,    previous = 1
```

---

## C++ Code — Recursive Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    TreeNode* previous;

    void reversePreorder(TreeNode* root) {
        if (root == nullptr) return;

        // Process right first, then left.
        reversePreorder(root->right);
        reversePreorder(root->left);

        // Link current node to the already-built list.
        root->right = previous;
        root->left = nullptr;
        previous = root;
    }

public:
    void flatten(TreeNode* root) {
        previous = nullptr;
        reversePreorder(root);
    }
};

void printFlattenedList(TreeNode* root) {
    while (root != nullptr) {
        cout << root->val;
        if (root->right) cout << " → ";
        root = root->right;
    }
    cout << endl;
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
           1
          / \
         2   5
        / \   \
       3   4   6
                \
                 7
    */
    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(5);
    root->left->left = new TreeNode(3);
    root->left->right = new TreeNode(4);
    root->right->right = new TreeNode(6);
    root->right->right->right = new TreeNode(7);

    Solution solution;
    solution.flatten(root);

    cout << "Flattened list: ";
    printFlattenedList(root);

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Flattened list: 1 → 2 → 3 → 4 → 5 → 6 → 7
```

### Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N)` |
| Extra space | `O(H)` recursion stack |

# Approach 2: Iterative Stack

## Simple Idea

Use a stack to simulate preorder traversal.

To visit left before right, push nodes in this order:

```text
1. Push right child first.
2. Push left child second.
```

A stack is LIFO, so the left child comes out first.

---

## Stack Walkthrough

For this tree:

```text
       1
      / \
     2   5
    / \
   3   4
```

```text
Stack starts: [1]

Pop 1:
  push 5, then 2
  stack = [5, 2]
  1.right = 2

Pop 2:
  push 4, then 3
  stack = [5, 4, 3]
  2.right = 3

Pop 3:
  stack = [5, 4]
  3.right = 4

Pop 4:
  stack = [5]
  4.right = 5
```

```text
Result: 1 → 2 → 3 → 4 → 5
```

---

## C++ Code — Stack Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    void flatten(TreeNode* root) {
        if (root == nullptr) return;

        stack<TreeNode*> st;
        st.push(root);

        while (!st.empty()) {
            TreeNode* current = st.top();
            st.pop();

            // Push right first so left is processed first.
            if (current->right) st.push(current->right);
            if (current->left) st.push(current->left);

            // The next stack node is the next preorder node.
            current->right = st.empty() ? nullptr : st.top();
            current->left = nullptr;
        }
    }
};

void printFlattenedList(TreeNode* root) {
    while (root != nullptr) {
        cout << root->val;
        if (root->right) cout << " → ";
        root = root->right;
    }
    cout << endl;
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
           1
          / \
         2   5
        / \   \
       3   4   6
                \
                 7
    */
    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(5);
    root->left->left = new TreeNode(3);
    root->left->right = new TreeNode(4);
    root->right->right = new TreeNode(6);
    root->right->right->right = new TreeNode(7);

    Solution solution;
    solution.flatten(root);

    cout << "Flattened list: ";
    printFlattenedList(root);

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Flattened list: 1 → 2 → 3 → 4 → 5 → 6 → 7
```

### Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N)` |
| Extra space | `O(H)` stack space |

# Approach 3: In-Place Rewiring (Optimal) ⚡

## Key Observation

For a node with a left subtree:

```text
       current
       /     \
    left     right
```

The whole left subtree must appear before the original right subtree in preorder.

So:

```text
1. Find the rightmost node in the left subtree.
2. Attach original right subtree to that rightmost node.
3. Move left subtree to current->right.
4. Set current->left = NULL.
```

---

## Rewiring Diagram

Before processing node `1`:

```text
       1
      / \
     2   5
    / \
   3   4
```

The rightmost node of the left subtree is `4`.

```text
Step 1: 4.right = 5

       1
      /
     2
    / \
   3   4
        \
         5
```

Move the left subtree to the right:

```text
Step 2: 1.right = 2
Step 3: 1.left = NULL

       1
        \
         2
        / \
       3   4
            \
             5
```

Now continue at node `2` and repeat.

---

## In-Place Walkthrough

```text
       1
      / \
     2   5
    / \
   3   4
```

### Process Node 1

```text
rightmost node in left subtree = 4

4.right = 5
1.right = 2
1.left = NULL
```

```text
1 → 2
    / \
   3   4 → 5
```

### Process Node 2

```text
rightmost node in left subtree = 3

3.right = 4
2.right = 3
2.left = NULL
```

```text
1 → 2 → 3 → 4 → 5
```

---

## C++ Code — Optimal Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    void flatten(TreeNode* root) {
        TreeNode* current = root;

        while (current != nullptr) {
            if (current->left != nullptr) {
                // Find the rightmost node in the left subtree.
                TreeNode* predecessor = current->left;
                while (predecessor->right != nullptr) {
                    predecessor = predecessor->right;
                }

                // Put original right subtree after the left subtree.
                predecessor->right = current->right;

                // Move left subtree to the right and clear left pointer.
                current->right = current->left;
                current->left = nullptr;
            }

            current = current->right;
        }
    }
};

void printFlattenedList(TreeNode* root) {
    while (root != nullptr) {
        cout << root->val;
        if (root->right) cout << " → ";
        root = root->right;
    }
    cout << endl;
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
           1
          / \
         2   5
        / \   \
       3   4   6
                \
                 7
    */
    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(5);
    root->left->left = new TreeNode(3);
    root->left->right = new TreeNode(4);
    root->right->right = new TreeNode(6);
    root->right->right->right = new TreeNode(7);

    Solution solution;
    solution.flatten(root);

    cout << "Flattened list: ";
    printFlattenedList(root);

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Flattened list: 1 → 2 → 3 → 4 → 5 → 6 → 7
```

### Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N)` |
| Extra space | `O(1)` |

> The optimal approach changes pointers in place and does not use recursion, a stack, or new nodes.

---

## Comparison

| Approach | Time | Extra Space | Key Idea |
|---|---:|---:|---|
| Recursive reverse preorder | `O(N)` | `O(H)` | Build the list backward using `previous`. |
| Iterative stack | `O(N)` | `O(H)` | Simulate preorder with a stack. |
| In-place rewiring | `O(N)` | `O(1)` | Attach original right subtree after left subtree. |

## Interview Questions 🎯

### 1. What order must the flattened list follow?

Preorder:

```text
Root → Left → Right
```

### 2. Why does reverse preorder process right before left?

It builds the final preorder list backward.

```text
Right → Left → Root
```

### 3. Why push right before left in the stack approach?

A stack is LIFO. Pushing right first makes left appear on top and get processed first.

### 4. Why do we find the rightmost node of the left subtree in the optimal solution?

It is the last node of the left subtree in preorder, so the original right subtree must be attached there.

### 5. Why set every left pointer to NULL?

The required final structure is a linked list that uses only right pointers.

### 6. Does the optimal solution create new nodes?

No. It only rearranges existing pointers.

### 7. What is the time complexity of all approaches?

`O(N)`.

### 8. What is the extra space of the optimal approach?

`O(1)`.
