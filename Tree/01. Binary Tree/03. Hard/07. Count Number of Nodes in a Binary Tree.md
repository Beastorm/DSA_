# Count Nodes in a Complete Binary Tree

> Count the number of nodes in a **complete binary tree**.

A complete binary tree has these rules:

```text
1. Every level is full, except possibly the last level.
2. Nodes in the last level are filled from left to right.
```

## Perfect vs. Complete Binary Tree 💡

### Perfect Binary Tree

Every level is completely full.

```text
           1
          / \
         2   3
        / \ / \
       4  5 6  7
```

If height is `3` nodes:

```text
number of nodes = 2³ - 1 = 7
```

---

### Complete Binary Tree

Only the last level may be incomplete, and it must fill from left to right.

```text
           1
          / \
         2   3
        / \ /
       4  5 6
```

This tree is not perfect, but it is complete.

# Approach 1: Brute Force Traversal

## Simple Idea

Visit every node and add `1` to the count.

Any traversal works:

```text
DFS, BFS, inorder, preorder, or postorder
```

For the example:

```text
       1
      / \
     2   3
    / \ /
   4  5 6
```

One inorder traversal is:

```text
4 → 2 → 5 → 1 → 6 → 3
```

There are `6` visited nodes.

---

## C++ Code — Brute Force Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    int countNodes(TreeNode* root) {
        if (root == nullptr) return 0;

        // Count current node + all nodes in both subtrees.
        return 1 + countNodes(root->left) + countNodes(root->right);
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
           1
          / \
         2   3
        / \ /
       4  5 6
    */
    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(3);
    root->left->left = new TreeNode(4);
    root->left->right = new TreeNode(5);
    root->right->left = new TreeNode(6);

    Solution solution;
    cout << "Total nodes: " << solution.countNodes(root) << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Total nodes: 6
```

---

## Brute Force Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(N)` | Every node is visited once. |
| Extra space | `O(H)` | Recursive call stack, where `H` is tree height. |

> In the worst case of a skewed tree, `H = N`. For a complete tree, `H = O(log N)`.

# Approach 2: Use the Complete Tree Property ⚡

## Key Idea

At any node, find:

```text
leftHeight  = length of the leftmost path
rightHeight = length of the rightmost path
```

```text
       root
       /  \
      ...  ...
     /        \
leftmost    rightmost
```

### If Both Heights Are Equal

```text
leftHeight == rightHeight
```

Then this subtree is a **perfect binary tree**.

```text
nodes = 2^height - 1
```

We can count the whole subtree immediately without visiting every node.

---

## Example: Detect a Perfect Subtree

```text
       2
      / \
     4   5
```

```text
leftmost path:  2 → 4  → height = 2
rightmost path: 2 → 5  → height = 2
```

Heights are equal, so it is perfect.

```text
nodes = 2² - 1 = 3
```

No need to visit nodes `4` and `5` one by one.

---

## Example: Non-Perfect Complete Tree

```text
       1
      / \
     2   3
    / \ /
   4  5 6
```

At root `1`:

```text
leftmost path:  1 → 2 → 4  → height = 3
rightmost path: 1 → 3      → height = 2
```

The heights differ, so the whole tree is not perfect.

```text
Count root + left subtree + right subtree
```

But the left subtree is perfect:

```text
       2
      / \
     4   5

nodes = 2² - 1 = 3
```

This lets us skip most of the work.

---

## Why Does This Work?

This shortcut depends on the tree being **complete**.

```text
In a complete tree:

leftmost height == rightmost height
            ↓
subtree must be perfect
```

> For an arbitrary binary tree, equal leftmost and rightmost heights do **not** always mean the subtree is perfect. Use this optimization only for complete binary trees.

---

## Step-by-Step Trace

```text
       1
      / \
     2   3
    / \ /
   4  5 6
```

### At Node 1

```text
leftHeight  = 3  (1 → 2 → 4)
rightHeight = 2  (1 → 3)

3 != 2 → not perfect
```

Recurse into both children.

### At Node 2

```text
leftHeight  = 2  (2 → 4)
rightHeight = 2  (2 → 5)

2 == 2 → perfect subtree
nodes = 2² - 1 = 3
```

### At Node 3

```text
leftHeight  = 2  (3 → 6)
rightHeight = 1  (3)

2 != 1 → not perfect
```

```text
count(3) = 1 + count(6) + count(NULL)
         = 1 + 1 + 0
         = 2
```

### Final Count

```text
count(1) = 1 + count(2) + count(3)
         = 1 + 3 + 2
         = 6
```

## C++ Code — Optimal Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    int leftHeight(TreeNode* node) {
        int height = 0;
        while (node != nullptr) {
            height++;
            node = node->left;
        }
        return height;
    }

    int rightHeight(TreeNode* node) {
        int height = 0;
        while (node != nullptr) {
            height++;
            node = node->right;
        }
        return height;
    }

public:
    long long countNodes(TreeNode* root) {
        if (root == nullptr) return 0;

        int left = leftHeight(root);
        int right = rightHeight(root);

        // Equal heights mean this complete subtree is perfect.
        if (left == right) {
            return (1LL << left) - 1;
        }

        return 1 + countNodes(root->left) + countNodes(root->right);
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
           1
          / \
         2   3
        / \ /
       4  5 6
    */
    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(3);
    root->left->left = new TreeNode(4);
    root->left->right = new TreeNode(5);
    root->right->left = new TreeNode(6);

    Solution solution;
    cout << "Total nodes: " << solution.countNodes(root) << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Total nodes: 6
```

---

## Optimal Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(log² N)` | At most `O(log N)` recursive levels; each height check costs `O(log N)`. |
| Extra space | `O(log N)` | Recursion depth is the tree height. |

The optimal method is faster because it counts perfect subtrees using a formula instead of visiting all nodes.

---

## Comparison

| Approach | Time | Extra Space | Main Idea |
|---|---:|---:|---|
| Brute Force | `O(N)` | `O(H)` | Visit every node. |
| Complete-tree optimization | `O(log² N)` | `O(log N)` | Use `2^height - 1` for perfect subtrees. |

## Interview Questions 🎯

### 1. What makes a binary tree complete?

All levels are full except possibly the last, and the last level fills from left to right.

### 2. What is the difference between complete and perfect trees?

```text
Perfect  → every level is full
Complete → only the last level may be incomplete
```

### 3. Why do equal leftmost and rightmost heights help?

In a complete tree, equal heights mean the subtree is perfect.

```text
nodes = 2^height - 1
```

### 4. Can we use this optimization on any binary tree?

No. It relies on the complete-tree property.

### 5. Why is the optimal time complexity `O(log² N)`?

There are at most `O(log N)` recursive levels, and each level computes two heights in `O(log N)` time.

### 6. What is the brute-force time complexity?

`O(N)` because it visits every node.

### 7. Why use `1LL << height` instead of `1 << height`?

`1LL` uses `long long`, which supports larger tree counts before overflow.
