# Print All Nodes at Distance `K` in a Binary Tree

> Return all nodes that are exactly `K` edges away from a target node.

The answer can be in any order.

## The Main Problem 💡

A binary-tree node can move only **downward** through its children.

```text
      parent
      /    \
   left   right
```

But to find nodes at distance `K`, we may need to move **upward** too.

For target `5`, we must move upward to node `3`:

```text
      3
     /
    5  ← target
```

Then from node `3`, we can move down to node `1`.

```text
5 → 3 → 1
```

So we need a way to move from every child back to its parent.

---

## Solution: Treat the Tree Like an Undirected Graph

### Step 1: Build Parent Links

Store this mapping:

```text
child → parent
```

For the example tree:

```text
5 → 3       1 → 3
6 → 5       2 → 5
0 → 1       8 → 1
7 → 2       4 → 2
```

Now each node can move in up to three directions:

```text
left child
right child
parent
```

```text
Original tree links:            After using parent links:

        3                              3
       / \                           /   \
      5   1                        ↔5     1↔
     / \                          /  \   / \
    6   2                       6↔   2 0   8
       / \                          / \
      7   4                        7   4

From node 5, valid moves: 6, 2, 3
```

---

## Step 2: BFS from the Target

After parent links are available, run BFS starting from the target node.

```text
BFS level = distance from target
```

```text
Level 0 → nodes at distance 0
Level 1 → nodes at distance 1
Level 2 → nodes at distance 2
...
```

When BFS reaches level `K`, all nodes in the queue are the answer.

---

## Why Do We Need a `visited` Set?

After adding parent links, we can go back and forth between a node and its parent.

```text
5 → 3 → 5 → 3 → ...
```

Without a visited set, BFS could revisit the same nodes forever.

```text
visited = { nodes already added to the queue }
```

```text
When visiting 5:
add 6, 2, 3
mark all of them visited

When later visiting 3:
node 5 is already visited, so do not add it again
```

---

## Step-by-Step BFS Trace: `target = 5`, `K = 2`

### Start

```text
Queue:   [5]
Visited: {5}
Distance = 0
```

### Process Distance 0

From node `5`, explore:

```text
left child  → 6
right child → 2
parent      → 3
```

```text
Queue:   [6, 2, 3]
Visited: {5, 6, 2, 3}
Distance = 1
```

### Process Distance 1

```text
Node 6 → parent 5 is already visited

Node 2 → add children 7 and 4

Node 3 → left child 5 is visited
         add right child 1
```

```text
Queue:   [7, 4, 1]
Visited: {5, 6, 2, 3, 7, 4, 1}
Distance = 2
```

Distance is now `K`, so stop.

```text
Answer = [7, 4, 1]
```

---

## Full Algorithm

```text
1. If root is NULL, return an empty list.
2. Build a parent map for every node using BFS.
3. Start another BFS from the target node.
4. Mark target as visited.
5. For each BFS level:
      a. If distance == K, stop.
      b. For every node, try left child, right child, and parent.
      c. Add only unvisited nodes to the queue.
6. The remaining queue nodes are exactly distance K away.
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    void buildParentMap(TreeNode* root,
                        unordered_map<TreeNode*, TreeNode*>& parent) {
        queue<TreeNode*> q;
        q.push(root);

        while (!q.empty()) {
            TreeNode* current = q.front();
            q.pop();

            if (current->left) {
                parent[current->left] = current;
                q.push(current->left);
            }

            if (current->right) {
                parent[current->right] = current;
                q.push(current->right);
            }
        }
    }

public:
    vector<int> distanceK(TreeNode* root, TreeNode* target, int k) {
        if (root == nullptr || target == nullptr) return {};

        // Step 1: enable upward movement.
        unordered_map<TreeNode*, TreeNode*> parent;
        buildParentMap(root, parent);

        // Step 2: BFS starting from target.
        queue<TreeNode*> q;
        unordered_set<TreeNode*> visited;

        q.push(target);
        visited.insert(target);
        int distance = 0;

        while (!q.empty()) {
            if (distance == k) break;

            int levelSize = q.size();
            distance++;

            for (int i = 0; i < levelSize; i++) {
                TreeNode* current = q.front();
                q.pop();

                // All possible graph neighbours.
                vector<TreeNode*> neighbours = {
                    current->left,
                    current->right,
                    parent.count(current) ? parent[current] : nullptr
                };

                for (TreeNode* next : neighbours) {
                    if (next != nullptr && !visited.count(next)) {
                        visited.insert(next);
                        q.push(next);
                    }
                }
            }
        }

        // Queue now contains nodes at exactly distance k.
        vector<int> answer;
        while (!q.empty()) {
            answer.push_back(q.front()->val);
            q.pop();
        }

        return answer;
    }
};

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
               3
              / \
             5   1
            / \ / \
           6  2 0  8
             / \
            7   4
    */
    TreeNode* root = new TreeNode(3);
    root->left = new TreeNode(5);
    root->right = new TreeNode(1);
    root->left->left = new TreeNode(6);
    root->left->right = new TreeNode(2);
    root->right->left = new TreeNode(0);
    root->right->right = new TreeNode(8);
    root->left->right->left = new TreeNode(7);
    root->left->right->right = new TreeNode(4);

    TreeNode* target = root->left; // Node 5
    int k = 2;

    Solution solution;
    cout << "Nodes at distance " << k << " from " << target->val << ": ";
    printVector(solution.distanceK(root, target, k));

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Nodes at distance 2 from 5: [7, 4, 1]
```

## Special Cases

### `K = 0`

The target itself is at distance `0`.

```text
Target = 5, K = 0
Answer = [5]
```

### `K` Is Larger Than the Farthest Distance

```text
Target = 5, K = 10
Answer = []
```

There are no nodes that far away.

### Target Is the Root

```text
       3
      / \
     5   1
```

```text
Target = 3, K = 1
Answer = [5, 1]
```

The root has no parent, so only its children are explored.

### Single Node Tree

```text
  1
```

```text
Target = 1, K = 0 → [1]
Target = 1, K = 1 → []
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(N)` | One BFS builds parents; another visits nodes at most once. |
| Space | `O(N)` | Parent map, visited set, and queue can store all nodes. |

- `N` = number of nodes in the tree.

## Interview Questions 🎯

### 1. Why can’t normal DFS from the target solve this directly?

A tree node normally has only child links. We also need to move upward to its parent.

### 2. Why build a parent map?

It gives every node a parent link.

```text
child → parent
```

This lets us treat the tree like an undirected graph.

### 3. Why use BFS from the target?

BFS processes nodes by distance.

```text
BFS level 0 = distance 0
BFS level 1 = distance 1
BFS level K = answer
```

### 4. Why is a visited set required?

It prevents going back and forth between a child and its parent.

```text
5 → 3 → 5 → ...
```

### 5. What if `K = 0`?

Return the target node itself.

### 6. What if the target is the root?

There is no parent to explore. BFS uses only the root’s children.

### 7. What is the time complexity?

`O(N)`.

### 8. Can we avoid the parent map?

Yes, with a recursive approach that searches for the target and sends distance information back upward. But the parent-map + BFS solution is easier to understand.
