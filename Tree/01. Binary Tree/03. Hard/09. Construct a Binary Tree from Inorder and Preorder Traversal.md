# Construct a Binary Tree from Preorder and Inorder Traversal

> Given preorder and inorder traversals, build the unique binary tree.

This works when all node values are **distinct**.

[Construct a Binary Tree from Preorder and Inorder Traversal](https://htmlpreview.github.io/?https://github.com/Beastorm/DSA_/blob/main/junk/pages/buildtree-visualizer.html)

---

## Traversal Rules 💡

```text
Preorder: Root → Left → Right
Inorder:  Left → Root → Right
```

This gives us everything we need:

```text
Preorder tells us: the next root node
Inorder tells us: where left and right subtrees split
```

---

## Example 1

```text
preorder = [3, 9, 20, 15, 7]
inorder  = [9, 3, 15, 20, 7]
```

### Find the Root

The first preorder value is always the root.

```text
preorder = [3, 9, 20, 15, 7]
            ↑
          root = 3
```

Find `3` in inorder:

```text
inorder = [9, 3, 15, 20, 7]
              ↑
           root = 3
```

Everything left of `3` belongs to the left subtree. Everything right belongs to the right subtree.

```text
inorder = [ 9 | 3 | 15, 20, 7 ]
             left   root   right
```

So the tree starts like this:

```text
      3
     / \
    9   ?
```

The next preorder value after `9` is `20`, so it is the right subtree root.

```text
         3
        / \
       9   20
          /  \
         15   7
```

**Output:**

```text
[3, 9, 20, null, null, 15, 7]
```

## Why Store Inorder Indexes?

At every recursive call, we must find the root in the inorder array.

```text
value → index in inorder

9  → 0
3  → 1
15 → 2
20 → 3
7  → 4
```

With the provided `std::map`:

```text
find index of root → O(log N)
```

Without storing indexes, searching the inorder array repeatedly can make the solution `O(N²)`.

> If you replace `map<int, int>` with `unordered_map<int, int>`, lookup becomes `O(1)` on average and total time becomes `O(N)`.

---

## Simple Recursive Idea

The provided code keeps four array boundaries:

```text
preStart, preEnd   → current preorder range
inStart, inEnd     → current inorder range
```

For each recursive call:

```text
1. preorder[preStart] is the current root.
2. Find that root's index in inorder using inMap.
3. Count left-subtree nodes:
      numsLeft = inRoot - inStart
4. Build the left subtree using its matching preorder and inorder ranges.
5. Build the right subtree using its matching preorder and inorder ranges.
```

Because preorder is `Root → Left → Right`, the left subtree values appear immediately after the root in preorder.

---

## Recursive Flow

```text
build(preStart, preEnd, inStart, inEnd):

if preStart > preEnd OR inStart > inEnd:
    return NULL

root   = preorder[preStart]
inRoot = inMap[root]
numsLeft = inRoot - inStart

root.left = build(
    preStart + 1,
    preStart + numsLeft,
    inStart,
    inRoot - 1
)

root.right = build(
    preStart + numsLeft + 1,
    preEnd,
    inRoot + 1,
    inEnd
)

return root
```

## Step-by-Step Trace

```text

inorder  = [9, 3, 15, 20, 7]
```

### Call 1: Build the Full Tree

```text
build(pre: 0-4, in: 0-4)

root = preorder[0] = 3
inRoot = 1
numsLeft = 1 - 0 = 1
```

```text
left subtree:  build(pre: 1-1, in: 0-0)  → inorder [9]
right subtree: build(pre: 2-4, in: 2-4)  → inorder [15, 20, 7]
```

### Call 2: Build the Left Subtree

```text
build(pre: 1-1, in: 0-0)

root = preorder[1] = 9
inRoot = 0
numsLeft = 0
```

There is nothing to the left or right of `9` in this inorder range.

```text
9 is a leaf node
```

### Call 3: Build the Right Subtree

```text
build(pre: 2-4, in: 2-4)

root = preorder[2] = 20
inRoot = 3
numsLeft = 3 - 2 = 1
```

```text
left subtree:  build(pre: 3-3, in: 2-2) → root = 15
right subtree: build(pre: 4-4, in: 4-4) → root = 7
```

Final tree:

```text
         3
        / \
       9   20
          /  \
         15   7
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        map<int, int> inMap;
        for (int i = 0; i < inorder.size(); i++) {
            inMap[inorder[i]] = i;  // value → inorder index
        }

        return build(preorder, 0, preorder.size() - 1,
                     inorder, 0, inorder.size() - 1, inMap);
    }

private:
    TreeNode* build(vector<int>& preorder, int preStart, int preEnd,
                    vector<int>& inorder, int inStart, int inEnd,
                    map<int, int>& inMap) {
        if (preStart > preEnd || inStart > inEnd) return nullptr;

        TreeNode* root = new TreeNode(preorder[preStart]);
        int inRoot = inMap[root->val];
        int numsLeft = inRoot - inStart;

        root->left = build(preorder, preStart + 1, preStart + numsLeft,
                           inorder, inStart, inRoot - 1, inMap);

        root->right = build(preorder, preStart + numsLeft + 1, preEnd,
                            inorder, inRoot + 1, inEnd, inMap);

        return root;
    }
};

void printLevelOrder(TreeNode* root) {
    if (root == nullptr) {
        cout << "[]\n";
        return;
    }

    vector<string> values;
    queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        TreeNode* current = q.front();
        q.pop();

        if (current == nullptr) {
            values.push_back("null");
            continue;
        }

        values.push_back(to_string(current->val));
        q.push(current->left);
        q.push(current->right);
    }

    while (!values.empty() && values.back() == "null") {
        values.pop_back();
    }

    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    vector<int> preorder = {3, 9, 20, 15, 7};
    vector<int> inorder = {9, 3, 15, 20, 7};

    Solution solution;
    TreeNode* root = solution.buildTree(preorder, inorder);

    cout << "Constructed tree (level order): ";
    printLevelOrder(root);

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Constructed tree (level order): [3, 9, 20, null, null, 15, 7]
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(N log N)` | Each value builds one node; `std::map` lookup is `O(log N)`. |
| Extra space | `O(N)` | Inorder map plus recursion stack. |

```text
Balanced tree → recursion stack O(log N)
Skewed tree   → recursion stack O(N)
```

> With the provided `std::map`, time is `O(N log N)`. Without stored indexes, repeated inorder scans make worst-case time `O(N²)`. Using `unordered_map` gives `O(N)` average time.

## Interview Questions 🎯

### 1. Why is preorder useful here?

The first unprocessed preorder value is always the root of the current subtree.

### 2. Why is inorder useful here?

It splits nodes into left and right subtrees around the root.

```text
[left subtree | root | right subtree]
```

### 3. Why do we build the left subtree before the right subtree?

Preorder order is:

```text
Root → Left → Right
```

After consuming a root, the next preorder values belong to the left subtree first.

### 4. Why use a map of inorder indexes?

The provided `std::map` finds each root’s inorder index in `O(log N)` time. It avoids scanning the inorder array every time.

### 5. Are preorder and inorder always enough to build a unique tree?

Only when node values are distinct. With duplicate values, the root position in inorder can be ambiguous.

### 6. Can preorder and postorder always build a unique binary tree?

No. Different trees can have the same preorder and postorder traversals.

### 7. What is the time complexity of the provided `std::map` code?

`O(N log N)`. Replacing `map` with `unordered_map` makes it `O(N)` on average.

### 8. What is the space complexity?

`O(N)` for the index map and recursion stack in the worst case.
