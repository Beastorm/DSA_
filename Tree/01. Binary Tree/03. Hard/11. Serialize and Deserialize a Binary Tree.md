# Serialize and Deserialize a Binary Tree

> Convert a binary tree into a string (**serialize**) and rebuild the same tree from that string (**deserialize**).

```text
Tree → String → Same Tree
```

[Serialize and Deserialize a Binary Tree](https://htmlpreview.github.io/?https://github.com/Beastorm/DSA_/blob/main/junk/pages/serdes-visualizer.html)

---

## Why Is Serialization Needed? 💡

A tree uses pointers, so it cannot be directly stored in a file or sent over a network.

Serialization converts it into plain text:

```text
Binary tree → "1,2,3,#,#,4,5,#,#,#,#,"
```

Deserialization reads that text and recreates the exact tree structure.

---

## Example Tree

```text
       1
      / \
     2   3
        / \
       4   5
```

Serialized string using level-order traversal:

```text
"1,2,3,#,#,4,5,#,#,#,#,"
```

```text
#  means NULL / missing child
,  separates values
```

---

## Why Do We Store `#` for Null Nodes?

Without null markers, different trees can produce the same values.

```text
Tree A:              Tree B:
    1                    1
   /                      \
  2                        2
```

Without `#`, both could look like:

```text
"1,2"
```

With null markers:

```text
Tree A → "1,2,#,#,#,"
Tree B → "1,#,2,#,#,"
```

Now the structure is preserved.

---

## Main Idea: BFS for Both Operations 📚

### Serialize: Tree → String

Use level-order traversal.

```text
For every queue item:

real node → add "value,"
NULL node → add "#,"
```

For a real node, add both children to the queue, even if a child is `NULL`.

---

### Deserialize: String → Tree

Read tokens one by one.

```text
"1" → create root
"2" → make root.left
"3" → make root.right
"#" → missing child
```

Use a queue of parents waiting for their left and right children.

## Serialization Walkthrough

```text
       1
      / \
     2   3
        / \
       4   5
```

```text
Queue: [1]
```

| Remove from queue | Add to string | Add to queue |
|---|---|---|
| `1` | `1,` | `2, 3` |
| `2` | `2,` | `NULL, NULL` |
| `3` | `3,` | `4, 5` |
| `NULL` | `#,` | nothing |
| `NULL` | `#,` | nothing |
| `4` | `4,` | `NULL, NULL` |
| `5` | `5,` | `NULL, NULL` |
| `NULL` × 4 | `#,#,#,#,` | nothing |

```text
Final string:
"1,2,3,#,#,4,5,#,#,#,#,"
```

## Deserialization Walkthrough

```text
Input: "1,2,3,#,#,4,5,#,#,#,#,"
```

### Start

```text
Read "1" → create root node 1
Queue: [1]
```

### Process Node 1

```text
Read "2" → 1.left = 2
Read "3" → 1.right = 3

Queue: [2, 3]
```

### Process Node 2

```text
Read "#" → 2.left = NULL
Read "#" → 2.right = NULL

Queue: [3]
```

### Process Node 3

```text
Read "4" → 3.left = 4
Read "5" → 3.right = 5

Queue: [4, 5]
```

The next four `#` tokens make nodes `4` and `5` leaves.

```text
Original tree is restored ✓
```

---

## Full Algorithm

### Serialization

```text
1. If root is NULL, return an empty string.
2. Put root in a queue.
3. While queue is not empty:
      a. Remove a node.
      b. If it is NULL, append "#,".
      c. Otherwise append "value," and add both children to queue.
4. Return the string.
```

### Deserialization

```text
1. If the string is empty, return NULL.
2. Read first token and create the root.
3. Put root in a queue.
4. While queue is not empty:
      a. Remove a parent node.
      b. Read next token for left child.
      c. Read next token for right child.
      d. Create and queue a child only when its token is not "#".
5. Return root.
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    // Serialize: Tree → String
    string serialize(TreeNode* root) {
        if (root == nullptr) return "";

        string data;
        queue<TreeNode*> q;
        q.push(root);

        while (!q.empty()) {
            TreeNode* current = q.front();
            q.pop();

            if (current == nullptr) {
                data += "#,";
            } else {
                data += to_string(current->val) + ",";
                q.push(current->left);
                q.push(current->right);
            }
        }

        return data;
    }

    // Deserialize: String → Tree
    TreeNode* deserialize(const string& data) {
        if (data.empty()) return nullptr;

        stringstream stream(data);
        string token;

        getline(stream, token, ',');
        TreeNode* root = new TreeNode(stoi(token));

        queue<TreeNode*> q;
        q.push(root);

        while (!q.empty()) {
            TreeNode* parent = q.front();
            q.pop();

            // Read left child token.
            getline(stream, token, ',');
            if (token != "#") {
                parent->left = new TreeNode(stoi(token));
                q.push(parent->left);
            }

            // Read right child token.
            getline(stream, token, ',');
            if (token != "#") {
                parent->right = new TreeNode(stoi(token));
                q.push(parent->right);
            }
        }

        return root;
    }
};

void printLevelOrder(TreeNode* root) {
    if (root == nullptr) {
        cout << "[]\n";
        return;
    }

    vector<string> values;
    queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        TreeNode* current = q.front();
        q.pop();

        if (current == nullptr) {
            values.push_back("null");
            continue;
        }

        values.push_back(to_string(current->val));
        q.push(current->left);
        q.push(current->right);
    }

    while (!values.empty() && values.back() == "null") {
        values.pop_back();
    }

    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
           1
          / \
         2   3
            / \
           4   5
    */
    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(3);
    root->right->left = new TreeNode(4);
    root->right->right = new TreeNode(5);

    Solution solution;

    cout << "Original tree: ";
    printLevelOrder(root);

    string data = solution.serialize(root);
    cout << "Serialized: " << data << endl;

    TreeNode* restored = solution.deserialize(data);
    cout << "Restored tree: ";
    printLevelOrder(restored);

    deleteTree(root);
    deleteTree(restored);
    return 0;
}
```

**Output:**

```text
Original tree: [1, 2, 3, null, null, 4, 5]
Serialized: 1,2,3,#,#,4,5,#,#,#,#,
Restored tree: [1, 2, 3, null, null, 4, 5]
```

## Special Cases

### Empty Tree

```text
serialize(NULL)     → ""
deserialize("")     → NULL
```

### Single Node

```text
  1
```

```text
serialize → "1,#,#,"
```

### Left-Skewed Tree

```text
    1
   /
  2
 /
3
```

```text
serialize → "1,2,#,3,#,#,#,"
```

The `#` values are necessary to show that every right child is missing.

---

## Complexity

| Operation | Time | Space |
|---|---:|---:|
| Serialize | `O(N)` | `O(N)` |
| Deserialize | `O(N)` | `O(N)` |

- Every real node and null marker is processed a constant number of times.
- The queue can hold up to one full level of nodes.
- The serialized string itself also uses `O(N)` space.

## Interview Questions 🎯

### 1. Why are null markers needed?

They preserve the exact tree structure.

```text
1 with left child 2  ≠  1 with right child 2
```

### 2. Why use BFS for serialization?

BFS naturally writes nodes level by level, and it matches the queue-based reconstruction process.

### 3. Can DFS be used instead?

Yes. Preorder DFS with null markers also works.

```text
root, left subtree, right subtree
```

### 4. Why do we add null children to the serialization queue?

They must be written as `#` so that missing child positions are not lost.

### 5. What does an empty tree serialize to?

In this implementation, it serializes to an empty string: `""`.

### 6. What is the time complexity?

`O(N)` for both serialization and deserialization.

### 7. What is the space complexity?

`O(N)` for the queue, serialized string, and reconstructed tree.

### 8. Can values be negative or multi-digit?

Yes. `to_string()` writes them and `stoi()` reads them correctly. The comma delimiter separates tokens.
