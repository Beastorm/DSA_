# Maximum Width of a Binary Tree

> Return the largest width among all levels of a binary tree.

The width of a level is measured from its leftmost node to its rightmost node, **including missing positions between them**.

[Maximum Width of a Binary Tree](https://htmlpreview.github.io/?https://github.com/Beastorm/DSA_/blob/main/junk/pages/width-visualizer.html)

---

## Example 1

```text
          1
         / \
        2   3
       / \   \
      5   6   9
```

At level 3, there is a missing position between `6` and `9`.

```text
Complete-tree positions at level 3:

Position:   3   4   5   6
Node:       5   6   _   9

Width = last position - first position + 1
      = 6 - 3 + 1
      = 4
```

**Output:**

```text
Maximum width = 4
```

> There are only 3 real nodes at this level (`5, 6, 9`), but the width is `4` because the empty position also counts.

Level 1: [1]     → width = 1

## Main Idea: Complete Binary Tree Indexing 💡

Give every node an index as if the tree were a **complete binary tree**.

```text
                 0
               /   \
              1     2
             / \   / \
            3   4 5   6
```

For a node at index `i`:

```text
left child index  = 2 × i + 1
right child index = 2 × i + 2
```

Even if a child is missing, its position still exists conceptually.

```text
          0
        /   \
       1     2
      /       \
     3         6

Positions 4 and 5 are empty, but they count in the width.
Width = 6 - 3 + 1 = 4
```

---

## Why Can’t We Use Only the Number of Nodes at a Level?

For this level:

```text
      5   6       9
```

There are 3 nodes, but there are 4 positions from `5` to `9`.

```text
[5] [6] [_] [9]
 1   2   3   4 positions
```

```text
Number of nodes = 3  ❌
Actual width    = 4  ✅
```

---

## BFS with `(node, index)`

Use level-order traversal. The queue stores:

```text
(node pointer, complete-tree index)
```

For every level:

```text
firstIndex = index of first node in the level
lastIndex  = index of last node in the level

width = lastIndex - firstIndex + 1
```

---

## Index Normalization (Important) ⚠️

In a very deep tree, complete-tree indexes can become very large.

To avoid unnecessary large values, subtract the first index of the current level from every index at that level.

```text
Original indexes:    [100, 101, 103]
minimum index:        100
Normalized indexes:  [  0,   1,   3]
```

The width does not change:

```text
Original:   103 - 100 + 1 = 4
Normalized:   3 -   0 + 1 = 4
```

## Step-by-Step BFS Trace

```text
          1
         / \
        2   3
       / \   \
      5   6   9
```

### Level 1

```text
Queue: [(1, 0)]

first = 0, last = 0
width = 0 - 0 + 1 = 1

Push children: (2, 1), (3, 2)
```

### Level 2

```text
Queue: [(2, 1), (3, 2)]

minimum index = 1
Normalized indexes: 0, 1

first = 0, last = 1
width = 1 - 0 + 1 = 2

Push children:
2 → 5 at index 1, 6 at index 2
3 → 9 at index 4
```

### Level 3

```text
Queue: [(5, 1), (6, 2), (9, 4)]

minimum index = 1
Normalized indexes: 0, 1, 3

first = 0, last = 3
width = 3 - 0 + 1 = 4  ✓
```

## Full Algorithm

```text
1. If root is NULL, return 0.
2. Put (root, 0) in a queue.
3. While the queue is not empty:
      a. Save the current level size.
      b. Save the first queue index as minIndex.
      c. Process all nodes of this level.
      d. Normalize each index: index - minIndex.
      e. Record the first and last normalized indexes.
      f. Push children with complete-tree indexes.
      g. Update answer using last - first + 1.
4. Return the maximum width.
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    int widthOfBinaryTree(TreeNode* root) {
        if (root == nullptr) return 0;

        // node and its complete-tree index
        queue<pair<TreeNode*, unsigned long long>> q;
        q.push({root, 0});

        int maxWidth = 0;

        while (!q.empty()) {
            int levelSize = q.size();
            unsigned long long minIndex = q.front().second;
            unsigned long long first = 0, last = 0;

            for (int i = 0; i < levelSize; i++) {
                TreeNode* current = q.front().first;
                unsigned long long index = q.front().second - minIndex;
                q.pop();

                if (i == 0) first = index;
                if (i == levelSize - 1) last = index;

                // Use normalized index to keep values small.
                if (current->left) {
                    q.push({current->left, 2 * index + 1});
                }

                if (current->right) {
                    q.push({current->right, 2 * index + 2});
                }
            }

            maxWidth = max(maxWidth, static_cast<int>(last - first + 1));
        }

        return maxWidth;
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this tree:
              1
             / \
            2   3
           / \   \
          5   6   9
    */
    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(3);
    root->left->left = new TreeNode(5);
    root->left->right = new TreeNode(6);
    root->right->right = new TreeNode(9);

    Solution solution;
    cout << "Maximum width: " << solution.widthOfBinaryTree(root) << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Maximum width: 4
```

## Special Cases

### Empty Tree

```text
root = NULL
Maximum width = 0
```

### Single Node

```text
  1
```

```text
Maximum width = 1
```

### Left-Skewed Tree

```text
    1
   /
  2
 /
3
```

Every level has one node.

```text
Maximum width = 1
```

### Perfect Binary Tree

```text
          1
         / \
        2   3
       / \ / \
      4  5 6  7
```

```text
Last level: [4, 5, 6, 7]
Maximum width = 4
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(N)` | Every node enters and leaves the queue once. |
| Space | `O(N)` | The queue may hold a full level of nodes. |

- `N` = number of nodes in the tree.

## Interview Questions 🎯

### 1. Why is width not just the number of nodes at a level?

Missing positions between the first and last real node must also count.

```text
[5] [6] [_] [9]
width = 4, not 3
```

### 2. Why use complete-tree indexes?

They tell us the conceptual position of nodes, including gaps caused by missing children.

### 3. Why use BFS?

Width is calculated level by level, and BFS naturally processes one full level at a time.

### 4. Why normalize indexes at each level?

It prevents indexes from becoming unnecessarily large in deep trees.

### 5. Does normalization change the width?

No.

```text
(last - min) - (first - min) + 1
= last - first + 1
```

### 6. What is the time complexity?

`O(N)` because each node is processed once.

### 7. What is the space complexity?

`O(N)` in the worst case because the queue can store an entire wide level.
