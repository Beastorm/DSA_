# Search in a Binary Search Tree

> Given a BST and a key, return the node containing that key. If it does not exist, return `nullptr`.

---

## BST Rule 💡

For every node:

```text
left subtree values  < node value
right subtree values > node value
```

This rule tells us where to search next.

```text
key < current value → search left
key > current value → search right
key = current value → found
```

---

## Example 1: Search for `10`

```text
              8
            /   \
           5     12
          / \   /  \
         4   7 10   14
            /       /
           6       13
```

### Search Path

```text
At 8:
10 > 8 → go RIGHT

At 12:
10 < 12 → go LEFT

At 10:
10 == 10 → FOUND ✓
```

```text
Result: node 10
```

## Key Not Found Example

```text
           4
          / \
         2   7
        / \
       1   3
```

Search for `9`:

```text
9 > 4 → go RIGHT to 7
9 > 7 → go RIGHT
right child is NULL → not found
```

```text
Return nullptr
```

---

## Simple Idea

Start from the root and keep moving in one direction.

```text
                 current
                 /     \
key < current → left   right ← key > current
```

At every step, one complete subtree is ignored.

```text
Searching for 10 at node 8:

All values in left subtree are less than 8.
10 is greater than 8.

Ignore the whole left subtree.
Go right.
```

---

## Iterative Algorithm

```text
current = root

while current is not NULL:

    if current.value == key:
        return current

    if key < current.value:
        current = current.left
    else:
        current = current.right

return NULL
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    TreeNode* searchBST(TreeNode* root, int key) {
        TreeNode* current = root;

        while (current != nullptr) {
            if (current->val == key) {
                return current;
            }

            if (key < current->val) {
                current = current->left;
            } else {
                current = current->right;
            }
        }

        return nullptr;
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

void printSearchResult(TreeNode* result, int key) {
    if (result != nullptr) {
        cout << "Key " << key << " found at node " << result->val << endl;
    } else {
        cout << "Key " << key << " not found" << endl;
    }
}

int main() {
    /* Create this BST:
                  8
                /   \
               5     12
              / \   /  \
             4   7 10   14
                /       /
               6       13
    */
    TreeNode* root = new TreeNode(8);
    root->left = new TreeNode(5);
    root->right = new TreeNode(12);
    root->left->left = new TreeNode(4);
    root->left->right = new TreeNode(7);
    root->left->right->left = new TreeNode(6);
    root->right->left = new TreeNode(10);
    root->right->right = new TreeNode(14);
    root->right->right->left = new TreeNode(13);

    Solution solution;

    printSearchResult(solution.searchBST(root, 10), 10);
    printSearchResult(solution.searchBST(root, 9), 9);

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Key 10 found at node 10
Key 9 not found
```

## Complexity

Let `H` be the height of the BST.

| Resource | Complexity |
|---|---:|
| Time | `O(H)` |
| Extra space | `O(1)` |

```text
Balanced BST → H ≈ log N → O(log N) search
Skewed BST   → H = N     → O(N) search
```

The iterative solution uses constant extra space because it stores only one pointer.

## Interview Questions 🎯

### 1. Why is search faster in a BST than in a normal binary tree?

The BST ordering tells us which subtree can be ignored after each comparison.

### 2. What happens if the key is smaller than the current node?

Move to the left child.

### 3. What happens if the key is greater than the current node?

Move to the right child.

### 4. What is the time complexity in a balanced BST?

`O(log N)`.

### 5. What is the worst-case time complexity?

`O(N)` when the BST is skewed.

### 6. Why is iterative search space `O(1)`?

It uses only one current-node pointer and no recursion or stack.

### 7. What does the function return if the key is absent?

`nullptr`.
