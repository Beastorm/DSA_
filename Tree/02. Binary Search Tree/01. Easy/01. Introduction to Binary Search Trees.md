# Introduction to Binary Search Trees (BST)

> A **Binary Search Tree (BST)** is a binary tree that keeps values in sorted order through its structure.

This ordering makes searching, inserting, and deleting values faster than in a normal binary tree when the tree is reasonably balanced.

---

## BST Example

```text
            8
          /   \
         3     10
        / \      \
       1   6      14
          / \     /
         4   7   13
```

For every node:

```text
all values in left subtree  < node value
all values in right subtree > node value
```

For node `8`:

```text
Left subtree:  1, 3, 4, 6, 7  < 8
Right subtree: 10, 13, 14      > 8
```

---

## Important Rule 💡

The BST rule applies to the **whole subtree**, not only direct children.

```text
        8
       / \
      3   10
       \
        6
       /
      4
```

Node `4` is in the left subtree of `8`, so it must also be smaller than `8`.

```text
4 < 8  ✓
```

A short way to remember the rule:

```text
left subtree < node < right subtree
```

---

## Why Use a BST?

In a normal binary tree, a value can be anywhere. We may need to check every node.

```text
Normal binary tree search → O(N)
```

In a BST, comparison tells us which entire subtree can be ignored.

```text
target < current node → go left
 target > current node → go right
 target = current node → found
```

---

## Search Example: Find `4`

```text
            8
          /
         3
          \
           6
          /
         4
```

### Step 1

```text
4 < 8 → go left to 3
```

### Step 2

```text
4 > 3 → go right to 6
```

### Step 3

```text
4 < 6 → go left to 4
```

```text
4 == 4 → found ✓
```

Only `3` comparisons were needed.

---

## BST vs. Normal Binary Tree

```text
Balanced BST                    Skewed BST

        8                           1
       / \                           \
      3  10                           2
     / \   \                           \
    1   6  14                           3
                                         \
                                          4

Height ≈ log N                   Height = N
```

### Important Note ⚠️

A normal BST is **not always balanced**.

If values are inserted in sorted order:

```text
Insert: 1, 2, 3, 4
```

The BST becomes skewed:

```text
1
 \
  2
   \
    3
     \
      4
```

Then searching can take `O(N)` time.

> Trees such as AVL Trees and Red-Black Trees are self-balancing BSTs. They guarantee height close to `O(log N)`.

---

## Basic Operations

| Operation | What it does |
|---|---|
| Search | Find a value. |
| Insert | Add a new value in the correct position. |
| Delete | Remove a value while keeping BST order valid. |
| Inorder traversal | Prints values in sorted order. |

---

## Inorder Traversal Is Sorted

For a BST, inorder traversal visits:

```text
Left → Root → Right
```

For the example tree:

```text
            8
          /   \
         3     10
        / \      \
       1   6      14
          / \     /
         4   7   13
```

```text
Inorder: 1, 3, 4, 6, 7, 8, 10, 13, 14
```

The output is sorted in increasing order. ✅

---

## How Insertion Works

To insert `5`:

```text
            8        5 < 8  → go left
          /
         3            5 > 3  → go right
          \
           6          5 < 6  → go left
          /
         4            5 > 4  → go right
          \
           5          insert here
```

Final part of the tree:

```text
      6
     / \
    4   7
     \
      5
```

---

## Handling Duplicate Values

Many BST problems assume all values are unique.

If duplicates are allowed, choose one clear rule. For example:

```text
left subtree  < node
right subtree ≥ node
```

Or store a frequency count inside every node:

```text
value = 5, count = 3
```

> Always check the problem statement’s duplicate-value rule.

## C++ Code — Search and Insert Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class BST {
public:
    TreeNode* insert(TreeNode* root, int value) {
        // Empty position: create the new node here.
        if (root == nullptr) return new TreeNode(value);

        if (value < root->val) {
            root->left = insert(root->left, value);
        } else if (value > root->val) {
            root->right = insert(root->right, value);
        }
        // Duplicate value: do nothing in this implementation.

        return root;
    }

    bool search(TreeNode* root, int target) {
        TreeNode* current = root;

        while (current != nullptr) {
            if (current->val == target) return true;

            if (target < current->val) {
                current = current->left;
            } else {
                current = current->right;
            }
        }

        return false;
    }

    void inorder(TreeNode* root) {
        if (root == nullptr) return;

        inorder(root->left);
        cout << root->val << " ";
        inorder(root->right);
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    BST bst;
    TreeNode* root = nullptr;

    // Insert values to build the BST.
    vector<int> values = {8, 3, 10, 1, 6, 14, 4, 7, 13};
    for (int value : values) {
        root = bst.insert(root, value);
    }

    cout << "Inorder traversal: ";
    bst.inorder(root);
    cout << endl;

    cout << boolalpha;
    cout << "Is 4 present?  " << bst.search(root, 4) << endl;
    cout << "Is 12 present? " << bst.search(root, 12) << endl;

    // Insert one more value.
    root = bst.insert(root, 5);
    cout << "After inserting 5: ";
    bst.inorder(root);
    cout << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Inorder traversal: 1 3 4 6 7 8 10 13 14
Is 4 present?  true
Is 12 present? false
After inserting 5: 1 3 4 5 6 7 8 10 13 14
```

## Complexity

Let `H` be the height of the BST.

| Operation | Time |
|---|---:|
| Search | `O(H)` |
| Insert | `O(H)` |
| Delete | `O(H)` |
| Inorder traversal | `O(N)` |

```text
Balanced BST → H ≈ log N → search/insert/delete ≈ O(log N)
Skewed BST   → H = N     → search/insert/delete = O(N)
```

## Interview Questions 🎯

### 1. What is the BST property?

```text
all left-subtree values  < node value
all right-subtree values > node value
```

### 2. Is every binary tree a BST?

No. A binary tree is a BST only when it follows the ordering rule at every node.

### 3. Is every BST balanced?

No. A regular BST can become skewed after inserting values in sorted order.

### 4. Why is search faster in a balanced BST?

Each comparison removes about half of the remaining tree.

```text
height ≈ log N
```

### 5. Which traversal gives sorted values in a BST?

Inorder traversal.

```text
Left → Root → Right
```

### 6. How are duplicates handled in a BST?

Either reject duplicates, store a count, or always place duplicates on one chosen side.

### 7. What is the worst-case search time in a BST?

`O(N)` when the tree is skewed.

### 8. Which trees guarantee balance?

AVL Trees and Red-Black Trees are common self-balancing BSTs.
