# Find Minimum and Maximum in a Binary Search Tree

> In a BST, the minimum value is at the **leftmost** node and the maximum value is at the **rightmost** node.

---

## Example BST

```text
              8
            /   \
           3     10
          / \      \
         1   6      14
            / \     /
           4   7   13
```

```text
Minimum = 1   (leftmost node)
Maximum = 14  (rightmost node)
```

---

## Why Does This Work? 💡

BST property:

```text
all left-subtree values  < current node
all right-subtree values > current node
```

### Minimum

If a node has a left child, that child is smaller.

```text
8 → 3 → 1
```

When there is no more left child, no smaller value exists in the tree.

```text
1 is the minimum
```

### Maximum

If a node has a right child, that child is larger.

```text
8 → 10 → 14
```

When there is no more right child, no larger value exists in the tree.

```text
14 is the maximum
```

---

## Find Minimum

```text
              8
             /
            3
           /
          1  ← no left child
```

```text
Start at 8
8 has left child → move to 3
3 has left child → move to 1
1 has no left child → minimum found
```

---

## Find Maximum

```text
       8
        \
        10
          \
          14  ← no right child
```

```text
Start at 8
8 has right child → move to 10
10 has right child → move to 14
14 has no right child → maximum found
```

---

## Algorithm

### Minimum

```text
current = root

while current.left exists:
    current = current.left

return current
```

### Maximum

```text
current = root

while current.right exists:
    current = current.right

return current
```

---

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    TreeNode* findMinNode(TreeNode* root) {
        if (root == nullptr) return nullptr;

        TreeNode* current = root;
        while (current->left != nullptr) {
            current = current->left;
        }

        return current;
    }

    TreeNode* findMaxNode(TreeNode* root) {
        if (root == nullptr) return nullptr;

        TreeNode* current = root;
        while (current->right != nullptr) {
            current = current->right;
        }

        return current;
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this BST:
                  8
                /   \
               3     10
              / \      \
             1   6      14
                / \     /
               4   7   13
    */
    TreeNode* root = new TreeNode(8);
    root->left = new TreeNode(3);
    root->right = new TreeNode(10);
    root->left->left = new TreeNode(1);
    root->left->right = new TreeNode(6);
    root->left->right->left = new TreeNode(4);
    root->left->right->right = new TreeNode(7);
    root->right->right = new TreeNode(14);
    root->right->right->left = new TreeNode(13);

    Solution solution;
    TreeNode* minimum = solution.findMinNode(root);
    TreeNode* maximum = solution.findMaxNode(root);

    if (minimum) {
        cout << "Minimum value: " << minimum->val << endl;
    }

    if (maximum) {
        cout << "Maximum value: " << maximum->val << endl;
    }

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Minimum value: 1
Maximum value: 14
```

## Why Return a Node Pointer Instead of `-1`?

A BST may contain negative values.

```text
      0
     /
   -1
```

Here, `-1` is a valid minimum value. Returning `nullptr` for an empty tree avoids confusing “not found” with a real value.

## Special Cases

### Empty Tree

```text
root = NULL
```

```text
minimum = nullptr
maximum = nullptr
```

### Single Node

```text
  5
```

```text
minimum = 5
maximum = 5
```

### Left-Skewed BST

```text
      8
     /
    5
   /
  3
 /
1
```

```text
minimum = 1
maximum = 8
```

### Right-Skewed BST

```text
1
 \
  3
   \
    5
     \
      8
```

```text
minimum = 1
maximum = 8
```

## Complexity

Let `H` be the height of the BST.

| Operation | Time | Extra Space |
|---|---:|---:|
| Find minimum | `O(H)` | `O(1)` |
| Find maximum | `O(H)` | `O(1)` |

```text
Balanced BST → H ≈ log N → O(log N)
Skewed BST   → H = N     → O(N)
```

The solution is iterative, so it does not use recursion or an extra data structure.

## Interview Questions 🎯

### 1. Where is the minimum node in a BST?

At the leftmost node.

### 2. Where is the maximum node in a BST?

At the rightmost node.

### 3. Why can we keep moving left to find the minimum?

Every left child is smaller than its parent.

### 4. What is the time complexity in a balanced BST?

`O(log N)`.

### 5. What is the worst-case time complexity?

`O(N)` for a skewed tree.

### 6. What is the extra space complexity?

`O(1)` because the solution uses one pointer.

### 7. Can we use `-1` as the result for an empty BST?

It is better to return `nullptr`, because `-1` can be a valid node value.
