# Delete a Node in a Binary Search Tree

> Delete a key from a BST while keeping the BST property valid.

Deletion is harder than insertion because removing a node can disconnect part of the tree.

---

## Three Deletion Cases 💡

### Case 1: Node Has No Children (Leaf)

Simply remove it.

```text
Delete 4:

       5                    5
      / \                  / \
     3   7      →         3   7
    / \
   2   4

4 is a leaf → remove it
```

---

### Case 2: Node Has One Child

Replace the node with its only child.

```text
Delete 3:

       5                    5
      / \                  / \
     3   7      →         2   7
    /
   2

3 has only left child 2 → connect 5.left to 2
```

The same idea works if the node has only a right child.

---

### Case 3: Node Has Two Children

Use the **inorder successor**:

```text
inorder successor = smallest node in the right subtree
```

Steps:

```text
1. Find the successor.
2. Copy successor value into the node to delete.
3. Delete the successor from the right subtree.
```

---

## Example: Delete Node `3` with Two Children

### Before

```text
       5
      / \
     3   6
    / \
   2   4
```

The inorder successor of `3` is `4`.

```text
Right subtree of 3:

  4  ← leftmost / smallest node
```

### Step 1: Copy Successor Value

```text
       5
      / \
     4   6
    / \
   2   4  ← old successor still exists for now
```

### Step 2: Delete the Old Successor

```text
       5
      / \
     4   6
    /
   2
```

```text
Inorder before: 2, 3, 4, 5, 6
Inorder after:  2, 4, 5, 6
```

---

## Why Does the Successor Work?

The successor is the smallest value that is greater than the current node.

```text
All left-subtree values  < successor
All right-subtree values > successor
```

So replacing the deleted node with its successor keeps the BST sorted.

```text
       5
      / \
     3   8
        / \
       6   9

Delete 5
Successor = 6
```

```text
       6
      / \
     3   8
          \
           9
```

## Recursive Algorithm

```text
deleteNode(root, key):

if root is NULL:
    return NULL

if key < root.value:
    root.left = deleteNode(root.left, key)

else if key > root.value:
    root.right = deleteNode(root.right, key)

else:
    node found

    if root has no left child:
        return root.right

    if root has no right child:
        return root.left

    successor = minimum node in root.right
    root.value = successor.value
    root.right = deleteNode(root.right, successor.value)

return root
```

Delete `6`:



## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    TreeNode* findMin(TreeNode* root) {
        TreeNode* current = root;
        while (current->left != nullptr) {
            current = current->left;
        }
        return current;
    }

public:
    TreeNode* deleteNode(TreeNode* root, int key) {
        if (root == nullptr) return nullptr;

        if (key < root->val) {
            root->left = deleteNode(root->left, key);
        } else if (key > root->val) {
            root->right = deleteNode(root->right, key);
        } else {
            // Case 1 and Case 2: zero or one child.
            if (root->left == nullptr) {
                TreeNode* replacement = root->right;
                delete root;
                return replacement;
            }

            if (root->right == nullptr) {
                TreeNode* replacement = root->left;
                delete root;
                return replacement;
            }

            // Case 3: two children.
            TreeNode* successor = findMin(root->right);
            root->val = successor->val;
            root->right = deleteNode(root->right, successor->val);
        }

        return root;
    }
};

void inorder(TreeNode* root) {
    if (root == nullptr) return;
    inorder(root->left);
    cout << root->val << " ";
    inorder(root->right);
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this BST:
           5
          / \
         3   6
        / \
       2   4
    */
    TreeNode* root = new TreeNode(5);
    root->left = new TreeNode(3);
    root->right = new TreeNode(6);
    root->left->left = new TreeNode(2);
    root->left->right = new TreeNode(4);

    Solution solution;

    cout << "Inorder before deleting 3: ";
    inorder(root);
    cout << endl;

    root = solution.deleteNode(root, 3);

    cout << "Inorder after deleting 3:  ";
    inorder(root);
    cout << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Inorder before deleting 3: 2 3 4 5 6
Inorder after deleting 3:  2 4 5 6
```

## Edge Cases

### Delete from an Empty Tree

```text
root = NULL
```

```text
deleteNode(NULL, 5) → NULL
```

### Delete the Only Node

```text
  5
```

```text
delete 5 → NULL
```

### Delete a Key That Does Not Exist

```text
       5
      / \
     3   7
```

```text
delete 9 → reach NULL → tree stays unchanged
```

### Delete Root with Two Children

```text
       5
      / \
     3   8
        / \
       6   9
```

```text
delete 5
successor = 6
```

```text
       6
      / \
     3   8
          \
           9
```

## Complexity

Let `H` be the height of the BST.

| Resource | Complexity |
|---|---:|
| Time | `O(H)` |
| Extra space | `O(H)` recursion stack |

```text
Balanced BST → H ≈ log N → O(log N)
Skewed BST   → H = N     → O(N)
```

## Interview Questions 🎯

### 1. What are the three cases when deleting a BST node?

```text
No child   → remove it
One child  → replace it with its child
Two child  → replace it with successor or predecessor
```

### 2. What is the inorder successor?

The smallest node in the right subtree.

### 3. What is the inorder predecessor?

The largest node in the left subtree.

### 4. Why does replacing with successor preserve BST order?

The successor is the next larger value after the deleted node.

### 5. What happens if the key does not exist?

The recursion reaches `NULL`; the tree is unchanged.

### 6. Can we use predecessor instead of successor?

Yes. Replace with the largest value in the left subtree, then delete that predecessor.

### 7. What is the time complexity in a balanced BST?

`O(log N)`.

### 8. What is the worst-case time complexity?

`O(N)` for a skewed BST.
