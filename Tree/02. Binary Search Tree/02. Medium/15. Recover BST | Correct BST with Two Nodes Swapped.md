# Recover a BST with Two Swapped Nodes

> A BST has exactly two node values swapped by mistake. Restore the BST without changing its structure.

Only node **values** are swapped. Tree pointers stay in the same places.

---

## Key BST Property 💡

Inorder traversal of a correct BST is strictly increasing.

```text
Inorder = Left → Root → Right
```

If two values are swapped, the inorder sequence is no longer sorted.

---

## Example 1 — Adjacent Values Swapped

```text
Swapped tree:              Correct tree:

       1                        3
      /                        /
     3            →           1
      \                        \
       2                        2
```

```text
Swapped inorder:   [3, 2, 1]
Correct inorder:   [1, 2, 3]
```

The two swapped node values are `3` and `1`.

---

## Example 2 — Non-Adjacent Values Swapped

```text
Swapped tree:              Recovered tree:

       3                        2
      / \                      / \
     1   4        →           1   4
        /                      /
       2                      3
```

```text
Swapped inorder:   [1, 3, 2, 4]
Correct inorder:   [1, 2, 3, 4]
```

Swap the values `3` and `2` to fix the tree.

---

## How to Find the Swapped Nodes

While doing inorder traversal, compare:

```text
previous node value
current node value
```

A correct inorder sequence must satisfy:

```text
previous < current
```

A violation happens when:

```text
previous > current
```

---

## Two Violation Cases

### Case 1: Adjacent Nodes Are Swapped

```text
Correct inorder: [1, 2, 3, 4, 5]
Swapped inorder: [1, 2, 4, 3, 5]
                         ↑  ↑
                      prev  curr
```

There is one violation:

```text
4 > 3

first = 4
second = 3
```

Swap `4` and `3`.

---

### Case 2: Non-Adjacent Nodes Are Swapped

```text
Correct inorder: [1, 2, 3, 4, 5]
Swapped inorder: [1, 5, 3, 4, 2]
                         ↑     ↑
```

There are two violations:

```text
5 > 3  → first = 5, second = 3
4 > 2  → second = 2  (update second)
```

```text
first = 5
second = 2
```

Swap `5` and `2`.

---

# Approach 1: Collect, Sort, and Reassign (Brute Force)

## Simple Idea

1. Store all node values in inorder order.
2. Sort the values.
3. Run inorder again and write sorted values back into the nodes.

```text
Swapped inorder: [1, 3, 2, 4]
Sort:            [1, 2, 3, 4]

Write sorted values back in inorder positions.
```

---

## C++ Code — Brute Force Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    void collectInorder(TreeNode* root, vector<int>& values) {
        if (root == nullptr) return;

        collectInorder(root->left, values);
        values.push_back(root->val);
        collectInorder(root->right, values);
    }

    void assignInorder(TreeNode* root, const vector<int>& values, int& index) {
        if (root == nullptr) return;

        assignInorder(root->left, values, index);
        root->val = values[index++];
        assignInorder(root->right, values, index);
    }

public:
    void recoverTree(TreeNode* root) {
        vector<int> values;
        collectInorder(root, values);

        sort(values.begin(), values.end());

        int index = 0;
        assignInorder(root, values, index);
    }
};

void printInorder(TreeNode* root) {
    if (root == nullptr) return;
    printInorder(root->left);
    cout << root->val << " ";
    printInorder(root->right);
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this swapped BST:
           3
          / \
         1   4
            /
           2
    */
    TreeNode* root = new TreeNode(3);
    root->left = new TreeNode(1);
    root->right = new TreeNode(4);
    root->right->left = new TreeNode(2);

    cout << "Before recovery: ";
    printInorder(root);
    cout << endl;

    Solution solution;
    solution.recoverTree(root);

    cout << "After recovery:  ";
    printInorder(root);
    cout << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Before recovery: 1 3 2 4
After recovery:  1 2 3 4
```

### Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N log N)` |
| Extra space | `O(N)` |

Sorting is the expensive step.

# Approach 2: Detect Violations with Recursive Inorder (Better)

## Simple Idea

Do not sort or store all values.

Keep three pointers:

```text
previous → previously visited inorder node
first    → first wrong node
second   → second wrong node
```

Whenever:

```text
previous.value > current.value
```

Update nodes like this:

```text
if first is NULL:
    first = previous

second = current
```

After traversal, swap `first->val` and `second->val`.

---

## Trace for `[1, 3, 2, 4]`

```text
Visit 1:
previous = NULL → no violation

Visit 3:
1 < 3 → no violation
previous = 3

Visit 2:
3 > 2 → violation
first = 3
second = 2

Visit 4:
2 < 4 → no violation

Swap first and second: 3 ↔ 2
```

---

## C++ Code — Recursive Inorder Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    TreeNode* first;
    TreeNode* second;
    TreeNode* previous;

    void inorder(TreeNode* root) {
        if (root == nullptr) return;

        inorder(root->left);

        if (previous != nullptr && previous->val > root->val) {
            if (first == nullptr) {
                first = previous;
            }
            second = root;
        }

        previous = root;
        inorder(root->right);
    }

public:
    void recoverTree(TreeNode* root) {
        first = nullptr;
        second = nullptr;
        previous = nullptr;

        inorder(root);

        if (first != nullptr && second != nullptr) {
            swap(first->val, second->val);
        }
    }
};

void printInorder(TreeNode* root) {
    if (root == nullptr) return;
    printInorder(root->left);
    cout << root->val << " ";
    printInorder(root->right);
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this swapped BST:
           3
          / \
         1   4
            /
           2
    */
    TreeNode* root = new TreeNode(3);
    root->left = new TreeNode(1);
    root->right = new TreeNode(4);
    root->right->left = new TreeNode(2);

    cout << "Before recovery: ";
    printInorder(root);
    cout << endl;

    Solution solution;
    solution.recoverTree(root);

    cout << "After recovery:  ";
    printInorder(root);
    cout << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Before recovery: 1 3 2 4
After recovery:  1 2 3 4
```

### Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N)` |
| Extra space | `O(H)` recursion stack |

# Approach 3: Morris Inorder Traversal (Optimal Space) ⚡

## Main Idea

The recursive method uses `O(H)` stack space.

Morris traversal visits nodes in inorder without recursion or a stack. It creates temporary threads, then removes them.

```text
predecessor.right → current
```

During every inorder “visit”, use the same violation check:

```text
if previous.value > current.value:
    find/update first and second
```

---

## Morris Thread Diagram

```text
Before thread:             Temporary thread:

       3                        3
      / \                      / \
     1   4                    1   4
        /                        / \
       2                        2 → 3

rightmost node in left subtree points back to current
```

The thread is removed before moving to the right subtree.

---

## C++ Code — Morris Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    void checkViolation(TreeNode* current, TreeNode*& previous,
                        TreeNode*& first, TreeNode*& second) {
        if (previous != nullptr && previous->val > current->val) {
            if (first == nullptr) {
                first = previous;
            }
            second = current;
        }
        previous = current;
    }

public:
    void recoverTree(TreeNode* root) {
        TreeNode* first = nullptr;
        TreeNode* second = nullptr;
        TreeNode* previous = nullptr;
        TreeNode* current = root;

        while (current != nullptr) {
            if (current->left == nullptr) {
                // Inorder visit without a left subtree.
                checkViolation(current, previous, first, second);
                current = current->right;
            } else {
                // Find rightmost node in the left subtree.
                TreeNode* predecessor = current->left;
                while (predecessor->right != nullptr &&
                       predecessor->right != current) {
                    predecessor = predecessor->right;
                }

                if (predecessor->right == nullptr) {
                    // Create temporary thread and go left.
                    predecessor->right = current;
                    current = current->left;
                } else {
                    // Left subtree is done: remove thread and visit current.
                    predecessor->right = nullptr;
                    checkViolation(current, previous, first, second);
                    current = current->right;
                }
            }
        }

        if (first != nullptr && second != nullptr) {
            swap(first->val, second->val);
        }
    }
};

void printInorder(TreeNode* root) {
    if (root == nullptr) return;
    printInorder(root->left);
    cout << root->val << " ";
    printInorder(root->right);
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this swapped BST:
           3
          / \
         1   4
            /
           2
    */
    TreeNode* root = new TreeNode(3);
    root->left = new TreeNode(1);
    root->right = new TreeNode(4);
    root->right->left = new TreeNode(2);

    cout << "Before recovery: ";
    printInorder(root);
    cout << endl;

    Solution solution;
    solution.recoverTree(root);

    cout << "After recovery:  ";
    printInorder(root);
    cout << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Before recovery: 1 3 2 4
After recovery:  1 2 3 4
```

### Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N)` |
| Auxiliary space | `O(1)` |

> Morris traversal temporarily changes pointers, but removes every temporary thread before it finishes.

---

## Comparison

| Approach | Time | Extra Space | Main Idea |
|---|---:|---:|---|
| Collect + sort | `O(N log N)` | `O(N)` | Sort inorder values and write them back. |
| Recursive inorder | `O(N)` | `O(H)` | Detect inorder violations with pointers. |
| Morris inorder | `O(N)` | `O(1)` | Detect violations without recursion or stack. |

---

## Special Cases

### Already Valid BST

```text
Inorder: [1, 2, 3, 4]
```

No violation is found, so no values are swapped.

### Adjacent Swap

```text
[1, 2, 4, 3, 5]
        4 > 3
```

One violation. Swap `4` and `3`.

### Non-Adjacent Swap

```text
[1, 5, 3, 4, 2]
    5 > 3     4 > 2
```

Two violations. Swap the first large value (`5`) with the last small value (`2`).

---

## Interview Questions 🎯

### 1. Why does inorder traversal help recover a BST?

A correct BST has a strictly increasing inorder sequence.

### 2. What is a violation?

```text
previous.value > current.value
```

### 3. Why is `first` set only once?

It must keep the first wrong large node.

### 4. Why is `second` updated on every violation?

For a non-adjacent swap, the last wrong small node is the one that must be swapped with `first`.

### 5. How many violations can two swapped nodes create?

One for adjacent values, or two for non-adjacent values.

### 6. What is the optimal time complexity?

`O(N)`.

### 7. What is the optimal auxiliary-space complexity?

`O(1)` with Morris inorder traversal.

### 8. Does Morris traversal permanently change the tree?

No. It removes all temporary threads before finishing.
