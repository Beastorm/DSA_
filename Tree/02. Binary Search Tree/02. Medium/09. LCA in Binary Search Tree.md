# Lowest Common Ancestor (LCA) in a Binary Search Tree

> Given two nodes `p` and `q` in a BST, find their lowest common ancestor.

The LCA is the lowest node that has both `p` and `q` in its subtree. A node can be a descendant of itself.

---

## Example BST

```text
           6
          / \
         2   8
        / \ / \
       0  4 7  9
         / \
        3   5
```

---

## Example 1: `p = 2`, `q = 8`

```text
           6  ← LCA
          / \
      p=2   q=8
```

```text
2 < 6 and 8 > 6
```

The two nodes are on opposite sides of node `6`.

```text
LCA = 6
```

---

## Example 2: `p = 2`, `q = 4`

```text
           6
          /
         2  ← LCA
          \
           4
```

At node `6`:

```text
2 < 6 and 4 < 6 → both are on the left → go LEFT
```

At node `2`:

```text
p equals current node
```

A node can be an ancestor of itself, so:

```text
LCA = 2
```

---

## Example 3: `p = 7`, `q = 9`

```text
           6
            \
             8  ← LCA
            / \
           7   9
```

```text
7 > 6 and 9 > 6 → both are on the right → go RIGHT

At 8:
7 < 8 and 9 > 8 → they split here

LCA = 8
```

---

## BST Shortcut 💡

For a normal binary tree, we may need to search both subtrees.

For a BST, comparisons tell us where the LCA must be.

```text
Both p and q < current → LCA is in left subtree
Both p and q > current → LCA is in right subtree
Otherwise              → current node is the LCA
```

---

## Three Cases

### Case 1: Both Nodes Are Smaller

```text
          current
          /
       LCA
       / \
      p   q
```

```text
p < current AND q < current
→ move left
```

---

### Case 2: Both Nodes Are Larger

```text
          current
              \
              LCA
              / \
             p   q
```

```text
p > current AND q > current
→ move right
```

---

### Case 3: Nodes Split or Current Equals One Target

```text
              current  ← LCA
             /       \
            p         q
```

```text
p and q are on opposite sides
OR p == current
OR q == current

→ current is the LCA
```

---

## Iterative Walkthrough: LCA of `2` and `4`

```text
           6
          / \
         2   8
          \
           4
```

```text
current = 6
2 < 6 AND 4 < 6 → move left

current = 2
2 == current → return 2
```

```text
Answer = 2
```

---

## Algorithm

```text
current = root

while current is not NULL:

    if p.value < current.value AND q.value < current.value:
        current = current.left

    else if p.value > current.value AND q.value > current.value:
        current = current.right

    else:
        return current

return NULL
```

---

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        TreeNode* current = root;

        while (current != nullptr) {
            if (p->val < current->val && q->val < current->val) {
                current = current->left;
            } else if (p->val > current->val && q->val > current->val) {
                current = current->right;
            } else {
                // Nodes split here, or one node equals current.
                return current;
            }
        }

        return nullptr;
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

void printLCA(Solution& solution, TreeNode* root, TreeNode* p, TreeNode* q) {
    TreeNode* lca = solution.lowestCommonAncestor(root, p, q);
    cout << "LCA of " << p->val << " and " << q->val << ": "
         << (lca ? to_string(lca->val) : "nullptr") << endl;
}

int main() {
    /* Create this BST:
               6
              / \
             2   8
            / \ / \
           0  4 7  9
             / \
            3   5
    */
    TreeNode* root = new TreeNode(6);
    root->left = new TreeNode(2);
    root->right = new TreeNode(8);
    root->left->left = new TreeNode(0);
    root->left->right = new TreeNode(4);
    root->right->left = new TreeNode(7);
    root->right->right = new TreeNode(9);
    root->left->right->left = new TreeNode(3);
    root->left->right->right = new TreeNode(5);

    Solution solution;

    printLCA(solution, root, root->left, root->right);              // 2, 8
    printLCA(solution, root, root->left, root->left->right);        // 2, 4
    printLCA(solution, root, root->right->left, root->right->right); // 7, 9

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
LCA of 2 and 8: 6
LCA of 2 and 4: 2
LCA of 7 and 9: 8
```

## LCA in Binary Tree vs. BST

| General Binary Tree | BST |
|---|---|
| May need to explore both subtrees | Uses value comparisons to choose one direction |
| Time: `O(N)` | Time: `O(H)` |
| Recursive stack usually `O(H)` | Iterative extra space `O(1)` |

The BST property is what makes the direct search possible.

---

## Special Cases

### One Node Is an Ancestor of the Other

```text
       6
      /
     2
      \
       4
```

```text
LCA(2, 4) = 2
```

### Both Nodes Are the Same

```text
LCA(4, 4) = 4
```

The current node equals both targets, so it is returned.

### Root Is the LCA

```text
       6
      / \
     2   8
```

```text
LCA(2, 8) = 6
```

---

## Complexity

Let `H` be the height of the BST.

| Resource | Complexity |
|---|---:|
| Time | `O(H)` |
| Extra space | `O(1)` |

```text
Balanced BST → H ≈ log N → O(log N)
Skewed BST   → H = N     → O(N)
```

---

## Important Assumption

This approach assumes `p` and `q` are present in the BST.

It also assumes BST values are unique or that node values uniquely identify the target nodes. In general code, passing node pointers is safer than passing only values.

## Interview Questions 🎯

### 1. Why is BST LCA faster than general binary-tree LCA?

The BST ordering tells us whether both nodes are left, both right, or split around the current node.

### 2. When do we move left?

When both target values are smaller than the current value.

### 3. When do we move right?

When both target values are larger than the current value.

### 4. When is the current node the LCA?

When targets are on opposite sides, or when current equals one target.

### 5. What happens if one node is the ancestor of the other?

The ancestor is the LCA.

### 6. What is the time complexity in a balanced BST?

`O(log N)`.

### 7. What is the extra space complexity of the iterative solution?

`O(1)`.
