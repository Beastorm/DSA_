# Insert a Node in a Binary Search Tree

> Insert a new value into a BST while keeping the BST property valid.

```text
left subtree values  < node value
right subtree values > node value
```

---

## Example 1: Insert `5`

### Before

```text
       8
      / \
     3   10
    / \    \
   1   6    14
```

### Search for the Correct Empty Position

```text
At 8:
5 < 8 → go LEFT

At 3:
5 > 3 → go RIGHT

At 6:
5 < 6 → go LEFT

left child is NULL → insert 5 here
```

### After

```text
       8
      / \
     3   10
    / \    \
   1   6    14
      /
     5
```

```text
Inorder before: 1, 3, 6, 8, 10, 14
Inorder after:  1, 3, 5, 6, 8, 10, 14
```

## Main Idea 💡

Insertion uses the same comparison logic as BST search.

```text
value < current → move left
value > current → move right
```

The only difference is what happens at `NULL`:

```text
Search: NULL means value is not found.
Insert: NULL is the correct place to create the new node.
```

---

## Algorithm

```text
insert(root, value):

1. If root is NULL:
       return a new node

2. Start current at root.

3. While true:
       if value < current.value:
           if current.left is NULL:
               insert new node as current.left
               stop
           move left

       else if value > current.value:
           if current.right is NULL:
               insert new node as current.right
               stop
           move right

       else:
           duplicate value found
           stop (ignore it in this implementation)

4. Return the original root.
```

---

## Decision Diagram

```text
              current node
                   |
           compare new value
          /        |         \
       smaller    equal       larger
         |          |           |
      go left    duplicate   go right
                   ignore
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    TreeNode* insertIntoBST(TreeNode* root, int value) {
        // Empty BST: new node becomes the root.
        if (root == nullptr) {
            return new TreeNode(value);
        }

        TreeNode* current = root;

        while (true) {
            if (value < current->val) {
                if (current->left == nullptr) {
                    current->left = new TreeNode(value);
                    break;
                }
                current = current->left;
            } else if (value > current->val) {
                if (current->right == nullptr) {
                    current->right = new TreeNode(value);
                    break;
                }
                current = current->right;
            } else {
                // Duplicate values are ignored in this implementation.
                break;
            }
        }

        return root;
    }
};

void inorder(TreeNode* root) {
    if (root == nullptr) return;

    inorder(root->left);
    cout << root->val << " ";
    inorder(root->right);
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this BST:
              8
             / \
            3   10
           / \    \
          1   6    14
    */
    TreeNode* root = new TreeNode(8);
    root->left = new TreeNode(3);
    root->right = new TreeNode(10);
    root->left->left = new TreeNode(1);
    root->left->right = new TreeNode(6);
    root->right->right = new TreeNode(14);

    Solution solution;

    cout << "Inorder before insertion: ";
    inorder(root);
    cout << endl;

    root = solution.insertIntoBST(root, 5);
    cout << "After inserting 5:        ";
    inorder(root);
    cout << endl;

    root = solution.insertIntoBST(root, 11);
    cout << "After inserting 11:       ";
    inorder(root);
    cout << endl;

    root = solution.insertIntoBST(root, 5); // Duplicate: ignored.
    cout << "After inserting 5 again:  ";
    inorder(root);
    cout << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Inorder before insertion: 1 3 6 8 10 14
After inserting 5:        1 3 5 6 8 10 14
After inserting 11:       1 3 5 6 8 10 11 14
After inserting 5 again:  1 3 5 6 8 10 11 14
```

## Empty BST Case

```text
root = NULL
insert 1
```

```text
Before: NULL
After:
  1
```

The new node becomes the root.

---

## Duplicate Values

This guide ignores duplicates:

```text
insert 5 when 5 already exists → no change
```

Other valid BST rules are possible:

```text
- Store duplicates in the right subtree.
- Store duplicates in the left subtree.
- Keep a count field inside the node.
```

> Always follow the duplicate-value rule given in the problem statement.

## Complexity

Let `H` be the height of the BST.

| Resource | Complexity |
|---|---:|
| Time | `O(H)` |
| Extra space | `O(1)` |

```text
Balanced BST → H ≈ log N → O(log N) insertion
Skewed BST   → H = N     → O(N) insertion
```

The iterative solution does not use recursion, a stack, or a queue.

## Interview Questions 🎯

### 1. How is BST insertion similar to BST search?

Both compare the value and move left or right using BST ordering.

### 2. Where is a new node inserted?

At the first `NULL` position reached by the search path.

### 3. Why return the original root?

The root stays the same for a non-empty BST. Returning it also handles the empty-tree case, where the new node becomes the root.

### 4. What happens with duplicates?

It depends on the chosen rule. This implementation ignores them.

### 5. What is the time complexity in a balanced BST?

`O(log N)`.

### 6. What is the worst-case time complexity?

`O(N)` for a skewed BST.

### 7. What is the extra space complexity?

`O(1)` for this iterative solution.
