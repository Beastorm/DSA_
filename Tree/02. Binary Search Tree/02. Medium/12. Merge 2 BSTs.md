# Merge Two Binary Search Trees

> Return all values from two BSTs in one sorted array.

Duplicate values are kept.

---

## Example 1

```text
BST 1:                 BST 2:

       5                    2
      / \
     3   6                1   3
    / \                        \
   2   4                        7
                               /
                              6
```

```text
Inorder BST 1: [2, 3, 4, 5, 6]
Inorder BST 2: [1, 2, 3, 6, 7]
```

```text
Merged result:
[1, 2, 2, 3, 3, 4, 5, 6, 6, 7]
```

---

## Key BST Property 💡

Inorder traversal of a BST is sorted.

```text
Inorder = Left → Root → Right
```

```text
       5
      / \
     3   6
    / \
   2   4

Inorder: [2, 3, 4, 5, 6]
```

So, merging two BSTs is similar to merging two sorted arrays in merge sort.

---

# Approach 1: Collect All Values, Then Sort (Brute Force)

## Simple Idea

1. Traverse both trees and add values to one array.
2. Sort that array.
3. Return it.

```text
BST 1 values: [2, 3, 4, 5, 6]
BST 2 values: [1, 2, 3, 6, 7]

Combined:     [2, 3, 4, 5, 6, 1, 2, 3, 6, 7]
After sorting: [1, 2, 2, 3, 3, 4, 5, 6, 6, 7]
```

---

## C++ Code — Brute Force Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int data;
    Node *left, *right;

    Node(int value) : data(value), left(nullptr), right(nullptr) {}
};

class Solution {
    void collectValues(Node* root, vector<int>& values) {
        if (root == nullptr) return;

        collectValues(root->left, values);
        values.push_back(root->data);
        collectValues(root->right, values);
    }

public:
    vector<int> mergeBSTs(Node* root1, Node* root2) {
        vector<int> values;

        collectValues(root1, values);
        collectValues(root2, values);

        sort(values.begin(), values.end());
        return values;
    }
};

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

void deleteTree(Node* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* BST 1:
           5
          / \
         3   6
        / \
       2   4
    */
    Node* root1 = new Node(5);
    root1->left = new Node(3);
    root1->right = new Node(6);
    root1->left->left = new Node(2);
    root1->left->right = new Node(4);

    /* BST 2:
           2
          / \
         1   3
              \
               7
              /
             6
    */
    Node* root2 = new Node(2);
    root2->left = new Node(1);
    root2->right = new Node(3);
    root2->right->right = new Node(7);
    root2->right->right->left = new Node(6);

    Solution solution;
    cout << "Merged BST values: ";
    printVector(solution.mergeBSTs(root1, root2));

    deleteTree(root1);
    deleteTree(root2);
    return 0;
}
```

**Output:**

```text
Merged BST values: [1, 2, 2, 3, 3, 4, 5, 6, 6, 7]
```

### Complexity

| Resource | Complexity |
|---|---:|
| Time | `O((N + M) log(N + M))` |
| Extra space | `O(N + M)` |

The sorting step is the slow part.

# Approach 2: Inorder + Two-Pointer Merge (Optimal) ⚡

## Main Idea

Get two already-sorted arrays using inorder traversal.

```text
arr1 = inorder(BST 1)
arr2 = inorder(BST 2)
```

Then merge them using two pointers.

```text
arr1: [2, 3, 4, 5, 6]
       ↑
arr2: [1, 2, 3, 6, 7]
       ↑
```

Always take the smaller current value.

---

## Two-Pointer Walkthrough

```text
arr1 = [2, 3, 4, 5, 6]
arr2 = [1, 2, 3, 6, 7]
```

| Step | Compare | Take | Result |
|---:|---|---|---|
| 1 | `2` and `1` | `1` from arr2 | `[1]` |
| 2 | `2` and `2` | `2` from arr1 | `[1, 2]` |
| 3 | `3` and `2` | `2` from arr2 | `[1, 2, 2]` |
| 4 | `3` and `3` | `3` from arr1 | `[1, 2, 2, 3]` |
| 5 | `4` and `3` | `3` from arr2 | `[1, 2, 2, 3, 3]` |

Continue until one array ends, then append the remaining values.

```text
Final: [1, 2, 2, 3, 3, 4, 5, 6, 6, 7]
```

---

## Merge Logic

```text
i = 0, j = 0

while i < arr1.size AND j < arr2.size:
    if arr1[i] <= arr2[j]:
        add arr1[i]
        i++
    else:
        add arr2[j]
        j++

add remaining values from arr1
add remaining values from arr2
```

Using `<=` keeps duplicate values from both trees.

---

## C++ Code — Optimal Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int data;
    Node *left, *right;

    Node(int value) : data(value), left(nullptr), right(nullptr) {}
};

class Solution {
    void inorder(Node* root, vector<int>& values) {
        if (root == nullptr) return;

        inorder(root->left, values);
        values.push_back(root->data);
        inorder(root->right, values);
    }

    vector<int> mergeSortedArrays(const vector<int>& arr1,
                                  const vector<int>& arr2) {
        vector<int> result;
        int i = 0, j = 0;

        while (i < arr1.size() && j < arr2.size()) {
            if (arr1[i] <= arr2[j]) {
                result.push_back(arr1[i]);
                i++;
            } else {
                result.push_back(arr2[j]);
                j++;
            }
        }

        while (i < arr1.size()) {
            result.push_back(arr1[i]);
            i++;
        }

        while (j < arr2.size()) {
            result.push_back(arr2[j]);
            j++;
        }

        return result;
    }

public:
    vector<int> mergeBSTs(Node* root1, Node* root2) {
        vector<int> arr1, arr2;

        inorder(root1, arr1);
        inorder(root2, arr2);

        return mergeSortedArrays(arr1, arr2);
    }
};

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

void deleteTree(Node* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* BST 1:
           5
          / \
         3   6
        / \
       2   4
    */
    Node* root1 = new Node(5);
    root1->left = new Node(3);
    root1->right = new Node(6);
    root1->left->left = new Node(2);
    root1->left->right = new Node(4);

    /* BST 2:
           2
          / \
         1   3
              \
               7
              /
             6
    */
    Node* root2 = new Node(2);
    root2->left = new Node(1);
    root2->right = new Node(3);
    root2->right->right = new Node(7);
    root2->right->right->left = new Node(6);

    Solution solution;
    cout << "Merged BST values: ";
    printVector(solution.mergeBSTs(root1, root2));

    deleteTree(root1);
    deleteTree(root2);
    return 0;
}
```

**Output:**

```text
Merged BST values: [1, 2, 2, 3, 3, 4, 5, 6, 6, 7]
```

### Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N + M)` |
| Extra space | `O(N + M)` |

- Inorder visits all nodes once.
- The two-pointer merge also visits every array value once.

## Example 2

```text
BST 1:              BST 2:

      12                   8
      /                   / \
     9                   5   10
    / \                 /
   6  11               2
```

```text
Inorder BST 1: [6, 9, 11, 12]
Inorder BST 2: [2, 5, 8, 10]

Merged: [2, 5, 6, 8, 9, 10, 11, 12]
```

---

## Comparison

| Approach | Time | Extra Space | Main Idea |
|---|---:|---:|---|
| Collect + sort | `O((N+M) log(N+M))` | `O(N+M)` | Add all values and sort. |
| Inorder + merge | `O(N+M)` | `O(N+M)` | Merge two sorted inorder arrays. |

---

## Special Cases

### One Tree Is Empty

```text
BST 1 = NULL
BST 2 inorder = [1, 3, 5]

Answer = [1, 3, 5]
```

### Both Trees Are Empty

```text
Answer = []
```

### Duplicate Values

```text
BST 1 inorder: [2, 4]
BST 2 inorder: [2, 3]

Answer: [2, 2, 3, 4]
```

Duplicates are kept in the merged output.

## Interview Questions 🎯

### 1. Why does inorder traversal help merge BSTs?

It returns each BST’s values in sorted order.

### 2. Which algorithm is used to merge the two inorder arrays?

The two-pointer merge step from merge sort.

### 3. Why is sorting all values slower?

Sorting adds `O((N+M) log(N+M))` time.

### 4. What is the time complexity of the optimal approach?

`O(N + M)`.

### 5. What is the space complexity of the optimal approach?

`O(N + M)` because it stores two inorder arrays and the result.

### 6. Are duplicate values removed?

No. Values from both BSTs stay in the final sorted result.

### 7. Can we reduce extra space further?

Yes. Use two stacks to perform inorder traversal of both trees at the same time. That uses `O(H1 + H2)` auxiliary space, excluding the output array.
