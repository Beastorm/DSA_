# Kth Smallest and Kth Largest Element in a BST

> Given a BST and a 1-indexed integer `k`, return:
>
> ```text
> [kth smallest, kth largest]
> ```

---

## Key BST Property 💡

Inorder traversal of a BST is sorted in ascending order.

```text
Inorder: Left → Root → Right
```

Reverse inorder is sorted in descending order.

```text
Reverse inorder: Right → Root → Left
```

---

## Example 1

```text
       3
      / \
     1   4
      \
       2
```

```text
Inorder:         [1, 2, 3, 4]
Reverse inorder: [4, 3, 2, 1]
```

For `k = 1`:

```text
1st smallest = 1
1st largest  = 4

Answer = [1, 4]
```

---

## Example 2

```text
       5
      / \
     3   6
    /
   2
  /
 1
```

```text
Inorder:         [1, 2, 3, 5, 6]
Reverse inorder: [6, 5, 3, 2, 1]
```

For `k = 3`:

```text
3rd smallest = 3
3rd largest  = 3

Answer = [3, 3]
```

---

## How the Traversals Find the Answer

```text
kth smallest → kth node visited in inorder
kth largest  → kth node visited in reverse inorder
```

```text
BST:
       5
      / \
     3   7
    / \ / \
   2  4 6  8

Inorder:         2, 3, 4, 5, 6, 7, 8
Reverse inorder: 8, 7, 6, 5, 4, 3, 2
```

For `k = 2`:

```text
2nd smallest = 3
2nd largest  = 7
```

---

# Approach 1: Store Full Inorder Traversal

## Simple Idea

1. Perform inorder traversal.
2. Store every value in a vector.
3. The vector is sorted.
4. Use indexes to get both answers.

```text
kth smallest = values[k - 1]
kth largest  = values[N - k]
```

---

## Example

```text
Inorder values = [2, 3, 4, 5, 6, 7, 8]
k = 2

kth smallest = values[1] = 3
kth largest  = values[5] = 7
```

---

## C++ Code — Brute Force Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    void inorder(TreeNode* root, vector<int>& values) {
        if (root == nullptr) return;

        inorder(root->left, values);
        values.push_back(root->val);
        inorder(root->right, values);
    }

public:
    vector<int> kthSmallestAndLargest(TreeNode* root, int k) {
        vector<int> values;
        inorder(root, values);

        // This problem assumes 1 <= k <= number of nodes.
        return {values[k - 1], values[values.size() - k]};
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this BST:
           3
          / \
         1   4
          \
           2
    */
    TreeNode* root = new TreeNode(3);
    root->left = new TreeNode(1);
    root->right = new TreeNode(4);
    root->left->right = new TreeNode(2);

    int k = 1;
    Solution solution;
    vector<int> answer = solution.kthSmallestAndLargest(root, k);

    cout << "[" << answer[0] << ", " << answer[1] << "]" << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
[1, 4]
```

---

## Brute Force Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N)` |
| Extra space | `O(N)` |

The vector stores all `N` values.

# Approach 2: Stop at the Kth Node (Optimal Space) ⚡

## Simple Idea

We do not need to store every value.

For kth smallest:

```text
Use inorder traversal.
Count visited nodes.
Stop when count = k.
```

For kth largest:

```text
Use reverse inorder traversal.
Count visited nodes.
Stop when count = k.
```

---

## Kth Smallest Walkthrough

```text
       5
      / \
     3   6
    /
   2
```

Find the 2nd smallest:

```text
Inorder visits: 2 → 3 → 5 → 6

Visit 2 → count = 1
Visit 3 → count = 2 → answer = 3 ✓
```

---

## Kth Largest Walkthrough

```text
       5
      / \
     3   6
    /
   2
```

Find the 2nd largest:

```text
Reverse inorder visits: 6 → 5 → 3 → 2

Visit 6 → count = 1
Visit 5 → count = 2 → answer = 5 ✓
```

---

## Early Stop Logic

The helper returns `true` once it finds the answer.

```text
if left/right recursive call already found the answer:
    return true immediately
```

This prevents unnecessary traversal after reaching the kth node.

---

## C++ Code — Optimal Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    bool findKthSmallest(TreeNode* root, int& k, int& answer) {
        if (root == nullptr) return false;

        if (findKthSmallest(root->left, k, answer)) {
            return true;
        }

        if (--k == 0) {
            answer = root->val;
            return true;
        }

        return findKthSmallest(root->right, k, answer);
    }

    bool findKthLargest(TreeNode* root, int& k, int& answer) {
        if (root == nullptr) return false;

        if (findKthLargest(root->right, k, answer)) {
            return true;
        }

        if (--k == 0) {
            answer = root->val;
            return true;
        }

        return findKthLargest(root->left, k, answer);
    }

public:
    vector<int> kthSmallestAndLargest(TreeNode* root, int k) {
        int smallest = -1;
        int largest = -1;

        int kthSmall = k;
        int kthLarge = k;

        findKthSmallest(root, kthSmall, smallest);
        findKthLargest(root, kthLarge, largest);

        return {smallest, largest};
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this BST:
           3
          / \
         1   4
          \
           2
    */
    TreeNode* root = new TreeNode(3);
    root->left = new TreeNode(1);
    root->right = new TreeNode(4);
    root->left->right = new TreeNode(2);

    int k = 1;
    Solution solution;
    vector<int> answer = solution.kthSmallestAndLargest(root, k);

    cout << "[" << answer[0] << ", " << answer[1] << "]" << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
[1, 4]
```

---

## Optimal Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(H + K)` per traversal, `O(N)` worst case |
| Extra space | `O(H)` recursion stack |

- `H` = tree height.
- The traversal stops as soon as it reaches the kth node.
- For a balanced tree, `H` is about `log N`.

> The returned vector has two values, so it uses `O(1)` output space.

---

## Comparison

| Approach | Time | Extra Space | Main Idea |
|---|---:|---:|---|
| Store full inorder | `O(N)` | `O(N)` | Store all sorted values. |
| Early-stop traversals | `O(H + K)` | `O(H)` | Stop at kth inorder and reverse-inorder nodes. |

---

## Special Cases

### `k = 1`

```text
1st smallest → minimum value
1st largest  → maximum value
```

### `k = N`

```text
Nth smallest → maximum value
Nth largest  → minimum value
```

### One Node Tree

```text
  5
```

```text
k = 1
Answer = [5, 5]
```

### Invalid `k`

The examples assume:

```text
1 <= k <= number of nodes
```

If this is not guaranteed, validate `k` before accessing a vector or return an error value.

## Interview Questions 🎯

### 1. Why is inorder traversal sorted in a BST?

It visits:

```text
all smaller values → node → all larger values
```

### 2. How do we find the kth largest value?

Use reverse inorder:

```text
Right → Root → Left
```

### 3. Why is storing all values not optimal?

It uses `O(N)` extra space even if we need only one or two values.

### 4. Why do we use two separate counters?

One traversal counts ascending order; the other counts descending order. Each starts from the same `k`.

### 5. What is the worst-case time complexity of the optimal approach?

`O(N)` when `k` is large or the tree is skewed.

### 6. What is the extra-space complexity of the recursive approach?

`O(H)` due to the recursion stack.

### 7. Can this be solved iteratively?

Yes. Use a stack for inorder and reverse inorder traversal.

### 8. What is the 1st smallest node in a BST?

The minimum / leftmost node.
