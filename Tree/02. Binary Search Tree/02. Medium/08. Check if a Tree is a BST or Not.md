# Check if a Tree Is a Binary Search Tree

> Return `true` if a binary tree follows the BST property at **every node**; otherwise return `false`.

For a valid BST with unique values:

```text
all left-subtree values  < node value
all right-subtree values > node value
```

---

## Example 1 — Valid BST ✅

```text
       2
      / \
     1   3
```

```text
1 < 2 < 3
```

```text
Result: true
```

---

## Example 2 — Invalid BST ❌

```text
       5
      / \
     1   4
        / \
       3   6
```

Node `4` is in the right subtree of `5`, but:

```text
4 < 5
```

All nodes in the right subtree of `5` must be greater than `5`.

```text
Result: false
```

---

## Why Checking Only Parent and Children Is Not Enough 💡

Consider this tree:

```text
        10
       /  \
      5    15
          /  \
         6   20
```

At node `15`:

```text
6 < 15  ✓
20 > 15 ✓
```

A local check says node `15` looks correct.

But node `6` is in the **right subtree of 10**:

```text
6 < 10  ✗
```

So the whole tree is not a BST.

```text
Local parent-child checks are not enough.
We must also follow ancestor limits.
```

---

# Approach 1: Store Inorder Traversal

## Key Idea

Inorder traversal of a valid BST is strictly increasing.

```text
Inorder: Left → Root → Right
```

For this valid BST:

```text
       5
      / \
     3   7
    / \
   2   4
```

```text
Inorder = [2, 3, 4, 5, 7]
```

Every next value is larger than the previous one.

---

## Inorder Check

```text
values = [2, 3, 4, 5, 7]

2 < 3 < 4 < 5 < 7  ✓ valid BST
```

For an invalid tree:

```text
        10
       /  \
      5    15
          /
         6
```

```text
Inorder = [5, 10, 6, 15]

10 < 6  ✗ not increasing
```

---

## C++ Code — Inorder Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    void inorder(TreeNode* root, vector<int>& values) {
        if (root == nullptr) return;

        inorder(root->left, values);
        values.push_back(root->val);
        inorder(root->right, values);
    }

public:
    bool isValidBST(TreeNode* root) {
        vector<int> values;
        inorder(root, values);

        for (int i = 1; i < values.size(); i++) {
            if (values[i] <= values[i - 1]) {
                return false;
            }
        }

        return true;
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this BST:
           5
          / \
         3   7
        / \
       2   4
    */
    TreeNode* root = new TreeNode(5);
    root->left = new TreeNode(3);
    root->right = new TreeNode(7);
    root->left->left = new TreeNode(2);
    root->left->right = new TreeNode(4);

    Solution solution;
    cout << boolalpha << "Is valid BST? " << solution.isValidBST(root) << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Is valid BST? true
```

---

## Inorder Approach Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N)` |
| Extra space | `O(N)` |

The vector stores every node value.

# Approach 2: Valid Range Check (Optimal Space) ⚡

## Key Idea

Every node must stay inside a valid range inherited from its ancestors.

At the root:

```text
valid range = (-∞, +∞)
```

For every node:

```text
left child  range = (minValue, current value)
right child range = (current value, maxValue)
```

---

## Range Diagram

```text
        10  range (-∞, +∞)
       /  \
      5    15
   (-∞,10) (10,+∞)
          /  \
         6   20
     (10,15) (15,+∞)
```

Check node `6`:

```text
required range: (10, 15)
actual value: 6

6 is not greater than 10 → invalid ✗
```

---

## Range Algorithm

```text
validate(node, minimum, maximum):

if node is NULL:
    return true

if node.value <= minimum OR node.value >= maximum:
    return false

return validate(node.left, minimum, node.value)
   AND validate(node.right, node.value, maximum)
```

---

## C++ Code — Range Check Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    bool validate(TreeNode* root, long long minimum, long long maximum) {
        if (root == nullptr) return true;

        // Value must be strictly inside the allowed range.
        if (root->val <= minimum || root->val >= maximum) {
            return false;
        }

        return validate(root->left, minimum, root->val) &&
               validate(root->right, root->val, maximum);
    }

public:
    bool isValidBST(TreeNode* root) {
        return validate(root, LLONG_MIN, LLONG_MAX);
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    // Valid BST:
    //       5
    //      / \
    //     3   7
    //    / \
    //   2   4
    TreeNode* validRoot = new TreeNode(5);
    validRoot->left = new TreeNode(3);
    validRoot->right = new TreeNode(7);
    validRoot->left->left = new TreeNode(2);
    validRoot->left->right = new TreeNode(4);

    // Invalid BST:
    //        10
    //       /  \
    //      5    15
    //          /  \
    //         6   20
    TreeNode* invalidRoot = new TreeNode(10);
    invalidRoot->left = new TreeNode(5);
    invalidRoot->right = new TreeNode(15);
    invalidRoot->right->left = new TreeNode(6);
    invalidRoot->right->right = new TreeNode(20);

    Solution solution;
    cout << boolalpha;
    cout << "Valid tree:   " << solution.isValidBST(validRoot) << endl;
    cout << "Invalid tree: " << solution.isValidBST(invalidRoot) << endl;

    deleteTree(validRoot);
    deleteTree(invalidRoot);
    return 0;
}
```

**Output:**

```text
Valid tree:   true
Invalid tree: false
```

---

## Range Check Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N)` |
| Extra space | `O(H)` recursion stack |

```text
Balanced tree → H ≈ log N
Skewed tree   → H = N
```

The range approach does not store all values, so it uses less extra space than the inorder-vector method.

---

## Duplicate Values

This guide uses strict BST rules:

```text
left < node < right
```

So duplicates are invalid.

```text
      5
     / \
    5   5

not valid under strict BST rules ✗
```

If a problem allows duplicates, check its rule. For example, duplicates may be allowed only on the right side. Then the range comparisons must be adjusted.

---

## Special Cases

### Empty Tree

```text
root = NULL
```

An empty tree is a valid BST.

```text
Answer = true
```

### Single Node

```text
  5
```

Always valid.

### Left-Skewed Valid BST

```text
      5
     /
    3
   /
  1
```

Every node is within its allowed range.

---

## Comparison

| Approach | Time | Extra Space | Main Idea |
|---|---:|---:|---|
| Store inorder values | `O(N)` | `O(N)` | Check strictly increasing order. |
| Range validation | `O(N)` | `O(H)` | Check every node against ancestor limits. |

## Interview Questions 🎯

### 1. Why is checking only direct children not enough?

A descendant can violate a higher ancestor’s BST rule.

```text
Node 6 < 15 is locally valid,
but node 6 < 10 is invalid in 10's right subtree.
```

### 2. Why does inorder traversal work?

A valid BST produces a strictly increasing inorder sequence.

### 3. What range does the root start with?

```text
(-∞, +∞)
```

### 4. How does the left-child range change?

The current node becomes the new upper bound.

### 5. How does the right-child range change?

The current node becomes the new lower bound.

### 6. What is the time complexity?

`O(N)` for both approaches.

### 7. Which approach uses less extra space?

Range validation uses `O(H)` stack space; inorder storage uses `O(N)` vector space.

### 8. Are duplicate values valid in this BST definition?

No. This guide uses strict inequalities.
