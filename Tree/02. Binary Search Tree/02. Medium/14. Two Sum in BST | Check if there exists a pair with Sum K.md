# Two Sum in a Binary Search Tree

> Return `true` if two **different nodes** in a BST add up to target sum `K`; otherwise return `false`.

---

## Example 1

```text
       5
      / \
     3   6
    / \   \
   2   4   7
```

```text
K = 9

Inorder: [2, 3, 4, 5, 6, 7]
Pair: 2 + 7 = 9 ✓

Answer = true
```

---

## Main BST Property 💡

Inorder traversal of a BST is sorted.

```text
Inorder = Left → Root → Right
```

```text
       5
      / \
     3   6
    / \   \
   2   4   7

Inorder: [2, 3, 4, 5, 6, 7]
```

Once values are sorted, we can use the classic **two-pointer** idea.

---

## Two-Pointer Rule

```text
left pointer  → smallest value
right pointer → largest value
```

```text
If left + right < K:
    need a larger sum → move left pointer forward

If left + right > K:
    need a smaller sum → move right pointer backward

If left + right == K:
    pair found
```

---

## Example Walkthrough: `K = 9`

```text
Sorted inorder: [2, 3, 4, 5, 6, 7]
                 ↑              ↑
               left           right
```

```text
2 + 7 = 9
```

```text
Pair found → return true
```

---

## Example Walkthrough: `K = 15`

```text
Sorted inorder: [2, 3, 4, 5, 6, 7]
                 ↑              ↑
```

```text
2 + 7 = 9  < 15 → move left
3 + 7 = 10 < 15 → move left
4 + 7 = 11 < 15 → move left
5 + 7 = 12 < 15 → move left
6 + 7 = 13 < 15 → move left
```

Pointers meet, so no pair exists.

```text
Answer = false
```

# Approach 1: Inorder Array + Two Pointers

## Simple Idea

1. Store inorder traversal in an array.
2. Use one pointer at the start and one at the end.
3. Adjust pointers based on the current sum.

```text
inorder = [2, 3, 4, 5, 6, 7]
           L              R
```

---

## C++ Code — Array Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    void inorder(TreeNode* root, vector<int>& values) {
        if (root == nullptr) return;

        inorder(root->left, values);
        values.push_back(root->val);
        inorder(root->right, values);
    }

public:
    bool findTarget(TreeNode* root, int target) {
        vector<int> values;
        inorder(root, values);

        int left = 0;
        int right = static_cast<int>(values.size()) - 1;

        while (left < right) {
            int sum = values[left] + values[right];

            if (sum == target) return true;

            if (sum < target) {
                left++;
            } else {
                right--;
            }
        }

        return false;
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this BST:
           5
          / \
         3   6
        / \   \
       2   4   7
    */
    TreeNode* root = new TreeNode(5);
    root->left = new TreeNode(3);
    root->right = new TreeNode(6);
    root->left->left = new TreeNode(2);
    root->left->right = new TreeNode(4);
    root->right->right = new TreeNode(7);

    int target = 9;
    Solution solution;
    cout << boolalpha << "Pair with sum " << target << " exists: "
         << solution.findTarget(root, target) << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Pair with sum 9 exists: true
```

### Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N)` |
| Extra space | `O(N)` |

The inorder array stores all node values.

# Approach 2: Two BST Iterators (Optimal Space) ⚡

## Main Idea

Do not store the full inorder array.

Use two iterators:

```text
Forward iterator → smallest to largest (inorder)
Reverse iterator → largest to smallest (reverse inorder)
```

```text
        7
       / \
      3   15
         /  \
        9   20

forward starts at 3
reverse starts at 20
```

---

## Iterator Movement

```text
Forward iterator:
Left → Root → Right

Reverse iterator:
Right → Root → Left
```

Each iterator stores only one root-to-leaf path in a stack.

```text
Balanced BST → stack height ≈ log N
Skewed BST   → stack height = N
```

---

## Iterator Walkthrough: `K = 22`

```text
        7
       / \
      3   15
         /  \
        9   20
```

```text
Forward value = 3
Reverse value = 20

3 + 20 = 23 > 22 → move reverse iterator

Forward value = 3
Reverse value = 15

3 + 15 = 18 < 22 → move forward iterator

Forward value = 7
Reverse value = 15

7 + 15 = 22 → pair found ✓
```

---

## C++ Code — Iterator Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class BSTIterator {
    stack<TreeNode*> st;
    bool reverseOrder;

    void pushPath(TreeNode* node) {
        while (node != nullptr) {
            st.push(node);
            node = reverseOrder ? node->right : node->left;
        }
    }

public:
    BSTIterator(TreeNode* root, bool isReverse) : reverseOrder(isReverse) {
        pushPath(root);
    }

    bool hasNext() const {
        return !st.empty();
    }

    TreeNode* nextNode() {
        TreeNode* current = st.top();
        st.pop();

        // Forward: after node, process its right subtree.
        // Reverse: after node, process its left subtree.
        if (reverseOrder) {
            pushPath(current->left);
        } else {
            pushPath(current->right);
        }

        return current;
    }
};

class Solution {
public:
    bool findTarget(TreeNode* root, int target) {
        if (root == nullptr) return false;

        BSTIterator forward(root, false); // Smallest → largest
        BSTIterator reverse(root, true);  // Largest → smallest

        TreeNode* leftNode = forward.nextNode();
        TreeNode* rightNode = reverse.nextNode();

        // Compare pointers so two different nodes are required.
        while (leftNode != rightNode) {
            long long sum = 1LL * leftNode->val + rightNode->val;

            if (sum == target) return true;

            if (sum < target) {
                if (!forward.hasNext()) break;
                leftNode = forward.nextNode();
            } else {
                if (!reverse.hasNext()) break;
                rightNode = reverse.nextNode();
            }
        }

        return false;
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this BST:
            7
           / \
          3   15
             /  \
            9   20
    */
    TreeNode* root = new TreeNode(7);
    root->left = new TreeNode(3);
    root->right = new TreeNode(15);
    root->right->left = new TreeNode(9);
    root->right->right = new TreeNode(20);

    int target = 22;
    Solution solution;
    cout << boolalpha << "Pair with sum " << target << " exists: "
         << solution.findTarget(root, target) << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Pair with sum 22 exists: true
```

### Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N)` worst case |
| Extra space | `O(H)` |

The two stacks together hold at most `O(H)` nodes at a time.

---

## Comparison

| Approach | Time | Extra Space | Main Idea |
|---|---:|---:|---|
| Inorder array | `O(N)` | `O(N)` | Store sorted values, then use pointers. |
| BST iterators | `O(N)` | `O(H)` | Generate smallest and largest values when needed. |

## Special Cases

### One Node Tree

```text
  5
```

```text
K = 10
Answer = false
```

The same node cannot be used twice.

### Two Nodes Form the Pair

```text
    5
   / \
  3   7
```

```text
K = 10
3 + 7 = 10
Answer = true
```

### No Valid Pair

```text
Inorder: [2, 3, 4, 5, 6, 7]
K = 15

largest possible pair = 6 + 7 = 13
Answer = false
```

## Interview Questions 🎯

### 1. Why does inorder traversal help with Two Sum in BST?

It gives the values in sorted order, which makes two pointers possible.

### 2. Why move left forward when sum is too small?

The array is sorted, so moving left forward increases the sum.

### 3. Why move right backward when sum is too large?

The array is sorted, so moving right backward decreases the sum.

### 4. Why use two BST iterators in the optimal approach?

They avoid storing all `N` values in an inorder array.

### 5. Why compare node pointers in the iterator solution?

It ensures the same node is never used twice.

### 6. What is the time complexity of both approaches?

`O(N)` in the worst case.

### 7. What is the extra-space complexity of the iterator approach?

`O(H)`, where `H` is the tree height.
