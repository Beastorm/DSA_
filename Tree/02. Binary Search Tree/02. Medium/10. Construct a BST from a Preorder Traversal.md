# Construct a BST from Preorder Traversal

> Given preorder traversal of a BST, construct and return the root of the BST.

This guide assumes all values are distinct and the input is a valid BST preorder traversal.

---

## Preorder Rule 💡

```text
Preorder = Root → Left → Right
```

For a BST:

```text
values smaller than root → left subtree
values larger than root  → right subtree
```

---

## Example 1

```text
preorder = [8, 5, 1, 7, 10, 12]
```

The first value is always the root.

```text
             8
            / \
           5   10
          / \    \
         1   7    12
```

Verify preorder:

```text
Root: 8
Left subtree: 5, 1, 7
Right subtree: 10, 12

[8, 5, 1, 7, 10, 12] ✓
```

---

## Example 2

```text
preorder = [4, 2, 1, 3, 6, 5, 7]
```

```text
         4
        / \
       2   6
      / \ / \
     1  3 5  7
```

---

# Method 1: Find the Split Point (Brute Force)

## Simple Idea

For each subtree:

```text
1. First preorder value is the root.
2. Find the first value greater than root.
3. Values before it belong to left subtree.
4. Values from it onward belong to right subtree.
5. Recurse on both parts.
```

---

## Example Split

```text
preorder = [8, 5, 1, 7, 10, 12]
             ↑
           root = 8
```

Find the first value greater than `8`:

```text
[5, 1, 7] < 8     → left subtree
[10, 12] > 8      → right subtree
```

```text
       8
      / \
     ?   ?

left uses:  [5, 1, 7]
right uses: [10, 12]
```

Then repeat recursively.

---

## C++ Code — Split-Point Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    TreeNode* build(const vector<int>& preorder, int start, int end) {
        if (start > end) return nullptr;

        TreeNode* root = new TreeNode(preorder[start]);

        // Find first value that belongs to the right subtree.
        int split = end + 1;
        for (int i = start + 1; i <= end; i++) {
            if (preorder[i] > root->val) {
                split = i;
                break;
            }
        }

        root->left = build(preorder, start + 1, split - 1);
        root->right = build(preorder, split, end);

        return root;
    }

public:
    TreeNode* bstFromPreorder(const vector<int>& preorder) {
        if (preorder.empty()) return nullptr;
        return build(preorder, 0, static_cast<int>(preorder.size()) - 1);
    }
};

void inorder(TreeNode* root) {
    if (root == nullptr) return;
    inorder(root->left);
    cout << root->val << " ";
    inorder(root->right);
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    vector<int> preorder = {8, 5, 1, 7, 10, 12};

    Solution solution;
    TreeNode* root = solution.bstFromPreorder(preorder);

    cout << "Inorder of constructed BST: ";
    inorder(root);
    cout << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Inorder of constructed BST: 1 5 7 8 10 12
```

### Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N²)` worst case |
| Extra space | `O(H)` recursion stack |

In a skewed preorder input, every recursive call may scan almost all remaining values.

# Method 2: Upper Bound + Preorder Index (Optimal Recursive) ⚡

## Main Idea

Keep one index pointing to the next unused preorder value.

```text
index = 0
```

Each recursive call gets an upper bound:

```text
build(bound)
```

The current preorder value can be used only if:

```text
preorder[index] < bound
```

Otherwise, it belongs to an ancestor’s right subtree, so return `NULL`.

---

## Why Does the Bound Work?

Start with no upper limit:

```text
bound = +∞
```

For a node `8`:

```text
left subtree values must be < 8
right subtree values can be < parent bound
```

```text
       8  bound = +∞
      / \
     ?   ?

left call:  bound = 8
right call: bound = +∞
```

---

## Upper-Bound Trace

```text
preorder = [8, 5, 1, 7, 10, 12]
index = 0
```

```text
build(+∞):
  8 < +∞ → create 8, index = 1

  build(8):
    5 < 8 → create 5, index = 2

    build(5):
      1 < 5 → create 1, index = 3

      next value is 7
      7 >= 5 → cannot belong below 1's right side
      return NULL

    build(8):
      7 < 8 → create 7, index = 4

  build(+∞):
    10 < +∞ → create 10, index = 5
    12 becomes right child of 10
```

---

## C++ Code — Upper Bound Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    int index;

    TreeNode* build(const vector<int>& preorder, long long upperBound) {
        // Current value does not belong to this subtree.
        if (index == preorder.size() || preorder[index] >= upperBound) {
            return nullptr;
        }

        TreeNode* root = new TreeNode(preorder[index++]);

        // Left subtree must contain values smaller than root.
        root->left = build(preorder, root->val);

        // Right subtree keeps the upper bound from the parent.
        root->right = build(preorder, upperBound);

        return root;
    }

public:
    TreeNode* bstFromPreorder(const vector<int>& preorder) {
        index = 0;
        return build(preorder, LLONG_MAX);
    }
};

void inorder(TreeNode* root) {
    if (root == nullptr) return;
    inorder(root->left);
    cout << root->val << " ";
    inorder(root->right);
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    vector<int> preorder = {8, 5, 1, 7, 10, 12};

    Solution solution;
    TreeNode* root = solution.bstFromPreorder(preorder);

    cout << "Inorder of constructed BST: ";
    inorder(root);
    cout << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Inorder of constructed BST: 1 5 7 8 10 12
```

### Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N)` |
| Extra space | `O(H)` recursion stack |

Every preorder value is used exactly once.

# Method 3: Iterative Stack

## Simple Idea

The stack stores the path of possible parents.

For every new value:

```text
value < stack.top() → it is left child of stack.top()
value > stack.top() → pop smaller nodes
                     last popped node becomes its parent
                     new value becomes that parent's right child
```

---

## Stack Walkthrough

```text
preorder = [8, 5, 1, 7, 10, 12]
```

```text
Process 8:
stack = [8]

Process 5:
5 < 8 → 5 becomes left child of 8
stack = [8, 5]

Process 1:
1 < 5 → 1 becomes left child of 5
stack = [8, 5, 1]

Process 7:
7 > 1 → pop 1
7 > 5 → pop 5 (last popped = 5)
7 < 8 → stop
7 becomes right child of 5
stack = [8, 7]

Process 10:
pop 7, then pop 8
10 becomes right child of 8
stack = [10]
```

---

## C++ Code — Stack Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    TreeNode* bstFromPreorder(const vector<int>& preorder) {
        if (preorder.empty()) return nullptr;

        TreeNode* root = new TreeNode(preorder[0]);
        stack<TreeNode*> st;
        st.push(root);

        for (int i = 1; i < preorder.size(); i++) {
            TreeNode* node = new TreeNode(preorder[i]);
            TreeNode* parent = nullptr;

            // The last popped node is the parent for a right child.
            while (!st.empty() && st.top()->val < node->val) {
                parent = st.top();
                st.pop();
            }

            if (parent != nullptr) {
                parent->right = node;
            } else {
                // Current stack top is larger, so this is its left child.
                st.top()->left = node;
            }

            st.push(node);
        }

        return root;
    }
};

void inorder(TreeNode* root) {
    if (root == nullptr) return;
    inorder(root->left);
    cout << root->val << " ";
    inorder(root->right);
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    vector<int> preorder = {8, 5, 1, 7, 10, 12};

    Solution solution;
    TreeNode* root = solution.bstFromPreorder(preorder);

    cout << "Inorder of constructed BST: ";
    inorder(root);
    cout << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Inorder of constructed BST: 1 5 7 8 10 12
```

### Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N)` |
| Extra space | `O(H)` worst case |

Every node is pushed once and popped at most once.

---

## Comparison

| Method | Time | Extra Space | Main Idea |
|---|---:|---:|---|
| Find split point | `O(N²)` worst case | `O(H)` | Scan each range for the first greater value. |
| Upper bound + index | `O(N)` | `O(H)` | Use preorder index and subtree upper limits. |
| Iterative stack | `O(N)` | `O(H)` | Keep possible parents in a stack. |

## Interview Questions 🎯

### 1. Why is the first preorder value the root?

Preorder traversal always visits root before its subtrees.

### 2. How do smaller and larger values split the BST?

```text
smaller than root → left subtree
larger than root  → right subtree
```

### 3. Why does the upper-bound method run in `O(N)` time?

Every preorder value is consumed once. No range scanning is needed.

### 4. Why does the upper-bound method need only an upper bound?

The preorder order and the recursive call position already ensure the lower bound. The upper bound prevents a value from entering the wrong left subtree.

### 5. Why does the stack approach pop smaller values?

The new value belongs to the right subtree of the last smaller ancestor.

### 6. What happens if duplicate values are allowed?

You need a clear rule, such as placing duplicates consistently on one side, and adjust comparisons accordingly.

### 7. What is the space complexity of the recursive optimal method?

`O(H)` for the recursion stack.

### 8. What is the space complexity of the stack method?

`O(H)` in the worst case.
