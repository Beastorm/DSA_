# Construct a BST from Preorder Traversal

> Given preorder traversal of a BST, construct and return the BST root.

This guide follows the **three approaches** from the linked lesson:

1. Insert every preorder value into a BST.
2. Sort preorder to get inorder, then build the tree from preorder + inorder.
3. Use preorder index + an upper bound (**optimal**).

> **Assumption:** values are distinct and the preorder array is a valid BST preorder traversal.

---

## Preorder Rule 💡

```text
Preorder = Root → Left → Right
```

For a BST:

```text
smaller values → left subtree
larger values  → right subtree
```

---

## Example

```text
preorder = [8, 5, 1, 7, 10, 12]
```

```text
             8
            / \
           5   10
          / \    \
         1   7    12
```

```text
Preorder check:
8 → 5 → 1 → 7 → 10 → 12 ✓
```

---

# Method 1: Insert Values One by One (Brute Force)

## Simple Idea

The first value becomes the root. Then insert every remaining value into the BST using normal BST insertion.

```text
preorder = [8, 5, 1, 7, 10, 12]

Create root: 8
Insert: 5
Insert: 1
Insert: 7
Insert: 10
Insert: 12
```

---

## Insertion Walkthrough

### Start with Root `8`

```text
  8
```

### Insert `5`

```text
5 < 8 → insert on the left

    8
   /
  5
```

### Insert `1`

```text
1 < 8 → left
1 < 5 → left

    8
   /
  5
 /
1
```

### Insert `7`

```text
7 < 8 → left
7 > 5 → right

    8
   /
  5
 / \
1   7
```

Continue the same way for `10` and `12`.

---

## C++ Code — Method 1 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    TreeNode* insert(TreeNode* root, int value) {
        if (root == nullptr) return new TreeNode(value);

        TreeNode* current = root;

        while (true) {
            if (value < current->val) {
                if (current->left == nullptr) {
                    current->left = new TreeNode(value);
                    break;
                }
                current = current->left;
            } else {
                if (current->right == nullptr) {
                    current->right = new TreeNode(value);
                    break;
                }
                current = current->right;
            }
        }

        return root;
    }

public:
    TreeNode* bstFromPreorder(const vector<int>& preorder) {
        if (preorder.empty()) return nullptr;

        TreeNode* root = new TreeNode(preorder[0]);

        for (int i = 1; i < preorder.size(); i++) {
            insert(root, preorder[i]);
        }

        return root;
    }
};

void inorder(TreeNode* root) {
    if (root == nullptr) return;
    inorder(root->left);
    cout << root->val << " ";
    inorder(root->right);
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    vector<int> preorder = {8, 5, 1, 7, 10, 12};

    Solution solution;
    TreeNode* root = solution.bstFromPreorder(preorder);

    cout << "Inorder of constructed BST: ";
    inorder(root);
    cout << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Inorder of constructed BST: 1 5 7 8 10 12
```

### Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N × H)`, `O(N²)` worst case |
| Extra space | `O(1)` iterative insertion |

`H` is the current tree height. In a skewed tree, each insertion can take `O(N)` time.

# Method 2: Sort to Get Inorder, Then Construct Tree

## Main Idea

Inorder traversal of a BST is sorted.

So, sorting preorder gives the inorder traversal:

```text
preorder = [8, 5, 1, 7, 10, 12]

sort(preorder)

inorder  = [1, 5, 7, 8, 10, 12]
```

Now use the same technique as **constructing a binary tree from preorder and inorder**.

---

## How the Two Arrays Help

```text
preorder = [8, 5, 1, 7, 10, 12]
             ↑
           root = 8

inorder  = [1, 5, 7, 8, 10, 12]
                      ↑
                    root = 8
```

Split inorder around root `8`:

```text
inorder = [1, 5, 7 | 8 | 10, 12]
              left     root    right
```

```text
left subtree has 3 nodes: [5, 1, 7]
right subtree:            [10, 12]
```

---

## Recursive Ranges

```text
build(preStart, preEnd, inStart, inEnd):

root = preorder[preStart]
inRoot = inorder position of root
leftSize = inRoot - inStart

left subtree:
  preorder: preStart + 1  to preStart + leftSize
  inorder:  inStart       to inRoot - 1

right subtree:
  preorder: preStart + leftSize + 1 to preEnd
  inorder:  inRoot + 1              to inEnd
```

---

## C++ Code — Method 2 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    TreeNode* build(const vector<int>& preorder, int preStart, int preEnd,
                    int inStart, int inEnd,
                    unordered_map<int, int>& inorderIndex) {
        if (preStart > preEnd || inStart > inEnd) return nullptr;

        int rootValue = preorder[preStart];
        TreeNode* root = new TreeNode(rootValue);

        int inRoot = inorderIndex[rootValue];
        int leftSize = inRoot - inStart;

        root->left = build(preorder, preStart + 1, preStart + leftSize,
                           inStart, inRoot - 1, inorderIndex);

        root->right = build(preorder, preStart + leftSize + 1, preEnd,
                            inRoot + 1, inEnd, inorderIndex);

        return root;
    }

public:
    TreeNode* bstFromPreorder(const vector<int>& preorder) {
        if (preorder.empty()) return nullptr;

        // Sorted preorder is inorder for a BST with distinct values.
        vector<int> inorder = preorder;
        sort(inorder.begin(), inorder.end());

        unordered_map<int, int> inorderIndex;
        for (int i = 0; i < inorder.size(); i++) {
            inorderIndex[inorder[i]] = i;
        }

        return build(preorder, 0, static_cast<int>(preorder.size()) - 1,
                     0, static_cast<int>(inorder.size()) - 1,
                     inorderIndex);
    }
};

void inorder(TreeNode* root) {
    if (root == nullptr) return;
    inorder(root->left);
    cout << root->val << " ";
    inorder(root->right);
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    vector<int> preorder = {8, 5, 1, 7, 10, 12};

    Solution solution;
    TreeNode* root = solution.bstFromPreorder(preorder);

    cout << "Inorder of constructed BST: ";
    inorder(root);
    cout << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Inorder of constructed BST: 1 5 7 8 10 12
```

### Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N log N)` |
| Extra space | `O(N)` |

```text
Sorting          → O(N log N)
Tree construction → O(N)
Map + sorted array + recursion → O(N) extra space
```

# Method 3: Preorder Index + Upper Bound (Optimal) ⚡

## Main Idea

Do not sort and do not scan for a split point.

Keep one preorder index:

```text
index = 0
```

Each recursive call gets an upper bound. A value can be added only if it is smaller than that bound.

```text
build(upperBound)
```

---

## Why the Bound Works

At root `8`:

```text
       8  (allowed range: -∞ to +∞)
      / \
     ?   ?
```

For the left subtree, every value must be smaller than `8`:

```text
left call: build(8)
```

For the right subtree, values can still be as large as the parent allows:

```text
right call: build(+∞)
```

---

## Upper-Bound Trace

```text
preorder = [8, 5, 1, 7, 10, 12]
index = 0
```

```text
build(+∞):
  8 < +∞ → create 8, index = 1

  build(8):
    5 < 8 → create 5, index = 2

    build(5):
      1 < 5 → create 1, index = 3
      next value = 7
      7 >= 5 → return NULL

    build(8):
      7 < 8 → create 7, index = 4

  build(+∞):
    10 < +∞ → create 10, index = 5
    12 becomes right child of 10
```

---

## C++ Code — Method 3 Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    int index;

    TreeNode* build(const vector<int>& preorder, long long upperBound) {
        // Current value belongs to an ancestor's right subtree.
        if (index == preorder.size() || preorder[index] >= upperBound) {
            return nullptr;
        }

        TreeNode* root = new TreeNode(preorder[index++]);

        // Values in left subtree must be smaller than root.
        root->left = build(preorder, root->val);

        // Right subtree keeps the ancestor's upper bound.
        root->right = build(preorder, upperBound);

        return root;
    }

public:
    TreeNode* bstFromPreorder(const vector<int>& preorder) {
        index = 0;
        return build(preorder, LLONG_MAX);
    }
};

void inorder(TreeNode* root) {
    if (root == nullptr) return;
    inorder(root->left);
    cout << root->val << " ";
    inorder(root->right);
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    vector<int> preorder = {8, 5, 1, 7, 10, 12};

    Solution solution;
    TreeNode* root = solution.bstFromPreorder(preorder);

    cout << "Inorder of constructed BST: ";
    inorder(root);
    cout << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Inorder of constructed BST: 1 5 7 8 10 12
```

### Complexity

| Resource | Complexity |
|---|---:|
| Time | `O(N)` |
| Extra space | `O(H)` recursion stack |

Every preorder value is used exactly once.

---

## Comparison of All 3 Methods

| Method | Time | Extra Space | Main Idea |
|---|---:|---:|---|
| Insert one by one | `O(N²)` worst case | `O(1)` | Build the BST using normal insertion. |
| Sort + preorder/inorder | `O(N log N)` | `O(N)` | Sorted preorder becomes inorder. |
| Upper bound + index | `O(N)` | `O(H)` | Build only values allowed by each subtree bound. |

## Interview Questions 🎯

### 1. Why can a BST be built from preorder alone?

BST ordering tells whether a value belongs in the left or right subtree.

### 2. What are the three construction methods?

```text
1. Insert values one by one
2. Sort to get inorder, then construct from preorder + inorder
3. Use preorder index with an upper bound
```

### 3. Why does sorting preorder give inorder?

Inorder traversal of a BST with distinct values is sorted.

### 4. Why is the upper-bound method `O(N)`?

Each preorder value is read and used once. No sorting or repeated insertion is needed.

### 5. Why does the optimal method use only an upper bound?

Preorder order and the current recursive position already enforce the lower limit. The upper bound prevents a value from entering the wrong left subtree.

### 6. What happens with duplicate values?

Use a clear duplicate policy and change comparisons consistently. This guide assumes distinct values.

### 7. Which method is best for interviews?

The upper-bound + preorder-index method is usually the expected optimal solution.
