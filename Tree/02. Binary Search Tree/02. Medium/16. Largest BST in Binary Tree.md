# Largest BST in a Binary Tree

> Given any binary tree, find the size of its largest subtree that is a valid BST.

A valid BST uses strict ordering:

```text
all left-subtree values  < node value
all right-subtree values > node value
```

---

## Example 1

```text
          10
         /  \
        5    15
       / \     \
      1   8     7
```

### Check Subtree Rooted at `5`

```text
       5
      / \
     1   8
```

```text
1 < 5 < 8 ✓
```

This is a valid BST of size `3`.

### Check Subtree Rooted at `15`

```text
      15
        \
         7
```

```text
7 is right child of 15, but 7 < 15 ✗
```

This is not a BST. Therefore, the subtree rooted at `10` is also not a BST.

```text
Largest BST size = 3
```

---

## Example 2

```text
        6
       / \
      6   2
         / \
        1   3
```

The whole tree is not a strict BST because:

```text
left child 6 = root 6 ✗
```

But this subtree is valid:

```text
       2
      / \
     1   3
```

```text
1 < 2 < 3 ✓
```

```text
Largest BST size = 3
```

---

## Main Idea: Postorder + Information from Children 💡

At every node, we need information from its left and right subtree:

```text
1. Is the subtree a BST?
2. What is its minimum value?
3. What is its maximum value?
4. What is the largest BST size inside it?
```

Process children first, then process the parent.

```text
Postorder:
Left subtree → Right subtree → Current node
```

---

## When Is a Subtree a BST?

```text
            node
           /    \
        left    right
```

The current subtree is a valid BST only if:

```text
left subtree is a BST
AND right subtree is a BST
AND node.value > left subtree maximum
AND node.value < right subtree minimum
```

```text
left.max < node.value < right.min
```

---

## Information Returned from Each Node

```text
Info = {
    minimum value in subtree,
    maximum value in subtree,
    largest BST size in subtree,
    isBST
}
```

For an empty subtree:

```text
min = +∞
max = -∞
size = 0
isBST = true
```

This makes leaf nodes easy to validate:

```text
Leaf 7:

left.max  = -∞
right.min = +∞

-∞ < 7 < +∞ ✓
```

---

## How We Combine Information

### If Current Subtree Is a BST

```text
       node
       /  \
    BST    BST
```

```text
current size = left.size + right.size + 1
current min  = min(left.min, node.value)
current max  = max(right.max, node.value)
```

### If Current Subtree Is Not a BST

```text
       node
       /  \
    BST   invalid
```

We cannot combine the two sides. Keep the larger valid BST already found in either child.

```text
largest size = max(left.largestBSTSize, right.largestBSTSize)
```

## Step-by-Step Trace

```text
          10
         /  \
        5    15
       / \     \
      1   8     7
```

### Leaf Nodes

```text
Node 1 → BST, min=1, max=1, size=1
Node 8 → BST, min=8, max=8, size=1
Node 7 → BST, min=7, max=7, size=1
```

### Node 5

```text
left  info: min=1, max=1, size=1, BST=true
right info: min=8, max=8, size=1, BST=true

1 < 5 < 8 ✓
```

```text
Node 5 subtree is BST
size = 1 + 1 + 1 = 3
min = 1
max = 8
```

### Node 15

```text
left  info: empty
right info: min=7, max=7, size=1, BST=true

15 < 7 ✗
```

```text
Node 15 subtree is NOT a BST
largest BST below it = 1
```

### Node 10

```text
left subtree is BST of size 3
right subtree is NOT a BST
```

So node `10` cannot make one large BST.

```text
largest BST size = max(3, 1) = 3
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;

    TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};

class Solution {
    struct Info {
        long long minValue;
        long long maxValue;
        int largestBSTSize;
        bool isBST;
    };

    Info postorder(TreeNode* root) {
        // Empty subtree is a valid BST of size 0.
        if (root == nullptr) {
            return {LLONG_MAX, LLONG_MIN, 0, true};
        }

        Info left = postorder(root->left);
        Info right = postorder(root->right);

        // Check whether the complete subtree rooted at root is a BST.
        if (left.isBST && right.isBST &&
            left.maxValue < root->val && root->val < right.minValue) {

            int currentSize = left.largestBSTSize + right.largestBSTSize + 1;

            return {
                min(left.minValue, static_cast<long long>(root->val)),
                max(right.maxValue, static_cast<long long>(root->val)),
                currentSize,
                true
            };
        }

        // Current subtree is invalid. Keep the best BST from either child.
        return {
            LLONG_MIN,
            LLONG_MAX,
            max(left.largestBSTSize, right.largestBSTSize),
            false
        };
    }

public:
    int largestBSTSubtree(TreeNode* root) {
        return postorder(root).largestBSTSize;
    }
};

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* Create this binary tree:
              10
             /  \
            5    15
           / \     \
          1   8     7
    */
    TreeNode* root = new TreeNode(10);
    root->left = new TreeNode(5);
    root->right = new TreeNode(15);
    root->left->left = new TreeNode(1);
    root->left->right = new TreeNode(8);
    root->right->right = new TreeNode(7);

    Solution solution;
    cout << "Largest BST size: " << solution.largestBSTSubtree(root) << endl;

    deleteTree(root);
    return 0;
}
```

**Output:**

```text
Largest BST size: 3
```

## Important Note About Example 3

For this tree:

```text
              60
             /  \
           65    50
           /    /  \
          70   45   55
              /
             40
```

The valid subtree rooted at `50` is:

```text
        50
       /  \
      45   55
     /
    40
```

It has `4` nodes:

```text
40, 45, 50, 55
```

So for the shown tree, the largest BST size is **4**, not 5.

## Special Cases

### Empty Tree

```text
root = NULL
Largest BST size = 0
```

### Single Node

```text
  5
```

A single node is always a BST.

```text
Largest BST size = 1
```

### Entire Tree Is a BST

```text
       5
      / \
     3   7
```

```text
Largest BST size = 3
```

### No Multi-Node BST Exists

```text
      5
     / \
    5   5
```

Duplicates violate strict BST ordering.

```text
Largest BST size = 1
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(N)` | Each tree node is processed once. |
| Extra space | `O(H)` | Recursive call stack, where `H` is tree height. |

```text
Balanced tree → H ≈ log N
Skewed tree   → H = N
```

## Interview Questions 🎯

### 1. Why do we use postorder traversal?

A node needs information from both children before it can decide whether its own subtree is a BST.

### 2. What information does each recursive call return?

```text
minimum value, maximum value, largest BST size, isBST flag
```

### 3. What condition makes a subtree valid?

```text
left is BST AND right is BST
AND left.max < root.value < right.min
```

### 4. Why do we need minimum and maximum values?

They check the BST rule against every value in the left and right subtree, not just direct children.

### 5. What happens when the current subtree is invalid?

Return the larger BST size found in either child subtree.

### 6. What is the time complexity?

`O(N)`.

### 7. What is the extra-space complexity?

`O(H)` because of recursion.

### 8. Are duplicate values valid in this solution?

No. This guide uses strict BST ordering.
