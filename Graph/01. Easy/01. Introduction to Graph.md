# Introduction to Graphs | Types | Conventions

> A graph is a non-linear data structure made of **vertices (nodes)** and **edges (connections)**.

> All diagrams below use fixed-width ASCII characters for proper alignment.

---

## 1. What Is a Graph?

```text
              (1)
             /   \
           /       \
         (2)       (3)
        /   \
      /       \
    (4)       (5)

Vertices: {1, 2, 3, 4, 5}
Edges:    {(1,2), (1,3), (2,4), (2,5)}
```

```text
Vertex = an entity
Edge   = a connection between two entities
```

Unlike a tree, a graph can have cycles, disconnected components, multiple paths, directions, and weights.

# 3. Types of Graphs

## Undirected Graph

An edge works in both directions.

```text
    (1) ----- (2)
     |         |
     |         |
    (3) ----- (4)

(1,2) means: 1 can reach 2 and 2 can reach 1
```

```text
adj[1] = [2, 3]
adj[2] = [1, 4]
adj[3] = [1, 4]
adj[4] = [2, 3]
```

---

## Directed Graph

An edge has one fixed direction.

```text
    (1) -----> (2)
     ^           |
     |           v
    (4) <----- (3)

1 -> 2 does NOT mean 2 -> 1
```

```text
adj[1] = [2]
adj[2] = [3]
adj[3] = [4]
adj[4] = [1]
```

---

## Weighted Graph

Edges can have distance, time, price, or another cost.

```text
          5
    (1) ----- (2)
     |         |
   3 |         | 10
     |         |
    (3) ----- (4)
          8

Edge (1,2) has weight 5
Edge (3,4) has weight 8
```

Used in:

```text
Dijkstra's shortest path
Minimum spanning tree
Road and flight cost problems
```

---

## Unweighted Graph

Edges have no cost, or every edge has equal cost `1`.

```text
    (1) ----- (2)
     |         |
     |         |
    (3) ----- (4)

Every edge has the same cost.
```

Used in BFS shortest-path problems.

---

## Cyclic and Acyclic Graphs

```text
Cyclic graph:                 Acyclic graph:

    (1) -- (2)                    (1)
     |       |                    /   \
     |       |                  (2)   (3)
    (4) -- (3)                          |
                                        (4)

Cycle: 1 -> 2 -> 3 -> 4 -> 1      No cycle
```

---

## Connected and Disconnected Graphs

```text
Connected:                    Disconnected:

(1) -- (2) -- (3)             (1) -- (2)     (3) -- (4)
        |
       (4)

Every node can reach          Component 1      Component 2
all other nodes.
```

---

## DAG: Directed Acyclic Graph

```text
          (A)
         /   \
        v     v
      (B)   (C)
        \   /
         v v
         (D)

Directed + no cycle = DAG
```

Used for topological sorting, course schedules, and build dependencies.

---

## Bipartite Graph

A graph is bipartite when nodes can be split into two groups and every edge goes between groups.

```text
Group A                         Group B

  (1) -------------------------- (4)
  (2) -------------------------- (4)
  (2) -------------------------- (5)
  (3) -------------------------- (6)

No edge is allowed inside Group A.
No edge is allowed inside Group B.
```

```text
Bipartite graph <=> no odd-length cycle
```

---

## Complete Graph

Every node connects to every other node.

```text
             (1)
            / | \
           /  |  \
         (2)--+--(3)
           \  |  /
            \ | /
             (4)

K4 has 4 nodes and 6 edges.
```

For an undirected complete graph with `N` nodes:

```text
edges = N * (N - 1) / 2
```

# 4. Important Graph Terms

## Path, Simple Path, and Cycle

```text
Path:
(1) -- (2) -- (4) -- (5)

Path 1 -> 2 -> 4 -> 5
Length = 3 edges
```

```text
Simple path:
No node repeats.

Cycle:
(1) -> (2) -> (3) -> (1)
```

---

## Degree of a Node

### Undirected Graph

```text
        (1) ----- (2) ----- (4)
         |         |
         |         |
        (3) -------+

Degree(1) = 2   connected to 2, 3
Degree(2) = 3   connected to 1, 3, 4
Degree(3) = 2   connected to 1, 2
Degree(4) = 1   connected to 2
```

Handshaking lemma:

```text
sum of all node degrees = 2 * number of edges
```

### Directed Graph

```text
    (1) -----> (2) -----> (3)
                  ^
                  |
                 (4)

Node 2:
in-degree  = 2  (from 1 and 4)
out-degree = 1  (to 3)
```

---

## Tree as a Graph

A tree is a graph that is:

```text
Undirected
Connected
Acyclic
```

```text
              (1)
             /   \
           (2)   (3)
          /   \
        (4)   (5)

Vertices = 5
Edges    = 4 = V - 1
```

# 5. Graph Conventions

## 0-indexed vs 1-indexed

```text
0-indexed nodes: 0, 1, 2, ..., N - 1
Use: vector<vector<int>> adj(N);

1-indexed nodes: 1, 2, 3, ..., N
Use: vector<vector<int>> adj(N + 1);
```

Always follow the indexing used in the problem statement.

---

## Directed vs Undirected Storage

For an edge between `u` and `v`:

```text
Undirected graph:
adj[u].push_back(v);
adj[v].push_back(u);

Directed graph:
adj[u].push_back(v);
```

An undirected edge appears twice in an adjacency list.

---

## Self Loops and Multi-edges

```text
Self loop:

       +---+
       |   |
      (1)-+

Edge: (1,1)
```

```text
Parallel / multi-edge:

(1) ===== (2)
(1) ----- (2)

Two edges connect the same pair of nodes.
```

```text
Simple graph: no self loops and no parallel edges
Multigraph:   self loops and parallel edges may exist
```

# 6. Graph Representations

## Adjacency List

```text
Graph:

    (1) ----- (2)
     |         |
     |         |
    (3) ----- (4)

Adjacency list:
1: [2, 3]
2: [1, 4]
3: [1, 4]
4: [2, 3]
```

```text
Space = O(V + E)
```

Use adjacency lists for most graph problems, especially sparse graphs.

---

## Adjacency Matrix

For the same graph:

```text
        1  2  3  4
      +------------+
  1   | 0  1  1  0 |
  2   | 1  0  0  1 |
  3   | 1  0  0  1 |
  4   | 0  1  1  0 |
      +------------+

matrix[u][v] = 1 means edge (u,v) exists.
```

```text
Space = O(V * V)
Edge lookup = O(1)
```

Use an adjacency matrix when the graph is dense or edge-existence checks are frequent.

# 7. C++ Code: Build and Print Graphs

```cpp
#include <bits/stdc++.h>
using namespace std;

void printUnweightedGraph(const vector<vector<int>>& graph) {
    for (int node = 1; node < graph.size(); node++) {
        cout << node << ": ";
        for (int neighbour : graph[node]) {
            cout << neighbour << " ";
        }
        cout << endl;
    }
}

void printWeightedGraph(const vector<vector<pair<int, int>>>& graph) {
    for (int node = 1; node < graph.size(); node++) {
        cout << node << ": ";
        for (auto [neighbour, weight] : graph[node]) {
            cout << "(" << neighbour << ", weight=" << weight << ") ";
        }
        cout << endl;
    }
}

int main() {
    int nodes = 4;

    // 1-indexed, undirected, unweighted graph.
    vector<vector<int>> graph(nodes + 1);
    vector<pair<int, int>> edges = {
        {1, 2}, {1, 3}, {2, 4}, {3, 4}
    };

    for (auto [u, v] : edges) {
        graph[u].push_back(v);
        graph[v].push_back(u);
    }

    cout << "Undirected adjacency list:\n";
    printUnweightedGraph(graph);

    // 1-indexed, directed, weighted graph.
    vector<vector<pair<int, int>>> weightedGraph(nodes + 1);
    weightedGraph[1].push_back({2, 5});
    weightedGraph[1].push_back({3, 2});
    weightedGraph[2].push_back({4, 7});
    weightedGraph[3].push_back({4, 1});

    cout << "\nDirected weighted adjacency list:\n";
    printWeightedGraph(weightedGraph);

    return 0;
}
```

**Output:**

```text
Undirected adjacency list:
1: 2 3
2: 1 4
3: 1 4
4: 2 3

Directed weighted adjacency list:
1: (2, weight=5) (3, weight=2)
2: (4, weight=7)
3: (4, weight=1)
4:
```

## Graph Type Summary

| Type | Directed? | Weighted? | Cycle rule | Example |
|---|---|---|---|---|
| Undirected graph | No | Optional | May exist | Friendship network |
| Directed graph | Yes | Optional | May exist | Web links |
| Tree | No | Optional | No cycles | File hierarchy |
| DAG | Yes | Optional | No cycles | Task dependencies |
| Bipartite graph | Usually no | Optional | No odd cycles | Job matching |
| Complete graph | Usually no | Optional | Exists for `N >= 3` | Fully connected network |

## Quick Checklist Before Solving a Graph Problem

```text
1. Are node numbers 0-indexed or 1-indexed?
2. Is the graph directed or undirected?
3. Is it weighted or unweighted?
4. Are self loops allowed?
5. Are multiple edges allowed?
6. Is the graph connected?
7. Which representation is suitable: list or matrix?
```

## Interview Questions

### 1. What is a graph?
A set of vertices and edges.

### 2. What is the difference between directed and undirected edges?

```text
Undirected: u <-> v
Directed:   u -> v
```

### 3. What is the adjacency-list space complexity?
`O(V + E)`.

### 4. What is the adjacency-matrix space complexity?
`O(V * V)`.

### 5. What is a DAG?
A directed graph with no cycle.

### 6. What makes a graph a tree?
It must be connected, undirected, and acyclic.

### 7. What is the handshaking lemma?
For an undirected graph, total degree is `2 * E`.

### 8. Which graph representation is usually preferred?
Adjacency list, because it uses `O(V + E)` space.
