# Depth First Search (DFS)

> DFS visits a graph by going as deep as possible along one path before backtracking.

DFS can be written using:

```text
Recursion  -> implicit call stack
Iteration  -> explicit stack
```

---

## Example 1

```text
Graph:

          (1)
         /   \
       (2)   (3)
       / \
     (4)--(5)

Edges: (1,2), (1,3), (2,4), (2,5), (4,5)
```

Adjacency list order:

```text
1 : [2, 3]
2 : [1, 4, 5]
3 : [1]
4 : [2, 5]
5 : [2, 4]
```

DFS starting from node `1`:

```text
1 -> 2 -> 4 -> 5 -> backtrack -> 3
```

```text
Output: [1, 2, 4, 5, 3]
```

> DFS order depends on adjacency-list order. A different neighbor order can produce another valid DFS traversal.

---

## Example 2

```text
          (1)
         /   \
       (2)   (3)
        |
       (4)
```

```text
Adjacency list:
1 : [2, 3]
2 : [1, 4]
3 : [1]
4 : [2]
```

```text
DFS from 1:
1 -> 2 -> 4 -> backtrack -> 3

Output: [1, 2, 4, 3]
```

---

## DFS Intuition

Think about exploring a maze.

```text
1. Choose an unvisited path.
2. Keep moving forward.
3. When no new path exists, go back.
4. Try the next unvisited path.
```

```text
DFS = go DEEP first, then backtrack
```

---

## DFS Call Flow

For Example 2:

```text
          (1)
         /   \
       (2)   (3)
        |
       (4)
```

```text
DFS(1)
 |
 +-- visit 1
 |
 +-- DFS(2)
 |    |
 |    +-- visit 2
 |    |
 |    +-- DFS(4)
 |         |
 |         +-- visit 4
 |         +-- no unvisited neighbor
 |         +-- return to 2
 |
 +-- return to 1
 |
 +-- DFS(3)
      |
      +-- visit 3
      +-- return
```

```text
Final order: [1, 2, 4, 3]
```

---

## DFS Algorithm

```text
DFS(node):

1. Mark node as visited.
2. Add node to answer.
3. For every neighbor of node:
      if neighbor is not visited:
          DFS(neighbor)
```

The `visited` array is important because graphs can have cycles.

```text
(1) -- (2)
 |      |
(3) -- (4)

Without visited:
1 -> 2 -> 4 -> 3 -> 1 -> ... forever
```

# Recursive DFS

## C++ Code — Recursive DFS Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
    void dfs(int node, const vector<vector<int>>& adjacencyList,
             vector<bool>& visited, vector<int>& order) {
        visited[node] = true;
        order.push_back(node);

        for (int neighbor : adjacencyList[node]) {
            if (!visited[neighbor]) {
                dfs(neighbor, adjacencyList, visited, order);
            }
        }
    }

public:
    vector<int> dfsFromStart(int vertices,
                             const vector<vector<int>>& adjacencyList,
                             int start) {
        vector<bool> visited(vertices + 1, false);
        vector<int> order;

        dfs(start, adjacencyList, visited, order);
        return order;
    }
};

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

int main() {
    /* Graph:
              1
             / \
            2   3
           / \
          4---5
    */
    int vertices = 5;
    vector<vector<int>> adjacencyList(vertices + 1);

    adjacencyList[1] = {2, 3};
    adjacencyList[2] = {1, 4, 5};
    adjacencyList[3] = {1};
    adjacencyList[4] = {2, 5};
    adjacencyList[5] = {2, 4};

    Solution solution;
    cout << "Recursive DFS from 1: ";
    printVector(solution.dfsFromStart(vertices, adjacencyList, 1));

    return 0;
}
```

**Output:**

```text
Recursive DFS from 1: [1, 2, 4, 5, 3]
```

# Iterative DFS Using a Stack

## Main Idea

Use an explicit stack instead of the recursion call stack.

```text
Recursion stack: created automatically
Iterative stack: created by us using stack<int>
```

To process a smaller neighbor first, push neighbors in reverse order.

```text
Adjacency list of 1 = [2, 3]

Push 3 first, then 2:

Stack top
   |
  [2]
  [3]

2 is popped first.
```

---

## C++ Code — Iterative DFS Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    vector<int> dfsFromStart(int vertices,
                             const vector<vector<int>>& adjacencyList,
                             int start) {
        vector<bool> visited(vertices + 1, false);
        vector<int> order;
        stack<int> st;

        st.push(start);
        visited[start] = true;

        while (!st.empty()) {
            int node = st.top();
            st.pop();

            order.push_back(node);

            // Push in reverse to match recursive DFS neighbor order.
            for (int i = static_cast<int>(adjacencyList[node].size()) - 1;
                 i >= 0; i--) {
                int neighbor = adjacencyList[node][i];

                if (!visited[neighbor]) {
                    visited[neighbor] = true;
                    st.push(neighbor);
                }
            }
        }

        return order;
    }
};

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

int main() {
    /* Graph:
              1
             / \
            2   3
           / \
          4---5
    */
    int vertices = 5;
    vector<vector<int>> adjacencyList(vertices + 1);

    adjacencyList[1] = {2, 3};
    adjacencyList[2] = {1, 4, 5};
    adjacencyList[3] = {1};
    adjacencyList[4] = {2, 5};
    adjacencyList[5] = {2, 4};

    Solution solution;
    cout << "Iterative DFS from 1: ";
    printVector(solution.dfsFromStart(vertices, adjacencyList, 1));

    return 0;
}
```

**Output:**

```text
Iterative DFS from 1: [1, 2, 4, 5, 3]
```

# DFS for a Disconnected Graph

DFS from one start node visits only that component.

```text
(1) -- (2)      (3) -- (4)

DFS from 1: [1, 2]
Nodes 3 and 4 are not visited.
```

To traverse every component, use an outer loop.

```text
for every node:
    if node is not visited:
        DFS(node)
```

---

## C++ Code — DFS All Components

```cpp
#include <bits/stdc++.h>
using namespace std;

void dfs(int node, const vector<vector<int>>& adjacencyList,
         vector<bool>& visited, vector<int>& order) {
    visited[node] = true;
    order.push_back(node);

    for (int neighbor : adjacencyList[node]) {
        if (!visited[neighbor]) {
            dfs(neighbor, adjacencyList, visited, order);
        }
    }
}

vector<int> dfsAll(int vertices, const vector<vector<int>>& adjacencyList) {
    vector<bool> visited(vertices + 1, false);
    vector<int> order;

    for (int node = 1; node <= vertices; node++) {
        if (!visited[node]) {
            dfs(node, adjacencyList, visited, order);
        }
    }

    return order;
}

int main() {
    /* Disconnected graph:
       1 -- 2      3 -- 4
    */
    int vertices = 4;
    vector<vector<int>> adjacencyList(vertices + 1);
    adjacencyList[1] = {2};
    adjacencyList[2] = {1};
    adjacencyList[3] = {4};
    adjacencyList[4] = {3};

    vector<int> order = dfsAll(vertices, adjacencyList);

    cout << "DFS over all components: ";
    for (int node : order) cout << node << " ";
    cout << endl;

    return 0;
}
```

**Output:**

```text
DFS over all components: 1 2 3 4
```

## DFS vs BFS

| Feature | DFS | BFS |
|---|---|---|
| Main data structure | Stack / recursion | Queue |
| Search style | Go deep first | Go level by level |
| Shortest path in unweighted graph | Not guaranteed | Guaranteed |
| Cycle detection | Yes | Yes |
| Connected components | Yes | Yes |
| Topological sort | Yes, in DAG | Kahn's algorithm uses BFS idea |

---

## Edge Cases

### Single Node

```text
V = 1
Edges = []

DFS(1) = [1]
```

### Self Loop

```text
(1) --> (1)
```

Node `1` is marked visited before checking its neighbors, so the self loop is skipped safely.

### Cycle

```text
(1) -- (2)
 |      |
(4) -- (3)
```

The visited array prevents DFS from looping forever.

---

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(V + E)` | Visit each vertex and inspect each edge. |
| Extra space | `O(V)` | Visited array plus recursion/stack. |
| Output order | `O(V)` | Stores visited vertices. |

For an undirected graph, each edge appears twice in the adjacency list, but time stays `O(V + E)`.

## Interview Questions

### 1. What is DFS?
Go as deep as possible before backtracking.

### 2. Which data structure does DFS use?
A stack, either explicit or through recursion.

### 3. Why do we need a visited array?
To avoid revisiting nodes and getting stuck in cycles.

### 4. Is DFS order always unique?
No. It depends on neighbor order in the adjacency list.

### 5. Can DFS find the shortest path in an unweighted graph?
No. BFS is used for guaranteed shortest paths.

### 6. How do we run DFS on a disconnected graph?
Use an outer loop and start DFS from every unvisited node.

### 7. What is DFS time complexity?
`O(V + E)`.
