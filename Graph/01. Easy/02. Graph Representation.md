# Graph Representation

> Before using BFS, DFS, Dijkstra, or any graph algorithm, we need a way to store nodes and edges.

The two most common choices are:

```text
1. Adjacency Matrix
2. Adjacency List
```

---

## Input Format

```text
First line:     N M

N = number of nodes
M = number of edges

Next M lines:   U V
```

Example:

```text
5 6
1 2
1 3
2 4
3 4
3 5
4 5
```

This means:

```text
Nodes: 1, 2, 3, 4, 5
Edges: (1,2), (1,3), (2,4), (3,4), (3,5), (4,5)
```

---

## Graph Visualized

```text
                 (1)
                /   \
               /     \
             (2)     (3)
              | \     / \
              |  \   /   \
              |   \ /     \
             (4)---------(5)

Edges:
(1,2)  (1,3)  (2,4)
(3,4)  (3,5)  (4,5)
```

---

## Quick Comparison

| Feature | Adjacency Matrix | Adjacency List |
|---|---:|---:|
| Space | `O(V²)` | `O(V + E)` |
| Add edge | `O(1)` | `O(1)` amortized |
| Check edge `(u,v)` | `O(1)` | `O(degree(u))` |
| Find neighbors of `u` | `O(V)` | `O(degree(u))` |
| Best for | Dense graphs | Sparse graphs / most DSA problems |

# 1. Adjacency Matrix

An adjacency matrix is a 2D array.

```text
adj[u][v] = 1  → edge between u and v exists
adj[u][v] = 0  → no edge exists
```

For the undirected graph above:

```text
            to
          1  2  3  4  5
        +----------------+
from 1 | 0  1  1  0  0 |
from 2 | 1  0  0  1  0 |
from 3 | 1  0  0  1  1 |
from 4 | 0  1  1  0  1 |
from 5 | 0  0  1  1  0 |
        +----------------+
```

Examples:

```text
adj[3][5] = 1  → edge (3,5) exists
adj[1][5] = 0  → edge (1,5) does not exist
```

Because the graph is undirected:

```text
adj[u][v] = adj[v][u]
```

The matrix is symmetric across its diagonal.

---

## C++ Code — Adjacency Matrix Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

void printMatrix(const vector<vector<int>>& matrix) {
    int n = static_cast<int>(matrix.size()) - 1;

    cout << "    ";
    for (int col = 1; col <= n; col++) {
        cout << col << " ";
    }
    cout << endl;

    for (int row = 1; row <= n; row++) {
        cout << row << " : ";
        for (int col = 1; col <= n; col++) {
            cout << matrix[row][col] << " ";
        }
        cout << endl;
    }
}

int main() {
    int n = 5;
    vector<pair<int, int>> edges = {
        {1, 2}, {1, 3}, {2, 4}, {3, 4}, {3, 5}, {4, 5}
    };

    // 1-indexed adjacency matrix.
    vector<vector<int>> adjacencyMatrix(n + 1, vector<int>(n + 1, 0));

    for (auto [u, v] : edges) {
        adjacencyMatrix[u][v] = 1;
        adjacencyMatrix[v][u] = 1; // Remove this line for a directed graph.
    }

    cout << "Adjacency matrix:\n";
    printMatrix(adjacencyMatrix);

    cout << "\nIs there an edge from 3 to 5? "
         << (adjacencyMatrix[3][5] ? "Yes" : "No") << endl;

    return 0;
}
```

**Output:**

```text
Adjacency matrix:
    1 2 3 4 5
1 : 0 1 1 0 0
2 : 1 0 0 1 0
3 : 1 0 0 1 1
4 : 0 1 1 0 1
5 : 0 0 1 1 0

Is there an edge from 3 to 5? Yes
```

---

## Matrix Complexity

```text
Space:                O(V * V)
Check edge (u,v):     O(1)
Find all neighbors:   O(V)
```

Why can it be expensive?

```text
V = 100,000
V * V = 10,000,000,000 cells
```

This uses too much memory for a sparse graph.

---

# 2. Adjacency List

An adjacency list stores only the neighbors that actually exist.

```text
adj[1] = [2, 3]
adj[2] = [1, 4]
adj[3] = [1, 4, 5]
adj[4] = [2, 3, 5]
adj[5] = [3, 4]
```

Visual connection:

```text
(1) : (2), (3)
(2) : (1), (4)
(3) : (1), (4), (5)
(4) : (2), (3), (5)
(5) : (3), (4)
```

For an undirected edge `(u,v)`, store it twice:

```text
adj[u].push_back(v);
adj[v].push_back(u);
```

---

## C++ Code — Undirected Adjacency List Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

void printGraph(const vector<vector<int>>& graph) {
    for (int node = 1; node < graph.size(); node++) {
        cout << node << " : ";

        for (int neighbor : graph[node]) {
            cout << neighbor << " ";
        }

        cout << endl;
    }
}

int main() {
    int n = 5;
    vector<pair<int, int>> edges = {
        {1, 2}, {1, 3}, {2, 4}, {3, 4}, {3, 5}, {4, 5}
    };

    // 1-indexed adjacency list.
    vector<vector<int>> adjacencyList(n + 1);

    for (auto [u, v] : edges) {
        adjacencyList[u].push_back(v);
        adjacencyList[v].push_back(u);
    }

    cout << "Undirected adjacency list:\n";
    printGraph(adjacencyList);

    return 0;
}
```

**Output:**

```text
Undirected adjacency list:
1 : 2 3
2 : 1 4
3 : 1 4 5
4 : 2 3 5
5 : 3 4
```

## Directed Adjacency List

For a directed edge `u -> v`, store only one direction.

```text
Graph:

(1) -----> (2)
 |          |
 |          v
 +-------> (3)

Edges: 1 -> 2, 1 -> 3, 2 -> 3
```

```text
adj[1] = [2, 3]
adj[2] = [3]
adj[3] = []
```

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n = 3;
    vector<pair<int, int>> edges = {
        {1, 2}, {1, 3}, {2, 3}
    };

    vector<vector<int>> adjacencyList(n + 1);

    for (auto [u, v] : edges) {
        adjacencyList[u].push_back(v);
        // Do not add adjacencyList[v].push_back(u).
    }

    cout << "Directed adjacency list:\n";
    for (int node = 1; node <= n; node++) {
        cout << node << " : ";
        for (int neighbor : adjacencyList[node]) {
            cout << neighbor << " ";
        }
        cout << endl;
    }

    return 0;
}
```

**Output:**

```text
Directed adjacency list:
1 : 2 3
2 : 3
3 :
```

---

## List Complexity

```text
Space:                O(V + E)
Check edge (u,v):     O(degree(u))
Find all neighbors:   O(degree(u))
```

For an undirected graph, every edge is stored twice:

```text
2 * E neighbor entries
```

But Big-O is still:

```text
O(V + E)
```

# 3. Weighted Graph Representation

For a weighted graph, store:

```text
(neighbor, weight)
```

Example:

```text
          5
    (1) ----- (2)
     |         |
   3 |         | 10
     |         |
    (3) ----- (4)
          8
```

Adjacency list:

```text
adj[1] = [(2,5),  (3,3)]
adj[2] = [(1,5),  (4,10)]
adj[3] = [(1,3),  (4,8)]
adj[4] = [(2,10), (3,8)]
```

---

## C++ Code — Weighted Adjacency List Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n = 4;

    // Each item is: {from, to, weight}.
    vector<tuple<int, int, int>> edges = {
        {1, 2, 5},
        {1, 3, 3},
        {2, 4, 10},
        {3, 4, 8}
    };

    // pair<neighbor, weight>
    vector<vector<pair<int, int>>> adjacencyList(n + 1);

    for (auto [u, v, weight] : edges) {
        adjacencyList[u].push_back({v, weight});
        adjacencyList[v].push_back({u, weight}); // Remove for directed graph.
    }

    cout << "Weighted adjacency list:\n";

    for (int node = 1; node <= n; node++) {
        cout << node << " : ";

        for (auto [neighbor, weight] : adjacencyList[node]) {
            cout << "(" << neighbor << ", " << weight << ") ";
        }

        cout << endl;
    }

    return 0;
}
```

**Output:**

```text
Weighted adjacency list:
1 : (2, 5) (3, 3)
2 : (1, 5) (4, 10)
3 : (1, 3) (4, 8)
4 : (2, 10) (3, 8)
```

# 4. Weighted Adjacency Matrix

```text
matrix[u][v] = edge weight
```

For the weighted graph above:

```text
            to
          1   2   3   4
        +------------------+
from 1 | 0   5   3   -1 |
from 2 | 5   0  -1   10 |
from 3 | 3  -1   0    8 |
from 4 |-1  10   8    0 |
        +------------------+

-1 means no edge.
```

> Do not use `0` for “no edge” if zero-weight edges are allowed. Use `-1` or a large `INF` value instead.

## When Should You Use Each?

```text
Need O(1) edge check?
→ Adjacency matrix

Graph is dense?
→ Adjacency matrix can be suitable

Graph is sparse / BFS / DFS / Dijkstra?
→ Adjacency list (most common)
```

## Interview Questions

### 1. Which graph representation is most common in DSA?
Adjacency list.

### 2. Why is an adjacency list better for sparse graphs?
It stores only existing edges, so it uses `O(V + E)` space.

### 3. Why is an adjacency matrix good for edge checks?
`matrix[u][v]` directly tells whether the edge exists in `O(1)` time.

### 4. How do you store an undirected edge in an adjacency list?

```cpp
adj[u].push_back(v);
adj[v].push_back(u);
```

### 5. How do you store a weighted edge?

```cpp
adj[u].push_back({v, weight});
```

### 6. What changes for a directed graph?
Store only `u -> v`; do not add the reverse edge.

### 7. What is the space complexity of an adjacency matrix?
`O(V²)`.

### 8. What is the space complexity of an adjacency list?
`O(V + E)`.
