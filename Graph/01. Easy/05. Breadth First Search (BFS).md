# Breadth First Search (BFS)

> BFS visits a graph level by level. It explores all nearby nodes before moving farther away.

BFS uses a **queue**.

```text
Queue = First In, First Out (FIFO)
```

---

## Example 1

```text
Graph:

          (1)
         /   \
       (2)   (3)
       / \
     (4)--(5)

Edges: (1,2), (1,3), (2,4), (2,5), (4,5)
```

Adjacency-list order:

```text
1 : [2, 3]
2 : [1, 4, 5]
3 : [1]
4 : [2, 5]
5 : [2, 4]
```

BFS from node `1`:

```text
Level 0: 1
Level 1: 2, 3
Level 2: 4, 5

Output: [1, 2, 3, 4, 5]
```

---

## Example 2

```text
          (1)
         /   \
       (2)   (3)
        |
       (4)
```

```text
Level 0: 1
Level 1: 2, 3
Level 2: 4

Output: [1, 2, 3, 4]
```

---

## BFS Intuition 💡

Think of ripples spreading in water.

```text
Start from source node.
First visit nodes 1 edge away.
Then visit nodes 2 edges away.
Then visit nodes 3 edges away.
```

```text
BFS = go WIDE first, then go deeper
```

```text
DFS: 1 -> 2 -> 4 -> 5 -> 3
BFS: 1 -> 2 -> 3 -> 4 -> 5
```

## Main Algorithm

```text
1. Mark start node as visited.
2. Push start node into queue.
3. While queue is not empty:
      a. Remove front node.
      b. Add it to answer.
      c. For every unvisited neighbor:
           mark it visited
           push it into queue
4. Return answer.
```

---

## Why Mark Visited When Pushing? ⚠️

Consider this graph:

```text
          (1)
         /   \
       (2)---(3)
```

Start BFS from `1`:

```text
Pop 1 -> push 2 and 3
Queue = [2, 3]
```

When processing `2`, node `3` is already in queue.

```text
Mark visited when pushing:
3 is already visited -> do not push again ✓
```

If we wait until popping, node `3` can be pushed more than once.

```text
Correct:
mark visited -> push

Wrong:
push -> mark visited later
```

## C++ Code — BFS Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    vector<int> bfsFromStart(int vertices,
                             const vector<vector<int>>& adjacencyList,
                             int start) {
        vector<bool> visited(vertices + 1, false);
        vector<int> order;
        queue<int> q;

        // Start BFS.
        visited[start] = true;
        q.push(start);

        while (!q.empty()) {
            int node = q.front();
            q.pop();

            order.push_back(node);

            for (int neighbor : adjacencyList[node]) {
                if (!visited[neighbor]) {
                    // Mark when adding to queue to prevent duplicates.
                    visited[neighbor] = true;
                    q.push(neighbor);
                }
            }
        }

        return order;
    }
};

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

int main() {
    /* Graph:
              1
             / \
            2   3
           / \
          4---5
    */
    int vertices = 5;
    vector<vector<int>> adjacencyList(vertices + 1);

    adjacencyList[1] = {2, 3};
    adjacencyList[2] = {1, 4, 5};
    adjacencyList[3] = {1};
    adjacencyList[4] = {2, 5};
    adjacencyList[5] = {2, 4};

    Solution solution;
    cout << "BFS from 1: ";
    printVector(solution.bfsFromStart(vertices, adjacencyList, 1));

    return 0;
}
```

**Output:**

```text
BFS from 1: [1, 2, 3, 4, 5]
```

# BFS for a Disconnected Graph

BFS from one node visits only that node’s component.

```text
(1) -- (2) -- (3)      (4) -- (5)      (6)

BFS from 1 -> [1, 2, 3]
```

To visit all components, use an outer loop.

```text
for every node:
    if node is not visited:
        start BFS from node
```

---

## C++ Code — BFS All Components

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> bfsAll(int vertices, const vector<vector<int>>& adjacencyList) {
    vector<bool> visited(vertices + 1, false);
    vector<int> order;

    for (int start = 1; start <= vertices; start++) {
        if (visited[start]) continue;

        queue<int> q;
        q.push(start);
        visited[start] = true;

        while (!q.empty()) {
            int node = q.front();
            q.pop();
            order.push_back(node);

            for (int neighbor : adjacencyList[node]) {
                if (!visited[neighbor]) {
                    visited[neighbor] = true;
                    q.push(neighbor);
                }
            }
        }
    }

    return order;
}

int main() {
    /* Disconnected graph:
       1 -- 2 -- 3      4 -- 5      6
    */
    int vertices = 6;
    vector<vector<int>> adjacencyList(vertices + 1);

    adjacencyList[1] = {2};
    adjacencyList[2] = {1, 3};
    adjacencyList[3] = {2};
    adjacencyList[4] = {5};
    adjacencyList[5] = {4};

    vector<int> order = bfsAll(vertices, adjacencyList);

    cout << "BFS over all components: ";
    for (int node : order) cout << node << " ";
    cout << endl;

    return 0;
}
```

**Output:**

```text
BFS over all components: 1 2 3 4 5 6
```

## BFS vs DFS

| Feature | BFS | DFS |
|---|---|---|
| Main structure | Queue | Stack / recursion |
| Search style | Level by level | Go deep first |
| Shortest path in unweighted graph | Yes | No guarantee |
| Connected components | Yes | Yes |
| Cycle detection | Yes | Yes |
| Best use | Shortest path, nearest node | Topological sort, deep exploration |

## Edge Cases

### Single Node

```text
V = 1
Edges = []

BFS(1) = [1]
```

### No Edges

```text
V = 4
Edges = []

BFS from 1 = [1]
BFS all components = [1, 2, 3, 4]
```

### Star Graph

```text
            (2)
             |
(3) ------ (1) ------ (4)
             |
            (5)

BFS from 1:
Level 0: 1
Level 1: 2, 3, 4, 5
```

### Cycle

```text
(1) -- (2)
 |      |
(4) -- (3)
```

Visited nodes prevent adding the same node again.

---

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(V + E)` | Every vertex and edge is processed at most once. |
| Extra space | `O(V)` | Visited array and queue can hold vertices. |
| Output | `O(V)` | Stores the traversal order. |

For an undirected graph, each edge is in two adjacency lists, but total time remains `O(V + E)`.

## Interview Questions

### 1. What is BFS?
Visit graph nodes level by level using a queue.

### 2. Why is a queue used in BFS?
A queue processes earlier-discovered nodes first, which keeps traversal level by level.

### 3. Why mark visited while pushing into queue?
It prevents a node from being added multiple times.

### 4. Does BFS find shortest paths?
Yes, in an unweighted graph, BFS finds the shortest path in number of edges.

### 5. How do you run BFS on a disconnected graph?
Start a new BFS from every unvisited node.

### 6. What is BFS time complexity?
`O(V + E)`.

### 7. What is BFS extra-space complexity?
`O(V)`.
