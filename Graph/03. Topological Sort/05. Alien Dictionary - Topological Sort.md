# Alien Dictionary | Topological Sort

> Given a sorted dictionary of alien words, find one valid order of its characters.

The key rule is:

```text
If word A appears before word B in the dictionary,
the first different character in A and B determines an order.
```

---

## Example 1

```text
N = 5
K = 4
Dictionary = ["baa", "abcd", "abca", "cab", "cad"]
```

`K = 4` means alien letters are:

```text
a, b, c, d
```

---

## Build Character Rules

### Compare `"baa"` and `"abcd"`

```text
b a a
^
a b c d
^

First different character: b vs a
Rule: b -> a
```

### Compare `"abcd"` and `"abca"`

```text
a b c d
      ^
a b c a
      ^

First different character: d vs a
Rule: d -> a
```

### Compare `"abca"` and `"cab"`

```text
a b c a
^
c a b
^

First different character: a vs c
Rule: a -> c
```

### Compare `"cab"` and `"cad"`

```text
c a b
    ^
c a d
    ^

First different character: b vs d
Rule: b -> d
```

---

## Directed Graph

All discovered rules:

```text
b -> a
b -> d
d -> a
a -> c
```

Graph:

```text
(b) -> (d) -> (a) -> (c)
  \                 ^
   \________________|

Extra edge: b -> a
```

A valid topological order:

```text
b, d, a, c
```

```text
Answer = "bdac"
```

---

## Why Compare Only the First Different Character? 💡

The first different character decides the ordering.

```text
"abcd"
"abca"
```

The first three characters are equal:

```text
a == a
b == b
c == c
```

The first difference is:

```text
d vs a
```

So:

```text
d must come before a
```

Characters after the first difference provide no new ordering information.

## Example 2

```text
Dictionary = ["caa", "aaa", "aab"]
K = 3
```

```text
"caa" vs "aaa"
 c != a -> c -> a

"aaa" vs "aab"
 last a != b -> a -> b
```

```text
Graph: c -> a -> b
Order: "cab"
```

---

## Invalid Prefix Case ⚠️

```text
Dictionary = ["abc", "ab"]
```

This is invalid.

```text
"abc" cannot come before "ab"
```

The shorter word must come first if one word is a prefix of another.

```text
Valid:   ["ab", "abc"]
Invalid: ["abc", "ab"]
```

Return an empty string for this case.

---

## Algorithm

```text
1. Create a directed graph for K characters.

2. Compare every adjacent word pair:
      a. Find first different character.
      b. Add directed edge firstChar -> secondChar.
      c. If no difference and first word is longer:
           dictionary is invalid.

3. Run Kahn's topological sort.

4. If topo order has K characters:
      convert indexes back to characters and return it.
   Otherwise:
      cycle exists -> return empty string.
```

---

## Kahn's Topological Sort

```text
in-degree = number of rules that must come before a character
```

For graph:

```text
b -> d -> a -> c
 \__________-> a
```

```text
Character:  a  b  c  d
In-degree:  2  0  1  1
```

Start with zero in-degree character:

```text
Queue = [b]
```

Process:

```text
Pop b -> d becomes 0 -> queue [d]
Pop d -> a becomes 0 -> queue [a]
Pop a -> c becomes 0 -> queue [c]
Pop c
```

```text
Topological order = b, d, a, c
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    string findOrder(const vector<string>& dictionary, int k) {
        vector<unordered_set<int>> graph(k);
        vector<int> inDegree(k, 0);

        // Build graph by comparing adjacent dictionary words.
        for (int i = 0; i + 1 < dictionary.size(); i++) {
            const string& first = dictionary[i];
            const string& second = dictionary[i + 1];
            int length = min(first.size(), second.size());
            int position = 0;

            while (position < length && first[position] == second[position]) {
                position++;
            }

            // Invalid: longer word appears before its own prefix.
            if (position == length) {
                if (first.size() > second.size()) {
                    return "";
                }
                continue;
            }

            int from = first[position] - 'a';
            int to = second[position] - 'a';

            // Add each rule only once.
            if (graph[from].insert(to).second) {
                inDegree[to]++;
            }
        }

        queue<int> q;
        for (int character = 0; character < k; character++) {
            if (inDegree[character] == 0) {
                q.push(character);
            }
        }

        string order;

        while (!q.empty()) {
            int character = q.front();
            q.pop();
            order += static_cast<char>('a' + character);

            for (int neighbor : graph[character]) {
                inDegree[neighbor]--;

                if (inDegree[neighbor] == 0) {
                    q.push(neighbor);
                }
            }
        }

        // A shorter order means a cycle exists.
        if (order.size() != k) {
            return "";
        }

        return order;
    }
};

int main() {
    Solution solution;

    vector<string> dictionary1 = {"baa", "abcd", "abca", "cab", "cad"};
    cout << "Example 1 order: "
         << solution.findOrder(dictionary1, 4) << endl;

    vector<string> dictionary2 = {"caa", "aaa", "aab"};
    cout << "Example 2 order: "
         << solution.findOrder(dictionary2, 3) << endl;

    vector<string> invalidDictionary = {"abc", "ab"};
    string invalidOrder = solution.findOrder(invalidDictionary, 3);
    cout << "Invalid prefix order: "
         << (invalidOrder.empty() ? "invalid" : invalidOrder) << endl;

    return 0;
}
```

**Output:**

```text
Example 1 order: bdac
Example 2 order: cab
Invalid prefix order: invalid
```

## Why Multiple Orders Can Be Valid

Suppose no rule exists between two characters.

```text
b -> a
c has no connection
```

Both orders can be valid:

```text
b, a, c
c, b, a
```

Alien Dictionary problems usually accept any valid order unless they ask for a specific tie-breaking rule.

---

## Edge Cases

### One Word

```text
Dictionary = ["abc"]
```

No character-order rule is given. Any order of the K characters is acceptable.

### Same Words

```text
["abc", "abc"]
```

No new rule is added.

### Invalid Prefix

```text
["abc", "ab"]
```

```text
Return empty string.
```

### Cycle in Character Rules

```text
a -> b
b -> a
```

No topological order exists.

```text
Return empty string.
```

---

## Complexity

Let:

```text
N = number of words
L = total number of characters compared across adjacent pairs
K = number of distinct alien characters
E = number of character-order edges
```

| Resource | Complexity |
|---|---:|
| Compare words and build graph | `O(L)` |
| Kahn's topological sort | `O(K + E)` |
| Extra space | `O(K + E)` |

Total time:

```text
O(L + K + E)
```

## Interview Questions

### 1. Why compare only adjacent words?
The dictionary is sorted, so each adjacent pair gives the necessary ordering constraint.

### 2. Why use the first different character only?
It is the first point that determines which word should come earlier.

### 3. What does `[a, b]` correspond to in the alien graph?
If words show character `x` before `y`, add edge `x -> y`.

### 4. Why use topological sort?
Character ordering rules form a directed dependency graph.

### 5. What does an empty answer mean?
The dictionary is invalid because of a prefix issue or a cycle in character rules.

### 6. Can the alien order be non-unique?
Yes. Characters without ordering constraints can appear in different valid positions.

### 7. What is the time complexity?
`O(L + K + E)`.
