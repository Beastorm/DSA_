# Course Schedule I and II | Prerequisite Tasks

> Course Schedule problems are topological-sort problems.

A prerequisite pair `[course, prerequisite]` means:

```text
Finish prerequisite before course
```

Graph edge direction:

```text
[course, prerequisite] -> prerequisite -> course
```

---

## Course Schedule I

Question:

```text
Can we finish all courses?
```

Return:

```text
true  -> possible
false -> impossible because of a cycle
```

---

## Course Schedule II

Question:

```text
What valid order should we finish all courses in?
```

Return:

```text
valid course order -> possible
[]                 -> impossible because of a cycle
```

---

## Example 1 — Valid Course Plan

```text
N = 4
prerequisites = [[1,0], [2,1], [3,2]]
```

Convert pairs to edges:

```text
[1,0] -> 0 -> 1
[2,1] -> 1 -> 2
[3,2] -> 2 -> 3
```

```text
(0) -> (1) -> (2) -> (3)
```

Only valid course order:

```text
[0, 1, 2, 3]
```

> `[3, 2, 1, 0]` is not valid here because course `0` must come before course `1`.

---

## Example 2 — Impossible Course Plan

```text
N = 5
prerequisites = [[1,2], [4,3], [2,4], [4,1]]
```

Convert pairs to edges:

```text
2 -> 1
3 -> 4
4 -> 2
1 -> 4
```

Cycle:

```text
(1) -> (4) -> (2)
 ^                 |
 |_________________|
```

```text
1 needs 2
2 needs 4
4 needs 1

Impossible to finish all three.
```

```text
Course Schedule I  -> false
Course Schedule II -> []
```

---

## Main Idea: Kahn's Algorithm (BFS) 💡

Use in-degree.

```text
in-degree = number of prerequisites still required
```

A course with in-degree `0` has no remaining prerequisite.

```text
It can be taken now.
```

Process all in-degree-0 courses, remove their outgoing edges, and unlock more courses.

---

## Kahn's Algorithm

```text
1. Build graph:
   prerequisite -> course

2. Count in-degree of every course.

3. Push all courses with in-degree 0 into a queue.

4. While queue is not empty:
      a. Take a course from queue.
      b. Add it to order.
      c. Reduce in-degree of courses unlocked by it.
      d. If a course's in-degree becomes 0, push it.

5. If order contains all N courses:
      schedule is possible
   Otherwise:
      cycle exists
```

## Example 1 Trace

```text
Graph:

(0) -> (1) -> (2) -> (3)
```

Initial in-degrees:

```text
Course:    0  1  2  3
In-degree: 0  1  1  1

Queue = [0]
```

```text
Take 0:
order = [0]
1 loses prerequisite 0
in-degree[1] becomes 0 -> push 1
```

```text
Take 1:
order = [0, 1]
2 loses prerequisite 1
in-degree[2] becomes 0 -> push 2
```

```text
Take 2:
order = [0, 1, 2]
3 loses prerequisite 2
in-degree[3] becomes 0 -> push 3
```

```text
Take 3:
order = [0, 1, 2, 3]
```

```text
order size = 4 = N
Course plan is possible ✓
```

## Example 2 Trace

```text
Cycle:

(1) -> (4) -> (2)
 ^                 |
 |_________________|

(3) -> (4)

(0) is isolated
```

Initial in-degrees:

```text
Course:    0  1  2  3  4
In-degree: 0  1  1  0  2

Queue = [0, 3]
```

```text
Take 0:
order = [0]

Take 3:
4 loses one prerequisite
in-degree[4]: 2 -> 1
```

```text
Queue is empty.

Courses 1, 2, 4 are stuck in a cycle.
order size = 2 < N = 5
```

```text
Course plan is impossible.
```

## Course Schedule I vs. II

| Feature | Course Schedule I | Course Schedule II |
|---|---|---|
| Question | Can all courses be finished? | Return a valid course order |
| Return type | `bool` | `vector<int>` |
| Kahn result size = N | `true` | return order |
| Kahn result size < N | `false` | return empty vector |

Both use the same graph and the same Kahn's BFS process.

---

## C++ Code — Course Schedule I (Can Finish?)

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    bool canFinish(int courses, const vector<vector<int>>& prerequisites) {
        vector<vector<int>> adjacencyList(courses);
        vector<int> inDegree(courses, 0);

        // [course, prerequisite] means prerequisite -> course.
        for (const vector<int>& pair : prerequisites) {
            int course = pair[0];
            int prerequisite = pair[1];

            adjacencyList[prerequisite].push_back(course);
            inDegree[course]++;
        }

        queue<int> q;
        for (int course = 0; course < courses; course++) {
            if (inDegree[course] == 0) {
                q.push(course);
            }
        }

        int processedCourses = 0;

        while (!q.empty()) {
            int course = q.front();
            q.pop();
            processedCourses++;

            for (int nextCourse : adjacencyList[course]) {
                inDegree[nextCourse]--;

                if (inDegree[nextCourse] == 0) {
                    q.push(nextCourse);
                }
            }
        }

        return processedCourses == courses;
    }
};

int main() {
    Solution solution;

    // Valid chain: 0 -> 1 -> 2 -> 3
    vector<vector<int>> prerequisites1 = {
        {1, 0}, {2, 1}, {3, 2}
    };

    // Cycle: 1 -> 4 -> 2 -> 1
    vector<vector<int>> prerequisites2 = {
        {1, 2}, {4, 3}, {2, 4}, {4, 1}
    };

    cout << boolalpha;
    cout << "Can finish example 1: "
         << solution.canFinish(4, prerequisites1) << endl;

    cout << "Can finish example 2: "
         << solution.canFinish(5, prerequisites2) << endl;

    return 0;
}
```

**Output:**

```text
Can finish example 1: true
Can finish example 2: false
```

## C++ Code — Course Schedule II (Return Order)

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    vector<int> findOrder(int courses,
                          const vector<vector<int>>& prerequisites) {
        vector<vector<int>> adjacencyList(courses);
        vector<int> inDegree(courses, 0);

        // [course, prerequisite] means prerequisite -> course.
        for (const vector<int>& pair : prerequisites) {
            int course = pair[0];
            int prerequisite = pair[1];

            adjacencyList[prerequisite].push_back(course);
            inDegree[course]++;
        }

        queue<int> q;
        for (int course = 0; course < courses; course++) {
            if (inDegree[course] == 0) {
                q.push(course);
            }
        }

        vector<int> order;

        while (!q.empty()) {
            int course = q.front();
            q.pop();
            order.push_back(course);

            for (int nextCourse : adjacencyList[course]) {
                inDegree[nextCourse]--;

                if (inDegree[nextCourse] == 0) {
                    q.push(nextCourse);
                }
            }
        }

        // A cycle exists if not all courses appear in order.
        if (static_cast<int>(order.size()) != courses) {
            return {};
        }

        return order;
    }
};

void printOrder(const vector<int>& order) {
    cout << "[";
    for (int i = 0; i < order.size(); i++) {
        cout << order[i];
        if (i + 1 < order.size()) cout << ", ";
    }
    cout << "]\n";
}

int main() {
    Solution solution;

    // Valid chain: 0 -> 1 -> 2 -> 3
    vector<vector<int>> prerequisites1 = {
        {1, 0}, {2, 1}, {3, 2}
    };

    // Cycle: 1 -> 4 -> 2 -> 1
    vector<vector<int>> prerequisites2 = {
        {1, 2}, {4, 3}, {2, 4}, {4, 1}
    };

    cout << "Order for example 1: ";
    printOrder(solution.findOrder(4, prerequisites1));

    cout << "Order for example 2: ";
    printOrder(solution.findOrder(5, prerequisites2));

    return 0;
}
```

**Output:**

```text
Order for example 1: [0, 1, 2, 3]
Order for example 2: []
```

## Real-World Analogy

```text
Course plan:

CS101 -> CS201 -> CS301 -> CS401
```

```text
CS101 has no prerequisite -> take it first
CS201 requires CS101     -> take it after CS101
CS301 requires CS201     -> take it after CS201
```

Circular prerequisite:

```text
A requires B
B requires C
C requires A

Impossible
```

## Edge Cases

### No Prerequisites

```text
N = 3
prerequisites = []
```

Every course has in-degree `0`.

```text
Any order is valid, for example [0, 1, 2].
```

### One Course

```text
N = 1
prerequisites = []

Can finish = true
Order = [0]
```

### Self Dependency

```text
N = 1
prerequisites = [[0,0]]
```

```text
0 -> 0

Course 0 has in-degree 1.
No course enters queue.

Can finish = false
Order = []
```

---

## Complexity

Let `N` be number of courses and `P` be number of prerequisite pairs.

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(N + P)` | Build graph and process every course/edge once. |
| Extra space | `O(N + P)` | Adjacency list, in-degree array, queue, order. |

## Interview Questions

### 1. What does `[a, b]` mean in Course Schedule?
Course `b` must be finished before course `a`, so add edge `b -> a`.

### 2. Why use Kahn's Algorithm?
It processes courses with no remaining prerequisites and detects cycles when some courses remain stuck.

### 3. How do we know all courses can be finished?
Kahn's order contains exactly `N` courses.

### 4. What does an empty order mean in Course Schedule II?
A cycle exists, so no valid order is possible.

### 5. Can there be multiple valid course orders?
Yes. When several courses have in-degree 0, they can be taken in different orders.

### 6. What is the time complexity?
`O(N + P)`.
