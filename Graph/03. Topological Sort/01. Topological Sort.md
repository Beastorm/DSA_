# Topological Sort | DFS and Kahn's Algorithm

> A topological sort is a linear order of vertices in a **Directed Acyclic Graph (DAG)** such that every edge `u -> v` places `u` before `v`.

```text
If u -> v exists:
u must appear before v in the answer.
```

---

## Important Rule 💡

Topological sorting is possible only for a DAG.

```text
DAG -> topological order exists
Cycle -> topological order does not exist
```

Why?

```text
0 -> 1 -> 2 -> 0

0 before 1
1 before 2
2 before 0

Impossible to satisfy all three.
```

---

## Example 1

Edges:

```text
5 -> 0
5 -> 2
4 -> 0
4 -> 1
2 -> 3
3 -> 1
```

Graph:

```text
(5) -----> (0) <----- (4)
 |
 |
 v
(2) -----> (3) -----> (1)
                       ^
                       |
                      (4)
```

Valid topological orders include:

```text
[5, 4, 2, 3, 1, 0]
[4, 5, 0, 2, 3, 1]
[5, 4, 2, 3, 0, 1]
```

> A DAG can have more than one valid topological order.

---

## Example 2

```text
(1) --+
       \
(2) -----> (0)
       /
(3) --+
```

Edges:

```text
1 -> 0
2 -> 0
3 -> 0
```

Nodes `1`, `2`, and `3` must all appear before `0`.

```text
[1, 2, 3, 0]  ✓
[3, 2, 1, 0]  ✓
```

# Method 1: DFS + Stack

## Main Idea

In DFS, push a node to a stack **after** all its outgoing neighbors are processed.

```text
DFS explores dependencies first.
Then push current node.
```

Finally, pop the stack to get topological order.

---

## DFS Intuition

```text
(5) -> (2) -> (3) -> (1)
```

DFS starts from `5`:

```text
visit 5
visit 2
visit 3
visit 1

1 has no neighbor -> push 1
return to 3 -> push 3
return to 2 -> push 2
return to 5 -> push 5
```

Stack pop order:

```text
5 -> 2 -> 3 -> 1
```

Every edge goes from earlier to later in this order.

---

## DFS Algorithm

```text
1. visited[] = false
2. Create empty stack.
3. For every vertex:
      if not visited:
          DFS(vertex)
4. DFS(node):
      mark node visited
      DFS every unvisited neighbor
      push node into stack
5. Pop all stack values into answer.
```

---

## C++ Code — DFS Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
    void dfs(int node, const vector<vector<int>>& adjacencyList,
             vector<bool>& visited, stack<int>& st) {
        visited[node] = true;

        for (int neighbor : adjacencyList[node]) {
            if (!visited[neighbor]) {
                dfs(neighbor, adjacencyList, visited, st);
            }
        }

        // Push only after all outgoing neighbors are processed.
        st.push(node);
    }

public:
    vector<int> topologicalSort(int vertices,
                                const vector<vector<int>>& edges) {
        vector<vector<int>> adjacencyList(vertices);

        for (const vector<int>& edge : edges) {
            adjacencyList[edge[0]].push_back(edge[1]);
        }

        vector<bool> visited(vertices, false);
        stack<int> st;

        for (int node = 0; node < vertices; node++) {
            if (!visited[node]) {
                dfs(node, adjacencyList, visited, st);
            }
        }

        vector<int> order;
        while (!st.empty()) {
            order.push_back(st.top());
            st.pop();
        }

        return order;
    }
};

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

int main() {
    int vertices = 6;
    vector<vector<int>> edges = {
        {5, 0}, {5, 2}, {4, 0}, {4, 1}, {2, 3}, {3, 1}
    };

    Solution solution;
    cout << "Topological order (DFS): ";
    printVector(solution.topologicalSort(vertices, edges));

    return 0;
}
```

**Output:**

```text
Topological order (DFS): [5, 4, 2, 3, 1, 0]
```

> DFS topological sort assumes the graph is a DAG. To detect a directed cycle with DFS, use a recursion-path array, as shown in directed-cycle detection.

# Method 2: BFS — Kahn's Algorithm

## Main Idea

Use **in-degree**.

```text
in-degree of node = number of incoming edges
```

A node with in-degree `0` has no dependency before it.

```text
Process all in-degree 0 nodes first.
```

After processing a node, remove its outgoing edges by decreasing its neighbors' in-degrees.

---

## In-Degree Example

For the example graph:

```text
Node:      0  1  2  3  4  5
In-degree: 2  2  1  1  0  0
```

```text
Nodes 4 and 5 have in-degree 0.
They can be processed first.
```

---

## Kahn's Algorithm

```text
1. Find in-degree of every vertex.
2. Push all vertices with in-degree 0 into a queue.
3. While queue is not empty:
      a. Pop a node.
      b. Add it to topo order.
      c. Decrease in-degree of every outgoing neighbor.
      d. If a neighbor becomes 0, push it into queue.
4. Return topo order.
```

---

## Kahn's Trace

```text
Initial in-degree:
[2, 2, 1, 1, 0, 0]

Queue = [4, 5]
```

```text
Pop 4:
order = [4]

4 -> 0: indegree 2 -> 1
4 -> 1: indegree 2 -> 1

Queue = [5]
```

```text
Pop 5:
order = [4, 5]

5 -> 0: indegree 1 -> 0 -> push 0
5 -> 2: indegree 1 -> 0 -> push 2

Queue = [0, 2]
```

```text
Pop 0:
order = [4, 5, 0]

Pop 2:
2 -> 3: indegree 1 -> 0 -> push 3

Pop 3:
3 -> 1: indegree 1 -> 0 -> push 1

Final order: [4, 5, 0, 2, 3, 1]
```

This is different from DFS order but still valid.

---

## C++ Code — Kahn's Algorithm Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    vector<int> topologicalSort(int vertices,
                                const vector<vector<int>>& edges) {
        vector<vector<int>> adjacencyList(vertices);
        vector<int> inDegree(vertices, 0);

        for (const vector<int>& edge : edges) {
            int from = edge[0];
            int to = edge[1];

            adjacencyList[from].push_back(to);
            inDegree[to]++;
        }

        queue<int> q;

        // Start with nodes that have no incoming edges.
        for (int node = 0; node < vertices; node++) {
            if (inDegree[node] == 0) {
                q.push(node);
            }
        }

        vector<int> order;

        while (!q.empty()) {
            int node = q.front();
            q.pop();
            order.push_back(node);

            for (int neighbor : adjacencyList[node]) {
                inDegree[neighbor]--;

                if (inDegree[neighbor] == 0) {
                    q.push(neighbor);
                }
            }
        }

        return order;
    }
};

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

int main() {
    int vertices = 6;
    vector<vector<int>> edges = {
        {5, 0}, {5, 2}, {4, 0}, {4, 1}, {2, 3}, {3, 1}
    };

    Solution solution;
    cout << "Topological order (Kahn's): ";
    printVector(solution.topologicalSort(vertices, edges));

    return 0;
}
```

**Output:**

```text
Topological order (Kahn's): [4, 5, 0, 2, 3, 1]
```

## Kahn's Algorithm Detects Cycles

For a graph with a cycle:

```text
(0) -> (1) -> (2)
 ^                 |
 |_________________|
```

```text
In-degree = [1, 1, 1]

No vertex has in-degree 0.
Queue stays empty.
Topological order size = 0
```

```text
order.size() < V -> cycle exists
```

Code check:

```cpp
if (static_cast<int>(order.size()) != vertices) {
    // Cycle exists: graph is not a DAG.
}
```

---

## DFS vs. Kahn's Algorithm

| Feature | DFS + Stack | BFS (Kahn's) |
|---|---|---|
| Main structure | Recursion stack + stack | Queue + in-degree array |
| Main idea | Reverse DFS finish order | Process zero in-degree nodes |
| Cycle detection | Need separate path-visited check | `order.size() < V` |
| Traversal style | Depth first | Breadth first |
| Time | `O(V + E)` | `O(V + E)` |

---

## Edge Cases

### No Edges

```text
(0)      (1)      (2)
```

Every order is valid.

```text
Example output: [0, 1, 2]
```

### One Directed Chain

```text
(0) -> (1) -> (2) -> (3)
```

Only one topological order:

```text
[0, 1, 2, 3]
```

### Cycle

```text
(0) -> (1) -> (2) -> (0)
```

```text
No topological order exists.
```

---

## Complexity

| Method | Time | Extra Space |
|---|---:|---:|
| DFS + stack | `O(V + E)` | `O(V)` |
| Kahn's BFS | `O(V + E)` | `O(V)` |

Graph storage uses an adjacency list with `O(V + E)` space.

## Interview Questions

### 1. What is topological sorting?
A linear ordering where every directed edge `u -> v` places `u` before `v`.

### 2. Which graphs allow topological sort?
Directed acyclic graphs (DAGs).

### 3. Can a DAG have multiple valid topological orders?
Yes.

### 4. What is in-degree?
The number of edges entering a vertex.

### 5. What are Kahn's algorithm starting nodes?
All vertices with in-degree 0.

### 6. How does Kahn's algorithm detect a cycle?
If its output order has fewer than `V` vertices, a cycle exists.

### 7. What is the time complexity?
`O(V + E)`.
