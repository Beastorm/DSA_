# Detect Cycle in a Directed Graph | Kahn's Algorithm (BFS)

> Use Kahn's Algorithm to check whether a directed graph contains a cycle.

Kahn's Algorithm is a BFS-based topological-sort algorithm.

```text
If Kahn processes every vertex -> no cycle
If some vertices remain unprocessed -> cycle exists
```

---

## Important Note

```text
Topological sort:
- DFS method exists
- BFS method = Kahn's Algorithm

Cycle detection with Kahn's:
- If topological order has fewer than V nodes -> cycle
```

## Main Idea: In-Degree 💡

```text
In-degree = number of edges coming into a node
```

A vertex with in-degree `0` has no dependency before it.

```text
It can be processed immediately.
```

Kahn's Algorithm repeatedly:

```text
1. Takes a node with in-degree 0.
2. Removes its outgoing edges.
3. Reduces in-degree of its neighbors.
4. Adds new in-degree-0 nodes to queue.
```

---

## Why Cycles Get Stuck

Cycle:

```text
(2) -> (3) -> (4)
 ^                 |
 |_________________|
```

In-degrees inside the cycle:

```text
2 needs 4 to be processed first
3 needs 2 to be processed first
4 needs 3 to be processed first
```

```text
No cycle node can reach in-degree 0.
No cycle node enters the queue.
```

---

## Algorithm

```text
1. Calculate in-degree for all vertices.
2. Push every vertex with in-degree 0 into a queue.
3. processedCount = 0
4. While queue is not empty:
      a. Pop a node.
      b. processedCount++
      c. For every outgoing neighbor:
           decrease its in-degree
           if in-degree becomes 0:
               push it into queue
5. Return processedCount != V.
```


```text
Pop 0
Processed = 1

0 -> 1
in-degree[1]: 1 -> 0
push 1

Queue = [1]
```

### Process Node 1

```text
Pop 1
Processed = 2

1 -> 2
in-degree[2]: 2 -> 1

Queue = []
```

Nodes `2`, `3`, and `4` still have positive in-degree.

```text
Queue is empty
Processed = 2
V = 5

2 < 5 -> cycle exists
```

```text
          (0)

        v     v
```

### Initial In-Degrees

```text

In-degree: 0  1  1  2

```

### BFS Processing

```text
Pop 0:
0 -> 1: indegree 1 -> 0 -> push 1
0 -> 2: indegree 1 -> 0 -> push 2

Queue = [1, 2]
```

```text
Pop 1:
1 -> 3: indegree 2 -> 1

Pop 2:
2 -> 3: indegree 1 -> 0 -> push 3

Pop 3:
no outgoing edges
```

```text
Processed = 4 = V
No cycle
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    bool hasCycle(int vertices, const vector<vector<int>>& edges) {
        vector<vector<int>> adjacencyList(vertices);
        vector<int> inDegree(vertices, 0);

        // Build directed graph and count incoming edges.
        for (const vector<int>& edge : edges) {
            int from = edge[0];
            int to = edge[1];

            adjacencyList[from].push_back(to);
            inDegree[to]++;
        }

        queue<int> q;

        // Nodes with no incoming edges start BFS.
        for (int node = 0; node < vertices; node++) {
            if (inDegree[node] == 0) {
                q.push(node);
            }
        }

        int processedCount = 0;

        while (!q.empty()) {
            int node = q.front();
            q.pop();
            processedCount++;

            for (int neighbor : adjacencyList[node]) {
                inDegree[neighbor]--;

                if (inDegree[neighbor] == 0) {
                    q.push(neighbor);
                }
            }
        }

        // Unprocessed nodes are part of or depend on a cycle.
        return processedCount != vertices;
    }
};

int main() {
    Solution solution;

    // Cycle: 0 -> 1 -> 2 -> 3 -> 4 -> 2
    vector<vector<int>> cycleEdges = {
        {0, 1}, {1, 2}, {2, 3}, {3, 4}, {4, 2}
    };
    cout << boolalpha << "Cycle graph: "
         << solution.hasCycle(5, cycleEdges) << endl;

    // DAG: 0 -> 1, 0 -> 2, 1 -> 3, 2 -> 3
    vector<vector<int>> noCycleEdges = {
        {0, 1}, {0, 2}, {1, 3}, {2, 3}
    };
    cout << "DAG:         "
         << solution.hasCycle(4, noCycleEdges) << endl;

    return 0;
}
```

**Output:**

```text
Cycle graph: true
DAG:         false
```

## Kahn's Algorithm and Topological Sort

The same BFS creates a topological order for a DAG.

```text
Instead of only processedCount:
store every popped node in a vector named topo.
```

```text
If topo.size() == V:
    topo is a valid topological sort

If topo.size() < V:
    a cycle exists
```

---

## Kahn's vs DFS Cycle Detection

| Kahn's Algorithm | DFS Method |
|---|---|
| Uses queue + in-degree | Uses recursion + current-path tracking |
| Cycle if processed count < V | Cycle if neighbor is on current path |
| Iterative | Usually recursive |
| Produces topo order for DAG | Can produce topo order with stack |

Both take:

```text
O(V + E) time
```

## Edge Cases

### No Edges

```text
(0)      (1)      (2)
```

All nodes have in-degree 0.

```text
All nodes enter queue.
Processed = V.
No cycle.
```

### Self Loop

```text
(0) -> (0)
```

```text
in-degree[0] = 1
Queue is empty.
Processed = 0 < 1.

Cycle found.
```

### One Directed Chain

```text
(0) -> (1) -> (2) -> (3)
```

```text
Each node eventually reaches in-degree 0.
No cycle.
```

### Disconnected Graph

```text
(0) -> (1)      (2) -> (3) -> (2)
```

The cycle component leaves nodes `2` and `3` unprocessed.

```text
Processed < V -> cycle found.
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(V + E)` | Compute in-degrees and process each vertex/edge once. |
| Extra space | `O(V)` | In-degree array and queue. |
| Graph storage | `O(V + E)` | Directed adjacency list. |

## Interview Questions

### 1. What is Kahn's Algorithm?
A BFS-based topological sorting algorithm that uses in-degrees.

### 2. Which nodes are inserted into Kahn's queue first?
All nodes with in-degree `0`.

### 3. How does Kahn's Algorithm detect a cycle?
If it processes fewer than `V` nodes, the graph has a cycle.

### 4. Why do cycle nodes get stuck?
Each cycle node always has an incoming edge from another cycle node.

### 5. Can Kahn's Algorithm be used for undirected graphs?
No. It is for directed graphs and topological ordering.

### 6. What is the time complexity?
`O(V + E)`.

### 7. What is the extra-space complexity?
`O(V)`.
