# Find Eventual Safe States | BFS (Topological Sort)

> Return all nodes in a directed graph from which every possible path eventually reaches a terminal node.

```text
Terminal node = node with no outgoing edges
```

A safe node:

```text
is not inside a cycle
and cannot reach a cycle
```

---

## Example 1

```text
0 -> 1, 2
1 -> 2, 3
2 -> 5
3 -> 0        <- cycle: 0 -> 1 -> 3 -> 0
4 -> 5
5 -> 6
6 -> []       <- terminal
```

```text
Unsafe nodes: 0, 1, 3
Safe nodes:   2, 4, 5, 6

Answer = [2, 4, 5, 6]
```

---

## Example 2

```text
0 -> 1, 2
1 -> 2
2 -> 0        <- cycle
3 -> []       <- terminal
```

```text
Nodes 0, 1, 2 can reach the cycle.
Node 3 is terminal.

Answer = [3]
```

---

## Main Idea: Work Backward from Terminal Nodes 💡

Terminal nodes are safe because they have no outgoing edges.

```text
(5) -> (6)

6 is terminal -> safe
5 leads only to safe 6 -> safe
```

So we want to move **backward**:

```text
If node A points to safe node B,
and B was A's last remaining outgoing path,
then A becomes safe too.
```

---

## Why Reverse the Graph?

Original edge:

```text
u -> v
```

Reversed edge:

```text
v -> u
```

```text
Original graph:          Reversed graph:

(4) -> (5) -> (6)       (4) <- (5) <- (6)

Terminal node 6          Node 6 has no incoming edge
has no outgoing edge     in reversed graph
```

Terminal nodes become starting points for Kahn's Algorithm on the reversed graph.

---

## Degree Used in This Algorithm

In the original graph:

```text
outDegree[node] = number of outgoing edges
```

A terminal node has:

```text
outDegree = 0
```

We start BFS from all nodes with original out-degree `0`.

```text
These are the terminal nodes.
```

---

## Algorithm

```text
1. Build reversed graph.
2. Count out-degree of every original node.
3. Push all nodes with out-degree 0 into queue.
   These are terminal and safe.
4. While queue is not empty:
      a. Pop safe node.
      b. Add it to answer.
      c. For every predecessor in reversed graph:
           outDegree[predecessor]--
           if it becomes 0:
               predecessor is safe -> push it
5. Sort answer and return it.
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    vector<int> eventualSafeNodes(int vertices,
                                  const vector<vector<int>>& edges) {
        vector<vector<int>> reverseGraph(vertices);
        vector<int> outDegree(vertices, 0);

        // Original edge: from -> to
        // Reversed edge: to -> from
        for (const vector<int>& edge : edges) {
            int from = edge[0];
            int to = edge[1];

            reverseGraph[to].push_back(from);
            outDegree[from]++;
        }

        queue<int> q;

        // Terminal nodes have out-degree 0.
        for (int node = 0; node < vertices; node++) {
            if (outDegree[node] == 0) {
                q.push(node);
            }
        }

        vector<int> safeNodes;

        while (!q.empty()) {
            int safeNode = q.front();
            q.pop();
            safeNodes.push_back(safeNode);

            // These nodes point to safeNode in original graph.
            for (int predecessor : reverseGraph[safeNode]) {
                outDegree[predecessor]--;

                if (outDegree[predecessor] == 0) {
                    q.push(predecessor);
                }
            }
        }

        sort(safeNodes.begin(), safeNodes.end());
        return safeNodes;
    }
};

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

int main() {
    // 0->1, 0->2, 1->2, 1->3, 2->5, 3->0, 4->5, 5->6
    vector<vector<int>> edges = {
        {0, 1}, {0, 2}, {1, 2}, {1, 3},
        {2, 5}, {3, 0}, {4, 5}, {5, 6}
    };

    Solution solution;
    cout << "Eventual safe nodes: ";
    printVector(solution.eventualSafeNodes(7, edges));

    return 0;
}
```

**Output:**

```text
Eventual safe nodes: [2, 4, 5, 6]
```

## Why Cycle Nodes Never Become Safe

```text
(0) -> (1) -> (3)
 ^                 |
 |_________________|
```

Every node in this cycle always has at least one outgoing edge to another cycle node.

```text
outDegree never becomes 0
```

So no cycle node enters the queue.

---

## BFS Topological Method vs DFS Method

| DFS Method | BFS / Kahn's Method |
|---|---|
| Uses `vis`, `pathVis`, `check` | Uses reversed graph + out-degree |
| Finds cycles through current DFS path | Starts from terminal nodes |
| Recursive | Iterative queue |
| Safe nodes marked after DFS succeeds | Nodes processed by BFS are safe |
| `O(V + E)` | `O(V + E)` before sorting |

---

## Edge Cases

### No Edges

```text
(0)      (1)      (2)
```

Every node is terminal.

```text
Safe nodes = [0, 1, 2]
```

### All Nodes in a Cycle

```text
(0) -> (1) -> (2)
 ^                 |
 |_________________|
```

No terminal node exists.

```text
Queue starts empty.
Safe nodes = []
```

### One Chain

```text
(0) -> (1) -> (2)
```

```text
2 is terminal -> safe
1 leads to safe 2 -> safe
0 leads to safe 1 -> safe

Safe nodes = [0, 1, 2]
```

## Complexity

Let `V` be vertices and `E` be directed edges.

| Resource | Complexity | Reason |
|---|---:|---|
| Build reverse graph | `O(V + E)` | Store each reversed edge. |
| Kahn BFS | `O(V + E)` | Process each node and edge once. |
| Sort safe nodes | `O(S log S)` | S = number of safe nodes. |
| Total time | `O(V + E + S log S)` | Sorting is needed for ascending output. |
| Extra space | `O(V + E)` | Reverse graph, out-degree, queue, answer. |

## Interview Questions

### 1. What is an eventual safe node?
A node where every possible path ends at a terminal node or another safe node.

### 2. Why reverse the graph?
It lets us move backward from terminal nodes to nodes that lead only to safe nodes.

### 3. Which nodes start Kahn's BFS?
Nodes with out-degree `0` in the original graph (terminal nodes).

### 4. Why are cycle nodes not processed?
Their outgoing degree never becomes `0` because they depend on each other inside the cycle.

### 5. Why sort the answer?
The problem asks for safe nodes in ascending order. Queue order is not guaranteed to be sorted.

### 6. What is the time complexity before sorting?
`O(V + E)`.

### 7. Can DFS solve this problem too?
Yes. DFS uses current-path tracking to detect cycles and mark safe nodes.
