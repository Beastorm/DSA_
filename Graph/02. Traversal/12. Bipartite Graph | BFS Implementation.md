# Bipartite Graph | BFS Implementation

> A graph is bipartite if we can color every vertex with two colors so that no adjacent vertices have the same color.

```text
color 0 and color 1
```

---

## Example 1 — Bipartite Graph

```text
       (0) ------ (1)
        |          |
        |          |
       (3) ------ (2)
```

A valid coloring:

```text
0 -> color 0
1 -> color 1
2 -> color 0
3 -> color 1
```

```text
Color 0 group: {0, 2}
Color 1 group: {1, 3}

Every edge connects different colors.
Answer = true
```

---

## Example 2 — Not Bipartite

```text
       (0)
      /   \
     /     \
   (1) -- (2)
```

Try coloring:

```text
0 -> color 0
1 -> color 1
2 -> color 1
```

But nodes `1` and `2` are adjacent and have the same color.

```text
Conflict -> not bipartite
Answer = false
```

---

## Important Property 💡

```text
Bipartite graph <=> no odd-length cycle
```

```text
Even cycle:                    Odd cycle:

(0) -- (1)                    (0) -- (1)
 |      |                      \      /
 |      |                       \    /
(3) -- (2)                     (2)

4 edges -> bipartite           3 edges -> not bipartite
```

## BFS Coloring Idea

BFS visits nodes level by level.

```text
Level 0 -> color 0
Level 1 -> color 1
Level 2 -> color 0
Level 3 -> color 1
```

For every edge:

```text
current node color = 0 -> uncolored neighbor gets 1
current node color = 1 -> uncolored neighbor gets 0
```

```text
oppositeColor = 1 - currentColor
```

---

## BFS Algorithm

```text
color[] = -1 for every vertex

For every vertex:
    if vertex is uncolored:
        color vertex with 0
        push vertex into queue

        while queue is not empty:
            pop node

            for every neighbor:
                if neighbor is uncolored:
                    color neighbor with 1 - color[node]
                    push neighbor

                else if neighbor color == color[node]:
                    return false

return true
```

---

## Why Check Every Vertex?

The graph may be disconnected.

```text
(0) -- (1)       (2) -- (3)
                    \    /
                     (4)
```

```text
Component 1 -> bipartite
Component 2 -> triangle -> not bipartite

Whole graph -> not bipartite
```

## BFS Trace — Square Graph

```text
       (0) ------ (1)
        |          |
        |          |
       (3) ------ (2)
```

### Start

```text
color = [-1, -1, -1, -1]

Start at 0:
color[0] = 0
queue = [0]
```

### Process Node 0

```text
Pop 0
Neighbors: 1, 3

color[1] = 1
color[3] = 1
queue = [1, 3]

color = [0, 1, -1, 1]
```

### Process Node 1

```text
Pop 1
neighbor 0 has color 0 -> okay
neighbor 2 is uncolored

color[2] = 0
queue = [3, 2]

color = [0, 1, 0, 1]
```

### Process Nodes 3 and 2

```text
Pop 3:
neighbor 0 has color 0 -> okay
neighbor 2 has color 0 -> okay

Pop 2:
neighbor 1 has color 1 -> okay
neighbor 3 has color 1 -> okay
```

```text
Queue becomes empty.
No conflict found.
Answer = true
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
    bool bfsCheck(int start, const vector<vector<int>>& adjacencyList,
                  vector<int>& color) {
        queue<int> q;
        q.push(start);
        color[start] = 0;

        while (!q.empty()) {
            int node = q.front();
            q.pop();

            for (int neighbor : adjacencyList[node]) {
                if (color[neighbor] == -1) {
                    // Assign opposite color and add to BFS queue.
                    color[neighbor] = 1 - color[node];
                    q.push(neighbor);
                } else if (color[neighbor] == color[node]) {
                    // Adjacent vertices with same color -> conflict.
                    return false;
                }
            }
        }

        return true;
    }

public:
    bool isBipartite(int vertices, const vector<vector<int>>& edges) {
        vector<vector<int>> adjacencyList(vertices);

        for (const vector<int>& edge : edges) {
            int u = edge[0];
            int v = edge[1];

            adjacencyList[u].push_back(v);
            adjacencyList[v].push_back(u);
        }

        vector<int> color(vertices, -1);

        // Check every disconnected component.
        for (int node = 0; node < vertices; node++) {
            if (color[node] == -1 && !bfsCheck(node, adjacencyList, color)) {
                return false;
            }
        }

        return true;
    }
};

int main() {
    Solution solution;

    // Square graph: bipartite.
    vector<vector<int>> squareEdges = {
        {0, 1}, {1, 2}, {2, 3}, {3, 0}
    };
    cout << boolalpha << "Square graph: "
         << solution.isBipartite(4, squareEdges) << endl;

    // Triangle graph: not bipartite.
    vector<vector<int>> triangleEdges = {
        {0, 1}, {1, 2}, {2, 0}
    };
    cout << "Triangle graph: "
         << solution.isBipartite(3, triangleEdges) << endl;

    // Disconnected graph; second component contains a triangle.
    vector<vector<int>> disconnectedEdges = {
        {0, 1}, {1, 2}, {3, 4}, {4, 5}, {5, 3}
    };
    cout << "Disconnected graph: "
         << solution.isBipartite(6, disconnectedEdges) << endl;

    return 0;
}
```

**Output:**

```text
Square graph: true
Triangle graph: false
Disconnected graph: false
```

## BFS vs DFS for Bipartite Check

| Feature | BFS | DFS |
|---|---|---|
| Main structure | Queue | Recursion / stack |
| Color assignment | When pushing neighbor | During DFS call |
| Conflict check | Same-color adjacent nodes | Same-color adjacent nodes |
| Time | `O(V + E)` | `O(V + E)` |
| Deep-graph risk | No recursion overflow | Recursion can overflow |

Both methods use exactly the same two-color rule.

## Edge Cases

### No Edges

```text
(0)      (1)      (2)

Every isolated node can have color 0.
Graph is bipartite.
```

### One Edge

```text
(0) -- (1)

0 -> color 0
1 -> color 1

Bipartite
```

### Self Loop

```text
(0) -- (0)
```

```text
Node 0 is adjacent to itself.
It would need a color different from itself.

Not bipartite.
```

### Even Cycle

```text
(0) -- (1)
 |      |
(3) -- (2)
```

```text
Bipartite
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(V + E)` | Every vertex is colored and every edge is checked. |
| Extra space | `O(V)` | Color array and BFS queue. |
| Graph storage | `O(V + E)` | Adjacency list. |

## Interview Questions

### 1. What is a bipartite graph?
A graph that can be colored using two colors so adjacent vertices have different colors.

### 2. What condition makes a graph not bipartite?
An edge connects two vertices with the same color.

### 3. What is the relation with odd cycles?
A graph is bipartite if and only if it has no odd-length cycle.

### 4. Why use color `-1` initially?
It means the vertex is still uncolored.

### 5. Why use `1 - color[node]`?
It switches between color `0` and color `1`.

### 6. Why check every component?
The graph may be disconnected, and any component can contain an odd cycle.

### 7. What is BFS time complexity?
`O(V + E)`.
