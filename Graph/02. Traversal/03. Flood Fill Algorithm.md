# Flood Fill Algorithm

> Starting from one pixel, change every 4-directionally connected pixel that has the same original color.

Flood fill is simply DFS or BFS on a 2D grid.

---

## What Does “4-Directionally Connected” Mean? 💡

From cell `(row, col)`, we can move only:

```text
Up:    (row - 1, col)
Right: (row, col + 1)
Down:  (row + 1, col)
Left:  (row, col - 1)
```

```text
          Up
           |
Left -- current -- Right
           |
          Down
```

Diagonal movement is **not** allowed.

---

## Example 1

```text
Image:

        c0  c1  c2
      +---+---+---+
r0    | 1 | 1 | 1 |
      +---+---+---+
r1    | 1 | 1 | 0 |
      +---+---+---+
r2    | 1 | 0 | 1 |
      +---+---+---+

Start pixel = (1,1)
Original color = 1
New color = 2
```

All connected `1` cells become `2`.

```text
Before:                 After:

1  1  1                 2  2  2
1  1  0                 2  2  0
1  0  1                 2  0  1
```

The `1` at `(2,2)` does not change because it is separated by `0` values.

```text
Diagonal connection does not count.
```

---

## Example 2

```text
Before:

0  0  0
0  0  0

Start = (0,0), new color = 2
```

Every `0` is connected, so all become `2`.

```text
After:

2  2  2
2  2  2
```

---

## Main Idea

```text
Flood fill = graph traversal on a grid

Cell        = graph node
Up/Down/Left/Right = graph edges
Same color  = allowed node to visit
```

For every cell we visit:

```text
1. Change its color.
2. Check its 4 neighbors.
3. Visit a neighbor only if:
      - it is inside the grid
      - it still has the original color
```

---

## Direction Arrays

```cpp
int rowChange[] = {-1, 0, 1, 0};
int colChange[] = {0, 1, 0, -1};
```

These represent:

```text
index 0 -> up
index 1 -> right
index 2 -> down
index 3 -> left
```

```text
Current = (r, c)

Next row = r + rowChange[i]
Next col = c + colChange[i]
```

# Approach 1: Recursive DFS

## DFS Rule

```text
dfs(row, col):

if cell is outside grid:
    stop

if cell color is not originalColor:
    stop

change cell to newColor

run DFS in 4 directions
```

Changing the color immediately also marks the cell as visited.

```text
Old color -> new color
```

So the same cell is never visited again.

---

## DFS Trace for Example 1

```text
Start DFS at (1,1):

1  1  1                 1  2  1
1 [1] 0      ->         1  2  0
1  0  1                 1  0  1
```

From `(1,1)`:

```text
Up    -> (0,1) is 1 -> visit
Right -> (1,2) is 0 -> skip
Down  -> (2,1) is 0 -> skip
Left  -> (1,0) is 1 -> visit
```

DFS continues through all connected `1` cells:

```text
(1,1)
  -> (0,1)
      -> (0,2)
      -> (0,0)
          -> (1,0)
              -> (2,0)
```

Final image:

```text
2  2  2
2  2  0
2  0  1
```

## C++ Code — Recursive DFS Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
    void dfs(vector<vector<int>>& image, int row, int col,
             int originalColor, int newColor) {
        int rows = image.size();
        int cols = image[0].size();

        // Stop if outside the image or not the original color.
        if (row < 0 || row >= rows || col < 0 || col >= cols ||
            image[row][col] != originalColor) {
            return;
        }

        // Recolor current cell. This also marks it as visited.
        image[row][col] = newColor;

        int rowChange[] = {-1, 0, 1, 0};
        int colChange[] = {0, 1, 0, -1};

        for (int direction = 0; direction < 4; direction++) {
            dfs(image,
                row + rowChange[direction],
                col + colChange[direction],
                originalColor,
                newColor);
        }
    }

public:
    vector<vector<int>> floodFill(vector<vector<int>> image,
                                  int startRow, int startCol, int newColor) {
        int originalColor = image[startRow][startCol];

        // Without this check, recoloring 1 to 1 would not mark cells visited.
        if (originalColor == newColor) return image;

        dfs(image, startRow, startCol, originalColor, newColor);
        return image;
    }
};

void printImage(const vector<vector<int>>& image) {
    for (const vector<int>& row : image) {
        for (int color : row) {
            cout << color << " ";
        }
        cout << endl;
    }
}

int main() {
    vector<vector<int>> image = {
        {1, 1, 1},
        {1, 1, 0},
        {1, 0, 1}
    };

    Solution solution;

    cout << "Before:\n";
    printImage(image);

    vector<vector<int>> result = solution.floodFill(image, 1, 1, 2);

    cout << "After:\n";
    printImage(result);

    return 0;
}
```

**Output:**

```text
Before:
1 1 1
1 1 0
1 0 1
After:
2 2 2
2 2 0
2 0 1
```

# Approach 2: Iterative BFS

BFS uses a queue instead of recursion.

```text
1. Push starting cell into queue.
2. Recolor it immediately.
3. Pop a cell and check its 4 neighbors.
4. Recolor and push every valid neighbor.
```

This is useful for large grids because it avoids recursion stack overflow.

---

## C++ Code — BFS Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    vector<vector<int>> floodFill(vector<vector<int>> image,
                                  int startRow, int startCol, int newColor) {
        int rows = image.size();
        int cols = image[0].size();
        int originalColor = image[startRow][startCol];

        if (originalColor == newColor) return image;

        queue<pair<int, int>> q;
        q.push({startRow, startCol});
        image[startRow][startCol] = newColor;

        int rowChange[] = {-1, 0, 1, 0};
        int colChange[] = {0, 1, 0, -1};

        while (!q.empty()) {
            auto [row, col] = q.front();
            q.pop();

            for (int direction = 0; direction < 4; direction++) {
                int nextRow = row + rowChange[direction];
                int nextCol = col + colChange[direction];

                if (nextRow >= 0 && nextRow < rows &&
                    nextCol >= 0 && nextCol < cols &&
                    image[nextRow][nextCol] == originalColor) {

                    // Recolor before pushing, so it is not added twice.
                    image[nextRow][nextCol] = newColor;
                    q.push({nextRow, nextCol});
                }
            }
        }

        return image;
    }
};

void printImage(const vector<vector<int>>& image) {
    for (const vector<int>& row : image) {
        for (int color : row) {
            cout << color << " ";
        }
        cout << endl;
    }
}

int main() {
    vector<vector<int>> image = {
        {0, 0, 0},
        {0, 0, 0}
    };

    Solution solution;
    vector<vector<int>> result = solution.floodFill(image, 0, 0, 2);

    cout << "Flood-filled image:\n";
    printImage(result);

    return 0;
}
```

**Output:**

```text
Flood-filled image:
2 2 2
2 2 2
```

## DFS vs BFS

| Feature | DFS | BFS |
|---|---|---|
| Main structure | Recursion / stack | Queue |
| Result | Same filled region | Same filled region |
| Time | `O(R * C)` | `O(R * C)` |
| Extra space | `O(R * C)` worst case | `O(R * C)` worst case |
| Good for | Simple code | Avoiding deep recursion |

`R` = rows, `C` = columns.

---

## Important Special Case: Same Color

```text
Image:
1  1

Start = (0,0)
newColor = 1
```

```text
originalColor == newColor
```

Return immediately.

```text
No work is needed.
```

This check is important for in-place DFS, because changing `1` to `1` does not mark a cell as visited.

---

## Edge Cases

### Single Pixel

```text
Image = [[5]]
Start = (0,0)
newColor = 3

Result = [[3]]
```

### Surrounded by Different Colors

```text
0  1  0
1  2  1
0  1  0

Start = center value 2
newColor = 3
```

```text
Only the center changes:

0  1  0
1  3  1
0  1  0
```

### Diagonal Same Color

```text
1  0
0  1

Start at top-left 1.
Bottom-right 1 is diagonal only.
It does not change.
```

---

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(R * C)` | Each cell is visited at most once. |
| DFS extra space | `O(R * C)` worst case | Recursion can contain many cells. |
| BFS extra space | `O(R * C)` worst case | Queue can contain many cells. |

> This version modifies a copy of the image passed by value. It does not create a separate `ans` grid inside the algorithm.

## Interview Questions

### 1. Which graph algorithm is flood fill?
DFS or BFS on a 2D grid.

### 2. Which directions are used?
Up, right, down, and left — 4 directions only.

### 3. Why save the original color?
Only cells with that color should be filled.

### 4. Why recolor a cell before exploring/pushing neighbors?
It marks the cell visited and prevents duplicate visits.

### 5. Why return early when original color equals new color?
Recoloring does not mark progress, so an in-place DFS could keep revisiting cells.

### 6. What is the time complexity?
`O(R * C)`.

### 7. What is the worst-case space complexity?
`O(R * C)`.
