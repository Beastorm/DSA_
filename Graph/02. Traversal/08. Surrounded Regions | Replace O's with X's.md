# Surrounded Regions | Replace O with X

> Replace every `O` that is completely surrounded by `X` with `X`.

An `O` connected to the boundary must stay `O` because it can escape outside the board.

---

## Main Idea: Find Safe O's First 💡

Trying to directly find surrounded `O` cells is difficult.

Instead:

```text
1. Start DFS/BFS from every boundary O.
2. Mark all boundary-connected O's as SAFE.
3. Change every unmarked O to X.
```

```text
Safe O       = connected to a boundary O
Surrounded O = not connected to any boundary O
```

---

Boundary O's:

```text
(4,2) and (4,3)

Safe region:          Surrounded region:

X X X X               X X X X
X X X X               X O X X
X X X X               X O O X

X X O O               X X X X
```

Final output:

```text
X X X X
X X X X
X X X X
X X X X

```

## Why Are Boundary O's Safe?

```text
Board boundary = top row + bottom row + left column + right column
```

An `O` on the boundary has one side open to the outside.

```text
O X X
X X X
X X X
^
boundary O -> cannot be surrounded
```

Any `O` connected to a boundary `O` is safe too.

```text
O O O X
X X O X
X X O X

All connected O's can reach the boundary.
All are safe.
```

## Four Directions

```text
          up
           |
left -- current -- right
           |
         down
```

Only up, right, down, and left are allowed. Diagonal `O` cells are not connected.

---

## Algorithm

```text
1. Create visited matrix filled with false.

2. Scan the boundary:
      - top row
      - bottom row
      - left column
      - right column

3. For every boundary O not visited:
      run DFS
      mark all connected O's visited (safe)

4. Scan whole board:
      O and not visited -> change to X
      O and visited     -> keep O

5. Return board.
```

---

## Boundary DFS Trace for Example 1

```text
Boundary scan:

Top row:    X X X X -> no DFS
Bottom row: X X O O -> start DFS at (4,2)
Left col:   all X
Right col:  all X
```

```text
DFS from (4,2):

(4,2) = O -> mark safe
right neighbor (4,3) = O -> mark safe
all other neighbors are X or outside board
```

Visited / safe cells:

```text
X X X X
X . X X
X . . X
X . X X
X X S S

S = safe O connected to boundary
. = not visited
```

Final scan:

```text
(1,1), (2,1), (2,2), (3,1)
are O but not safe -> change to X

(4,2), (4,3)
are safe -> keep O
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
    void dfs(int row, int col, const vector<vector<char>>& board,
             vector<vector<bool>>& visited) {
        int rows = board.size();
        int cols = board[0].size();

        visited[row][col] = true;

        int rowChange[] = {-1, 0, 1, 0};
        int colChange[] = {0, 1, 0, -1};

        for (int direction = 0; direction < 4; direction++) {
            int nextRow = row + rowChange[direction];
            int nextCol = col + colChange[direction];

            if (nextRow >= 0 && nextRow < rows &&
                nextCol >= 0 && nextCol < cols &&
                board[nextRow][nextCol] == 'O' &&
                !visited[nextRow][nextCol]) {

                dfs(nextRow, nextCol, board, visited);
            }
        }
    }

public:
    vector<vector<char>> replaceSurroundedRegions(vector<vector<char>> board) {
        if (board.empty() || board[0].empty()) return board;

        int rows = board.size();
        int cols = board[0].size();
        vector<vector<bool>> visited(rows, vector<bool>(cols, false));

        // Check top and bottom boundary rows.
        for (int col = 0; col < cols; col++) {
            if (board[0][col] == 'O' && !visited[0][col]) {
                dfs(0, col, board, visited);
            }

            if (board[rows - 1][col] == 'O' && !visited[rows - 1][col]) {
                dfs(rows - 1, col, board, visited);
            }
        }

        // Check left and right boundary columns.
        for (int row = 0; row < rows; row++) {
            if (board[row][0] == 'O' && !visited[row][0]) {
                dfs(row, 0, board, visited);
            }

            if (board[row][cols - 1] == 'O' && !visited[row][cols - 1]) {
                dfs(row, cols - 1, board, visited);
            }
        }

        // Flip every O that is not boundary-connected.
        for (int row = 0; row < rows; row++) {
            for (int col = 0; col < cols; col++) {
                if (board[row][col] == 'O' && !visited[row][col]) {
                    board[row][col] = 'X';
                }
            }
        }

        return board;
    }
};

void printBoard(const vector<vector<char>>& board) {
    for (const vector<char>& row : board) {
        for (char cell : row) {
            cout << cell << " ";
        }
        cout << endl;
    }
}

int main() {
    vector<vector<char>> board = {
        {'X', 'X', 'X', 'X'},
        {'X', 'O', 'X', 'X'},
        {'X', 'O', 'O', 'X'},
        {'X', 'O', 'X', 'X'},
        {'X', 'X', 'O', 'O'}
    };

    cout << "Before:\n";
    printBoard(board);

    Solution solution;
    vector<vector<char>> result = solution.replaceSurroundedRegions(board);

    cout << "After:\n";
    printBoard(result);

    return 0;
}
```

**Output:**

```text
Before:
X X X X
X O X X
X O O X
X O X X
X X O O

After:
X X X X
X X X X
X X X X
X X X X
X X O O
```

## Why Mark Safe O's Instead of Finding Surrounded O's?

```text
Boundary-connected O's are easy to identify:
start from boundary and traverse connected O's.

Surrounded O's are everything left over.
```

```text
Mark safe first.
Flip all unmarked O's.
```

This is simpler than checking every `O` to see if it can reach the boundary.

---

## Edge Cases

### No O's

```text
X X
X X

Nothing changes.
```

### All O's

```text
O O O
O O O
O O O
```

Every `O` can reach the boundary, so all remain `O`.

### Single Cell

```text
Board = [[O]]
```

The cell is on the boundary, so it remains `O`.

### Diagonal O's

```text
O X
X O
```

The bottom-right `O` is not connected diagonally to top-left `O`, but both are boundary cells anyway, so both remain `O`.

---

## Complexity

Let board size be `R x C`.

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(R * C)` | DFS and final scan visit cells at most once. |
| Extra space | `O(R * C)` | Visited matrix and recursion stack. |

## Interview Questions

### 1. Why start DFS only from boundary O's?
Boundary O's and all O's connected to them cannot be surrounded.

### 2. Why are unvisited O's changed to X?
They cannot reach any boundary, so they are surrounded by X cells.

### 3. Why do we use 4 directions only?
The problem considers only up, right, down, and left as connected.

### 4. Can BFS be used instead of DFS?
Yes. Use a queue to mark all boundary-connected O's as safe.

### 5. What is the time complexity?
`O(R * C)`.

### 6. What is the space complexity?
`O(R * C)`.
