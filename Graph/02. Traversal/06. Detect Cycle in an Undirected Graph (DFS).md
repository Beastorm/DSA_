# Detect Cycle in an Undirected Graph (DFS)

> Return `true` if an undirected graph contains a cycle; otherwise return `false`.

A cycle is a path that starts and ends at the same vertex.

```text
0 -> 1 -> 2 -> 0
```

---

## Example 1 — No Cycle

```text
(0) -- (1) -- (2) -- (3)
```

```text
This is a simple path.
No cycle exists.

Answer = false
```

---

## Example 2 — Cycle Exists

```text
       (0)
      /   \
     /     \
   (1) -- (2)
```

```text
Cycle: 0 -> 1 -> 2 -> 0

Answer = true
```

---

## Main Idea 💡

While doing DFS, remember the parent of the current node.

```text
DFS(node, parent)
```

For every neighbor:

```text
Neighbor is not visited
-> DFS(neighbor, current node)

Neighbor is visited AND neighbor == parent
-> skip

Neighbor is visited AND neighbor != parent
-> cycle found
```

---

## Why Do We Need Parent?

An undirected edge appears in both adjacency lists.

```text
(0) -- (1)

adj[0] = [1]
adj[1] = [0]
```

DFS starts at `0`:

```text
DFS(0, -1)
  -> DFS(1, 0)
```

At node `1`, neighbor `0` is already visited.

```text
But 0 is the parent of 1.
It is the same edge used to reach node 1.
It is NOT a cycle.
```

```text
visited neighbor == parent -> skip
```

## No-Cycle DFS Trace

```text
(0) -- (1) -- (2) -- (3)
```

```text
DFS(0, -1)
 |
 +-- visit 0
 |
 +-- DFS(1, 0)
 |    |
 |    +-- neighbor 0 is parent -> skip
 |    |
 |    +-- DFS(2, 1)
 |         |
 |         +-- neighbor 1 is parent -> skip
 |         |
 |         +-- DFS(3, 2)
 |              |
 |              +-- neighbor 2 is parent -> skip
 |              +-- return false
 |
 +-- return false
```

```text
No visited non-parent neighbor was found.
Answer = false
```

---

## Cycle DFS Trace

```text
       (0)
      /   \
     /     \
   (1) -- (2)
```

```text
DFS(0, -1)
 |
 +-- DFS(1, 0)
      |
      +-- neighbor 0 is parent -> skip
      |
      +-- DFS(2, 1)
           |
           +-- neighbor 0 is visited
           +-- 0 is NOT parent 1
           +-- cycle found! ✓
```

---

## Algorithm

```text
isCycle(graph):

1. visited[] = false

2. For every vertex:
      if vertex is not visited:
          if DFS(vertex, parent = -1) returns true:
              return true

3. Return false
```

```text
DFS(node, parent):

1. Mark node visited.

2. For every neighbor:
      if neighbor is not visited:
          if DFS(neighbor, node) is true:
              return true

      else if neighbor != parent:
          return true

3. Return false
```

---

## Why Check Every Vertex?

The graph may be disconnected.

```text
(0) -- (1) -- (2)       (3) -- (4)
                           \   /
                            (5)
```

```text
Component 1: no cycle
Component 2: cycle 3 -> 4 -> 5 -> 3
```

DFS only from node `0` would miss the second component.

```text
Run DFS from every unvisited vertex.
```

---

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
    bool dfsDetectCycle(int node, int parent,
                        const vector<vector<int>>& adjacencyList,
                        vector<bool>& visited) {
        visited[node] = true;

        for (int neighbor : adjacencyList[node]) {
            if (!visited[neighbor]) {
                if (dfsDetectCycle(neighbor, node, adjacencyList, visited)) {
                    return true;
                }
            } else if (neighbor != parent) {
                // Visited node reached by an edge other than parent edge.
                return true;
            }
        }

        return false;
    }

public:
    bool isCycle(int vertices, const vector<vector<int>>& edges) {
        vector<vector<int>> adjacencyList(vertices);

        for (const vector<int>& edge : edges) {
            int u = edge[0];
            int v = edge[1];

            adjacencyList[u].push_back(v);
            adjacencyList[v].push_back(u);
        }

        vector<bool> visited(vertices, false);

        // Check every connected component.
        for (int node = 0; node < vertices; node++) {
            if (!visited[node] &&
                dfsDetectCycle(node, -1, adjacencyList, visited)) {
                return true;
            }
        }

        return false;
    }
};

int main() {
    Solution solution;

    // No cycle: 0 -- 1 -- 2 -- 3
    vector<vector<int>> noCycleEdges = {{0, 1}, {1, 2}, {2, 3}};
    cout << boolalpha << "No-cycle graph: "
         << solution.isCycle(4, noCycleEdges) << endl;

    // Cycle: 0 -- 1 -- 2 -- 0
    vector<vector<int>> cycleEdges = {{0, 1}, {1, 2}, {2, 0}};
    cout << "Cycle graph:    "
         << solution.isCycle(3, cycleEdges) << endl;

    // Disconnected graph; second component has cycle 3-4-5-3.
    vector<vector<int>> disconnectedEdges = {
        {0, 1}, {1, 2}, {3, 4}, {4, 5}, {5, 3}
    };
    cout << "Disconnected graph with cycle: "
         << solution.isCycle(6, disconnectedEdges) << endl;

    return 0;
}
```

**Output:**

```text
No-cycle graph: false
Cycle graph:    true
Disconnected graph with cycle: true
```

## DFS vs BFS Cycle Detection

| Feature | DFS | BFS |
|---|---|---|
| Main structure | Recursion / stack | Queue |
| Parent stored in | Function parameter | Queue pair `(node, parent)` |
| Cycle condition | Visited neighbor != parent | Visited neighbor != parent |
| Time | `O(V + E)` | `O(V + E)` |
| Risk | Deep graph can overflow recursion stack | No recursion-stack overflow |

Both use the same cycle rule.

---

## Edge Cases

### Single Vertex

```text
(0)

No edge -> no cycle
```

### One Edge

```text
(0) -- (1)

At 1, node 0 is parent.
No cycle.
```

### Self Loop

```text
(0) -- (0)
```

```text
At node 0, neighbor 0 is visited.
0 != parent -1.

Cycle found.
```

### Parallel Edges

```text
(0) ===== (1)
(0) ----- (1)
```

This guide assumes a simple graph, which is the common DSA version. If parallel edges are allowed, check the problem’s definition of a cycle in a multigraph.

---

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(V + E)` | Every vertex is visited; every edge is checked. |
| Extra space | `O(V)` | Visited array and DFS recursion stack. |
| Graph storage | `O(V + E)` | Adjacency list. |

In a linear graph:

```text
(0) -- (1) -- (2) -- ... -- (V-1)
```

DFS recursion depth can reach `V`.

## Interview Questions

### 1. What detects a cycle in undirected DFS?

```text
neighbor is visited AND neighbor != parent
```

### 2. Why do we need the parent parameter?
To avoid treating the edge back to the parent as a cycle.

### 3. Why use an outer loop?
To check every disconnected component.

### 4. Can BFS also detect undirected cycles?
Yes. It uses the same parent-check logic.

### 5. Does a self loop count as a cycle?
Yes.

### 6. What is the time complexity?
`O(V + E)`.

### 7. What is DFS extra-space complexity?
`O(V)` in the worst case.
