# Detect Cycle in an Undirected Graph (BFS)

> Return `true` if an undirected graph contains a cycle; otherwise return `false`.

A cycle is a path that starts and ends at the same vertex.

```text
0 -> 1 -> 2 -> 0
```

---

## Example 1 — No Cycle

```text
(0) -- (1) -- (2) -- (3)
```

```text
This is a simple path.
No cycle exists.

Answer = false (or 0)
```

---

## Example 2 — Cycle Exists

```text
       (0)
      /   \
     /     \
   (1) -- (2)
```

```text
Cycle: 0 -> 1 -> 2 -> 0

Answer = true (or 1)
```

---

## Main Idea 💡

While doing BFS, store:

```text
(current node, parent node)
```

If we see a visited neighbor that is **not** the parent, a cycle exists.

```text
visited neighbor AND neighbor != parent
-> cycle found
```

---

## Why Do We Need a Parent?

In an undirected graph, every edge appears in both directions.

```text
(0) -- (1)
```

Adjacency list:

```text
adj[0] = [1]
adj[1] = [0]
```

During BFS from `0`:

```text
Visit 0 -> push 1 with parent 0

At 1:
neighbor 0 is already visited
```

This is not a cycle. It is only the same edge used to reach node `1`.

```text
neighbor 0 == parent 0
-> skip
```

## No-Cycle BFS Trace

```text
(0) -- (1) -- (2) -- (3)
```

```text
Start:
queue = [(0, -1)]
visited = {0}
```

```text
Pop (0, -1):
neighbor 1 is unvisited
mark 1 visited
push (1, 0)
```

```text
Pop (1, 0):
neighbor 0 is visited, but 0 is parent -> skip
neighbor 2 is unvisited -> push (2, 1)
```

```text
Pop (2, 1):
neighbor 1 is visited, but 1 is parent -> skip
neighbor 3 is unvisited -> push (3, 2)
```

```text
Pop (3, 2):
neighbor 2 is visited, but 2 is parent -> skip

Queue empty.
No cycle found.
```

---

## Cycle BFS Trace

```text
       (0)
      /   \
     /     \
   (1) -- (2)
```

```text
Start:
queue = [(0, -1)]
visited = {0}
```

```text
Pop (0, -1):
neighbor 1 is unvisited -> push (1, 0)
neighbor 2 is unvisited -> push (2, 0)

queue = [(1, 0), (2, 0)]
```

```text
Pop (1, 0):
neighbor 0 is parent -> skip
neighbor 2 is already visited
neighbor 2 != parent 0

Cycle found! ✓
```

---

## Algorithm

```text
isCycle(graph):

1. visited[] = false

2. For every vertex:
      if vertex is not visited:
          run BFS from it

3. BFS(start):
      push (start, parent = -1)
      mark start visited

      while queue is not empty:
          pop (node, parent)

          for every neighbor:
              if neighbor is not visited:
                  mark neighbor visited
                  push (neighbor, node)

              else if neighbor != parent:
                  return true

4. Return false
```

---

## Why Check Every Vertex?

The graph may be disconnected.

```text
(0) -- (1) -- (2)       (3) -- (4)
                           \   /
                            (5)
```

```text
Component 1: no cycle
Component 2: cycle 3 -> 4 -> 5 -> 3
```

If BFS starts only at `0`, it misses the cycle in the second component.

```text
Start BFS from every unvisited vertex.
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
    bool bfsDetectCycle(int start, const vector<vector<int>>& adjacencyList,
                        vector<bool>& visited) {
        queue<pair<int, int>> q; // {node, parent}
        q.push({start, -1});
        visited[start] = true;

        while (!q.empty()) {
            auto [node, parent] = q.front();
            q.pop();

            for (int neighbor : adjacencyList[node]) {
                if (!visited[neighbor]) {
                    visited[neighbor] = true;
                    q.push({neighbor, node});
                } else if (neighbor != parent) {
                    // Visited neighbor reached through another path.
                    return true;
                }
            }
        }

        return false;
    }

public:
    bool isCycle(int vertices, const vector<vector<int>>& edges) {
        vector<vector<int>> adjacencyList(vertices);

        for (const vector<int>& edge : edges) {
            int u = edge[0];
            int v = edge[1];

            adjacencyList[u].push_back(v);
            adjacencyList[v].push_back(u);
        }

        vector<bool> visited(vertices, false);

        // Check every component.
        for (int node = 0; node < vertices; node++) {
            if (!visited[node] && bfsDetectCycle(node, adjacencyList, visited)) {
                return true;
            }
        }

        return false;
    }
};

int main() {
    Solution solution;

    // No cycle: 0 -- 1 -- 2 -- 3
    vector<vector<int>> noCycleEdges = {{0, 1}, {1, 2}, {2, 3}};
    cout << boolalpha << "No-cycle graph: "
         << solution.isCycle(4, noCycleEdges) << endl;

    // Cycle: 0 -- 1 -- 2 -- 0
    vector<vector<int>> cycleEdges = {{0, 1}, {1, 2}, {2, 0}};
    cout << "Cycle graph:    "
         << solution.isCycle(3, cycleEdges) << endl;

    // Disconnected graph; cycle exists in second component.
    vector<vector<int>> disconnectedEdges = {
        {0, 1}, {1, 2}, {3, 4}, {4, 5}, {5, 3}
    };
    cout << "Disconnected graph with cycle: "
         << solution.isCycle(6, disconnectedEdges) << endl;

    return 0;
}
```

**Output:**

```text
No-cycle graph: false
Cycle graph:    true
Disconnected graph with cycle: true
```

## Neighbor Decision Table

| Neighbor state | Is it the parent? | Action |
|---|---|---|
| Not visited | Not relevant | Mark visited and push into queue |
| Already visited | Yes | Skip; it is the edge we came from |
| Already visited | No | Cycle found |

---

## Edge Cases

### Single Node

```text
(0)

No edge -> no cycle
```

### One Edge

```text
(0) -- (1)

At 1, node 0 is parent.
No cycle.
```

### Self Loop

```text
(0) -- (0)
```

```text
At node 0, neighbor 0 is visited and is not parent -1.
Cycle found.
```

### Parallel Edges

```text
(0) ===== (1)
(0) ----- (1)
```

This guide assumes a simple graph, which is the common interview/DSA version. If parallel edges are allowed, clarify whether two parallel edges count as a cycle in that problem’s definition.

---

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(V + E)` | Every vertex is visited and every edge is inspected. |
| Extra space | `O(V)` | Visited array and queue. |
| Graph storage | `O(V + E)` | Adjacency list. |

For an undirected graph, each edge is stored twice, but Big-O remains `O(V + E)`.

---

## Interview Questions

### 1. Why do we store the parent in BFS?
To avoid treating the edge back to the parent as a cycle.

### 2. What condition detects a cycle?

```text
neighbor is visited AND neighbor != parent
```

### 3. Why do we loop through all vertices?
The graph may have multiple disconnected components.

### 4. Can the same logic be used with DFS?
Yes. DFS also tracks the parent and checks for a visited non-parent neighbor.

### 5. Does a self-loop count as a cycle?
Yes.

### 6. What is the time complexity?
`O(V + E)`.

### 7. What is the BFS extra-space complexity?
`O(V)`.
