# Find Eventual Safe States — DFS

> A node is **eventually safe** if every possible path starting from it ends at a terminal node.

```text
Terminal node = node with no outgoing edges
```

A node is unsafe if it is in a cycle or can reach a cycle.

---

## Example Graph

```text
(0) ---> (1) ---> (3)
 |         |        |
 |         |        |
 v         v        v
(2) ---> (5) ---> (6)

(4) ---------> (5)
```

Edges:

```text
0 -> [1, 2]
1 -> [2, 3]
2 -> [5]
3 -> [0]     <- cycle: 0 -> 1 -> 3 -> 0
4 -> [5]
5 -> [6]
6 -> []      <- terminal node
```

```text
Unsafe nodes: 0, 1, 3  (in cycle)
Safe nodes:   2, 4, 5, 6

Answer = [2, 4, 5, 6]
```

---

## What Makes a Node Safe? 💡

```text
Safe:
node -> terminal node
node -> safe node -> terminal node
```

```text
Unsafe:
node is in a cycle
node has a path that can enter a cycle
```

Example:

```text
(4) -> (5) -> (6)

6 is terminal -> safe
5 leads only to safe 6 -> safe
4 leads only to safe 5 -> safe
```

But:

```text
(7) -> (0) -> (1) -> (3) -> (0)

7 can reach a cycle -> unsafe
```

---

## Key Idea: DFS Path Tracking

Use three arrays:

```text
vis[node]
= node was visited before

pathVis[node]
= node is on the current DFS path

check[node]
= node is eventually safe (1 = safe, 0 = unsafe)
```

A cycle is found when DFS reaches a node already on the current path.

```text
vis[neighbor] = 1
AND
pathVis[neighbor] = 1

-> cycle found
```

---

## Important Difference

A previously visited node is not always a cycle.

```text
        (0)
       /   \
      v     v
     (1)   (2)
       \   /
        v v
        (3)
```

```text
Path 1: 0 -> 1 -> 3
Path 2: 0 -> 2 -> 3
```

When DFS from `2` sees `3`:

```text
vis[3] = true
pathVis[3] = false
```

Node `3` was finished earlier. It is not on the current path.

```text
No cycle
```

---

## DFS Rule

```text
DFS(node):

1. Mark node visited.
2. Mark node as part of current path.
3. Visit all outgoing neighbors.
4. If any neighbor is unsafe, current node is unsafe.
5. If all neighbors are safe, current node is safe.
6. Remove node from current path before returning.
```

---

## Safe / Unsafe Cases

For each neighbor:

| Neighbor condition | Meaning | Current node result |
|---|---|---|
| Not visited | DFS it first | Depends on DFS result |
| On current path | Cycle | Unsafe |
| Already known safe | Leads to terminal | Continue |
| Already known unsafe | Leads to cycle | Unsafe |

## Step-by-Step Trace

```text
Graph:

0 -> 1 -> 3
|    |    |
v    v    v
2 -> 5 -> 6

4 -> 5
```

### DFS from Node 0

```text
DFS(0):
path = [0]
```

```text
DFS(1):
path = [0, 1]
```

First, DFS explores node `2`:

```text
DFS(2):
path = [0, 1, 2]
```

```text
DFS(5):
path = [0, 1, 2, 5]
```

```text
DFS(6):
node 6 has no outgoing edge
check[6] = true
```

Backtrack:

```text
check[5] = true
check[2] = true
```

Now DFS from node `1` explores `3`:

```text
DFS(3):
path = [0, 1, 3]

neighbor 0:
vis[0] = true
pathVis[0] = true
```

```text
0 is on current path.
Cycle found: 0 -> 1 -> 3 -> 0
```

So:

```text
check[3] = false
check[1] = false  (leads to cycle)
check[0] = false  (leads to cycle)
```

### DFS from Node 4

```text
4 -> 5

check[5] = true
```

```text
check[4] = true
```

Final:

```text
safe = [false, false, true, false, true, true, true]

Safe nodes = [2, 4, 5, 6]
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
private:
    // Returns true if a cycle is found from this node.
    bool dfsCheck(int node, vector<int> adj[],
                  vector<int>& vis, vector<int>& pathVis,
                  vector<int>& check) {
        vis[node] = 1;
        pathVis[node] = 1;
        check[node] = 0; // Assume unsafe until DFS proves otherwise.

        for (auto it : adj[node]) {
            // Neighbor has not been visited yet.
            if (!vis[it]) {
                if (dfsCheck(it, adj, vis, pathVis, check) == true) {
                    check[node] = 0;
                    return true;
                }
            }
            // Neighbor was visited and is on the current DFS path.
            else if (pathVis[it]) {
                check[node] = 0;
                return true;
            }
        }

        // No cycle was found from this node.
        check[node] = 1;
        pathVis[node] = 0; // Backtrack: remove from current path.
        return false;
    }

public:
    vector<int> eventualSafeNodes(int V, vector<int> adj[]) {
        vector<int> vis(V, 0);
        vector<int> pathVis(V, 0);
        vector<int> check(V, 0);
        vector<int> safeNodes;

        for (int i = 0; i < V; i++) {
            if (!vis[i]) {
                dfsCheck(i, adj, vis, pathVis, check);
            }
        }

        // Nodes marked 1 in check[] are eventually safe.
        for (int i = 0; i < V; i++) {
            if (check[i] == 1) {
                safeNodes.push_back(i);
            }
        }

        return safeNodes;
    }
};

void printVector(const vector<int>& values) {
    cout << "[";
    for (int i = 0; i < values.size(); i++) {
        cout << values[i];
        if (i + 1 < values.size()) cout << ", ";
    }
    cout << "]\n";
}

int main() {
    const int V = 7;
    vector<int> adj[V];

    // 0->1, 0->2, 1->2, 1->3, 2->5, 3->0, 4->5, 5->6
    adj[0] = {1, 2};
    adj[1] = {2, 3};
    adj[2] = {5};
    adj[3] = {0};
    adj[4] = {5};
    adj[5] = {6};
    adj[6] = {};

    Solution solution;
    vector<int> safeNodes = solution.eventualSafeNodes(V, adj);

    cout << "Eventual safe nodes: ";
    printVector(safeNodes);

    return 0;
}
```

**Output:**

```text
Eventual safe nodes: [2, 4, 5, 6]
```

## Why Are Nodes Leading to a Cycle Unsafe?

```text
(7) -> (0) -> (1) -> (3)
                    ^      |
                    |______|
```

Node `7` is not inside the cycle, but it can enter the cycle.

```text
There is a path from 7 that never reaches a terminal node.
So 7 is unsafe.
```

---

## Edge Cases

### No Edges

```text
0    1    2    3
```

Every node is terminal.

```text
Safe nodes = [0, 1, 2, 3]
```

### All Nodes in One Cycle

```text
(0) -> (1) -> (2)
 ^                 |
 |_________________|
```

```text
Safe nodes = []
```

### Node Leads to Safe Node

```text
(4) -> (5) -> (6)
```

```text
6 is terminal -> safe
5 leads to safe 6 -> safe
4 leads to safe 5 -> safe
```

### Node Leads to Cycle

```text
(4) -> (0) -> (1) -> (0)
```

```text
4 is unsafe because it can reach the cycle.
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(V + E)` | Each vertex and directed edge is processed once. |
| Extra space | `O(V)` | Three tracking arrays and DFS recursion stack. |
| Graph storage | `O(V + E)` | Directed adjacency list. |

## Interview Questions

### 1. What is an eventual safe node?
A node where every possible path ends at a terminal node or another safe node.

### 2. Are nodes inside a cycle safe?
No. They can keep moving around the cycle forever.

### 3. Are nodes leading to a cycle safe?
No. At least one path can enter the cycle and never terminate.

### 4. Why use `pathVis[]`?
It identifies nodes on the current DFS path, which detects directed cycles.

### 5. Why do we reset `pathVis[node]` on return?
The node is no longer on the active DFS path after backtracking.

### 6. What is the time complexity?
`O(V + E)`.

### 7. Can this problem be solved with BFS?
Yes. Reverse all edges and use topological sorting from terminal nodes.
