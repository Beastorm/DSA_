# Detect Cycle in a Directed Graph (DFS)

> Return `true` if a directed graph contains a cycle; otherwise return `false`.

A directed cycle follows edge directions and returns to the starting vertex.

```text
8 -> 9 -> 10
^           |
|___________|
```

---

## Example 1 — Cycle Exists

```text
       (8) -----> (9) -----> (10)
        ^                       |
        |_______________________|

Cycle: 8 -> 9 -> 10 -> 8
```

```text
Answer = true
```

---

## Example 2 — No Cycle

```text
(1) -> (2) -> (3)
                |
          +-----+-----+
          v           v
         (4)         (7)
          |           |
          v           v
         (5) <-------+
          |
          v
         (6)
```

Several paths can reach the same node without creating a cycle.

```text
Answer = false
```

---

## Why the Undirected-Graph Method Fails 💡

For undirected graphs, we use:

```text
visited neighbor AND neighbor != parent -> cycle
```

This does not work for directed graphs.

```text
        (0)
       /   \
      v     v
     (1)   (2)
       \   /
        v v
        (3)
```

Both `1` and `2` point to `3`.

```text
0 -> 1 -> 3
0 -> 2 -> 3
```

When DFS reaches `3` through `2`, node `3` may already be visited from path `0 -> 1 -> 3`.

```text
Already visited does NOT automatically mean cycle.
```

Node `3` is not on the current path anymore if DFS already finished it.

---

## Key Idea: Track the Current DFS Path

Use two arrays:

```text
visited[node] = node was visited at least once
pathVisited[node] = node is on the current DFS path
```

A directed cycle exists only when DFS reaches a node already on the current path.

```text
visited[neighbor] == true
AND
pathVisited[neighbor] == true

-> back edge -> cycle
```

---

## The Three Neighbor Cases

| Neighbor state | `visited` | `pathVisited` | Action |
|---|---:|---:|---|
| Not visited | 0 | 0 | Run DFS on neighbor |
| On current DFS path | 1 | 1 | Cycle found |
| Finished earlier path | 1 | 0 | Safe, skip |

---

## DFS Algorithm

```text
DFS(node):

1. visited[node] = true
2. pathVisited[node] = true

3. For every directed neighbor:
      if neighbor is not visited:
          if DFS(neighbor) finds cycle:
              return true

      else if pathVisited[neighbor] is true:
          return true

4. pathVisited[node] = false
   return false
```

The last step is backtracking:

```text
pathVisited[node] = false
```

It means this node is no longer on the active DFS path.

---

## Cycle Trace: `8 -> 9 -> 10 -> 8`

```text
DFS(8):
visited[8] = true
pathVisited[8] = true
```

```text
DFS(9):
visited[9] = true
pathVisited[9] = true
```

```text
DFS(10):
visited[10] = true
pathVisited[10] = true

neighbor 8:
visited[8] = true
pathVisited[8] = true

8 is already on current path -> cycle found ✓
```

## No-Cycle Trace: Two Paths Reach Same Node

```text
        (0)
       /   \
      v     v
     (1)   (2)
       \   /
        v v
        (3)
```

```text
DFS path 1:
0 -> 1 -> 3

Finish node 3:
pathVisited[3] = false
```

Later:

```text
DFS path 2:
0 -> 2 -> 3

visited[3] = true
pathVisited[3] = false

This is safe.
Node 3 belongs to a previous completed path, not current path.
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
    bool dfsCheck(int node, const vector<vector<int>>& adjacencyList,
                  vector<bool>& visited, vector<bool>& pathVisited) {
        visited[node] = true;
        pathVisited[node] = true;

        for (int neighbor : adjacencyList[node]) {
            if (!visited[neighbor]) {
                if (dfsCheck(neighbor, adjacencyList, visited, pathVisited)) {
                    return true;
                }
            } else if (pathVisited[neighbor]) {
                // Neighbor is part of the active DFS path.
                return true;
            }
        }

        // Backtrack: remove node from current DFS path.
        pathVisited[node] = false;
        return false;
    }

public:
    bool isCyclic(int vertices, const vector<vector<int>>& edges) {
        vector<vector<int>> adjacencyList(vertices);

        for (const vector<int>& edge : edges) {
            int from = edge[0];
            int to = edge[1];
            adjacencyList[from].push_back(to);
        }

        vector<bool> visited(vertices, false);
        vector<bool> pathVisited(vertices, false);

        // Check every disconnected component.
        for (int node = 0; node < vertices; node++) {
            if (!visited[node] &&
                dfsCheck(node, adjacencyList, visited, pathVisited)) {
                return true;
            }
        }

        return false;
    }
};

int main() {
    Solution solution;

    // Cycle: 8 -> 9 -> 10 -> 8
    vector<vector<int>> cycleEdges = {
        {1, 2}, {2, 3}, {3, 4}, {3, 7}, {4, 5}, {5, 6}, {7, 5},
        {8, 9}, {9, 10}, {10, 8}
    };
    cout << boolalpha << "Cycle graph: "
         << solution.isCyclic(11, cycleEdges) << endl;

    // DAG: 0 -> 1 -> 3 and 0 -> 2 -> 3
    vector<vector<int>> noCycleEdges = {
        {0, 1}, {0, 2}, {1, 3}, {2, 3}
    };
    cout << "No-cycle graph: "
         << solution.isCyclic(4, noCycleEdges) << endl;

    return 0;
}
```

**Output:**

```text
Cycle graph: true
No-cycle graph: false
```

---

## Why Check Every Vertex?

The directed graph may be disconnected.

```text
(0) -> (1) -> (2)       (3) -> (4) -> (5)
                              ^           |
                              |___________|
```

```text
Component 1 has no cycle.
Component 2 has a cycle.
```

DFS from only node `0` would miss the cycle.

```text
Run DFS from every unvisited vertex.
```

---

## Directed vs. Undirected Cycle Detection

| Undirected graph | Directed graph |
|---|---|
| Track parent | Track active DFS path |
| Cycle if visited neighbor is not parent | Cycle if neighbor is on current path |
| `visited + parent` | `visited + pathVisited` |

```text
Undirected: visiting parent again is normal.
Directed: visiting a completed node is normal.
Directed cycle: reach a node still active in current DFS path.
```

---

## Edge Cases

### Self Loop

```text
(0) -> (0)
```

```text
DFS(0):
pathVisited[0] = true
neighbor 0 is on current path

Cycle found.
```

### No Edges

```text
(0)      (1)      (2)
```

No DFS call finds a back edge.

```text
Answer = false
```

### Linear Directed Chain

```text
(0) -> (1) -> (2) -> (3)
```

No edge points back to an active node.

```text
Answer = false
```

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(V + E)` | Every vertex and directed edge is processed once. |
| Extra space | `O(V)` | Two visited arrays and recursion stack. |
| Graph storage | `O(V + E)` | Directed adjacency list. |

## Interview Questions

### 1. What detects a cycle in directed DFS?

```text
visited[neighbor] AND pathVisited[neighbor]
```

### 2. Why is `visited[]` alone not enough?
A node can be visited through a different completed path without forming a cycle.

### 3. Why reset `pathVisited[node]` during backtracking?
The node is no longer on the active DFS path.

### 4. What is a back edge?
A directed edge from the current node to an ancestor currently in the DFS path.

### 5. Can BFS detect cycles in directed graphs?
Yes. Kahn's topological-sort algorithm uses indegrees to detect cycles.

### 6. What is the time complexity?
`O(V + E)`.

### 7. What is the recursion-stack complexity?
`O(V)` in the worst case.
