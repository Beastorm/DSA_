# Bipartite Graph | DFS Implementation

**Problem Statement:**   
Given an adjacency list of a graph with `V` vertices (0-based index), check whether the graph is **bipartite** or not.

A graph is bipartite if we can color all vertices using **2 colors** such that **no two adjacent vertices have the same color**.

---

## What Does Bipartite Mean? 💡

Split vertices into two groups.

```text
Group A: vertices with color 0
Group B: vertices with color 1
```

Every edge must go from one group to the other.

```text
       color 0              color 1

          (0) -------------- (1)
           |                  |
           |                  |
          (3) -------------- (2)

Group A = {0, 2}
Group B = {1, 3}
```

No edge exists inside one group.

---

## Example 1 — Bipartite Graph

```text
       (0) ------ (1)
        |          |
        |          |
       (3) ------ (2)
```

Color nodes:

```text
0 -> color 0
1 -> color 1
2 -> color 0
3 -> color 1
```

```text
Every edge connects different colors.
Answer = true
```

---

## Example 2 — Not Bipartite

```text
       (0)
      /   \
     /     \
   (1) -- (2)
```

Try coloring:

```text
0 -> color 0
1 -> color 1
2 -> color 0
```

But edge `(2,0)` connects:

```text
color 0 <-> color 0
```

```text
Conflict -> not bipartite
```

---

## Important Property

```text
Bipartite graph <=> no odd-length cycle
```

```text
Even cycle:                     Odd cycle:

(0) -- (1)                     (0) -- (1)
 |      |                       \      /
 |      |                        \    /
(3) -- (2)                      (2)

4 edges -> bipartite            3 edges -> not bipartite
```

---

## DFS Coloring Rule

```text
Start node -> color 0

For every neighbor:
    if neighbor is uncolored:
        give it opposite color

    if neighbor has same color as current node:
        graph is not bipartite
```

```text
opposite color = 1 - currentColor
```

```text
If current color is 0 -> neighbor color is 1
If current color is 1 -> neighbor color is 0
```

---

## Algorithm

```text
color[] = -1 for every vertex

For every vertex:
    if vertex is uncolored:
        if DFS(vertex, color 0) fails:
            return false

return true
```

```text
DFS(node, color):

1. color[node] = color
2. For every neighbor:
      if neighbor is uncolored:
          DFS(neighbor, 1 - color)
      else if neighbor color == color:
          return false
3. Return true
```

## DFS Trace — Triangle Graph

```text
       (0)
      /   \
     /     \
   (1) -- (2)
```

```text
DFS(0, color 0)
 |
 +-- DFS(1, color 1)
      |
      +-- DFS(2, color 0)
           |
           +-- neighbor 0 already has color 0
           +-- current node 2 also has color 0
           +-- conflict found!
```

```text
Answer = false
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
    bool dfs(int node, int currentColor,
             const vector<vector<int>>& adjacencyList,
             vector<int>& color) {
        color[node] = currentColor;

        for (int neighbor : adjacencyList[node]) {
            if (color[neighbor] == -1) {
                // Give uncolored neighbor the opposite color.
                if (!dfs(neighbor, 1 - currentColor, adjacencyList, color)) {
                    return false;
                }
            } else if (color[neighbor] == currentColor) {
                // Adjacent nodes cannot have the same color.
                return false;
            }
        }

        return true;
    }

public:
    bool isBipartite(int vertices, const vector<vector<int>>& edges) {
        vector<vector<int>> adjacencyList(vertices);

        for (const vector<int>& edge : edges) {
            int u = edge[0];
            int v = edge[1];

            adjacencyList[u].push_back(v);
            adjacencyList[v].push_back(u);
        }

        vector<int> color(vertices, -1);

        // Check every disconnected component.
        for (int node = 0; node < vertices; node++) {
            if (color[node] == -1 &&
                !dfs(node, 0, adjacencyList, color)) {
                return false;
            }
        }

        return true;
    }
};

int main() {
    Solution solution;

    // Square: 0-1-2-3-0 -> bipartite.
    vector<vector<int>> squareEdges = {
        {0, 1}, {1, 2}, {2, 3}, {3, 0}
    };
    cout << boolalpha << "Square graph: "
         << solution.isBipartite(4, squareEdges) << endl;

    // Triangle: 0-1-2-0 -> not bipartite.
    vector<vector<int>> triangleEdges = {
        {0, 1}, {1, 2}, {2, 0}
    };
    cout << "Triangle graph: "
         << solution.isBipartite(3, triangleEdges) << endl;

    // Disconnected graph; second component is a triangle.
    vector<vector<int>> disconnectedEdges = {
        {0, 1}, {2, 3}, {3, 4}, {4, 2}
    };
    cout << "Disconnected graph: "
         << solution.isBipartite(5, disconnectedEdges) << endl;

    return 0;
}
```

**Output:**

```text
Square graph: true
Triangle graph: false
Disconnected graph: false
```

## Why Check Every Vertex?

The graph may be disconnected.

```text
(0) -- (1)       (2) -- (3)
                    \    /
                     (4)
```

```text
Component 1 is bipartite.
Component 2 has an odd cycle.

Whole graph is not bipartite.
```

Every component must be bipartite.

---

## DFS vs BFS

Both DFS and BFS use the same coloring rule.

| Feature | DFS | BFS |
|---|---|---|
| Main structure | Recursion / stack | Queue |
| Coloring | During recursive call | During queue insertion |
| Conflict | Neighbor has same color | Neighbor has same color |
| Time | `O(V + E)` | `O(V + E)` |

---

## Edge Cases

### Single Node

```text
(0)

No edges -> bipartite
```

### One Edge

```text
(0) -- (1)

0 -> color 0
1 -> color 1

Bipartite
```

### Self Loop

```text
(0) -- (0)
```

```text
Node 0 is adjacent to itself.
It must have both same and different color.

Not bipartite.
```

### Disconnected Graph

```text
(0) -- (1)       (2) -- (3)
```

Check both components.

---

## Complexity

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(V + E)` | Visit every vertex and inspect every edge. |
| Extra space | `O(V)` | Color array and DFS recursion stack. |
| Graph storage | `O(V + E)` | Adjacency list. |

## Interview Questions

### 1. What is a bipartite graph?
A graph that can be colored with two colors such that adjacent vertices have different colors.

### 2. What is the relation between bipartite graphs and odd cycles?
A graph is bipartite if and only if it has no odd-length cycle.

### 3. Why use `1 - color`?
It changes `0` to `1` and `1` to `0`.

### 4. Why use color `-1` initially?
It means the vertex has not been colored or visited yet.

### 5. Why check every vertex?
The graph may be disconnected.

### 6. Can BFS solve the same problem?
Yes. BFS uses the same two-color rule.

### 7. What is the time complexity?
`O(V + E)`.
