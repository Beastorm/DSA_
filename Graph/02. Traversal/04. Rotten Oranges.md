# Rotten Oranges — Minimum Time to Rot All Oranges

> In a grid:
>
> ```text
> 2 = rotten orange
> 1 = fresh orange
> 0 = empty cell
> ```
>
> Every minute, a rotten orange makes its fresh 4-directional neighbors rotten. Find the minimum minutes needed to rot all fresh oranges, or return `-1` if impossible.

---

## Why This Is Multi-Source BFS 💡

All initially rotten oranges spread at the **same time**.

```text
Time 0: all starting rotten oranges
Time 1: all fresh neighbors of Time 0 oranges
Time 2: all fresh neighbors of Time 1 oranges
...
```

So put **every initially rotten orange** into the queue before BFS starts.

```text
BFS level = one minute of rotting
```

---

## Four Directions

```text
          up
           |
left -- current -- right
           |
         down
```

```text
up:    (-1, 0)
right: ( 0, 1)
down:  ( 1, 0)
left:  ( 0,-1)
```

Diagonal oranges do not affect each other.

## Example 1 — Impossible Case

```text
Grid:

        c0  c1  c2
      +---+---+---+
r0    | 2 | 1 | 1 |
      +---+---+---+
r1    | 0 | 1 | 1 |
      +---+---+---+
r2    | 1 | 0 | 1 |
      +---+---+---+
```

The fresh orange at `(2,0)` cannot be reached.

```text
(2,0) is blocked by:

up    -> 0
right -> 0
left  -> outside grid
down  -> outside grid
```

```text
Answer = -1
```

## Main Algorithm

```text
1. Scan the grid.
      - Push every rotten orange into a queue.
      - Count fresh oranges.

2. While queue is not empty AND fresh oranges remain:
      - Process every orange currently in queue.
      - Each processed queue level represents one minute.
      - Turn all adjacent fresh oranges rotten.
      - Decrease fresh count.

3. If fresh count is 0, return minutes.
   Otherwise return -1.
```

## Why BFS and Not DFS?

Oranges spread in all directions at the same time.

```text
BFS:
Processes all oranges at distance 1,
then all oranges at distance 2,
and so on.

This exactly matches minutes passing.
```

```text
DFS:
Would go deep along one path first.
It does not naturally represent simultaneous spreading.
```

## C++ Code — Complete Program

```cpp
#include <bits/stdc++.h>
using namespace std;

int orangesRotting(vector<vector<int>> grid) {
    if (grid.empty() || grid[0].empty()) return 0;

    int rows = grid.size();
    int cols = grid[0].size();
    queue<pair<int, int>> q;
    int freshOranges = 0;

    // Add all starting rotten oranges to the queue.
    for (int row = 0; row < rows; row++) {
        for (int col = 0; col < cols; col++) {
            if (grid[row][col] == 2) {
                q.push({row, col});
            } else if (grid[row][col] == 1) {
                freshOranges++;
            }
        }
    }

    int rowChange[] = {-1, 0, 1, 0};
    int colChange[] = {0, 1, 0, -1};
    int minutes = 0;

    // Each BFS level takes one minute.
    while (!q.empty() && freshOranges > 0) {
        int levelSize = q.size();

        for (int i = 0; i < levelSize; i++) {
            auto [row, col] = q.front();
            q.pop();

            for (int direction = 0; direction < 4; direction++) {
                int nextRow = row + rowChange[direction];
                int nextCol = col + colChange[direction];

                if (nextRow >= 0 && nextRow < rows &&
                    nextCol >= 0 && nextCol < cols &&
                    grid[nextRow][nextCol] == 1) {

                    grid[nextRow][nextCol] = 2;
                    freshOranges--;
                    q.push({nextRow, nextCol});
                }
            }
        }

        minutes++;
    }

    return (freshOranges == 0) ? minutes : -1;
}

int main() {
    vector<vector<int>> grid1 = {
        {2, 1, 1},
        {1, 1, 0},
        {0, 1, 1}
    };

    vector<vector<int>> grid2 = {
        {2, 1, 1},
        {0, 1, 1},
        {1, 0, 1}
    };

    vector<vector<int>> grid3 = {{2, 2, 0}};

    cout << "Example 1: " << orangesRotting(grid1) << endl;
    cout << "Example 2: " << orangesRotting(grid2) << endl;
    cout << "Example 3: " << orangesRotting(grid3) << endl;

    return 0;
}
```

**Output:**

```text
Example 1: 4
Example 2: -1
Example 3: 0
```

## Edge Cases

### No Fresh Oranges

```text
Grid = [2, 2, 0]

All oranges are already rotten.
Answer = 0
```

### No Rotten Oranges

```text
Grid = [1, 1, 0]

No orange can start the spread.
Answer = -1
```

### All Cells Are Empty

```text
Grid = [0, 0, 0]

No fresh oranges exist.
Answer = 0
```

### One Fresh Orange

```text
Grid = [1]

No rotten neighbor exists.
Answer = -1
```

## Complexity

Let grid size be `R x C`.

| Resource | Complexity | Reason |
|---|---:|---|
| Time | `O(R * C)` | Every cell enters queue at most once. |
| Extra space | `O(R * C)` | Queue can hold many oranges. |

Each cell checks only 4 directions, which is constant work.

## Interview Questions

### 1. Why is this called multi-source BFS?
All initially rotten oranges are inserted into the queue before BFS begins.

### 2. What does one BFS level represent?
One minute of simultaneous rotting.

### 3. Why count fresh oranges?
After BFS, a positive fresh count means some orange could not be reached.

### 4. Why mark a fresh orange rotten before pushing it?
It prevents the same orange from being pushed into the queue multiple times.

### 5. When do we return `-1`?
When fresh oranges remain after BFS ends.

### 6. What is the time complexity?
`O(R * C)`.

### 7. What is the space complexity?
`O(R * C)` in the worst case.
